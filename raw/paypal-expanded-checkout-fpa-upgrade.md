# Upgrading to FPA

This flow applies to existingmerchants looking to upgrade from the [Fraud Protection](https://developer.paypal.com/docs/checkout/advanced/customize/fraud-protection/) (FP) tool to the Fraud Protection Advanced (FPA) tool. Your merchants should use the following steps:

- Go to **Account settings** → **Payment preferences** → **Manage fraud** . Select **Change fraud tool** .
![Change fraud tool screen](assets/Change_fraud_tool.png)

- Ensure you select **Fraud Protection Advanced** from the options provided based on your business characteristics. Select **Next** to go to the Fraud Protection Advanced tool and begin customizing your fraud tool.
![Select FPA tool screen](assets/protect_FPATool.png)

- Confirm your details to set up automatic bank payments for your fraud tool, and select **Next** .
![Set up auto debit screen](assets/Activate_Dir_Mer_Set_Up_auto_debit.png)

- When you select **Let's Go** , you'll see the FPA dashboard, where you can start customizing your fraud tool.
![FPA activation end screen](assets/Activate_DirMer_EndOfFlow_.png)


## Next steps 

### Create and set up filters
Use filters to decide whether FPA approves, rejects, or puts a transaction into a review queue.


### Manage lists
Use the lists feature to manage information and work with their rules
to help prevent fraud.


### Review transactions
Review transactions that are flagged for review.


### Monitor FPA activity
You can track which users made changes and when these changes occurred.
