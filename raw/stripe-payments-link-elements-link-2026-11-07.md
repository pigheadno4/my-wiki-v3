# Link with Web Elements

Embed Link into your custom payment page for faster checkout.

Use [Link](https://docs.stripe.com/payments/link.md) with Stripe’s [Web Elements](https://docs.stripe.com/payments/elements.md) to add one-click checkout to your custom payment page. Customers new to Link can save their payment details and shipping information to enable faster checkout in the future.

For information about how your payment integration affects Link, see [Link in different payment integrations](https://docs.stripe.com/payments/link/link-payment-integrations.md).

[Link in the Payment Element (Recommended)](https://docs.stripe.com/payments/link/payment-element-link.md): Trigger Link in the Payment Element whenever a customer selects a supported payment method.

[Link in the Express Checkout Element (Recommended)](https://docs.stripe.com/payments/link/express-checkout-element-link.md): Display Link alongside Apple Pay, Google Pay, and PayPal using the Express Checkout Element.

[Explore the Contact Details Element](https://docs.stripe.com/payments/link/contact-details-element.md): Use the Contact Details Element to create an email input field that authenticates Link customers.

[Link in the Payment Request Button (Deprecated)](https://docs.stripe.com/payments/link/payment-request-button-link.md): The Payment Request Button is deprecated. If you have existing Link integrations, [migrate them to the Express Checkout Element](https://docs.stripe.com/elements/express-checkout-element/migration.md).

[Link in the Card Element](https://docs.stripe.com/payments/link/card-element-link.md): Save and autofill your customer’s payment information by using Link in the Card Element.
