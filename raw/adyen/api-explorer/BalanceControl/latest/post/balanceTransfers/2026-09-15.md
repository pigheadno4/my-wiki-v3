# POST /balanceTransfers - Performs a balance transfer

Performs a balance transfer between merchant accounts. The following conditions must be met before you can successfully transfer balances:

- The source and destination merchant accounts must be under the same company account and legal entity.

- The source merchant account must have sufficient funds.

The source and destination merchant accounts must have at least one common processing currency.\n\n
When sending multiple API requests with the same source and destination merchant accounts, send the requests sequentially and *not* in parallel. Some requests may not be processed if the requests are sent in parallel.

## Servers

**Test Environment**
- https://balance-control-test.adyen.com/balance-control/api/v2

**Live Environment**
- https://balance-control-live.adyen.com/balance-control/api/v2

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| amount | object | Yes | The amount of the transfer. |
|   - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes) of the amount. |
|   - value | integer | Yes | The numeric value of the amount, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
| fromMerchant | string | Yes | The unique identifier of the source merchant account from which funds are deducted. |
| reference | string | No | A reference for the balance transfer. Maximum length: 80 characters. |
| toMerchant | string | Yes | The unique identifier of the destination merchant account to which funds are transferred. |
| type | string | Yes | The type of balance transfer. Possible values: **tax**, **fee**, **terminalSale**, **credit**, **debit**, and **adjustment**. |

## Request examples

### Create balance transfer
```json
{
  "amount": {
    "currency": "EUR",
    "value": 3000
  },
  "fromMerchant": "SOURCE_MERCHANT_ACCOUNT",
  "reference": "Your reference for the balance transfer.",
  "toMerchant": "DESTINATION_MERCHANT_ACCOUNT",
  "type": "adjustment"
}
```
