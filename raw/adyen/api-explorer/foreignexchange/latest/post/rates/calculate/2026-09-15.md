# POST /rates/calculate - Calculate amount in a different currency

Returns the calculated amounts and rates required to convert the currency of a transaction.

## Servers

**Test Environment**
- https://balanceplatform-api-test.adyen.com/fx/api/v1

**Live Environment**
- https://balanceplatform-api-live.adyen.com/fx/api/v1

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| exchangeCalculations | array of object | Yes | An array of objects, where each object defines a currency and value for which you want to perform an exchange calculation. |
|   - exchangeSide | string | Yes | The operation performed on the source amount. Possible values:  - **buy**  - **sell** |
|   - sourceAmount | object | Yes | An object specifying the currency and value for which you want to perform an exchange calculation. |
|     - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes). |
|     - value | integer | Yes | The amount of the transaction, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
|   - targetCurrency | string | Yes | The currency to which you want to convert the source amount. |
|   - type | string | Yes | The type of transaction. Possible values:  - **splitPayment**: for payments  - **splitRefund**: for refunds |

## Request examples

### calculate
```json
{
  "exchangeCalculations": [
    {
      "type": "splitPayment",
      "sourceAmount": {
        "currency": "CZK",
        "value": 112300
      },
      "targetCurrency": "EUR",
      "exchangeSide": "buy"
    },
    {
      "type": "splitRefund",
      "sourceAmount": {
        "currency": "CZK",
        "value": 24000
      },
      "targetCurrency": "USD",
      "exchangeSide": "sell"
    }
  ]
}
```
## Responses

### 200 Success
Successful operation

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| exchangeCalculations | array of object | No | An array of objects, where each object returns a currency and value for which you performed an exchange calculation. You can use the calculated amounts in your payment requests. |
|   - appliedExchangeRate | number | No | The exchange rate to convert the source currency to the target currency. This includes Adyen's markup. |
|   - exchangeSide | string | No | The operation performed on the source amount. Possible values:  - **buy**  - **sell** |
|   - sourceAmount | object | No | The currency of the amount you converted (the source amount). |
|     - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes). |
|     - value | integer | Yes | The amount of the transaction, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
|   - targetAmount | object | No | An object specifying the currency and value to which you want to convert the source amount (the target amount). |
|     - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes). |
|     - value | integer | Yes | The amount of the transaction, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
|   - type | string | No | The type of transaction. Possible values:  - **splitPayment**: for payments  - **splitRefund**: for refunds |
