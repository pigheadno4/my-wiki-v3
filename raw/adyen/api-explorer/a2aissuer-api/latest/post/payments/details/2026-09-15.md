# POST /payments/details - Retrieve payment details

Returns the details of an open payment, which you must show to the user. Also provides a token required to [confirm](https://docs.adyen.com/api-explorer/a2a-payments/latest/post/payments/confirm) or [cancel](https://docs.adyen.com/api-explorer/a2a-payments/latest/post/payments/cancel) the payment.

## Servers

**Test Environment**
- https://balanceplatform-api-test.adyen.com/a2aissuer-api/v1

**Live Environment**
- https://balanceplatform-api-live.adyen.com/a2aissuer-api/v1

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| method | string | Yes | The payment method for the transaction. |
| payload | string | Yes | An identifier for the payment, generated by the payment method, such as iDEAL. This is obtained from the specified `source`. |
| source | string | Yes | The source used to obtain the payload. Possible values: `qr`, `redirect`, and `pushNotification`. |

## Request examples

### Retrieve payment details request - iDEAL
```json
{
  "method": "ideal",
  "source": "redirect",
  "payload": "https://ext.tx.ideal.nl/2/AXE4R72TLPRCRN6Y4FDZX7MZHJQ?sig=BGBCQEIIA2F3CF7KR2SVLSJEDUJABL62V7TI4Y2LJPJIJBZEP6HXCHXPQCLTAEIB2FNUD3COVRNIT27TT7NFKYD5UJCUY4NMPS4NUCTKA6KIBHSRXWI"
}
```
## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| details | object | Yes | The details of the payment. You must show your user these details before they confirm or cancel the payment. |
|   - amount | object | Yes | The amount of the payment. |
|     - currency | string | Yes | The three-character [ISO 4217 currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes). |
|     - value | integer | Yes | The amount of the transaction in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units) (cents). |
|   - counterparty | object | Yes | Contains information about the party that receives the payment funds. |
|     - accountHolder | object | Yes | Contains the full name of the person or entity that receives the payment funds). |
|     - accountIdentification | object | Yes | Contains the account number to which the payment funds are sent. |
|   - description | string | Yes | The description for the payment. It is generated by the payment method, such as iDEAL, and should be shown to the user. |
|   - expiresAt | string | Yes | The expiration date of the payment in ISO DateTime format, as described on ISO 20022 (YYYY-MM-DDThh:mm:ss.sss+/-hh:mm).  Example: **2025-12-30T14:15:30+01:00** |
| token | string | Yes | The token that identifies the payment. It is generated by Adyen and is needed to confirm or cancel the payment. |
