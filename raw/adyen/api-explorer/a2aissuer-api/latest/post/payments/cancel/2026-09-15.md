# POST /payments/cancel - Cancel payment

Cancels the payment. Returns a URL for user redirection.

## Servers

**Test Environment**
- https://balanceplatform-api-test.adyen.com/a2aissuer-api/v1

**Live Environment**
- https://balanceplatform-api-live.adyen.com/a2aissuer-api/v1

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| token | string | Yes | The payment token is an identifier for the payment. It is generated by Adyen on the response of the payment details. |

## Request examples

### Cancel payment request.
```json
{
  "token": "TOKEN_PLACEHOLDER"
}
```
## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| links | object | Yes | Contains redirection URLs to guide the user to the appropriate page, after a successful payment or a cancellation. |
|   - cancel | object | No | The URL to where the user must be redirected after a payment has been canceled. |
|     - href | string | Yes | The full URL for the redirection. |
|   - success | object | No | The URL to where the user must be redirected after a successful payment. |
|     - href | string | Yes | The full URL for the redirection. |
