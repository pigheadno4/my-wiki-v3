# POST /ideal/profile/register - Register an iDEAL profile

Register a new iDEAL profile. The profile is linked to the account holder and payment instruments included in the request. The user must be redirected to the URL in the response to finish their IDEAL profile registration.

## Servers

**Test Environment**
- https://balanceplatform-api-test.adyen.com/a2aissuer-api/v1

**Live Environment**
- https://balanceplatform-api-live.adyen.com/a2aissuer-api/v1

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| accountHolderId | string | Yes | The unique identifier of the account holder. |
| paymentInstrumentIds | array of string | Yes | The unique identifiers of the payment instruments to be associated with the iDEAL profile. |

## Request examples

### Register iDEAL profile request
```json
{
  "accountHolderId": "AH00000000000000000000000",
  "paymentInstrumentIds": [
    "PI00000000000000000000000",
    "PI11111111111111111111111"
  ]
}
```
