# POST /ideal/profile/authenticate - Authenticate iDEAL profile

Generates an redirection URL to finish the authentication flow when requested by iDEAL. Before calling this endpoint, make sure that your user has completed multi-factor authentication.

## Servers

**Test Environment**
- https://balanceplatform-api-test.adyen.com/a2aissuer-api/v1

**Live Environment**
- https://balanceplatform-api-live.adyen.com/a2aissuer-api/v1

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| accountHolderId | string | Yes | The unique identifier for an account holder. |
| payload | string | Yes | A payload provided by iDEAL to complete the authentication process. |

## Request examples

### Authenticate iDEAL profile request
```json
{
  "accountHolderId": "AH00000000000000000000000",
  "payload": "https://ideal.auth/somePayload"
}
```

| Name | Type | Required | Description |
|------|------|----------|-------------|
| redirectUrl | object | No | A short-lived URL that redirects the user to the iDEAL page that is required for authentication. |
|   - href | string | Yes | The full URL for the redirection. |
