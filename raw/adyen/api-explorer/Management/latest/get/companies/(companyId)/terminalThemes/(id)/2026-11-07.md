# GET /companies/{companyId}/terminalThemes/{id} - Get a terminal theme

Returns the details of the terminal theme specified in the path. The response includes the metadata of the theme and the content delivery network (CDN) URLs for all assets that have been added to the theme.
The URL for the logo of the theme will lead to the Adyen logo if the theme is not associated with the permission to customize terminal logos.

To make this request, your API credential must have the following [role](https://docs.adyen.com/development-resources/api-credentials#manage-api-permissions):

- Management API - Terminal themes read and write

## Servers
- https://management-test.adyen.com/v3

## Parameters

### Path parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| id | string | Yes | The unique identifier of the terminal theme. |
| companyId | string | Yes | The unique identifier of the company account. |

## Responses

### 200 Success
OK

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| assets | array of object | Yes | The list of assets that have been added to the theme, including the CDN URLs of the assets. |
|   - model | string | Yes | The terminal model that the asset is for. Must be one of the supported terminal models. |
|   - type | string | Yes | The screen type that the asset is for. Possible values: **logo**, **homeScreen**, **idleScreen**, **afterPaymentScreen**, **shopperEngagementScreen**. |
|   - url | string | Yes | The CDN URL for this asset, including the token as a query parameter (?token=). This URL is valid for 24 hours. |
| id | string | Yes | The unique identifier of the theme. |
| mode | string | Yes | The terminal display mode. Possible values: **dark**, **light**. |
| name | string | Yes | The name of the theme. |
