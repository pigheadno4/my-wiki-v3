# GET /companies/{companyId}/androidApps - Get a list of Android apps

Returns a list of the Android apps that are available for the company identified in the path.
These apps have been uploaded to Adyen and can be installed or uninstalled on Android payment terminals through [terminal actions](https://docs.adyen.com/point-of-sale/automating-terminal-management/terminal-actions-api).

To make this request, your API credential must have one of the following [roles](https://docs.adyen.com/development-resources/api-credentials#api-permissions):

- Management API—Android files read

- Management API—Android files read and write

- Management API—Terminal actions read

- Management API—Terminal actions read and write

In the live environment, requests to this endpoint are subject to [rate limits](https://docs.adyen.com/point-of-sale/automating-terminal-management#rate-limits-in-the-live-environment).

## Servers
- https://management-test.adyen.com/v3

## Parameters

### Path parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| companyId | string | Yes | The unique identifier of the company account. |


### Query parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| versionCode | integer | No | The version number of the app. |
| packageName | string | No | The package name that uniquely identifies the Android app. |
| pageSize | integer | No | The number of items to have on a page, maximum 100. The default is 20 items on a page. |
| pageNumber | integer | No | The number of the page to fetch. |

## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| data | array of object | No | Apps uploaded for Android payment terminals. |
|   - description | string | No | The description that was provided when uploading the app. The description is not shown on the terminal. |
|   - errorCode | string | No | The error code of the Android app with the `status` of either **error** or **invalid**. |
|   - errors | array of object | No | The list of errors of the Android app. |
|     - errorCode | string | No | The error code of the Android app with the `status` of either **error** or **invalid**. |
|     - terminalModels | array of string | No | The list of payment terminal models to which the returned `errorCode` applies. |
|   - id | string | Yes | The unique identifier of the app. |
|   - label | string | No | The app name that is shown on the terminal. |
|   - packageName | string | No | The package name that uniquely identifies the Android app. |
|   - status | string | Yes | The status of the app. Possible values:  - `processing`: the app is being signed and converted to a format that the terminal can handle.  - `error`: something went wrong. Check that the app matches the [requirements](https://docs.adyen.com/point-of-sale/android-terminals/app-requirements).  - `invalid`: there is something wrong with the APK file of the app.  - `ready`: the app has been signed and converted.  - `archived`: the app is no longer available. |
|   - versionCode | integer | No | The version number of the app. |
|   - versionName | string | No | The app version number that is shown on the terminal. |
