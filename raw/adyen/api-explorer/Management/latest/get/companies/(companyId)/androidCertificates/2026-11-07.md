# GET /companies/{companyId}/androidCertificates - Get a list of Android certificates

Returns a list of the Android certificates that are available for the company identified in the path.
Typically, these certificates enable running apps on Android payment terminals. The certificates in the list have been uploaded to Adyen and can be installed or uninstalled on Android terminals through [terminal actions](https://docs.adyen.com/point-of-sale/automating-terminal-management/terminal-actions-api).

To make this request, your API credential must have one of the following [roles](https://docs.adyen.com/development-resources/api-credentials#api-permissions):

- Management API—Android files read

- Management API—Android files read and write

- Management API—Terminal actions read

- Management API—Terminal actions read and write

In the live environment, requests to this endpoint are subject to [rate limits](https://docs.adyen.com/point-of-sale/automating-terminal-management#rate-limits-in-the-live-environment).

## Servers
- https://management-test.adyen.com/v3

## Parameters

### Path parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| companyId | string | Yes | The unique identifier of the company account. |


### Query parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| certificateName | string | No | The name of the certificate. |
| pageSize | integer | No | The number of items to have on a page, maximum 100. The default is 20 items on a page. |
| pageNumber | integer | No | The number of the page to fetch. |

## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| data | array of object | No | Uploaded Android certificates for Android payment terminals. |
|   - description | string | No | The description that was provided when uploading the certificate. |
|   - extension | string | No | The file format of the certificate, as indicated by the file extension. For example, **.cert** or **.pem**. |
|   - id | string | Yes | The unique identifier of the certificate. |
|   - name | string | No | The file name of the certificate. For example, **mycert**. |
|   - notAfter | string | No | The date when the certificate stops to be valid. |
|   - notBefore | string | No | The date when the certificate starts to be valid. |
|   - status | string | No | The status of the certificate. |
