# GET /companies/{companyId}/terminalProducts - Get a list of terminal products

Returns a country-specific list of payment terminal packages and parts that the company identified in the path has access to.

To make this request, your API credential must have one of the following [roles](https://docs.adyen.com/development-resources/api-credentials#api-permissions):

- Management API—Terminal ordering read

- Management API—Terminal ordering read and write

In the live environment, requests to this endpoint are subject to [rate limits](https://docs.adyen.com/point-of-sale/automating-terminal-management#rate-limits-in-the-live-environment).

## Servers
- https://management-test.adyen.com/v3

## Parameters

### Path parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| companyId | string | Yes | The unique identifier of the company account. |


### Query parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| limit | integer | No | The number of products to return. |
| offset | integer | No | The number of products to skip. |
| terminalModelId | string | No | The terminal model to return products for. Use the ID returned in the [GET `/terminalModels`](https://docs.adyen.com/api-explorer/#/ManagementService/latest/get/companies/%7BcompanyId%7D/terminalModels) response. For example, **Verifone.M400** |
| country | string | Yes | The country to return products for, in [ISO 3166-1 alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2) format. For example, **US** |

## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| data | array of object | No | Terminal products that can be ordered. |
|   - description | string | No | Information about items included and integration options. |
|   - id | string | No | The unique identifier of the product. |
|   - itemsIncluded | array of string | No | A list of parts included in the terminal package. |
|   - name | string | No | The descriptive name of the product. |
|   - price | object | No | The price of the product. |
|     - currency | string | No | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes). |
|     - value | number | No | The price of the item. |
