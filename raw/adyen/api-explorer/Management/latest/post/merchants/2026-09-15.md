# POST /merchants - Create a merchant account

Creates a merchant account for the company account specified in the request.

Use this endpoint if your integration requires it, such as Adyen for Platforms Manage. Your Adyen contact will set up your access.

To make this request, your API credential must have the following [roles](https://docs.adyen.com/development-resources/api-credentials#api-permissions):

- Management API—Accounts read and write

## Servers
- https://management-test.adyen.com/v3

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| businessLineId | string | No | The unique identifier of the [business line](https://docs.adyen.com/api-explorer/#/legalentity/latest/post/businessLines). Required for an Adyen for Platforms Manage integration. |
| companyId | string | Yes | The unique identifier of the company account. |
| description | string | No | Your description for the merchant account, maximum 300 characters. |
| legalEntityId | string | No | The unique identifier of the [legal entity](https://docs.adyen.com/api-explorer/#/legalentity/latest/post/legalEntities). Required for an Adyen for Platforms Manage integration. |
| pricingPlan | string | No | Sets the pricing plan for the merchant account. Required for an Adyen for Platforms Manage integration. Your Adyen contact will provide the values that you can use. |
| reference | string | No | Your reference for the merchant account. To make this reference the unique identifier of the merchant account, your Adyen contact can set up a template on your company account. The template can have 6 to 255 characters with upper- and lower-case letters, underscores, and numbers. When your company account has a template, then the `reference` is required and must be unique within the company account. |
| salesChannels | array of string | No | List of sales channels that the merchant will process payments with |

## Request examples

### post-merchants
```json
{
  "companyId": "YOUR_COMPANY_ACCOUNT",
  "legalEntityId": "YOUR_LEGAL_ENTITY_ID",
  "businessLineId": "YOUR_BUSINESS_LINE_ID",
  "description": "YOUR_DESCRIPTION",
  "reference": "YOUR_OWN_REFERENCE"
}
```

The request has succeeded.

**Response body**

|------|------|----------|-------------|

| description | string | No | Your description for the merchant account, maximum 300 characters. |
| id | string | No | The unique identifier of the merchant account. If Adyen set up a template for the `reference`, then the `id` will have the same value as the `reference` that you sent in the request. Otherwise, the value is generated by Adyen. |

| pricingPlan | string | No | Partner pricing plan for the merchant, applicable for merchants under AfP managed company accounts. |
| reference | string | No | Your reference for the merchant account. |
