# POST /crossBorderInvoices - Upload a document

Uploads a document for a merchant account.

## Servers

**Test Environment**
- https://document-collector-test.adyen.com/v1

**Live Environment**
- https://document-collector-live.adyen.com/v1

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| context | string | Yes | The document context indicating the type of document being uploaded. Possible values: **paCbInvoice**. |
| file | string | Yes | The PDF file to upload. Filename must be {pspReference}.pdf |
| merchantAccount | string | Yes | The merchant account that the document belongs to. |

## Request examples

### upload-document
```json
{
  "file": "(binary PDF named {pspReference}.pdf)",
  "context": "paCbInvoice",
  "merchantAccount": "YourMerchantAccount"
}
```
