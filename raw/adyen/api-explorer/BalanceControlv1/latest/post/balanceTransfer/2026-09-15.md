# POST /balanceTransfer - Start a balance transfer

Starts a balance transfer request between merchant accounts. The following conditions must be met before you can successfully transfer balances:

The source and destination merchant accounts must be under the same company account and legal entity.

The source merchant account must have sufficient funds.

The source and destination merchant accounts must have at least one common processing currency.

When sending multiple API requests with the same source and destination merchant accounts, send the requests sequentially and *not* in parallel. Some requests may not be processed if the requests are sent in parallel.

## Servers
- https://pal-test.adyen.com/pal/servlet/BalanceControl/v1

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| amount | object | Yes | The amount of the transfer in [minor units](https://docs.adyen.com/development-resources/currency-codes). |
|   - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes) of the amount. |
|   - value | integer | Yes | The numeric value of the amount, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
| description | string | No | A human-readable description for the transfer. You can use alphanumeric characters and hyphens. We recommend sending a maximum of 140 characters, otherwise the description may be truncated. |
| fromMerchant | string | Yes | The unique identifier of the source merchant account from which funds are deducted. |
| reference | string | No | A reference for the balance transfer. If you don't provide this in the request, Adyen generates a unique reference. Maximum length: 80 characters. |
| toMerchant | string | Yes | The unique identifier of the destination merchant account from which funds are transferred. |
| type | string | Yes | The type of balance transfer. Possible values: **tax**, **fee**, **terminalSale**, **credit**, **debit**, and **adjustment**. |

## Request examples

### post-balance-transfer
```json
{
  "amount": {
    "value": 50000,
    "currency": "EUR"
  },
  "description": "Your description for the transfer",
  "fromMerchant": "MerchantAccount_NL",
  "toMerchant": "MerchantAccount_DE",
  "type": "debit"
}
```
## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| amount | object | Yes | The amount of the transfer in [minor units](https://docs.adyen.com/development-resources/currency-codes). |
|   - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes) of the amount. |
|   - value | integer | Yes | The numeric value of the amount, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
| createdAt | string | Yes | The date when the balance transfer was requested. |
| description | string | No | A human-readable description for the transfer. You can use alphanumeric characters and hyphens. We recommend sending a maximum of 140 characters, otherwise the description may be truncated. |
| fromMerchant | string | Yes | The unique identifier of the source merchant account from which funds are deducted. |
| pspReference | string | Yes | Adyen's 16-character string reference associated with the balance transfer. |
| reference | string | No | A reference for the balance transfer. If you don't provide this in the request, Adyen generates a unique reference. Maximum length: 80 characters. |
| status | string | Yes | The status of the balance transfer. Possible values: **transferred**, **failed**, **error**, and **notEnoughBalance**. |
| toMerchant | string | Yes | The unique identifier of the destination merchant account from which funds are transferred. |
| type | string | Yes | The type of balance transfer. Possible values: **tax**, **fee**, **terminalSale**, **credit**, **debit**, and **adjustment**. |
