# POST forwardApi.notification - Forward API request completed

Adyen forwarded a payment request to the third-party service on your behalf.

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| createdAt | string | Yes | The date and time when the webhook was created. |
| data | object | No | The details of the Forward API request. |
|   - amountCurrency | string | No | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes). |
|   - amountValue | integer | No | The amount of the transaction, in [minor units](https://docs.adyen.com/development-resources/currency-codes). |
|   - eventDateTime | string | Yes | The transaction date and time. |
|   - externalNetworkTxReferenceFound | boolean | No | Indicates if the `networkTxReferencePaths` matched a reference in the third-party response. |
|   - externalNetworkTxReferenceRequested | boolean | No | Indicates if a `networkTxReferencePaths` value was provided in the request. |
|   - externalPartyResponseBody | string | No | The raw response body returned by the third-party service. |
|   - externalPsp | string | Yes | The third-party service that processed the payment request. |
|   - externalPspTransactionStatus | string | No | The transaction status returned by the third-party service. |
|   - externalTransactionLinkIdFound | boolean | No | Indicates if the `transactionLinkIdPaths` matched a reference in the third-party response. |
|   - externalTransactionLinkIdRequested | boolean | No | Indicates if a `transactionLinkIdPaths` value was provided in the request. |
|   - merchantAccountCode | string | Yes | The merchant account that is used to process the payment. |
|   - merchantCountryCode | string | Yes | The country of the merchant account. |
|   - merchantReference | string | Yes | Your reference to uniquely identify the payment. |
|   - pspReference | string | Yes | Adyen's 16-character reference associated with the request. This value is globally unique, so you can use it as the reference when you communicate with us about this request. |
|   - scheme | string | Yes | The card network used for the transaction. For example, **visa** or **mc**. |
|   - shopperReference | string | Yes | Your reference to uniquely identify this shopper, for example user ID or account ID. |
|   - storedPaymentMethodId | string | Yes | The unique identifier of the token. |
| environment | string | No | The environment from which the webhook originated.  Possible values: **test**, **live**. |
| type | string | Yes | The type of notification. |
| version | string | No | The version of this webhook type. |

## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| notificationResponse | string | No | Respond with any **2xx** HTTP status code to [accept the webhook](https://docs.adyen.com/development-resources/webhooks/#accept-webhooks). |
