# POST balancePlatform.balanceAccountPayoutScheduleExecution.failed - Payout schedule execution failed

Adyen sends this webhook when a scheduled payout execution fails.

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| data | object | Yes | Contains event details. |
|   - balanceAccountId | string | No | The unique identifier of the balance account from which the payout is initiated. |
|   - balanceAccountPayoutScheduleId | string | No | The unique identifier of the managed payout schedule. |
|   - balancePlatform | string | No | The unique identifier of the balance platform. |
|   - result | string | No | The result of the execution. |
|   - resultDetails | object | No | Contains details of the execution result. |
|     - reason | string | No | The reason why the execution was not successful. |
|     - reasonCode | string | No | The numeric code of the reason. |
|     - transferId | string | No | The unique identifier of the transfer created for this execution. |
|   - triggeredAt | string | No | The timestamp of the moment when the execution was triggered. |
| environment | string | Yes | The environment from which the webhook originated.  Possible values: **test**, **live**. |
| timestamp | string | No | When the event was queued. |
| type | string | Yes | Type of webhook. |

## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| notificationResponse | string | No | Respond with any **2xx** HTTP status code to [accept the webhook](https://docs.adyen.com/development-resources/webhooks/#accept-webhooks). |
