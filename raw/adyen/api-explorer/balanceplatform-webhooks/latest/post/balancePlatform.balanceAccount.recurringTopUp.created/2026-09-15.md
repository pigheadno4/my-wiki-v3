# POST balancePlatform.balanceAccount.recurringTopUp.created - Recurring top-up created

Adyen sends this webhook when a [recurring top-up](https://docs.adyen.com/api-explorer/balanceplatform/latest/post/balanceAccounts/_balanceAccountId_/recurringTopUps) is successfully created for a balance account.

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| data | object | Yes | Contains event details. |
|   - accountId | string | Yes | The unique identifier of the balance account for which the recurring top-up is configured. |
|   - balancePlatform | string | No | The unique identifier of the balance platform. |
|   - creationDate | string | No | The date and time when the event was triggered, in ISO 8601 extended format. For example, **2025-03-19T10:15:30+01:00**. |
|   - id | string | No | The ID of the resource. |
|   - webhookTopUpConfiguration | object | Yes | The recurring top-up configuration details. |
|     - counterparty | object | Yes | The source of the funds. |
|     - description | string | Yes | The message that is used in the top-up transfer's description body with a maximum length of 140 characters.  If the message is longer after replacing placeholders, the message is cut off at 140 characters. |
|     - id | string | Yes | The unique identifier of the recurring top-up configuration. |
|     - mandate | object | No | The mandate associated with the recurring top-up. |
|     - referenceForBeneficiary | string | No | A reference that is sent to the recipient. This reference is also sent in all webhooks related to the transfer, so you can use it to track statuses for both parties involved in the funds movement.  Supported characters: **a-z**, **A-Z**, **0-9**. |
|     - status | string | Yes | The status of the top-up configuration.  Possible values:  **active**: the top-up is enabled and funds are pulled in.  **inactive**: the top-up is disabled and cannot be triggered. |
|     - topUpAmount | object | Yes | The amount of the top-up. This can be a fixed amount or a target amount. |
|     - trigger | object | Yes | The condition that triggers the top-up. This can be a recurring schedule or a minimum balance threshold. |
| environment | string | Yes | The environment from which the webhook originated.  Possible values: **test**, **live**. |
| timestamp | string | No | When the event was queued. |
| type | string | Yes | Type of webhook. |
