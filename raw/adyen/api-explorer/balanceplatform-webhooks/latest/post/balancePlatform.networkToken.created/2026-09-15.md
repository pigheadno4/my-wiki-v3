# POST balancePlatform.networkToken.created - Network token created

Adyen sends this webhook when you initiate a request for provisioning a network token.

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| data | object | Yes | Contains event details. |
|   - authentication | object | No | Contains information about the authentication process triggered during token provisioning. |
|     - method | string | No | The method used to complete the authentication process.  Possible values: **sms_OTP**, **email_OTP**. |
|     - result | string | No | The result of the authentication process. |
|   - authenticationApplied | boolean | No | Specifies whether the authentication process was triggered during token provisioning. |
|   - balancePlatform | string | No | The unique identifier of the balance platform. |
|   - decision | string | No | The decision about the network token provisioning.  Possible values: **approved**, **declined**, **requiresAuthentication**. |
|   - id | string | No | The unique identifier of the network token. |
|   - paymentInstrumentId | string | No | The unique identifier of the payment instrument to which the network token is associated. |
|   - schemeRiskScore | string | No | The confidence score of scheme, indicating the degree of risk associated with a token.  A high score indicates a high level of risk. A low score indicates a low level of risk.  Possible values for visa : **00** to **99**, a value of 00 signifies no score was provided by visa |
|   - status | string | No | The status of the network token. |
|   - tokenLastFour | string | No | The last four digits of the network token. Use this value to help your user to identify their network token. |
|   - tokenRequestor | object | No | Contains information about the entity or organization that is requesting the network token. |
|     - id | string | No | The unique identifier of the network token requestor. |
|     - name | string | No | The name of the network token requestor. |
|   - transactionRulesResult | object | No | Contains the results of the evaluation of the transaction rules that apply to network token creation. |
|     - advice | string | No | The advice given by the Risk analysis. |
|     - allHardBlockRulesPassed | boolean | No | Indicates whether the transaction passed all rules with `outcomeType` **hardBlock**. |
|     - score | integer | No | The score of the Risk analysis. |
|     - triggeredTransactionRules | array of object | No | Contains a list of all triggered transaction rules and the corresponding data. |
|   - type | string | No | The type of network token.  Possible values: **wallet**, **cof**. |
|   - validationFacts | array of object | No | The rules used to validate the request for provisioning the network token. |
|     - reasons | array of string | No | The reason for the `result` of the validations.  This field is only sent for `validationFacts.type` **walletValidation**, when `validationFacts.result` is **invalid**. |
|     - result | string | No | The evaluation result of the validation facts.  Possible values: **valid**, **invalid**, **notValidated**, **notApplicable**. |
|     - type | string | No | The type of the validation fact. |
|   - wallet | object | No | Contains information about the wallet for which the network token is provisioned.  Returned only when `type` is **wallet**. |
|     - accountScore | string | No | The confidence score of the wallet account, calculated by the wallet provider.  A high score means that account is considered trustworthy. A low score means that the account is considered suspicious.  Possible values: **1** to **5**. |
|     - device | object | No | Contains information about the device used for provisioning the network token. |
|     - deviceScore | string | No | The confidence score of the device, calculated by the wallet provider.  A high score means that device is considered trustworthy. A low score means that the device is considered suspicious.  Possible values: **1** to **5**. |
|     - provisioningMethod | string | No | The method used for provisioning the network token.  Possible values: **push**, **manual**, **cof**, **unknown**. |
|     - recommendationReasons | array of string | No | A list of risk indicators triggered at the time of provisioning the network token.  Some example values of risk indicators are:  - **accountTooNewSinceLaunch**  - **tooManyRecentAttempts**  - **lowDeviceScore**  - **lowAccountScore** |
|     - type | string | No | The type of wallet that the network token is associated with.  Possible values: **applePay**, **googlePay**, **garminPay**. |
| environment | string | Yes | The environment from which the webhook originated.  Possible values: **test**, **live**. |
| timestamp | string | No | When the event was queued. |
| type | string | Yes | The type of webhook. |

## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| notificationResponse | string | No | Respond with any **2xx** HTTP status code to [accept the webhook](https://docs.adyen.com/development-resources/webhooks/#accept-webhooks). |
