# POST balancePlatform.score.triggered - Score signal triggered

For merchants who opt in to the Score product, Adyen sends this webhook when a score signal is triggered against an account holder.

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| data | object | Yes | Contains event details. |
|   - accountHolder | object | No | Contains information about the account holder. |
|     - description | string | No | The description of the resource. |
|     - id | string | No | The unique identifier of the resource. |
|     - reference | string | No | The reference for the resource. |
|   - accountHolderStatus | string | No | The status of the account holder. |
|   - automatedActions | array of string | No | The automated action(s) taken as a result of the score signals that were triggered. |
|   - balancePlatform | string | No | The unique identifier of the balance platform. |
|   - creationDate | string | No | The date and time when the event was triggered, in ISO 8601 extended format. For example, **2025-03-19T10:15:30+01:00**. |
|   - id | string | No | The ID of the resource. |
|   - riskScore | integer | No | The score of the identity resulting from the signal(s) that were triggered. |
|   - scoreSignalsTriggered | array of string | No | The name(s) of the score signals that were triggered. |
|   - signalSourceTypes | array of string | No | The type(s) of the score signals that were triggered. |
| environment | string | Yes | The environment from which the webhook originated.  Possible values: **test**, **live**. |
| timestamp | string | No | When the event was queued. |
| type | string | Yes | Type of webhook. |

The request has succeeded.

**Response body**

|------|------|----------|-------------|
