# POST /getTerminalsUnderAccount - Get the list of terminals

Returns a list of payment terminals associated with a company account, merchant account, or store. The response shows whether the terminals are in the inventory, or in-store (ready for boarding or already boarded).

From January 1, 2025 POS Terminal Management API is deprecated and support stops on April 1, 2025. To automate the management of your terminal fleet, use our [Management API](https://docs.adyen.com/api-explorer/Management/latest/overview).

## Servers
- https://postfmapi-test.adyen.com/postfmapi/terminal/v1

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| companyAccount | string | Yes | Your company account. If you only specify this parameter, the response includes all terminals at all account levels. |
| merchantAccount | string | No | The merchant account. This is required if you are retrieving the terminals assigned to a store.If you don't specify a `store` the response includes the terminals assigned to the specified merchant account and the terminals assigned to the stores under this merchant account. |
| store | string | No | The store code of the store. With this parameter, the response only includes the terminals assigned to the specified store. |

## Request examples

### getTerminalsCompany
```json
{
  "companyAccount": "YOUR_COMPANY_ACCOUNT"
}
```

### getTerminalsMerchant
```json
{
  "companyAccount": "YOUR_COMPANY_ACCOUNT",
  "merchantAccount": "YOUR_MERCHANT_ACCOUNT"
}
```

### getTerminalsStore
```json
{
  "companyAccount": "YOUR_COMPANY_ACCOUNT",
  "merchantAccount": "YOUR_MERCHANT_ACCOUNT",
  "store": "YOUR_STORE"
}
```
## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| companyAccount | string | Yes | Your company account. |
| inventoryTerminals | array of string | No | Array that returns a list of all terminals that are in the inventory of the company account. |
| merchantAccounts | array of object | No | Array that returns a list of all merchant accounts belonging to the company account. |
|   - inStoreTerminals | array of string | No | List of terminals assigned to this merchant account as in-store terminals. This means that the terminal is ready to be boarded, or is already boarded. |
|   - inventoryTerminals | array of string | No | List of terminals assigned to the inventory of this merchant account. |
|   - merchantAccount | string | Yes | The merchant account. |
|   - stores | array of object | No | Array of stores under this merchant account. |
|     - address | object | No | The address of the store. |
|     - description | string | No | The description of the store. |
|     - inStoreTerminals | array of string | No | The list of terminals assigned to the store. |
|     - merchantAccountCode | string | No | The code of the merchant account. |
|     - status | string | No | The status of the store:  `PreActive`: the store has been created, but not yet activated.  `Active`: the store has been activated. This means you can process payments for this store.  `Inactive`: the store is currently not active.  `InactiveWithModifications`: the store is currently not active, but payment modifications such as refunds are possible.  `Closed`: the store has been closed. |
|     - store | string | Yes | The code of the store. |
