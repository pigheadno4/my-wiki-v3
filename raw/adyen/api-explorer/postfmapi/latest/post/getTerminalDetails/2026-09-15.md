# POST /getTerminalDetails - Get the details of a terminal

Returns the details of a payment terminal, including where the terminal is assigned to. The response returns the same details that are provided in the terminal list in your Customer Area and in the Terminal Fleet report.

From January 1, 2025 POS Terminal Management API is deprecated and support stops on April 1, 2025. To automate the management of your terminal fleet, use our [Management API](https://docs.adyen.com/api-explorer/Management/latest/overview).

## Servers
- https://postfmapi-test.adyen.com/postfmapi/terminal/v1

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| terminal | string | Yes | The unique terminal ID in the format `[Device model]-[Serial number]`.  For example, **V400m-324689776**. |

## Request examples

### getTerminalDetails
```json
{
  "terminal": "M400-401972715"
}
```
## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| bluetoothIp | string | No | The Bluetooth IP address of the terminal. |
| bluetoothMac | string | No | The Bluetooth MAC address of the terminal. |
| companyAccount | string | Yes | The company account that the terminal is associated with. If this is the only account level shown in the response, the terminal is assigned to the inventory of the company account. |
| country | string | No | The country where the terminal is used. |
| deviceModel | string | No | The model name of the terminal. |
| dhcpEnabled | boolean | No | Indicates whether assigning IP addresses through a DHCP server is enabled on the terminal. |
| displayLabel | string | No | The label shown on the status bar of the display. This label (if any) is specified in your Customer Area. |
| ethernetIp | string | No | The terminal's IP address in your Ethernet network. |
| ethernetMac | string | No | The terminal's MAC address in your Ethernet network. |
| firmwareVersion | string | No | The software release currently in use on the terminal. |
| iccid | string | No | The integrated circuit card identifier (ICCID) of the SIM card in the terminal. |
| lastActivityDateTime | string | No | Date and time of the last activity on the terminal. Not included when the last activity was more than 14 days ago. |
| lastTransactionDateTime | string | No | Date and time of the last transaction on the terminal. Not included when the last transaction was more than 14 days ago. |
| linkNegotiation | string | No | The Ethernet link negotiation that the terminal uses:  `auto`: Auto-negotiation  `100full`: 100 Mbps full duplex |
| merchantAccount | string | No | The merchant account that the terminal is associated with. If the response doesn't contain a `store` the terminal is assigned to this merchant account. |
| merchantInventory | boolean | No | Boolean that indicates if the terminal is assigned to the merchant inventory. This is returned when the terminal is assigned to a merchant account.  If **true**, this indicates that the terminal is in the merchant inventory. This also means that the terminal cannot be boarded.  If **false**, this indicates that the terminal is assigned to the merchant account as an in-store terminal. This means that the terminal is ready to be boarded, or is already boarded. |
| permanentTerminalId | string | No | The permanent terminal ID. |
| serialNumber | string | No | The serial number of the terminal. |
| simStatus | string | No | On a terminal that supports 3G or 4G connectivity, indicates the status of the SIM card in the terminal: ACTIVE or INVENTORY. |
| store | string | No | The store code of the store that the terminal is assigned to. |
| storeDetails | object | No | The store that the terminal is assigned to. |
|   - address | object | No | The address of the store. |
|     - city | string | No |  |
|     - countryCode | string | No |  |
|     - postalCode | string | No |  |
|     - stateOrProvince | string | No |  |
|     - streetAddress | string | No |  |
|     - streetAddress2 | string | No |  |
|   - description | string | No | The description of the store. |
|   - inStoreTerminals | array of string | No | The list of terminals assigned to the store. |
|   - merchantAccountCode | string | No | The code of the merchant account. |
|   - status | string | No | The status of the store:  `PreActive`: the store has been created, but not yet activated.  `Active`: the store has been activated. This means you can process payments for this store.  `Inactive`: the store is currently not active.  `InactiveWithModifications`: the store is currently not active, but payment modifications such as refunds are possible.  `Closed`: the store has been closed. |
|   - store | string | Yes | The code of the store. |
| terminal | string | Yes | The unique terminal ID. |
| terminalStatus | string | No | The status of the terminal:  `OnlineToday`, `OnlineLast1Day`, `OnlineLast2Days` etcetera to `OnlineLast7Days`: Indicates when in the past week the terminal was last online.  `SwitchedOff`: Indicates it was more than a week ago that the terminal was last online.  `ReAssignToInventoryPending`, `ReAssignToStorePending`, `ReAssignToMerchantInventoryPending`: Indicates the terminal is scheduled to be reassigned. |
| wifiIp | string | No | The terminal's IP address in your Wi-Fi network. |
| wifiMac | string | No | The terminal's MAC address in your Wi-Fi network. |
