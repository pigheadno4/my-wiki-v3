# Payments App API v1

Board and manage the Adyen Payments App on your Android mobile devices.

Authentication

Each request to the Payments App API must be signed with an API key. [Generate your API key](https://docs.adyen.com/development-resources/api-credentials#generate-api-key) in the Customer Area and then set this key to the `X-API-Key` header value.

Versioning

Payments App API handles versioning as part of the endpoint URL. For example, to send a request to this version of the `/merchants/{merchantId}/generatePaymentsAppBoardingToken` endpoint, use:

https://management-test.adyen.com/v1/merchants/{merchantId}/generatePaymentsAppBoardingToken

Going live

To access the live endpoints, you need an API key from your live Customer Area. Use this API key to make requests to:

https://management-live.adyen.com/v{version}

## Servers

**Live Environment**
- https://management-live.adyen.com/v1

**Test Environment**
- https://management-test.adyen.com/v1

## Endpoints

### General
| Method | Path | Summary |
|--------|------|---------|
| POST | /merchants/{merchantId}/generatePaymentsAppBoardingToken | Create a boarding token - merchant level |
| POST | /merchants/{merchantId}/stores/{storeId}/generatePaymentsAppBoardingToken | Create a boarding token - store level |
| GET | /merchants/{merchantId}/paymentsApps | Get a list of Payments Apps - merchant level |
| GET | /merchants/{merchantId}/stores/{storeId}/paymentsApps | Get a list of Payments Apps - store level |
| POST | /merchants/{merchantId}/paymentsApps/{installationId}/revoke | Revoke Payments App instance authentication |
