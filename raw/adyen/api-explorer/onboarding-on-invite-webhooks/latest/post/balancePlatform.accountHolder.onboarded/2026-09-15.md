# POST balancePlatform.accountHolder.onboarded - Account holder onboarded

Adyen sends this webhook when a new account holder has been onboarded to your balance platform.

The webhook payload contains information about resources created by Adyen for the specified account holder. You can use these resource references and IDs when processing payments or making payouts to your users.

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| data | object | Yes | Contains event details. |
|   - accountHolder | object | No | The unique identifier of the account holder that has been onboarded. |
|     - description | string | No | Your description of the account holder. |
|     - id | string | No | The unique identifier of the account holder. |
|     - reference | string | No | Your reference for the account holder. |
|     - timezone | string | No | The time zone of the account holder. For example, **Europe/Amsterdam**.  Defaults to the time zone of the balance platform if no time zone is set. For possible values, see the [list of time zone codes](https://en.wikipedia.org/wiki/List_of_tz_database_time_zones). |
|   - balanceAccount | object | No | The primary balance account of the account holder. |
|     - defaultCurrencyCode | string | No | The default three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes) of the balance account. For example, **EUR**. |
|     - description | string | No | Your description of the balance account. |
|     - id | string | No | The unique identifier of the balance account. |
|     - reference | string | No | Your reference for the balance account. |
|   - balancePlatform | string | No | The unique identifier of the balance platform. |
|   - capabilities | object (object) | No | Contains key-value pairs that specify the actions that the account holder can do in your platform. The key is a [capability](https://docs.adyen.com/platforms/verification-overview/capabilities/) required for your integration. For example, **receivePayments**. The value is an object containing the settings for the capability. |
|     - allowed | boolean | No | Indicates whether the account holder is permitted to use the capability. |
|     - enabled | boolean | No | Indicates whether the capability is enabled. |
|     - requested | boolean | No | Indicates whether the capability is requested. |
|     - verificationStatus | string | No | The status of the verification process for the capability. |
|   - creationDate | string | No | The date and time when the event was triggered, in ISO 8601 extended format. For example, **2025-03-19T10:15:30+01:00**. |
|   - legalEntityId | string | No | The unique identifier of the legal entity associated with the account holder. |
|   - merchantId | string | No | The unique identifier of the merchant account. |
|   - stores | array of object | No | The list of stores for the account holder. |
|     - balanceAccountId | string | No | The unique identifier of the balance account that the store is associated with. |
|     - businessLineId | string | No | The unique identifier of the business line that the store is associated with. |
|     - description | string | No | Your description of the store. |
|     - id | string | No | The unique identifier of the store. |
|     - paymentMethods | array of object | No | The list of payment methods associated with the store. |
|     - reference | string | No | Your reference to recognize the store by. |
|     - splitConfigurationId | string | No | The unique identifier of the [split configuration profile](https://docs.adyen.com/platforms/automatic-split-configuration/create-split-configuration/). |
|   - transferInstruments | array of object | No | The list of transfer instruments that the legal entity owns. |
|     - balanceAccountId | string | No | The unique identifier of the balance account this transfer instrument is associated with. |
|     - id | string | No | The unique identifier of the transfer instrument. |
|     - type | string | No | The type of transfer instrument.  Possible value: **bankAccount**. |
| environment | string | Yes | The environment from which the webhook originated.  Possible values: **test**, **live**. |
| timestamp | string | No | When the event was queued. |
| type | string | Yes | Type of webhook. |
