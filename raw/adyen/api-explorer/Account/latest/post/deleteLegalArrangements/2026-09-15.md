# POST /deleteLegalArrangements - Delete legal arrangements

Deletes legal arrangements and/or legal arrangement entities associated with an account holder.

## Servers
- https://cal-test.adyen.com/cal/services/Account/v6

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| accountHolderCode | string | Yes | The code of the account holder. |
| legalArrangements | array of object | Yes | List of legal arrangements. |
|   - legalArrangementCode | string | Yes | The code of the legal arrangement to be deleted. If you also send `legalArrangementEntityCodes`, only the entities listed will be deleted. |
|   - legalArrangementEntityCodes | array of string | No | List of legal arrangement entities to be deleted. |

## Request examples

### arrangements
```json
{
  "accountHolderCode": "CODE_OF_ACCOUNT_HOLDER",
  "legalArrangements": [
    {
      "legalArrangementCode": "cdf92f5a-a114-4ce6-8f19-c3f6ec83141c"
    }
  ]
}
```

### entities
```json
{
  "accountHolderCode": "CODE_OF_ACCOUNT_HOLDER",
  "legalArrangements": [
    {
      "legalArrangementCode": "cdf92f5a-a114-4ce6-8f19-c3f6ec83141c",
      "legalArrangementEntityCodes": [
        "755881d3-d6b0-4b34-8ace-1caceb8add63"
      ]
    }
  ]
}
```
