# POST /getAccountHolder - Get an account holder

Returns the details of an account holder.

## Servers
- https://cal-test.adyen.com/cal/services/Account/v6

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| accountCode | string | No | The code of the account of which to retrieve the details.  Required if no `accountHolderCode` is provided. |
| accountHolderCode | string | No | The code of the account holder of which to retrieve the details.  Required if no `accountCode` is provided. |
| showDetails | boolean | No | True if the request should return the account holder details |

## Request examples

### accountCode
```json
{
  "accountCode": "CODE_OF_ACCOUNT"
}
```

### accountHolderCode
```json
{
  "accountHolderCode": "CODE_OF_ACCOUNT_HOLDER"
}
```
