# POST /getTaxForm - Get a tax form

Generates a tax form for account holders operating in the US. For more information, refer to [Providing tax forms](https://docs.adyen.com/classic-platforms/tax-forms).

## Servers
- https://cal-test.adyen.com/cal/services/Account/v6

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| accountHolderCode | string | Yes | The account holder code you provided when you created the account holder. |
| formType | string | Yes | Type of the requested tax form. For example, 1099-K. |
| year | integer | Yes | Applicable tax year in the YYYY format. |

## Request examples

### basic
```json
{
  "accountHolderCode": "CODE_OF_ACCOUNT_HOLDER",
  "formType": "1099-K",
  "year": 2020
}
```
