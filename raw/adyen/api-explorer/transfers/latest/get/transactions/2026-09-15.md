# GET /transactions - Get all transactions

Versions 1 and 2 of the Transfers API are deprecated. If you are just starting your implementation, use the latest version.

Returns all the transactions related to a balance account, account holder, or balance platform.

When making this request, you must include at least one of the following:

- `balanceAccountId`

- `accountHolderId`

- `balancePlatform`.

This endpoint supports cursor-based pagination. The response returns the first page of results, and returns links to the next and previous pages when applicable. You can use the links to page through the results.

## Servers
- https://balanceplatform-api-test.adyen.com/btl/v4

## Parameters

### Query parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| limit | integer | No | The number of items returned per page, maximum of 100 items. By default, the response returns 10 items per page. |
| sortOrder | string | No | Determines the sort order of the returned transactions. The sort order is based on the creation date of the transaction.  Possible values:  **asc**: Ascending order, from oldest to most recent.  **desc**: Descending order, from most recent to oldest.  Default value: **asc**. |
| createdUntil | string | Yes | Only include transactions that have been created on or before this point in time. The value must be in ISO 8601 format. For example, **2021-05-30T15:07:40Z**. |
| createdSince | string | Yes | Only include transactions that have been created on or after this point in time. The value must be in ISO 8601 format. For example, **2021-05-30T15:07:40Z**. |
| cursor | string | No | The `cursor` returned in the links of the previous response. |
| balanceAccountId | string | No | The unique identifier of the [balance account](https://docs.adyen.com/api-explorer/#/balanceplatform/latest/get/balanceAccounts/%7Bid%7D__queryParam_id).  Required if you don't provide an `accountHolderId` or `balancePlatform`.  If you provide an `accountHolderId`, the `balanceAccountId` must be related to the `accountHolderId`. |
| accountHolderId | string | No | The unique identifier of the [account holder](https://docs.adyen.com/api-explorer/#/balanceplatform/latest/get/accountHolders/%7Bid%7D__queryParam_id).  Required if you don't provide a `balanceAccountId` or `balancePlatform`.  If you provide a `balanceAccountId`, the `accountHolderId` must be related to the `balanceAccountId`. |
| paymentInstrumentId | string | No | The unique identifier of the [payment instrument](https://docs.adyen.com/api-explorer/balanceplatform/latest/get/paymentInstruments/_id_).  To use this parameter, you must also provide a `balanceAccountId`, `accountHolderId`, or `balancePlatform`.  The `paymentInstrumentId` must be related to the `balanceAccountId` or `accountHolderId` that you provide. |
| balancePlatform | string | No | The unique identifier of the [balance platform](https://docs.adyen.com/api-explorer/#/balanceplatform/latest/get/balancePlatforms/%7Bid%7D__queryParam_id).  Required if you don't provide a `balanceAccountId` or `accountHolderId`. |

## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| _links | object | No | Contains links to the next and previous page whenever applicable. |
|   - next | object | No | Contains a link to the next page. |
|     - href | string | No | The link to the resource. |
|   - prev | object | No | Contains a link to the previous page. |
|     - href | string | No | The link to the resource. |
| data | array of object | No | Contains the transactions that match the query parameters. |
|   - accountHolder | object | Yes | Contains information about the account holder associated with the `balanceAccount`. |
|     - description | string | No | The description of the resource. |
|     - id | string | No | The unique identifier of the resource. |
|     - reference | string | No | The reference for the resource. |
|   - amount | object | Yes | Contains information about the amount of the transaction. |
|     - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes) of the amount. |
|     - value | integer | Yes | The numeric value of the amount, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
|   - balanceAccount | object | Yes | Contains information about the balance account involved in the transaction. |
|     - description | string | No | The description of the resource. |
|     - id | string | No | The unique identifier of the resource. |
|     - reference | string | No | The reference for the resource. |
|   - balancePlatform | string | Yes | The unique identifier of the balance platform. |
|   - bookingDate | string | Yes | The date the transaction was booked into the balance account. |
|   - creationDate | string | No | The date and time when the event was triggered, in ISO 8601 extended format. For example, **2025-03-19T10:15:30+01:00**. |
|   - description | string | No | The `description` from the `/transfers` request. |
|   - id | string | Yes | The unique identifier of the transaction. |
|   - paymentInstrument | object | No | Contains information about the payment instrument that was used for the transaction. |
|     - description | string | No | The description of the resource. |
|     - id | string | No | The unique identifier of the resource. |
|     - reference | string | No | The reference for the resource. |
|     - tokenType | string | No | The type of wallet that the network token is associated with. |
|   - referenceForBeneficiary | string | No | The reference sent to or received from the counterparty.  For outgoing funds, this is the [`referenceForBeneficiary`](https://docs.adyen.com/api-explorer/#/transfers/latest/post/transfers__resParam_referenceForBeneficiary) from the  [`/transfers`](https://docs.adyen.com/api-explorer/#/transfers/latest/post/transfers__reqParam_referenceForBeneficiary) request.  For incoming funds, this is the reference from the sender. |
|   - status | string | Yes | The status of the transaction.  Possible values:  **pending**: The transaction is still pending.  **booked**: The transaction has been booked to the balance account. |
|   - transfer | object | No | Contains information about the transfer related to the transaction. |
|     - categoryData |  | No | The relevant data according to the transfer category. |
|     - id | string | No | The ID of the resource. |
|     - reference | string | Yes | The [`reference`](https://docs.adyen.com/api-explorer/#/transfers/latest/post/transfers__reqParam_reference) from the `/transfers` request. If you haven't provided any, Adyen generates a unique reference. |
|   - valueDate | string | Yes | The date the transfer amount becomes available in the balance account. |
