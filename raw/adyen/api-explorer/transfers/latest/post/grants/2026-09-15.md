# POST /grants - Request a grant payout

Requests the payout of the selected grant offer.

## Servers
- https://balanceplatform-api-test.adyen.com/btl/v4

## Parameters

### Header parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| Idempotency-Key | string | No | A unique identifier for the message with a maximum of 64 characters (we recommend a UUID). |


### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| counterparty | object | No | An object containing the details of the receiving party of the grant. |
|   - balanceAccountId | string | No | The identifier of the balance account that belongs to the receiving account holder. |
|   - transferInstrumentId | string | No | The identifier of the transfer instrument that belongs to the legal entity of the account holder. |
| grantAccountId | string | Yes | The identifier of the grant account used for the grant. |
| grantOfferId | string | Yes | The identifier of the grant offer that has been selected and from which the grant details will be used. |

## Request examples

### requestGrant
```json
{
  "grantAccountId": "CG00000000000000000000001",
  "grantOfferId": "0000000000000001",
  "counterparty": {
    "balanceAccountId": "BA00000000000000000000001"
  }
}
```
## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| amount | object | No | An object containing the amount of the grant, in [minor units](https://docs.adyen.com/development-resources/currency-codes). |
|   - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes) of the amount. |
|   - value | integer | Yes | The numeric value of the amount, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
| balances | object | Yes | An object containing the details of the existing grant. |
|   - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes). |
|   - fee | integer | Yes | Fee amount. |
|   - principal | integer | Yes | Principal amount. |
|   - total | integer | Yes | Total amount. A sum of principal amount and fee amount. |
| counterparty | object | No | An object containing the details of the receiving party of the grant. |
|   - accountHolderId | string | No | The identifier of the receiving account holder. |
|   - balanceAccountId | string | No | The identifier of the balance account that belongs to the receiving account holder. |
|   - transferInstrumentId | string | No | The identifier of the transfer instrument that belongs to the legal entity of the account holder. |
| fee | object | No | An object containing the fee currency and value, in [minor units](https://docs.adyen.com/development-resources/currency-codes). |
|   - amount | object | Yes | Contains the fee amount. |
|     - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes) of the amount. |
|     - value | integer | Yes | The numeric value of the amount, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
| grantAccountId | string | Yes | The identifier of the grant account used for the grant. |
| grantOfferId | string | Yes | The identifier of the grant offer that has been selected and from which the grant details will be used. |
| id | string | Yes | The identifier of the grant reference. |
| repayment | object | No | An object containing the details of the 30-day repayment threshold. |
|   - basisPoints | integer | Yes | The repayment that is deducted daily from incoming net volume, in [basis points](https://www.investopedia.com/terms/b/basispoint.asp). |
|   - term | object | No | An object containing the details of the configuration for repayment term. |
|     - estimatedDays | integer | Yes | The estimated term for repaying the grant, in days. |
|     - maximumDays | integer | No | The maximum term for repaying the grant, in days. Only applies when `contractType` is **loan**. |
|   - threshold | object | No | An object containing the details of the 30-day repayment threshold. |
|     - amount | object | Yes | The amount to be repaid on a 30-day basis. |
| status | string | Yes | The current status of the grant. Possible values: **Pending**, **Active**, **Repaid**, **WrittenOff**, **Failed**, **Revoked**. |
