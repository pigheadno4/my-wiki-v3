# POST recurring.token.created - Token created

Adyen sends this webhook when a token is created.

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| createdAt | string | Yes | The date and time when the event happened, in ISO 8601 extended format. |
| data | object | Yes | Contains event details. |
|   - merchantAccount | string | Yes | The identifier of the merchant account related to the event that triggered the webhook. |
|   - operation | string | Yes | A text description that provides details about the operation, intended for audit purposes. |
|   - shopperReference | string | Yes | Your unique shopper reference that is associated with the `storedPaymentMethodId`. |
|   - storedPaymentMethodId | string | Yes | The ID of the token. |
|   - type | string | Yes | The type of the payment method. |
| environment | string | Yes | The environment from which the webhook originated.  Possible values: **test**, **live**. |
| eventId | string | Yes | The PSP reference of the event that triggered the webhook. |
| type | string | Yes | The type of webhook. |
| version | string | No | The version of this entity. |

## Request examples

### recurring-token-created
```json
{
  "createdAt": "2025-06-30T16:40:23+02:00",
  "eventId": "QBQQ9DLNRHHKGK38",
  "environment": "test",
  "data": {
    "merchantAccount": "YOUR_MERCHANT_ACCOUNT",
    "storedPaymentMethodId": "M5N7TQ4TG5PFWR50",
    "type": "visastandarddebit",
    "operation": "created",
    "shopperReference": "YOUR_SHOPPER_REFERENCE"
  },
  "type": "recurring.token.created"
}
```
## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| notificationResponse | string | No | Respond with any **2xx** HTTP status code to [accept the webhook](https://docs.adyen.com/development-resources/webhooks/#accept-webhooks). |
