# GET /dynamicOffers - Get all available dynamic offers

Returns a list of all [dynamic offers](https://docs.adyen.com/capital/get-grant-offers/dynamic-offers/) available for `accountHolderId` specified as a query parameter.

## Servers

**Test Environment**
- https://balanceplatform-api-test.adyen.com/capital/v1

**Live Environment**
- https://balanceplatform-api-live.adyen.com/capital/v1

## Parameters

### Query parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| financingType | string | No | The type of financing that the offer is for. If the value is not specified, returns all available types.  Possible values: **businessFinancing** |
| accountHolderId | string | Yes | The unique identifier of the account holder that the dynamic offer is for. |

## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| dynamicOffers | array of object | Yes | Contains a list of available dynamic offers for the specified account holder. |
|   - accountHolderId | string | Yes | The unique identifier of the account holder that the dynamic offer is for. |
|   - contractType | string | Yes | The contract type of the offer.  Possible values:  - **loan**  - **cashAdvance** |
|   - expiresAt | string | Yes | The expiration date and time of the offer validity period. |
|   - financingType | string | Yes | The type of financing that the offer is for.  Possible values: **businessFinancing**. |
|   - id | string | Yes | The unique identifier of the dynamic offer. |
|   - maximumAmount | object | Yes | The maximum financing amount available to the account holder under this offer. |
|     - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes) of the amount. |
|     - value | integer | Yes | The numeric value of the amount, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
|   - minimumAmount | object | Yes | The minimum financing amount available to the account holder under this offer. |
|     - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes) of the amount. |
|     - value | integer | Yes | The numeric value of the amount, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
|   - repayment | object | Yes | Contains information about the repayment configuration of the grant. |
|     - term | object | Yes | Contains information about the time period in which your user must repay the total amount of the grant. |
|   - startsAt | string | Yes | The starting date and time of the offer validity period. |
