# POST balancePlatform.negativeBalanceCompensationWarning.scheduled - Negative balance compensation scheduled

Adyen sends this webhook to inform you about a balance account whose balance has been negative for 20 or more days. If you do not transfer funds to that balance account to cover the negative balance before the scheduled compensation date, a transfer is made from your liable balance account on that date.

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| data | object | Yes | Contains event details. |
|   - accountHolder | object | No | The details of the account holder who owns the balance account with a negative balance. |
|     - description | string | No | The description of the resource. |
|     - id | string | No | The unique identifier of the resource. |
|     - reference | string | No | The reference for the resource. |
|   - amount | object | No | The negative balance amount of the balance account. |
|     - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes) of the amount. |
|     - value | integer | Yes | The numeric value of the amount, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
|   - balancePlatform | string | No | The unique identifier of the balance platform. |
|   - creationDate | string | No | The date and time when the event was triggered, in ISO 8601 extended format. For example, **2025-03-19T10:15:30+01:00**. |
|   - id | string | No | The ID of the resource. |
|   - liableBalanceAccountId | string | No | The balance account ID of the account that will be used to compensate the balance account whose balance is negative. |
|   - negativeBalanceSince | string | No | The date the balance for the account became negative. |
|   - scheduledCompensationAt | string | No | The date when a compensation transfer to the account is scheduled to happen. |
| environment | string | Yes | The environment from which the webhook originated.  Possible values: **test**, **live**. |
| timestamp | string | No | When the event was queued. |
| type | string | Yes | Type of webhook. |
