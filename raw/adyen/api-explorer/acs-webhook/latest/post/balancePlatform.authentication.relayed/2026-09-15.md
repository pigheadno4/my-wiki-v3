# POST balancePlatform.authentication.relayed - Out-of-band authentication requested

Adyen sends this webhook when a cardholder must perform [out-of-band authentication](https://docs.adyen.com/issuing/3d-secure/oob-auth-sdk/authenticate-cardholders).

To complete the authentication process, respond to this webhook with an **HTTP 200** response. Include the `authenticationDecision` in the response body.

If we do not receive the response within two seconds, the authentication process stops.

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| environment | string | Yes | The environment from which the webhook originated. Possible values: **test**, **live**. |
| id | string | Yes | The unique identifier of the challenge. |
| paymentInstrumentId | string | Yes | The unique identifier of the [payment instrument](https://docs.adyen.com/api-explorer/balanceplatform/latest/get/paymentInstruments/_id_) used for the purchase. |
| purchase | object | Yes | The details of the purchase. |
|   - date | string | Yes | The time of the purchase. |
|   - merchantName | string | Yes | The name of the merchant. |
|   - originalAmount | object | Yes | The amount of the purchase in the original currency. |
|     - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes) of the amount. |
|     - value | integer | Yes | The numeric value of the amount, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
| threeDSRequestorAppURL | string | No | URL for auto-switching to the threeDS Requestor App. If not present, the threeDS Requestor App doesn't support auto-switching. |
| timestamp | string | No | When the event was queued. |
| type | string | Yes | Type of notification. |

The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| authenticationDecision | object | Yes | The decision regarding the authentication. |
|   - status | string | Yes | The status of the authentication.  Possible values:  **refused**  **proceed**  For more information, refer to [Authenticate cardholders using the Authentication SDK](https://docs.adyen.com/issuing/3d-secure/oob-auth-sdk/authenticate-cardholders/). |
