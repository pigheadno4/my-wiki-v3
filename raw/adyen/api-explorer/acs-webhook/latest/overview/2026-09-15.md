# Authentication webhooks v1

Adyen sends webhooks to inform your system about events related to cardholder authentication.

## Endpoints

### General
| Method | Path | Summary |
|--------|------|---------|
| POST | balancePlatform.authentication.created | Cardholder authenticated |
| POST | balancePlatform.authentication.relayed | Out-of-band authentication requested |
