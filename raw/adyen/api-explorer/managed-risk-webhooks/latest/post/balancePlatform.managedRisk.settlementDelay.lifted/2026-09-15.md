# POST balancePlatform.managedRisk.settlementDelay.lifted - Settlement delay lifted

Adyen sends this webhook when we lift a settlement delay from your account holder's payouts after their risk review period has passed.

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| data | object | Yes | Contains event details. |
|   - accountHolderId | string | Yes | The unique identifier of the account holder whose risk settings changed. |
|   - balancePlatform | string | No | The unique identifier of the balance platform. |
|   - creationDate | string | No | The date and time when the event was triggered, in ISO 8601 extended format. For example, **2025-03-19T10:15:30+01:00**. |
|   - reason | string | Yes | The reason for the change in your account holder's settlement delay.  Possible values: **paymentProcessingEnabled**, **settlementDelayChanged**, **riskReviewPeriodPassed**. |
| environment | string | Yes | The environment from which the webhook originated.  Possible values: **test**, **live**. |
| timestamp | string | No | When the event was queued. |
| type | string | Yes | Type of webhook. |

## Request examples

### settlement-delay-lifted
```json
{
  "data": {
    "accountHolderId": "AH00000000000000000001",
    "reason": "riskReviewPeriodPassed",
    "balancePlatform": "YOUR_BALANCE_PLATFORM",
    "creationDate": "2025-01-19T13:37:38+02:00",
    "id": "9313547924908349"
  },
  "environment": "test",
  "type": "balancePlatform.managedRisk.settlementDelay.lifted"
}
```
## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| notificationResponse | string | No | Respond with any **2xx** HTTP status code to [accept the webhook](https://docs.adyen.com/development-resources/webhooks/#accept-webhooks). |
