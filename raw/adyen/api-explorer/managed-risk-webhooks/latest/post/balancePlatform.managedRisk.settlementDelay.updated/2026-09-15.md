# POST balancePlatform.managedRisk.settlementDelay.updated - Settlement delay updated

Adyen sends this webhook when we update the settlement delay for your account holder's payouts, because of their risk level.

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| data | object | Yes | Contains event details. |
|   - accountHolderId | string | Yes | The unique identifier of the account holder whose risk settings changed. |
|   - balancePlatform | string | No | The unique identifier of the balance platform. |
|   - configurations | array of object | Yes | Contains information about the configuration of a settlement delay. |
|     - paymentMethod | string | Yes | The payment method to which the settlement delay applies. |
|     - settlementDelay | integer | Yes | The updated settlement delay applied to your user's transactions. It indicates the number of days after which your user's funds become available in their balance account. |
|   - creationDate | string | No | The date and time when the event was triggered, in ISO 8601 extended format. For example, **2025-03-19T10:15:30+01:00**. |
|   - reason | string | Yes | The reason for the change in your account holder's settlement delay.  Possible values: **paymentProcessingEnabled**, **settlementDelayChanged**, **riskReviewPeriodPassed**. |
| environment | string | Yes | The environment from which the webhook originated.  Possible values: **test**, **live**. |
| timestamp | string | No | When the event was queued. |
| type | string | Yes | Type of webhook. |

## Request examples


The request has succeeded.

**Response body**
