# Managed risk webhooks v1

Adyen sends these webhooks to inform you when we adjust the risk measures applied to your account holders' payouts, based on their risk level.

These measures include settlement delays, rolling reserves, and reserve waivers.

These webhooks are sent to customers that use Adyen [Managed Risk](https://docs.adyen.com/platforms/managed-risk/).

## Endpoints

### General
| Method | Path | Summary |
|--------|------|---------|
| POST | balancePlatform.managedRisk.balance.block.released | Blocked funds released |
| POST | balancePlatform.managedRisk.reserveWaiver.applied | Reserve waiver applied |
| POST | balancePlatform.managedRisk.reserveWaiver.removed | Reserve waiver removed |
| POST | balancePlatform.managedRisk.rollingReserve.applied | Rolling reserve applied |
| POST | balancePlatform.managedRisk.rollingReserve.lifted | Rolling reserve lifted |
| POST | balancePlatform.managedRisk.rollingReserve.updated | Rolling reserve updated |
| POST | balancePlatform.managedRisk.settlementDelay.lifted | Settlement delay lifted |
| POST | balancePlatform.managedRisk.settlementDelay.updated | Settlement delay updated |
