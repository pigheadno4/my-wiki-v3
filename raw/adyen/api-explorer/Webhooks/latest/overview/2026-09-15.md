# Webhooks v1

We use webhooks to send you updates about payment status updates, newly available reports, and other events that you can subscribe to. For more information, refer to our [documentation](https://docs.adyen.com/development-resources/webhooks).

## Endpoints

### General
| Method | Path | Summary |
|--------|------|---------|
| POST | /ACH_NOTIFICATION_OF_CHANGE | ACH Notification of Change |
| POST | /AUTHORISATION | Result of authorisation request |
| POST | /AUTHORISATION_ADJUSTMENT | Result of payment authorisation adjustment request |
| POST | /AUTORESCUE | Auto Rescue process ended |
| POST | /CANCELLATION | Result of cancel request |
| POST | /CANCEL_AUTORESCUE | Auto Rescue process canceled |
| POST | /CANCEL_OR_REFUND | Result of cancel or refund request |
| POST | /CAPTURE | Result of capture request |
| POST | /CAPTURE_FAILED | Capture request failed due to scheme rejection |

| POST | /CHARGEBACK_REVERSED | Chargeback successfully defended |

| POST | /DISPUTE_DEFENSE_PERIOD_ENDED | Dispute defense period ended |
| POST | /EXPIRE | Authorisation expired |
| POST | /INFORMATION_SUPPLIED | Defense documents uploaded or dispute auto-defended |
| POST | /ISSUER_COMMENTS | Issuer included comments |
| POST | /ISSUER_RESPONSE_TIMEFRAME_EXPIRED | Issuer accepted defense or did not respond |
