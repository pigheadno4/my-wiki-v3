# POST /disputes - Raise a dispute

Raise a dispute for an underlying transaction, providing a dispute type and the amount you want to dispute.

Raising a dispute returns a dispute ID, which you can use to update details about the dispute, provide supporting documentation, close the dispute, or submit the dispute for a chargeback. You can also use the dispute ID to view the status of the dispute.

## Servers

**Test Environment**
- https://balanceplatform-api-test.adyen.com/btl/api/v4

**Live Environment**
- https://balanceplatform-api-live.adyen.com/btl/api/v4

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| description | string | No | Your description for the dispute. |
| disputedAmount | object | No | The amount for which you dispute the transaction. The disputed amount cannot be greater than the transaction amount. If you do not provide an amount, the entire transaction amount will be disputed. |
|   - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes) of the amount. |
|   - value | integer | Yes | The numeric value of the amount, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
| duplicateInfo | object | No | Additional information for raising a dispute of `type` **duplicate**. Required for disputes of `type` **duplicate**. |
|   - duplicateTransactionId | string | Yes | The transaction id associated with the duplicate charge for which you are disputing. The disputed transaction must be in the same amount as the duplicate transaction. |
|   - sameCard | boolean | Yes | The duplicate charge was made on the same card. Possible values: **true**, **false**. |
|   - sameIssuer | boolean | No | The issuer associated with each charge is the same. Possible values: **true**, **false**. |
| fraudInfo | object | No | Additional information for raising a dispute of `type` **fraud**. Required for disputes of `type` **fraud**. |
|   - cardDoesNotBelongToCardholder | boolean | Yes | The card is no longer in the cardholder's possession. Set to **true** if the card is lost or stolen. |
|   - cardWasCounterfeited | boolean | Yes | The card was counterfeited. |
|   - descriptionOfIssue | string | Yes | Your description of the issue for raising a dispute of `type` **fraud**. |
|   - reportOnly | boolean | No | Set to **true** to report fraud to Adyen with no further action, such as a request for a chargeback or fee reversal. The default value is **false**. |
| notDeliveredInfo | object | No | Additional information for raising a dispute of `type` **notDelivered**. Required for disputes of `type` **notDelivered**. |
|   - agreedDeliveryLocation | string | No | The delivery location specified by the cardholder. Required if **deliveredToWrongLocation** is **true**. |
|   - dateOfCancellation | string | No | The date the undelivered goods or services were cancelled in YYYY-MM-DD format. |
|   - deliveredToWrongLocation | boolean | No | Indicates goods were delivered to the wrong location.  Possible values: **true**, **false**. |
|   - descriptionOfIssue | string | Yes | Your description of the issue for raising a dispute of `type` **notDelivered**. |
|   - didCardholderReturn | boolean | No | Indicates if the cardholder returned the goods to the merchant. Required if **isDeliveryLate** is **true**.  Possible values: **true**, **false**. |
|   - isDeliveryLate | boolean | No | Indicates if the goods or services were delivered late. Required if **whatWasNotDelivered** is **goods**.  Possible values: **true**, **false**. |
|   - isMerchantBankrupt | boolean | No | Indicates if the transaction was processed by a bankrupt merchant.  Possible values: **true**, **false**. |
|   - isNonFiatOrNft | boolean | No | Indicates if the transaction is non-fiat or non-fungible token (NFT) related.  Possible values: **true**, **false**. |
|   - lastExpectedDate | string | Yes | The date the undelivered goods or services were expected to be delivered in YYYY-MM-DD format. |
|   - whatWasNotDelivered | string | Yes | The type of product that you expected to receive.  Possible values: **goods**, **services**. |
|   - whoCancelled | string | No | The party that initiated the cancellation of the transaction.  Possible values: **merchant**, **cardholder**. |
| otherInfo | object | No | Additional information for raising a dispute of `type` **other**. Required for disputes of `type` **other**.  **Note:** The **other** dispute `type` is currently in beta testing. Do not create or submit any disputes for this dispute `type` at this time. |
|   - descriptionOfIssue | string | Yes | Your description of the issue for raising a dispute of `type` **other**. |
|   - subType | string | Yes | The specific category of **other** dispute that you are raising.  Possible values: **atmDispute**, **cancelledGoodsServices**, **cancelledRecurring**, **counterfeit**, **creditNotProcessed**, **notAsDescribed**. |
|   - whatWasPurchased | string | Yes | The type of product that you purchased.  Possible values: **goods**, **services**. |
| status | string | No | The current status of the dispute.  When you create a dispute, you can only set the `status` to **draft**. When you update a dispute, you can set the `status` to **submitted** or **closed**.  Possible values: **draft**, **submitted**, **closed**, **won**, **chargeback**, **secondPresentment**. |
| transactionId | string | Yes | The unique reference of the transaction for which you are raising the dispute. |
| type | string | Yes | The type of the dispute.  Possible values: **duplicate**, **fraud**, **notDelivered**, **other**.  **Note:** The **other** dispute `type` is currently in beta testing. Do not create or submit any disputes for this dispute `type` at this time. |
