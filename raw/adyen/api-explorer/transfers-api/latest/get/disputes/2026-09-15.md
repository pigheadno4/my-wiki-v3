# GET /disputes - Get a list of raised disputes

Returns a list of raised disputes that match the query parameters.

This endpoint supports cursor-based pagination. The response returns the first page of results, and returns links to the next page when applicable. You can use the links to page through the results. The response also returns links to the previous page when applicable.

## Servers

**Test Environment**
- https://balanceplatform-api-test.adyen.com/btl/api/v4

**Live Environment**
- https://balanceplatform-api-live.adyen.com/btl/api/v4

## Parameters

### Query parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| limit | string | No | The number of items returned per page, maximum of 500 items. By default, the response returns 100 items per page. |
| offset | string | No | The number of items that you want to skip. |
| createdUntil | string | No | Only include disputes that have been created on or before this point in time. The value must be in [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601) format. For example, **2021-05-30T15:07:40Z**. |
| createdSince | string | No | Only include disputes that have been created on or after this point in time. The value must be in [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601)  format. For example, 2021-05-30T15:07:40Z. |
| paymentInstrument | string | No | The unique identifier of the payment instrument. |
| status | string | No | The current status of the dispute.  Possible values: **draft**, **submitted**, **closed**, **won**, **chargeback**, **secondPresentment**. |
