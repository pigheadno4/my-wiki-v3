# POST /deleteNotificationConfigurations - Delete a notification subscription configuration

Deletes an existing notification subscription configuration. After the subscription is deleted, no further event notifications will be sent to the URL defined in the subscription.

## Servers
- https://cal-test.adyen.com/cal/services/Notification/v6

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| notificationIds | array of integer | Yes | A list of IDs of the notification subscription configurations to be deleted. |

## Request examples

### basic
```json
{
  "notificationIds": [
    27891
  ]
}
```
