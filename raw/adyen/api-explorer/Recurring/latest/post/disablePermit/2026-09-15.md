# POST /disablePermit - Disable an existing permit.

Disable a permit that was previously linked to a recurringDetailReference.

## Servers
- https://pal-test.adyen.com/pal/servlet/Recurring/v68

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| merchantAccount | string | Yes | The merchant account identifier, with which you want to process the transaction. |
| token | string | Yes | The permit token to disable. |
