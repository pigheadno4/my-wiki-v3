# POST /createPermit - Create new permits linked to a recurring contract.

Create permits for a recurring contract, including support for defining restrictions.

## Servers
- https://pal-test.adyen.com/pal/servlet/Recurring/v68

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| merchantAccount | string | Yes | The merchant account identifier, with which you want to process the transaction. |
| permits | array of object | Yes | The permits to create for this recurring contract. |
|   - partnerId | string | No | Partner ID (when using the permit-per-partner token sharing model). |
|   - profileReference | string | No | The profile to apply to this permit (when using the shared permits model). |
|   - restriction | object | No | Permit level restriction overrides. |
|     - maxAmount | object | No | The total sum amount of one or more payments made using this permit may not exceed this amount if set. |
|     - singleTransactionLimit | object | No | The amount of any single payment using this permit may not exceed this amount if set. |
|     - singleUse | boolean | No | Only a single payment can be made using this permit if set to true, otherwise multiple payments are allowed. |
|   - resultKey | string | No | The key to link permit requests to permit results. |
|   - validTillDate | string | No | The expiry date for this permit. |
| recurringDetailReference | string | Yes | The recurring contract the new permits will use. |
| shopperReference | string | Yes | The shopper's reference to uniquely identify this shopper (e.g. user ID or account ID). |

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|

|   - resultKey | string | No | The key to link permit requests to permit results. |
|   - token | string | No | The permit token which is used to make payments by the partner company. |
