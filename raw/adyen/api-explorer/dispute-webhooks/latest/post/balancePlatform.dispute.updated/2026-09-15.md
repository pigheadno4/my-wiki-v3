# POST balancePlatform.dispute.updated - Dispute updated

Adyen sends this webhook when a dispute is updated. This webhook only informs your server of requests.

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| data | object | Yes | Contains event details. |
|   - arn | string | No | The unique Acquirer Reference Number (arn) generated by the card scheme for each capture. You can use the arn to trace the transaction through its lifecycle. |
|   - balancePlatform | string | No | The unique identifier of the balance platform. |
|   - creationDate | string | No | The date and time when the event was triggered, in ISO 8601 extended format. For example, **2025-03-19T10:15:30+01:00**. |
|   - description | string | No | Contains information about the dispute. |
|   - disputedAmount | object | No | The amount for which the transaction is being disputed. The disputed amount cannot be greater than the transaction amount. If an amount was not provided, the entire transaction amount is disputed. |
|     - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes) of the amount. |
|     - value | integer | Yes | The numeric value of the amount, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
|   - id | string | No | The ID of the resource. |
|   - status | string | No | The current status of the dispute. |
|   - statusDetail | string | No | Additional information about the status of the dispute, when available. |
|   - transactionId | string | No | The unique reference of the transaction for which the dispute is requested. |
|   - type | string | No | The type of dispute raised for the transaction. |
| type | string | Yes | Type of webhook. |

## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| notificationResponse | string | No | Respond with any **2xx** HTTP status code to [accept the webhook](https://docs.adyen.com/development-resources/webhooks/#accept-webhooks). |
