# GET /accountVerification/reports/{code} - Get account verification report

Get the account verification report using a unique code from a successful open banking connection. This report provides identity verification and bank account details.

## Servers

**Test Environment**
- https://obgateway-test.adyen.com/obgateway/v1

**Live Environment**
- https://obgateway-live.adyen.com/obgateway/v1

## Parameters

### Path parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| code | string | Yes | The unique code you receive after a successful open banking flow that is included as a query parameter in the `redirectUrl` callback. |

## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| accounts | array of object | Yes | A list of bank accounts with their respective information. |
|   - accountId | string | Yes | The unique identifier for the bank account. |
|   - accountName | string | Yes | The name of the bank account. This name is assigned by the banking institution, and it describes the type of bank account. |
|   - accountNumber | string | Yes | The account number of the bank account. |
|   - accountType | string | Yes | The type of the bank account. Possible values are **CURRENT**, **SAVINGS**, **BUSINESS**, **CREDIT_CARD**, **LOAN**, **UNKNOWN**. |
|   - bankName | string | No | The name of the banking institution where the bank account is held. |
|   - currency | string | Yes | The currency of the funds in the bank account. |
|   - identifiers | object | Yes | Contains various codes and details used to uniquely identify the bank account across different regions. |
|     - ach | object | No | Identifiers relevant for Automated Clearing House (ACH) payments, primarily used in the United States. |
|     - bacs | object | No | Identifiers relevant for Bankers' Automated Clearing Services (BACS) payments, primarily used in the United Kingdom. |
|     - bsb | object | No | Identifiers relevant for Australian banking, specifically for BSB (Bank-State-Branch) numbers. |
|     - eft | object | No | Identifiers relevant for Electronic Funds Transfer (EFT) payments, commonly used in Canada. |
|     - iban | object | No | The international bank account number as defined in the ISO-13616 standard. |
|     - rix | object | No | Identifiers relevant for the Rix (Russian Interbank eXchange) system, used for interbank payments within Russia. |
|   - parties | array of object | Yes | Contains details of all parties associated with the report. |
|     - identity | object | Yes | Contains the identity details of the party. |
|     - role | string | Yes | Specifies a role or capacity of the party in relation to the bank account. |
| country | string | Yes | The location where the third-party individual's bank account is registered. |
| id | string | Yes | The unique identifier for the specific report. |
