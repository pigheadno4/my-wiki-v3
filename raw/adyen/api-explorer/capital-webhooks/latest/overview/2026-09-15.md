# Capital webhooks v1

Adyen sends webhooks to notify your system when financing offers or grants are created or updated.

You can use these webhooks to build your implementation. For example, you can use webhook data to build a dashboard to show your users details about their business financing.

## Endpoints

### General
| Method | Path | Summary |
|--------|------|---------|
| POST | balancePlatform.balanceAccountHolder.capitalOffer.created | Static offer created |
| POST | balancePlatform.capital.dynamicOffer.created | Dynamic offer created |
| POST | balancePlatform.grants.created | Grant created |
| POST | balancePlatform.grants.updated | Grant updated |
