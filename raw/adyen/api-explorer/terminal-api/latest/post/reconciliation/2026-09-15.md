# POST /reconciliation - Reconciliation Request

Content of the Reconciliation Request message.
It conveys Information related to the Reconciliation requested by the Sale System.

## Servers

**with cloud integration**
- https://device-api-test.adyen.com/v1/merchants/{merchantAccount}/devices/{deviceId}/sync

**with cloud integration**
- https://device-api-test.adyen.com/v1/merchants/{merchantAccount}/devices/{deviceId}/async

**with local-hosting**
- <local-terminal-IP-address>

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| ReconciliationType | string | Yes | Possible values:  - **SaleReconciliation**  - **AcquirerSynchronisation**  - **AcquirerReconciliation**  - **PreviousReconciliation** |
| AcquirerID | array of integer | No | Identification of the Acquirer. Could be present only if ReconciliationType is AcquirerReconciliation or AcquirerSynchronisation. |
| POIReconciliationID | integer | No | Identification of the reconciliation period between Sale and POI. Absent if ReconciliationType is not PreviousReconciliation. |

## Responses

### 200 Success
It conveys Information related to the Reconciliation transaction processed by the POI System.
Content of the Reconciliation Response message.

| Response | object | Yes | Result of a message request processing. If Result is Success, `ErrorCondition` is absent or not used in the processing of the message.
