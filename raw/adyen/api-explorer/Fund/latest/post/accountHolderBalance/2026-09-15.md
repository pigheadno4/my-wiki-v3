# POST /accountHolderBalance - Get the balances of an account holder

Returns the account balances of an account holder. An account's balances are organized according by currencies. This mean that an account may have multiple balances: one for each currency.

## Servers
- https://cal-test.adyen.com/cal/services/Fund/v6

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| accountHolderCode | string | Yes | The code of the Account Holder of which to retrieve the balance. |

## Request examples

### basic
```json
{
  "accountHolderCode": "CODE_OF_ACCOUNT_HOLDER"
}
```
