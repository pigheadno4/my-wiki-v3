# GET /themes - Get a list of hosted onboarding page themes

Returns a list of hosted onboarding page themes.

Requests to this endpoint are subject to rate limits:

Live environments: 700 requests per 5 seconds.

Test environments: 200 requests per 5 seconds.

Failed requests are subject to a limit of 5 failures per 10 seconds.

## Servers
- https://kyc-test.adyen.com/lem/v4

## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| next | string | No | The next page. Only present if there is a next page. |
| previous | string | No | The previous page. Only present if there is a previous page. |
| themes | array of object | Yes | List of onboarding themes. |
|   - createdAt | string | Yes | The creation date of the theme. |
|   - description | string | No | The description of the theme. |
|   - id | string | Yes | The unique identifier of the theme. |
|   - properties | object (string) | Yes | The properties of the theme. |
|   - updatedAt | string | No | The date when the theme was last updated. |
