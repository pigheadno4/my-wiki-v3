# POST balancePlatform.report.created - Report generated

Adyen sends this webhook after a report is generated and ready to be downloaded. The webhook contains the URL at which the report can be downloaded.

Before you download reports, ask your Adyen contact for your report credentials. You must use your credentials to authenticate your GET request.

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| data | object | Yes | Contains event details. |
|   - accountHolder | object | No | The account holder related to the report. |
|     - description | string | No | The description of the resource. |
|     - id | string | No | The unique identifier of the resource. |
|     - reference | string | No | The reference for the resource. |
|   - balanceAccount | object | No | The balance account related to the report. |
|     - description | string | No | The description of the resource. |
|     - id | string | No | The unique identifier of the resource. |
|     - reference | string | No | The reference for the resource. |
|   - balancePlatform | string | No | The unique identifier of the balance platform. |
|   - creationDate | string | No | The date and time when the event was triggered, in ISO 8601 extended format. For example, **2025-03-19T10:15:30+01:00**. |
|   - downloadUrl | string | Yes | The URL at which you can download the report. To download, you must authenticate your GET request with your [API credentials](https://docs.adyen.com/api-explorer/#/balanceplatform/latest/overview). |
|   - fileName | string | Yes | The filename of the report. |
|   - id | string | No | The ID of the resource. |
|   - reportType | string | Yes | The type of report. Possible values:  - `balanceplatform_accounting_interactive_report`  - `balanceplatform_accounting_report`  - `balanceplatform_balance_report`  - `balanceplatform_fee_report`  - `balanceplatform_payment_instrument_report`  - `balanceplatform_payout_report`  - `balanceplatform_statement_report` |
| environment | string | Yes | The environment from which the webhook originated.  Possible values: **test**, **live**. |
| timestamp | string | No | When the event was queued. |
| type | string | Yes | Type of webhook. |

## Request examples

### balancePlatform.report.created
```json
{
  "data": {
    "balancePlatform": "YOUR_BALANCE_PLATFORM",
    "creationDate": "2024-07-02T02:01:08+02:00",
    "id": "balanceplatform_accounting_report_2024_07_01.csv",
    "downloadUrl": "https://balanceplatform-test.adyen.com/balanceplatform/.../.../.../balanceplatform_accounting_report_2024_07_01.csv",
    "fileName": "balanceplatform_accounting_report_2024_07_01.csv",
    "reportType": "balanceplatform_accounting_report"
  },
  "environment": "test",
  "timestamp": "2024-07-02T02:01:05+02:00",
  "type": "balancePlatform.report.created"
}
```
## Responses

### 200 Success
The request has succeeded.

**Response body**

|------|------|----------|-------------|
