# POST /orders/cancel - Cancel an order

Cancels an order. Cancellation of an order results in an automatic rollback of all payments made in the order, either by canceling or refunding the payment, depending on the type of payment method.

## Servers
- https://checkout-test.adyen.com/v72

## Parameters

### Header parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| Idempotency-Key | string | No | A unique identifier for the message with a maximum of 64 characters (we recommend a UUID). |


### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| merchantAccount | string | Yes | The merchant account identifier that orderData belongs to. |
| order | object | Yes | The order request object that contains a pspReference that represents the order and the matching encrypted order data. |
|   - orderData | string | Yes | The encrypted order data. |
|   - pspReference | string | Yes | The `pspReference` that belongs to the order. |

## Request examples

### basic
```json
{
  "order": {
    "pspReference": "8815517812932012",
    "orderData": "823fh892f8f18f4...148f13f9f3f"
  },
  "merchantAccount": "YOUR_MERCHANT_ACCOUNT"
}
```
