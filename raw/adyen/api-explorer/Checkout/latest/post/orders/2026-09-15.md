# POST /orders - Create an order

Creates an order to be used for partial payments. Make a POST `/orders` call before making a `/payments` call when processing payments with different payment methods.

## Servers
- https://checkout-test.adyen.com/v72

## Parameters

### Header parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| Idempotency-Key | string | No | A unique identifier for the message with a maximum of 64 characters (we recommend a UUID). |


### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| amount | object | Yes | The total amount of the order. |
|   - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes) of the amount. |
|   - value | integer | Yes | The numeric value of the amount, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
| expiresAt | string | No | The date when the order should expire. If not provided, the default expiry duration is 1 day.  [ISO 8601](https://www.w3.org/TR/NOTE-datetime) format: YYYY-MM-DDThh:mm:ss+TZD, for example, **2020-12-18T10:15:30+01:00**. |
| merchantAccount | string | Yes | The merchant account identifier, with which you want to process the order. |
| reference | string | Yes | A custom reference identifying the order. |

## Request examples

### basic
```json
{
  "reference": "YOUR_ORDER_REFERENCE",
  "amount": {
    "value": 2500,
    "currency": "EUR"
  },
  "merchantAccount": "YOUR_MERCHANT_ACCOUNT"
}
```
## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| additionalData | object (string) | No | Contains additional information about the payment. Some data fields are included only if you select them first: Go to **Customer Area** > **Developers** > **Additional data**. |
| amount | object | Yes | The initial amount of the order. |
|   - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes) of the amount. |
|   - value | integer | Yes | The numeric value of the amount, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
| expiresAt | string | Yes | The date that the order will expire. |
| fraudResult | object | No | The fraud result properties of the payment. |
|   - accountScore | integer | Yes | The total fraud score generated by the risk checks. |
|   - results | array of object | No | The result of the individual risk checks. |
|     - accountScore | integer | Yes | The fraud score generated by the risk check. |
|     - checkId | integer | Yes | The ID of the risk check. |
|     - name | string | Yes | The name of the risk check. |
| orderData | string | Yes | The encrypted data that will be used by merchant for adding payments to the order. |
| pspReference | string | No | Adyen's 16-character reference associated with the transaction/request. This value is globally unique; quote it when communicating with us about this request. |
| reference | string | No | The reference provided by merchant for creating the order. |
| refusalReason | string | No | If the payment's authorisation is refused or an error occurs during authorisation, this field holds Adyen's mapped reason for the refusal or a description of the error. When a transaction fails, the authorisation response includes `resultCode` and `refusalReason` values.  For more information, see [Refusal reasons](https://docs.adyen.com/development-resources/refusal-reasons). |
| remainingAmount | object | Yes | The remaining amount in the order. |
|   - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes) of the amount. |
|   - value | integer | Yes | The numeric value of the amount, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
| resultCode | string | Yes | The result of the order creation request. The value is always **Success**. |
