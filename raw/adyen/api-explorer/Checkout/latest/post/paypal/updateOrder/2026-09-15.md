# POST /paypal/updateOrder - Updates the order for PayPal Express Checkout

Updates the order for PayPal Express Checkout. This can be used to update the PayPal lightbox with an updated amount and delivery methods based on the delivery address.

## Servers
- https://checkout-test.adyen.com/v72

## Parameters

### Header parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| Idempotency-Key | string | No | A unique identifier for the message with a maximum of 64 characters (we recommend a UUID). |


### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| amount | object | No | The updated final payment amount. This amount is the item total plus the shipping costs of the selected `deliveryMethod`. |
|   - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes) of the amount. |
|   - value | integer | Yes | The numeric value of the amount, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
| deliveryAddress | object | No | The delivery address for this order. |
|   - city | string | Yes | The name of the city. Maximum length: 3000 characters. |
|   - country | string | Yes | The two-character ISO-3166-1 alpha-2 country code. For example, **US**.  If you don't know the country or are not collecting the country from the shopper, provide `country` as `ZZ`. |
|   - firstName | string | No |  |
|   - houseNumberOrName | string | Yes | The number or name of the house. Maximum length: 3000 characters. |
|   - lastName | string | No |  |
|   - postalCode | string | Yes | A maximum of five digits for an address in the US, or a maximum of ten characters for an address in all other countries. |
|   - stateOrProvince | string | No | The two-character ISO 3166-2 state or province code. For example, **CA** in the US or **ON** in Canada.  Required for the US and Canada. |
|   - street | string | Yes | The name of the street. Maximum length: 3000 characters.  The house number should not be included in this field; it should be separately provided via `houseNumberOrName`. |
| deliveryMethods | array of object | No | The list of new delivery methods and the cost of each. |
|   - amount | object | No | The cost of this delivery method. |
|     - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes) of the amount. |
|     - value | integer | Yes | The numeric value of the amount, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
|   - description | string | No | The name of the delivery method as shown to the shopper. |
|   - reference | string | No | The reference of the delivery method. |
|   - selected | boolean | No | If you display the PayPal lightbox with delivery methods, set to **true** for the delivery method that is selected. Only one delivery method can be selected at a time. |
|   - type | string | No | The type of the delivery method. |
| discountAmount | object | No | The discount amount for this order. |
|   - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes) of the amount. |
|   - value | integer | Yes | The numeric value of the amount, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
| paymentData | string | No | The `paymentData` from the client side. This value changes every time you make a `/paypal/updateOrder` request. |
| pspReference | string | No | The original `pspReference` from the `/payments` response. |
| sessionId | string | No | The original `sessionId` from the `/sessions` response. |
| shippingAmount | object | No | The shipping amount for this order. |
|   - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes) of the amount. |
|   - value | integer | Yes | The numeric value of the amount, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
| taxTotal | object | No | Total tax amount from the order. |
|   - amount | object | No |  |
|     - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes) of the amount. |
|     - value | integer | Yes | The numeric value of the amount, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
