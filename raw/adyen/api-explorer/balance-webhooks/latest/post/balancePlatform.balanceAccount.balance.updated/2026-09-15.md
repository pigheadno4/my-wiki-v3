# POST balancePlatform.balanceAccount.balance.updated - Balance updated

Adyen sends this webhook when the specified balance type reaches or drops below the threshold you configured.

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| data | object | Yes | Contains event details. |
|   - balanceAccountId | string | Yes | The unique identifier of the balance account. |
|   - balancePlatform | string | No | The unique identifier of the balance platform. |
|   - balances | object | Yes | The list balance types. |
|     - available | integer | No | The balance that is available for use. |
|     - balance | integer | No | The sum of transactions that have already been settled. |
|     - pending | integer | No | The sum of transactions that will be settled in the future. |
|     - reserved | integer | No | The balance currently held in reserve. |
|   - creationDate | string | No | The date and time when the event was triggered, in ISO 8601 extended format. For example, **2025-03-19T10:15:30+01:00**. |
|   - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes). |
|   - settingIds | array of string | Yes | The unique identifier of the balance webhook setting. |
| environment | string | Yes | The environment from which the webhook originated.  Possible values: **test**, **live**. |
| timestamp | string | No | When the event was queued. |
| type | string | Yes | Type of webhook. |
