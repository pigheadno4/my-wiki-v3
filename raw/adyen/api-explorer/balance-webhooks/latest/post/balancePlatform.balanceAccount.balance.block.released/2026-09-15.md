# POST balancePlatform.balanceAccount.balance.block.released - Blocked funds released

Adyen sends this webhook when funds that were previously blocked are released, making them available. Funds may be blocked for reasons such as:

**Collateral for payments**: Funds are held to secure loans or payments, and are released upon repayment.

**Risk mitigation**: Funds are held to cover potential risks like chargebacks, and are released after a set period, such as a return window.

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| data | object | Yes | Contains event details. |
|   - accountHolder | object | Yes | Contains information about the account holder associated with the `balanceAccount`. |
|     - description | string | No | The description of the resource. |
|     - id | string | No | The unique identifier of the resource. |
|     - reference | string | No | The reference for the resource. |
|   - amount | object | Yes | The amount released. |
|     - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes) of the amount. |
|     - value | integer | Yes | The numeric value of the amount, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
|   - balanceAccount | object | Yes | Contains information about the associated balance account. |
|     - description | string | No | The description of the resource. |
|     - id | string | No | The unique identifier of the resource. |
|     - reference | string | No | The reference for the resource. |
|   - balancePlatform | string | No | The unique identifier of the balance platform. |
|   - batchReference | string | No | The reference of the batch that was released. |
|   - blockedBalanceAfter | object | No | The new blocked balance after the funds were released. |
|     - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes) of the amount. |
|     - value | integer | Yes | The numeric value of the amount, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
|   - blockedBalanceBefore | object | No | The blocked balance before the funds were released. |
|     - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes) of the amount. |
|     - value | integer | Yes | The numeric value of the amount, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
|   - creationDate | string | No | The date and time when the event was triggered, in ISO 8601 extended format. For example, **2025-03-19T10:15:30+01:00**. |
|   - valueDate | string | No | The date and time when the amount was released, in ISO 8601 extended format. For example, **2025-03-19T10:15:30+01:00**. |
| environment | string | Yes | The environment from which the webhook originated.  Possible values: **test**, **live**. |
| timestamp | string | No | When the event was queued. |
| type | string | Yes | Type of webhook. |
