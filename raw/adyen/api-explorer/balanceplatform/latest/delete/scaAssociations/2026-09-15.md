# DELETE /scaAssociations - Delete association to devices

Deletes one or more SCA associations for a device.

## Servers
- https://balanceplatform-api-test.adyen.com/bcl/v2

## Parameters

### Header parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| WWW-Authenticate | string | Yes | The header for authenticating through SCA. |


### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| entityId | string | Yes | The unique identifier of the entity. |
| entityType | string | Yes | The type of the entity.  Possible values: **accountHolder**, **legalEntity** or **paymentInstrument**. |
| scaDeviceIds | array of string | Yes | A list of device ids associated with the entity that should be removed. |

## Request examples

### Remove SCA Association Request
```json
{
  "entityType": "accountHolder",
  "entityId": "AH00000000000000000000001",
  "scaDeviceIds": [
    "BSDR42XV3223223S5N6CDQDGH53M8H"
  ]
}
```
