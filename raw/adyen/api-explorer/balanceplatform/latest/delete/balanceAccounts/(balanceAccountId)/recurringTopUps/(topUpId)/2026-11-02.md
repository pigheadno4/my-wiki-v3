# DELETE /balanceAccounts/{balanceAccountId}/recurringTopUps/{topUpId} - Delete a recurring top up

Delete a recurring top up configuration by `topUpId`.

For more information, refer to [Manage recurring top-ups](https://docs.adyen.com/issuing/add-manage-funds/top-ups/manage-recurring-top-ups).

## Servers
- https://balanceplatform-api-test.adyen.com/bcl/v2

## Parameters

### Path parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| topUpId | string | Yes | The unique identifier of the recurring top-up you want to delete. |
| balanceAccountId | string | Yes | The unique identifier of the balance account. |
