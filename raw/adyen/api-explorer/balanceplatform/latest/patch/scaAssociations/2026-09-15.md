# PATCH /scaAssociations - Approve a pending approval association

Approves a previously created association that is in a pending state.

## Servers
- https://balanceplatform-api-test.adyen.com/bcl/v2

## Parameters

### Header parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| WWW-Authenticate | string | Yes | The header for authenticating through SCA. |


### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| entityId | string | Yes | The unique identifier of the entity. |
| entityType | string | Yes | The type of the entity.  Possible values: **accountHolder**, **legalEntity** or **paymentInstrument**. |
| scaDeviceIds | array of string | Yes | List of device ids associated to the entity that will be approved. |
| status | string | Yes | The status of the association.  Possible values: **active** or **pendingApproval**. |

## Request examples

### Approve SCA Association Request
```json
{
  "status": "active",
  "entityType": "accountHolder",
  "entityId": "AH00000000000000000000001",
  "scaDeviceIds": [
    "BSDR42XV3223223S5N6CDQDGH53M8H"
  ]
}
```
