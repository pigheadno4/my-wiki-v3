# GET /balanceAccounts/{balanceAccountId}/sweeps/{sweepId}/executions - View executions of a custom payout schedule

Returns a paginated list of executions of a custom payout schedule on a balance account. You can use query parameters to filter the executions that are returned in the list.

## Servers
- https://balanceplatform-api-test.adyen.com/bcl/v2

## Parameters

### Path parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| sweepId | string | Yes | The unique identifier of the sweep configuration. |
| balanceAccountId | string | Yes | The unique identifier of the balance account. |


### Query parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| cursor | string | No | The cursor from the `next` or `previous` pagination link in the previous response. |
| limit | integer | No | The number of items returned per page. By default, the response returns 10 items per page. |
| results | string | No | Contains a comma-separated list of sweep execution results. If included, the response returns only sweep executions with the specified results.  Possible results:  - **succeeded**: The sweep payout was completed successfully.  - **failed**: The sweep payout was not completed due to an error.  - **skipped**: The sweep payout was not triggered as expected. |
