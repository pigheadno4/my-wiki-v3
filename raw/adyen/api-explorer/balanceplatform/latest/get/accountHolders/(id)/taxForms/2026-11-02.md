# GET /accountHolders/{id}/taxForms - Get a tax form

Generates a tax form for account holders operating in the US. For more information, refer to US tax forms for [marketplaces](https://docs.adyen.com/marketplaces/us-tax-forms/) or [platforms](https://docs.adyen.com/platforms/us-tax-forms/) .

## Servers
- https://balanceplatform-api-test.adyen.com/bcl/v2

## Parameters

### Path parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| id | string | Yes | The unique identifier of the account holder. |


### Query parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| legalEntityId | string | No | The legal entity reference whose tax form you want to retrieve. |
| year | integer | Yes | The tax year in **YYYY** format for the tax form you want to retrieve. |
| formType | string | Yes | The type of tax form you want to retrieve. Accepted values are **US1099k** and **US1099nec**. |
