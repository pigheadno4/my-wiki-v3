# GET /mandates - Get a list of mandates

Returns a list of all [direct debit mandates](https://docs.adyen.com/business-accounts/accept-direct-debits-uk) created for a business account.

## Servers
- https://balanceplatform-api-test.adyen.com/bcl/v2

## Parameters

### Query parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| cursor | string | No | The pagination cursor returned in a previous GET `/mandates` request. |
| paymentInstrumentId | string | No | The unique identifier of the payment instrument linked to the mandate. |
| balanceAccountId | string | No | The unique identifier of the balance account linked to the payment instrument. |

## Responses

### 200 Success
The request has succeeded

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| link | object | Yes | Contains links to the next and previous page whenever applicable. |
|   - first | object | No | The link to the first page of the list. |
|     - href | string | No |  |
|   - last | object | No | The link to the last page of the list. |
|     - href | string | No |  |
|   - next | object | No | The link to the next page of the list. |
|     - href | string | No |  |
|   - previous | object | No | The link to the previous page of the list. |
|     - href | string | No |  |
|   - self | object | No | The link to the list page you are currently viewing. |
|     - href | string | No |  |
| mandates | array of object | Yes | Contains a list of the mandates. |
|   - balanceAccountId | string | No | The unique identifier of the balance account linked to the payment instrument. |
|   - counterparty | object | No | Contains information to identify the counterparty. |
|     - accountHolder | object | Yes | Contains information about the owner of the counterparty bank account. |
|     - accountIdentification | object | Yes | Contains the bank account details of the counterparty. The fields required in this object depend on the country of the bank account and the currency of the transfer. |
|   - createdAt | string | No | The date when the mandate was created. |
|   - id | string | No | The unique identifier of the mandate. |
|   - paymentInstrumentId | string | No | The unique identifier of the payment instrument linked to the mandate. |
|   - status | string | No | The status of the mandate.  Possible values: **pending**, **approved**, **cancelled**. |
|   - type | string | No | The type of mandate. Possible value: **bacs**. |
|   - updatedAt | string | No | The date when the mandate was updated. |
