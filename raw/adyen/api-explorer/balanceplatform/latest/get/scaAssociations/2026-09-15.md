# GET /scaAssociations - Get a list of devices associated with an entity

Returns a paginated list of the SCA devices associated with a specific entity.

## Servers
- https://balanceplatform-api-test.adyen.com/bcl/v2

## Parameters

### Query parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| pageNumber | integer | Yes | The index of the page to retrieve. The index of the first page is **0** (zero).  Default:  **0**. |
| pageSize | integer | Yes | The number of items to have on a page.  Default: **5**. |
| entityId | string | Yes | The unique identifier of the entity. |
| entityType | string | Yes | The type of entity you want to retrieve a list of associations for.  Possible values: **accountHolder**, **legalEntity** or **paymentInstrument**. |
