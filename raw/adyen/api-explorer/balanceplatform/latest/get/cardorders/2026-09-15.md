# GET /cardorders - Get a list of card orders

Returns a paginated list of card orders.

## Servers
- https://balanceplatform-api-test.adyen.com/bcl/v2

## Parameters

### Query parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| limit | integer | No | The number of card orders returned per page. **Default:** 10. |
| offset | integer | No | Specifies the position of an element in a list of card orders. The response includes a list of card orders that starts at the specified offset.  **Default:** 0, which means that the response contains all the elements in the list of card orders. |
| serviceCenter | string | No | The service center at which the card is issued. The value is case-sensitive. |
| lockedUntil | string | No | Only include card orders that have been locked on or before this point in time. The value must be in ISO 8601 format. For example, **2021-05-30T15:07:40Z**. |
| lockedSince | string | No | Only include card orders that have been locked on or after this point in time. The value must be in ISO 8601 format. For example, **2021-05-30T15:07:40Z**. |
| createdUntil | string | No | Only include card orders that have been created on or before this point in time. The value must be in ISO 8601 format. For example, **2021-05-30T15:07:40Z**. |
| createdSince | string | No | Only include card orders that have been created on or after this point in time. The value must be in ISO 8601 format. For example, **2021-05-30T15:07:40Z**. |
| txVariantCode | string | No | The unique code of the card manufacturer profile.  Possible values: **mcmaestro**, **mc**, **visa**, **mcdebit**. |
| status | string | No | The status of the card order. |
| cardManufacturingProfileId | string | No | The unique identifier of the card manufacturer profile. |
| id | string | No | The unique identifier of the card order. |

## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| cardOrders | array of object | No | Contains objects with information about card orders. |
|   - beginDate | string | No | The date when the card order is created. |
|   - cardManufacturingProfileId | string | No | The unique identifier of the card manufacturer profile. |
|   - closedDate | string | No | The date when the card order processing ends. |
|   - endDate | string | No | The date when you manually closed the card order.  Card orders are automatically closed by the end of the day it was created. If you manually closed it beforehand, the closing date is shown as the `endDate`. |
|   - id | string | No | The unique identifier of the card order. |
|   - lockDate | string | No | The date when the card order processing begins. |
|   - serviceCenter | string | No | The service center. |
|   - status | string | No | The status of the card order.  Possible values: **Open**, **Closed**. |
| hasNext | boolean | Yes | Indicates whether there are more items on the next page. |
| hasPrevious | boolean | Yes | Indicates whether there are more items on the previous page. |
