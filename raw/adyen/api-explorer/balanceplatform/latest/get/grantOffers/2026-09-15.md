# GET /grantOffers - Get all available grant offers

Returns a list of all [grant offers](https://docs.adyen.com/platforms/capital#grant-offers) available for `accountHolderId` specified as a query parameter.

## Servers
- https://balanceplatform-api-test.adyen.com/bcl/v2

## Parameters

### Query parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| accountHolderId | string | Yes | The unique identifier of the grant account. |

## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| grantOffers | array of object | Yes | A list of available grant offers. |
|   - accountHolderId | string | Yes | The identifier of the account holder to which the grant is offered. |
|   - amount | object | No | The principal amount of the grant. |
|     - currency | string | Yes | The three-character [ISO currency code](https://docs.adyen.com/development-resources/currency-codes#currency-codes) of the amount. |
|     - value | integer | Yes | The numeric value of the amount, in [minor units](https://docs.adyen.com/development-resources/currency-codes#minor-units). |
|   - contractType | string | No | The contract type of the grant offer. Possible value: **cashAdvance**, **loan**. |
|   - expiresAt | string | No | The end date of the grant offer validity period. |
|   - fee | object | No | Details of the fee configuration. |
|     - amount | object | Yes | Contains the fee amount. |
|   - id | string | No | The unique identifier of the grant offer. |
|   - repayment | object | No | Details of the repayment configuration. |
|     - basisPoints | integer | Yes | The repayment that is deducted daily from incoming net volume, in [basis points](https://www.investopedia.com/terms/b/basispoint.asp). |
|     - term | object | No | An object containing the details of the configuration for repayment term. |
|     - threshold | object | No | An object containing the details of the 30-day repayment threshold. |
|   - startsAt | string | No | The starting date of the grant offer validity period. |
