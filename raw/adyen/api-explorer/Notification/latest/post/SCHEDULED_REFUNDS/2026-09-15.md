# POST /SCHEDULED_REFUNDS - 'Refund Transfers Not Paid Out' call processed and refunds scheduled

Adyen sends this notification when a request to [refund transfers that are not yet paid out](https://docs.adyen.com/api-explorer/#/Fund/latest/refundNotPaidOutTransfers) is processed and the associated refunds are scheduled.

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| content | object | No | Details of the scheduling of the refunds. |
|   - accountCode | string | No | The code of the account. |
|   - accountHolderCode | string | No | The code of the Account Holder. |
|   - invalidFields | array of object | No | Invalid fields list. |
|     - errorCode | integer | No | The validation error code. |
|     - errorDescription | string | No | A description of the validation error. |
|     - fieldType | object | No | The type of error field. |
|   - lastPayout | object | No | The most recent payout (after which all transactions were scheduled to be refunded). |
|     - amount | object | No | The amount of the transaction. |
|     - bankAccountDetail | object | No | The details of the bank account to where a payout was made. |
|     - captureMerchantReference | string | No | The merchant reference of a related capture. |
|     - capturePspReference | string | No | The psp reference of a related capture. |
|     - creationDate | string | No | The date on which the transaction was performed. |
|     - description | string | No | A description of the transaction. |
|     - destinationAccountCode | string | No | The code of the account to which funds were credited during an outgoing fund transfer. |
|     - disputePspReference | string | No | The psp reference of the related dispute. |
|     - disputeReasonCode | string | No | The reason code of a dispute. |
|     - merchantReference | string | No | The merchant reference of a transaction. |
|     - paymentPspReference | string | No | The psp reference of the related authorisation or transfer. |
|     - payoutPspReference | string | No | The psp reference of the related payout. |
|     - pspReference | string | No | The psp reference of a transaction. |
|     - sourceAccountCode | string | No | The code of the account from which funds were debited during an incoming fund transfer. |
|     - transactionStatus | string | No | The status of the transaction.  Permitted values: `PendingCredit`, `CreditFailed`, `CreditClosed`, `CreditSuspended`, `Credited`, `Converted`, `PendingDebit`, `DebitFailed`, `Debited`, `DebitReversedReceived`, `DebitedReversed`, `ChargebackReceived`, `Chargeback`, `ChargebackReversedReceived`, `ChargebackReversed`, `Payout`, `PayoutReversed`, `FundTransfer`, `PendingFundTransfer`, `ManualCorrected`. |
|     - transferCode | string | No | The transfer code of the transaction. |
|   - refundResults | array of object | No | A list of the refunds that have been scheduled and their results. |
|     - originalTransaction | object | No | The transaction that has been refunded. |
|     - pspReference | string | No | The reference of the refund. |
|     - response | string | No | The response indicating if the refund has been received for processing. |
| error | object | No | Error information of failed request. No value provided here if no error occurred on processing. |
|   - errorCode | string | No | The Adyen code that is mapped to the error message. |
|   - message | string | No | A short explanation of the issue. |
| eventDate | string | Yes | The date and time when an event has been completed. |
| eventType | string | Yes | The event type of the notification. |
| executingUserKey | string | Yes | The user or process that has triggered the notification. |
| live | boolean | Yes | Indicates whether the notification originated from the live environment or the test environment. If true, the notification originated from the live environment. If false, the notification originated from the test environment. |
| pspReference | string | Yes | The PSP reference of the request from which the notification originates. |

The request has succeeded.

**Response body**

|------|------|----------|-------------|
| notificationResponse | string | No | Set this parameter to **[accepted]** to acknowledge that you received a notification from Adyen. |
