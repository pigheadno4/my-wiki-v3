# POST /PAYMENT_FAILURE - Booking for a capture or refund failed

Adyen sends this notification when a [split payment](https://docs.adyen.com/classic-platforms/processing-payments#providing-split-information) booking for a capture or refund fails. When a booking fails due to an invalid account status or an unknown `accountCode`, the funds are credited or debited to or fromyour platform's liable account instead of the account specified in the split data.

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| content | object | No | The details of the payment failure. |
|   - errorFields | array of object | No | Missing or invalid fields that caused the payment error. |
|     - errorCode | integer | No | The validation error code. |
|     - errorDescription | string | No | A description of the validation error. |
|     - fieldType | object | No | The type of error field. |
|   - errorMessage | object | No | The error message. |
|     - code | string | No | The message code. |
|     - text | string | No | The message text. |
|   - modificationMerchantReference | string | No | The `reference` of the capture or refund. |
|   - modificationPspReference | string | No | The `pspReference` of the capture or refund. |
|   - paymentMerchantReference | string | No | The `reference` of the payment. |
|   - paymentPspReference | string | No | The `pspReference` of the payment. |
| error | object | No | Error information of failed request. No value provided here if no error occurred on processing. |
|   - errorCode | string | No | The Adyen code that is mapped to the error message. |
|   - message | string | No | A short explanation of the issue. |
| eventDate | string | Yes | The date and time when an event has been completed. |
| eventType | string | Yes | The event type of the notification. |
| executingUserKey | string | Yes | The user or process that has triggered the notification. |
| live | boolean | Yes | Indicates whether the notification originated from the live environment or the test environment. If true, the notification originated from the live environment. If false, the notification originated from the test environment. |
| pspReference | string | Yes | The PSP reference of the request from which the notification originates. |
