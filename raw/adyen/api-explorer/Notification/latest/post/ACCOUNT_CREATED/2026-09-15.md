# POST /ACCOUNT_CREATED - Account created

Adyen sends this webhook when [an account is created](https://docs.adyen.com/api-explorer/#/Account/latest/post/createAccount).

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| content | object | No | The details of the account creation. |
|   - accountCode | string | No | The code of the new account. |
|   - accountHolderCode | string | No | The code of the account holder. |
|   - bankAccountUUID | string | No | The bankAccountUUID of the bank account held by the account holder to couple the account with. Scheduled payouts in currencies matching the currency of this bank account will be sent to this bank account. Payouts in different currencies will be sent to a matching bank account of the account holder. |
|   - description | string | No | The description of the account. |
|   - invalidFields | array of object | No | A list of fields that caused the `/createAccount` request to fail. |
|     - errorCode | integer | No | The validation error code. |
|     - errorDescription | string | No | A description of the validation error. |
|     - fieldType | object | No | The type of error field. |
|   - metadata | object (string) | No | A set of key and value pairs containing metadata. |
|   - payoutMethodCode | string | No | The payout method code held by the account holder to couple the account with. Scheduled card payouts will be sent using this payout method code. |
|   - payoutSchedule | object | No | The details of the payout schedule added to the account. |
|     - nextScheduledPayout | string | No | The date of the next scheduled payout. |
|     - schedule | string | No | The payout schedule for the account.  Possible values: `DEFAULT`, `DAILY`, `DAILY_US`, `DAILY_EU`, `DAILY_AU`, `DAILY_SG`, `WEEKLY`, `WEEKLY_ON_TUE_FRI_MIDNIGHT`, `BIWEEKLY_ON_1ST_AND_15TH_AT_MIDNIGHT`, `MONTHLY`, `HOLD`.  `HOLD` prevents scheduled payouts, but you can still initiate payouts manually. |
|   - payoutSpeed | string | No | Speed with which payouts for this account are processed. Permitted values: `STANDARD`, `SAME_DAY`. |
|   - pspReference | string | No | The reference of a request. Can be used to uniquely identify the request. |
|   - resultCode | string | No | The result code. |
|   - status | string | No | The status of the account.  Permitted values: `Active`. |
| error | object | No | Error information of failed request. No value provided here if no error occurred on processing. |
|   - errorCode | string | No | The Adyen code that is mapped to the error message. |
|   - message | string | No | A short explanation of the issue. |
| eventDate | string | Yes | The date and time when an event has been completed. |
| eventType | string | Yes | The event type of the notification. |
| executingUserKey | string | Yes | The user or process that has triggered the notification. |
| live | boolean | Yes | Indicates whether the notification originated from the live environment or the test environment. If true, the notification originated from the live environment. If false, the notification originated from the test environment. |
| pspReference | string | Yes | The PSP reference of the request from which the notification originates. |

## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| notificationResponse | string | No | Set this parameter to **[accepted]** to acknowledge that you received a notification from Adyen. |
