# POST paymentMethodRequest.removed - Payment method request removed

A request to add a payment method is removed. You must make another request to [add a payment method](https://docs.adyen.com/api-explorer/Management/latest/post/merchants/_merchantId_/paymentMethodSettings).

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| createdAt | string | Yes | Timestamp for when the webhook was created. |
| data | object | Yes | Contains event details. |
|   - allowed | boolean | No | Indicates whether receiving payments is allowed. This value is set to **true** by Adyen after screening your merchant account. |
|   - enabled | boolean | No | Indicates whether the payment method is enabled (**true**) or disabled (**false**). |
|   - id | string | Yes | The unique identifier of the resource. |
|   - merchantId | string | Yes | The unique identifier of the merchant account. |
|   - reference | string | No | Your reference for the payment method. |
|   - status | string | Yes | The status of the request to add a payment method. Possible values:  - **success**: the payment method was added.  - **failure**: the request failed.  - **capabilityPending**: the **receivePayments** capability is not allowed. |
|   - storeId | string | No | The unique identifier of the [store](https://docs.adyen.com/api-explorer/#/ManagementService/latest/post/merchants/%7Bid%7D/paymentMethodSettings__reqParam_storeId), if any. |
|   - type | string | Yes | Payment method [variant](https://docs.adyen.com/development-resources/paymentmethodvariant#management-api). |
|   - verificationStatus | string | No | Payment method status. Possible values:  - **valid**  - **pending**  - **invalid**  - **rejected** |
| environment | string | Yes | The environment from which the webhook originated.  Possible values: **test**, **live**. |
| type | string | Yes | Type of notification. |

## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| notificationResponse | string | No | Respond with any **2xx** HTTP status code to [accept the webhook](https://docs.adyen.com/development-resources/webhooks/#accept-webhooks). |
