# POST terminalSettings.modified - Terminal settings updated

A request to [update terminal settings](https://docs.adyen.com/api-explorer/Management/latest/patch/terminals/(terminalId)/terminalSettings) was completed.

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| createdAt | string | Yes | Timestamp for when the webhook was created. |
| data | object | Yes | Contains event details. |
|   - companyId | string | No | The unique identifier of the company account. |
|   - merchantId | string | No | The unique identifier of the merchant account. |
|   - storeId | string | No | The unique identifier of the store. |
|   - terminalId | string | No | The unique identifier of the terminal. |
|   - updateSource | string | Yes | Indicates whether the terminal settings were updated using the Customer Area or the Management API. |
|   - user | string | Yes | The user that updated the terminal settings. Can be Adyen or your API credential username. |
| environment | string | Yes | The environment from which the webhook originated.  Possible values: **test**, **live**. |
| type | string | Yes | Type of notification. |

## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| notificationResponse | string | No | Respond with any **2xx** HTTP status code to [accept the webhook](https://docs.adyen.com/development-resources/webhooks/#accept-webhooks). |
