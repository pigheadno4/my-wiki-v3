# POST terminalAssignment.completed - Terminal assignment completed

A request to [reassign a terminal](https://docs.adyen.com/api-explorer/Management/3/post/terminals/(terminalId)/reassign) was completed.

## Parameters

### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| assignedToAccount | string | Yes | The unique identifier of the merchant/company account to which the terminal is assigned. |
| assignedToStore | string | No | The store that the terminal is assigned to, identified by the store reference (also known as store code). |
| assignedToStoreId | string | No | The unique identifier of the store to which the terminal is assigned. |
| eventDate | string | Yes | The date and time when an event has been completed. |
| pspReference | string | Yes | The PSP reference of the request from which the notification originates. |
| uniqueTerminalId | string | Yes | The unique identifier of the terminal. |

## Responses

### 200 Success
The request has succeeded.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| notificationResponse | string | No | Respond with any **2xx** HTTP status code to [accept the webhook](https://docs.adyen.com/development-resources/webhooks/#accept-webhooks). |
