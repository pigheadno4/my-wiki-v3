# MOTO payments through Customer Area

Use Virtual Terminal to accept Mail Order/Telephone Order (MOTO) payments.

Your [Customer Area](https://ca-test.adyen.com/) includes the Virtual Terminal user interface that you can use to accept Mail Order/Telephone Order (MOTO) payments. For example, when a shopper calls your call center, you enter the shopper's card details in Virtual Terminal and make a payment.

## Requirements

| Requirement                                     | Description                                                                                      |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| **[Customer Area roles](/account/user-roles)**  | Make sure that you have the following role:- **Create payments from virtual terminal in the CA** |
| **[Webhooks](/development-resources/webhooks)** | Subscribe to the following webhook:- **Standard webhook**                                        |

## Make a payment

To make a payment in Virtual Terminal:

1. In your [Customer Area](https://ca-test.adyen.com/), select the merchant account to use for the payment.
2. Go to **Virtual Terminal**.
3. Under **Store selection**, select the store to process a payment for.
4. On the following pages, fill in the fields for shopper information and payment details.
5. Submit the payment.\
   You get a confirmation page for the transaction that shows if it was successful.

### Payment form

The Virtual Terminal transaction details form includes the fields that you can fill in with shopper information and payment details.

The following fields are always mandatory:

* Amount
* Merchant reference
* Country/Region

Some industries have additional fields. For example, if the [Merchant Category Code (MCC)](/get-started-with-adyen/adyen-glossary/#merchant-category-code) associated with your account indicates that you are in the airline industry, you get fields that are related to airline transactions.

## Test and go live

Test that Virtual Terminal payments work as expected:

1. In your [test Customer Area](https://ca-test.adyen.com/), go to Virtual Terminal and make a payment with [test card details](/development-resources/test-cards-and-credentials/test-card-numbers/).
2. Make sure that the test payment shows up on the list of payments in your Customer Area.
3. Get the **AUTHORISATION** webhook on your server.

Before you go live, make sure of the following:

* The fields on the Virtual Terminal payment form meet your business requirements.
* You have submitted the Self Assessment Questionnaire C-VT (SAQ C-VT) for PCI DSS compliance. Reach out to your Adyen contact to get this form.
* Your Customer Area users know how to use the Virtual Terminal user interface.

Use the Virtual Terminal in your [live Customer Area](https://ca-live.adyen.com/) to make live MOTO payments.
