# Platform reports

Learn where to find reports for your platform or marketplace.

For [platforms](/platforms) and [marketplaces](/marketplaces), there are various Adyen-generated reports that help you check balances, reconcile payments, track transfers, and reconcile fees. You need to use these platform reports in addition to specific payment processing reports.

See the [Adyen for Platforms documentation](/adyen-for-platforms-model/) to learn more about:

* Reports and fee types
* Preparing the reports
* Common reconciliation processes
* Balance Platform Accounting Report
* Balance Platform Balance Report

The above information is for new Adyen for Platforms integrations. If you are using our classic integration, instead refer to the [Classic platforms documentation](/classic-platforms) to read about:

* Classic integration reporting overview
* Marketplace payments accounting report
* Marketpay balance report
* Marketpay payout report
