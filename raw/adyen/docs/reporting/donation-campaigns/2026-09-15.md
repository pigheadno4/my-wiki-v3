# Donation campaigns

Get insights on your donation campaigns using our dashboard and report.

##### Read more

![](/user/pages/docs/11.reporting/17.donation-campaigns/giving.svg?decoding=auto\&fetchpriority=auto) Learn more about [Adyen Giving on adyen.com](https://www.adyen.com/giving).

When processing donations with Adyen Giving, you can monitor, analyze, share insights, and optimize the impact of donations. You can use the [Campaign dashboard](#campaign-insights) and generate the [Processed Donations Report](#processed-donations-report) to find detailed information on the performance of your donation campaigns.

If you are a nonprofit that is receiving donations, you can generate the [Received Donations Report](#received-donations-report) to get an overview of the donations that you received raised by each [Adyen company account](/account/account-structure/).

## Prerequisites

To view the report and the dashboard, you must first set up donation campaigns. See the instructions for campaign creation and management for [online payments](/online-payments/donations), [in-person payments](/point-of-sale/donate), or [platforms payments](/platforms/donations).

The following table shows which Customer Area [user roles](/account/user-roles) are required for which actions:

| User actions                                                                        | User roles                 |
| ----------------------------------------------------------------------------------- | -------------------------- |
| View campaigns, access campaign insights, and generate Processed Donations Report   | Donation Campaigns Viewer  |
| Manage campaigns, access campaign insights, and generate Processed Donations Report | Donation Campaigns Manager |
| Generate Received Donations Report                                                  | Merchant financial         |

These user roles do not give access to any other payment information.

## Campaign insights dashboard

Each active or past campaign has its own Campaign insights dashboard that shows its performance. It shows online and in-store performance, and includes a breakdown per shopper location.

The information on the dashboard is not real-time. It can take up to four hours for a donation to show up on the dashboard. For real-time information, we recommend that you [listen to **DONATION** webhooks](/development-resources/webhooks/webhook-types/#other-webhooks).

In your [Customer Area](https://ca-live.adyen.com/):

1. Go to **Giving** > **Campaigns**.
2. In the box for the specific campaign, select **See campaign insights**.

You can filter the data in the dashboard. For example, you can filter by the following:

* Date range
* Processing currency
* Merchant account
* Shopper location
* Donation channel

## Processed Donations Report

The Processed Donations Report gives you a granular perspective on donations. This report is a line-item report of individual processed donations from your account, allowing you to analyze and report on all donation activity on your account.

You can download the report in the following formats:

* Comma-Separated Values (`.CSV`)
* Excel (`.XLS` or `.XLSX`)

### Report generation and availability

**Generating and downloading**: Get this report [manually](/reporting/manually-get-reports) or [automatically](/reporting/automatically-get-reports).

**Time zone**: The [time zone setting](/reporting/time-zone-setting) of your account.

**Date range**: Select the date range of data included when you generate the report in your [Customer Area](https://ca-test.adyen.com/).

**Availability**: Only available for [company accounts](/account/account-structure#company-account).

### Report structure

#### Entries

Under the header line, each line in the report is a separate entry.

Each entry is a line-item that represents a single donation settled to the nonprofit. No data is aggregated in this report.

#### Columns

Each column shows specific information about the entries.

##### Standard columns

|    | Column name              | Description                                                                                                                                                         |
| -- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1  | Company account          | The name of the company account from which the donation was offered.                                                                                                |
| 2  | Merchant account         | The name of the merchant account from which the donation was offered.                                                                                               |
| 3  | Store ID                 | For in-person donations, the [store reference](/point-of-sale/design-your-integration/determine-account-structure/automate-store-management/#store-identification). |
| 4  | Terminal number          | For in-person donations, the [unique terminal identifier](/point-of-sale/design-your-integration/terminal-api/#get-the-terminal-id).                                |
| 5  | Donation account         | The nonprofit account to which the donation was settled. (Only for Giving integrations not using Campaign Manager.)                                                 |
| 6  | Campaign name            | The name of the campaign.                                                                                                                                           |
| 7  | Campaign ID              | The unique identifier of the campaign.                                                                                                                              |
| 8  | Nonprofit name           | The name of the nonprofit.                                                                                                                                          |
| 9  | Cause name               | The name of the donation cause.                                                                                                                                     |
| 10 | Donation origin country  | The country where the shopper made the donation from. In-person payments: the store country. Online payments: the shopper's IP address.                             |
| 11 | PSP reference            | Our unique reference for the donation.                                                                                                                              |
| 12 | Payment method           | The payment method used to donate.                                                                                                                                  |
| 13 | Creation date (AMS time) | The timestamp of the donation in the [CET time zone](https://en.wikipedia.org/wiki/Central_European_Time).                                                          |
| 14 | Donation channel         | The donation channel. Possible values: **Instore** or **Ecommerce**                                                                                                 |
| 15 | Type                     | The type of donation settlement.                                                                                                                                    |
| 16 | Currency                 | The currency used to process the donation.                                                                                                                          |
| 17 | Amount                   | The donation amount, in the donation currency.                                                                                                                      |
| 18 | Account holder           | The code of the account holder that offered the donation. Only available for [account holder campaigns](https://docs.adyen.com/platforms/donations).                |

##### Configurable columns

You can include or exclude some columns from your reports, and specify the order they should appear in. Configure these columns in your [Customer Area](https://ca-live.adyen.com/) at **Settings** > **Report columns**.

|   | Column name                          | Description                                                                                                                                                         |
| - | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1 | Commercial transaction PSP reference | The PSP reference of the original payment transaction that triggered the donation. Use this to link a donation back to the shopper's underlying commercial payment. |
| 2 | Merchant reference                   | The reference set by the merchant for the donation transaction.                                                                                                     |
| 3 | Merchant timezone                    | The time zone of the merchant account. Use this to interpret the Creation date (merchant time) column.                                                              |
| 4 | Creation date (merchant time)        | The timestamp of the donation in the merchant account's local time zone.                                                                                            |

## Received Donations Report

The Received Donations Report can only be generated and viewed by nonprofits.

The Received Donations Report is an aggregated overview of the donation amounts that were paid out to you. You can use this report to reconcile the funds raised by donation campaigns by each Adyen company account and the countries/regions from where the donations were received.

You can download it in the following formats:

* Comma-Separated Values (`.CSV`)
* Excel (`.XLS` or `.XLSX`)

### Report generation and availability

**Generating and downloading**: Get this report [manually](/reporting/manually-get-reports) or [automatically](/reporting/automatically-get-reports).

**Time zone**: The [time zone setting](/reporting/time-zone-setting) of your account.

**Date range**: Select the date range of data included when you generate the report in your [Customer Area](https://ca-test.adyen.com/).

**Availability**: Only available for [company accounts](/account/account-structure#company-account).

### Report structure

#### Entries

Under the header line, each line in the report is a separate entry.

Each entry is a line-item that summarizes donation data grouped by donation attributes.

#### Columns

Each column shows specific information about the entries.

##### Standard columns

|    | Column name             | Description                                                                                                                                                                                            |
| -- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1  | Company account         | The name of the company account from which the donation was offered.                                                                                                                                   |
| 2  | Donation origin country | The country from which the shopper made the donation. In-person payments: the store country. Online payments: the shopper's IP address.                                                                |
| 3  | Type                    | The [journal type](/reporting/settlement-reconciliation/transaction-level/settlement-details-report/#journal-types) of the donation settlement.                                                        |
| 4  | Total count             | The total count of transactions in the line-item that summarizes donations grouped by donation attributes.                                                                                             |
| 5  | Gross Currency          | The three-character [ISO currency code](https://en.wikipedia.org/wiki/ISO_4217) for the currency in which the donation transaction was initiated.                                                      |
| 6  | Gross Credit            | The amount received in the original donation currency.                                                                                                                                                 |
| 7  | Gross Debit             | The amount debited in the original donation transaction currency.                                                                                                                                      |
| 8  | Exchange Rate           | The exchange rate used for converting the gross amount into the net amount. This will be 1 if the currency used to initiate the donation transaction is the same as the currency you settle donations. |
| 9  | Net Currency            | The three-character [ISO currency code](https://en.wikipedia.org/wiki/ISO_4217) for the settlement currency.                                                                                           |
| 10 | Net Credit              | The amount submitted in the donation transaction request minus transaction costs and fees.                                                                                                             |
| 11 | Net Debit               | The amount debited in the donation settlement currency.                                                                                                                                                |

## Configure report columns

If you want to add additional columns or change the order of columns in a report, you can do so in the [Customer Area](https://ca-test.adyen.com/). If you have an automated system that uses the report's data, configuring the report columns can affect your automated system.

To configure report columns, you need to have one of the following [user roles](/account/user-roles):

* Merchant admin
* Merchant report role
* Merchant financial
* Merchant POS Report role

To configure report columns:

1. Log in to your [Customer Area](https://ca-test.adyen.com/).
2. Go to **Settings** > **Report columns**.\
   This opens a page with all the reports that you can configure.
3. Find the report that you want to configure and select **Configure**.
4. Select checkboxes to indicate which columns you want to include in the report.
5. Drag the columns into the order you want them to appear in.
6. Select **Save configuration**.
