# Plugins

Connect your existing commerce system to our payments platform.

To learn more about the system integrators and plugin partners we work with, check the full list on our [Partner Directory](https://www.adyen.com/partners/network).

A plugin is a pre-built integration that comes with Adyen payments platform functionality delivered out of the box. Our plugins are easy to integrate with and reduce the effort required to start processing payments with Adyen on leading technology platforms.

We offer a range of plugins that enables you to process online and in-person payments with Adyen on your existing commerce system. To learn more about the features supported per plugin, refer to the plugin-specific documentation. For some plugins, you can customize your integration to extend the functionality when an Adyen feature is not supported by a plugin.
