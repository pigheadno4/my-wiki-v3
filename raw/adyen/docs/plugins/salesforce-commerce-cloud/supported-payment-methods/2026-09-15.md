# Supported payment methods

Learn what payment methods are supported by our cartridge.

The list on this page shows the payment methods that are supported for each Salesforce Commerce Cloud storefront type. The **Version** column indicates the version from which the payment method is supported.

To see the countries/regions, and features that each payment method supports:

* For Storefront Reference Architecture (SFRA), check the [payment methods overview filtered by Web Components](/payment-methods).
* For Composable Storefront, check the [payment methods overview filtered by Web Drop-in](/payment-methods/?supported_integrations%5B0%5D=web%20drop-in).

If you want a new payment method to be added in one of our plugins, open an issue on [GitHub](https://github.com/Adyen/adyen-salesforce-commerce-cloud/issues).

## Add payment methods to your account

You can request payment methods to be added to your merchant account in your [test Customer Area](https://ca-test.adyen.com/) or [live Customer Area](https://ca-live.adyen.com/).

1. In your Customer Area, switch to your merchant account.
2. Go to **Payments** > **Payment methods**.
3. Select **Request payment methods** to view all available payment methods.
4. Use the dropdown lists to filter payment methods by location and type.
5. Select the payment method(s) you want to request for your merchant account.
6. Select **Add**.
7. Apply the payment method(s) to **This merchant account**.
8. If prompted, fill in the required information.
9. Review your requests.
10. Select **Submit request**.
