# Salesforce Commerce Cloud - B2C Commerce

Use Adyen as your payments processor online, in-app, and in-store for your Salesforce store.

![](/user/pages/docs/05.plugins/05.salesforce-commerce-cloud/salesforce_logo.svg?decoding=auto\&fetchpriority=auto)  **Read more**

Learn more about [Salesforce Commerce Cloud](https://www.adyen.com/partners/salesforce-commerce-cloud-and-quick-launch) in our Partner Directory.

There are two ways to integrate with Adyen as the payment processor for your [Salesforce Commerce Cloud (SFCC)](https://www.salesforce.com/products/commerce-cloud/ecommerce/) ecommerce site, depending on your storefront type:

* **Storefront Reference Architecture (SFRA)**:\
  The [Adyen payments cartridge](https://appexchange.salesforce.com/appxListingDetail?listingId=a0N3A00000FMdTNUA1) is a payment solution that gives you access to the features of the Adyen platform and requires minimal integration effort to start accepting payments. The cartridge uses the [Adyen Web Components](/online-payments/build-your-integration/sessions-flow/?platform=Web\&integration=Components) to show payment methods.
* **Composable Storefront (Headless)**:\
  The [Adyen payments npm package](https://www.npmjs.com/package/@adyen/adyen-salesforce-pwa) is a packaged integration that gives you access to the features of the Adyen platform and enables you to build custom shopping experiences for sites built with the [Salesforce Progressive Web Application (PWA) Kit](https://developer.salesforce.com/docs/commerce/pwa-kit-managed-runtime/guide/pwa-kit-overview.html). The package uses the [Adyen Web Drop-in](/online-payments/build-your-integration/sessions-flow?platform=Web\&integration=Drop-in) to show payment methods.

## Features

The Composable Storefront integration is the latest addition to our Salesforce packages, and we are working on the feature parity between the integrations. The Composable Storefront integration is flexible and lets you [customize features and functionality](/plugins/salesforce-commerce-cloud/composable-storefront/customization-guide) easily.

We no longer develop new features for our SiteGenesis cartridge.

## Support levels

The support schedule that applies to you depends on your integration type.

We provide three levels of cartridge/package support for major versions:

* **Level 1**: Full cartridge/package support.
* **Level 2**: High priority cartridge/package bug fixes and security updates.
* **Level 3**: Cartridge/Package security updates only.

After Level 3 support ends, your cartridge or package reaches end of support.
