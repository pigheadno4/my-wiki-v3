# Upgrade the package

Upgrade the package for your Composable Storefront integration.

We recommend that you upgrade when we have a major release, such as v2.x.x. You can find the latest version on our [npm repository](https://www.npmjs.com/package/@adyen/adyen-salesforce-pwa?activeTab=readme) and in our [release notes](/plugins/release-notes).

1. In the `package.json` file of your Retail React app, locate `"dependencies"`. This field shows the version of your package, for example:
   ```json
   "dependencies": {
     "@adyen/adyen-salesforce-pwa": "1.0.0"
   }
   ```
2. Change the version value to the version number you want to upgrade to. For example, if you want to upgrade to version 2.0.0:
   ```json
   "dependencies": {
     "@adyen/adyen-salesforce-pwa": "2.0.0"
   }
   ```
3. Install the new version:
   ```js
   npm install
   ```
4. Build your app with the new version:
   ```js
   npm install
   ```
5. Follow the [steps to deploy your app to MRT](/plugins/salesforce-commerce-cloud/composable-storefront/install-and-set-up-the-package#deploy-to-MRT) to deploy the new version.
