# Storefront Reference Architecture (SFRA)

Use our cartridge for SFRA to accept payments in your Salesforce store.

The [Adyen payments cartridge](https://appexchange.salesforce.com/appxListingDetail?listingId=a0N3A00000FMdTNUA1) is a full payment solution for your [Salesforce Commerce Cloud SFRA](https://www.salesforce.com/products/commerce/) site. With one integration, you get access to all features of the Adyen payments platform, including all global and preferred local payment methods, recurring payments, risk management, and conversion optimization.

Adyen is certified as an official [Quick Start solution for Salesforce Commerce Cloud B2C Commerce](https://www.salesforce.com/eu/campaign/quick-start-commerce-solutions/), reducing training and implementation time for the SFRA storefronts.

Our cartridge is built using the [Adyen Web Components](/online-payments/build-your-integration/sessions-flow/?platform=Web\&integration=Components).

## Supported versions

This documentation reflects the latest version of the cartridge. You can find the latest version on [GitHub](https://github.com/Adyen/adyen-salesforce-commerce-cloud).

Our plugin supports:

* SFRA versions 5, 6, and 7
* Node v14 or later

We may be unable to provide support if you are not using the default checkout. We do not recommend customizing the plugin, because this could make it harder to upgrade and maintain your integration.\
If you decide to customize your integration, we recommend that you:

* Keep track of the custom code added to your integration.
* Create an issue on [GitHub](https://github.com/Adyen/adyen-salesforce-commerce-cloud) if you want to suggest a new feature for the plugin.
* Follow the customization best practices outlined in our [Customization guide](/plugins/salesforce-commerce-cloud/sfra/customization-guide).

## Get started

Before you begin to integrate, make sure you have followed the [Get started with Adyen guide](/get-started-with-adyen) to:

* Get an overview of the steps needed to accept live payments.
* Create your test account.

While you wait for your live account credentials, you can start integrating by using your test account:

1. [Install the cartridge and import the metadata](/plugins/salesforce-commerce-cloud/sfra/install-the-cartridge-and-import-the-metadata).
2. [Set up the cartridge](/plugins/salesforce-commerce-cloud/sfra/set-up-the-cartridge).
3. [Set up payment methods](/plugins/salesforce-commerce-cloud/sfra/set-up-payment-methods).
4. Optionally, [customize your integration](/plugins/salesforce-commerce-cloud/sfra/customization-guide).
5. Use our [test card numbers](/development-resources/testing) to make test payments.

Before going live, follow our [go-live checklist](/plugins/salesforce-commerce-cloud/sfra/go-live-checklist) to make sure you have got everything set up correctly.

If you experience any issues with your integration, follow our [troubleshooting guide](/plugins/salesforce-commerce-cloud/composable-storefront/).
