# Adyen NetSuite reconciliation bundle

Use our bank reconciliation solution to fully automate your bank reconciliation process.

The Adyen NetSuite reconciliation bundle allows you to automate your reconciliation process. The bundle pulls in an Adyen [Settlement Detail Report](/reporting/settlement-detail-report) (SDR), uses the [PSP reference](/get-started-with-adyen/adyen-glossary/#psp-reference) and record type to match to transactions in Netsuite, and then creates deposits to Netsuite accounts.

## Setup and installation

Before you start setting up the reconciliation bundle, make sure that you:

1. [Add your payout account and currency](/account/manage-payout-account-details#add).
2. [Subscribe to the Settlement Detail Report](/reporting/automatically-get-reports).

### Step 1: Install the Bundle

1. Log in to your NetSuite Customer Center.
2. Go to **Customization** > **SuiteBundler** > **Search & Install Bundles**.
3. Search for the **ADYEN - Bank Deposit Reconciliation** bundle (ID 226682).
4. Select the name of the bundle.\
   This opens the **Bundle Details** window.
5. Select **Install**.\
   This opens the **Preview Bundle Update** window.
6. Select **Install Bundle**.\
   The bundle installation may take a few minutes.

If no results show up when searching for the bundle, or if there is no **Install** button, then the bundle hasn't been shared with your account yet. Contact our [Support Team](https://ca-test.adyen.com/ca/ca/contactUs/support.shtml?form=other) and provide your NetSuite account number.

### Step 2: Create the Integration Settings record

1. Log in to your NetSuite Customer Center.

2. Go to **Setup** > **Integration** > **Adyen Integration Settings**.

3. Enter the following:

   * **Domain Prefix**: Enter either `ca-test` for testing or `ca-live` for production.
   * **Report User Name**: The name of your Adyen [API credential](/development-resources/api-credentials) for reporting. You can either [create a new one](/development-resources/api-credentials#new-credential) with type **Reporting**, or use your existing one. You can find this in your [Customer Area](https://ca-test.adyen.com/), under **Developers** > **API credentials**. The relevant API credential is of type **Reporting**.
   * **Report User Password**: The [basic authentication password](/development-resources/api-credentials#basic-authentication) for your Adyen API credential for reporting.

4. Select **Save**.

### Step 3: Set up SDR Profiles

1. Log in to your NetSuite Customer Center.
2. Go to **Transactions** > **Bank** > **Adyen SDR Profile** > **New**.
3. Fill in the [Adyen SDR Profile Fields](#sdr-profile).
4. Select **Save**.

### Create a new mapping

1. Select the **Settlement Type Map** drop-down, and then select **New**.\
   This opens a new **Adyen SDR Settlement Type Map** window.

2. Fill in the fields. Each field name corresponds to a matching column header on the Adyen [Settlement Detail Report](/reporting/settlement-detail-report) CSV file, and must be populated with the script ID of its counterpart on your NetSuite transactions.

   The following field names refer to possible values in the **Type** column from the [Adyen Settlement Detail Report CSV](/reporting/settlement-detail-report):

   * **SETTLED**
   * **REFUNDED**
   * **CHARGEBACK**
   * **REVERSED**

   Setting a saved search and PSP field ID for each of these types lets the bundle match lines with these types in the CSV to their corresponding transactions in NetSuite. The saved searches for each type should be left at their default values.

3. Select **Save** on the bottom of the page.

## Polling for new Settlement Detail Reports

Our solution is automated and runs in the background on a schedule. However you might sometimes want to manually start the process, for example due to employee schedules or end of month timelines.

To process outside of the normal schedule:

1. Log in to your NetSuite Customer Center.

2. Go to **Transactions** > **Bank** > **Adyen – Bank Deposit Rec – Control Panel**.

3. Follow the instructions on the screen to:

   * Poll & Receive New SDRs
   * Find SDR Detail Matches
   * Create Bank Deposits

## Check status

To view the status of your Settlement Detail Report:

1. Log in to your NetSuite Customer Center.
2. Go to **Transactions** > **Bank** > **Adyen Settlement Detail Report**.\
   This opens a list of all your Settlement Detail Reports, along with a status for each.

* If you see the `Pending Approval` status, select **Approve**. The reconciliation bundle status will change to `Creating Deposits`.
* If you see an error status, [troubleshoot](/plugins/netsuite/reconciliation-bundle/troubleshooting) the issue.

## Manually upload a Settlement Detail Report

In some cases, you may want to manually upload an SDR into NetSuite, for example when doing advanced testing.\
To manually upload an SDR:

1. Log in to your NetSuite Customer Center.
2. Go to **Transactions** > **Bank** > **Adyen - Bank Deposit Rec - Control Panel**.
3. Prepare an Adyen SDR as a CSV file. You can [download a sample report](/reporting/settlement-reconciliation/transaction-level/settlement-details-report#sample-report) for examples of the included data.
4. Drag and drop your CSV file to the **Manual import: Drag and drop your SDR CSV file here** field on the Control Panel.
