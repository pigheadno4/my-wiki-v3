# BLIK Drop-in integration

Add BLIK to an existing Android Drop-in integration.

This page explains how to add BLIK to your existing Android Drop-in integration.

This page is for **v5.0.0**, released in October 2023. If you are using an earlier version, use [the guide for earlier versions](/payment-methods/blik/android-drop-in/earlier-versions) instead.

## Requirements

Select the [server-side flow](/online-payments/build-your-integration) that your integration uses:

### Tab: Sessions flow

| Requirement          | Description                                                                                                                                                                                                      |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Integration type** | Make sure that you have built a Sessions flow [Android Drop-in integration](/online-payments/build-your-integration/sessions-flow?platform=Android\&integration=Drop-in). The minimum required version is 5.0.0. |
| **Setup steps**      | Before you begin, [add BLIK in your Customer Area](/payment-methods/add-payment-methods).                                                                                                                        |

### Tab: Advanced flow

| Requirement          | Description                                                                                                                                                                                                       |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Integration type** | Make sure that you have built an Advanced flow [Android Drop-in integration](/online-payments/build-your-integration/advanced-flow?platform=Android\&integration=Drop-in). The minimum required version is 5.0.0. |
| **Setup steps**      | Before you begin, [add BLIK in your Customer Area](/payment-methods/add-payment-methods).                                                                                                                         |

## API reference

### Tab: Sessions flow

When you [make the `/sessions` request](/online-payments/build-your-integration/sessions-flow?platform=Android\&integration=Drop-in#create-a-payment-session), BLIK does not require any additional fields.

### Tab: Advanced flow

When you [make the `/payments` request](/online-payments/build-your-integration/advanced-flow?platform=Android\&integration=Drop-in#make-a-payment), BLIK does not require any additional fields.

## Drop-in Configuration

### Tab: Sessions flow

When you [configure](/online-payments/build-your-integration/sessions-flow?platform=Android\&integration=Drop-in#configure) Drop-in, BLIK does not require any additional configuration.

### Tab: Advanced flow

When you [configure](/online-payments/build-your-integration/advanced-flow?platform=Android\&integration=Drop-in#configure) Drop-in, BLIK does not require any additional configuration.

### Tab: Sessions flow

After adding configuration to Drop-in, [create the checkout session](/online-payments/build-your-integration/sessions-flow?platform=Android\&integration=Drop-in#create-the-checkout-session).

### Tab: Advanced flow

After adding configuration, [launch and show Drop-in](/online-payments/build-your-integration/advanced-flow?platform=Android\&integration=Drop-in#launch-and-show).

## Test and go live

To test a BLIK with code payment:

* Use BLIK code 999000.
* Make sure your implementation satisfies BLIK’s guidelines.
* Test your integration end-to-end.

### Going live

Before you can accept live BLIK payments, you need to add BLIK in your live Customer Area.
