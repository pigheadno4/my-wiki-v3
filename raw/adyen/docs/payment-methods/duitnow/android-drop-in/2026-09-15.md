# DuitNow Drop-in integration

Add DuitNow to an existing Drop-in integration.

This page explains how to add DuitNow to your existing Android Drop-in integration.

## Requirements

Select the [server-side flow](/online-payments/build-your-integration) that your integration uses:

### Tab: Sessions flow

| Requirement          | Description                                                                                                                                                               |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Integration type** | Make sure that you have built a Sessions flow [Android Drop-in integration](/online-payments/build-your-integration/sessions-flow?platform=Android\&integration=Drop-in). |
| **Setup steps**      | Before you begin, [add DuitNow in your Customer Area](/payment-methods/add-payment-methods).                                                                              |

### Tab: Advanced flow

| Requirement          | Description                                                                                                                                                                |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Integration type** | Make sure that you have built an Advanced flow [Android Drop-in integration](/online-payments/build-your-integration/advanced-flow?platform=Android\&integration=Drop-in). |
| **Setup steps**      | Before you begin, [add DuitNow in your Customer Area](/payment-methods/add-payment-methods).                                                                               |

## API reference

### Tab: Sessions flow

When you [make the `/sessions` request](/online-payments/build-your-integration/sessions-flow?platform=Android\&integration=Drop-in#create-a-payment-session), DuitNow does not require any additional fields.

### Tab: Advanced flow

When you [make the `/payments` request](/online-payments/build-your-integration/advanced-flow?platform=Android\&integration=Drop-in#make-a-payment), DuitNow does not require any additional fields.

## Drop-in Configuration

### Tab: Sessions flow

When you [configure](/online-payments/build-your-integration/sessions-flow?platform=Android\&integration=Drop-in#configure) Drop-in, DuitNow does not require any additional configuration.

### Tab: Advanced flow

When you [configure](/online-payments/build-your-integration/advanced-flow?platform=Android\&integration=Drop-in#configure) Drop-in, DuitNow does not require any additional configuration.

## Test and go live

Test DuitNow payments with real payment details and small amounts.

Check the status of your test DuitNow payments in your [Customer Area](https://ca-test.adyen.com/) > **Payments** > **Payment list**.

To accept live DuitNow payments, you must contact our [Support Team](https://ca-test.adyen.com/ca/ca/contactUs/support.shtml?form=other) to add DuitNow in your live Customer Area.
