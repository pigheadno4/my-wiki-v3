# Touch'n Go Drop-in integration

Add Touch

This page explains how to add Touch''n Go to your existing Android Drop-in integration.

This page is for **v5.0.0**, released in October 2023. If you are using an earlier version, use [the guide for earlier versions](/payment-methods/touchngo/android-drop-in/earlier-versions) instead.

## Requirements

Select the [server-side flow](/online-payments/build-your-integration) that your integration uses:

### Tab: Sessions flow

| Requirement          | Description                                                                                                                                                                                                      |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Integration type** | Make sure that you have built a Sessions flow [Android Drop-in integration](/online-payments/build-your-integration/sessions-flow?platform=Android\&integration=Drop-in). The minimum required version is 5.0.0. |
| **Setup steps**      | Before you begin, [add Touch''n Go in your Customer Area](/payment-methods/add-payment-methods).                                                                                                                 |

### Tab: Advanced flow

| Requirement          | Description                                                                                                                                                                                                       |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Integration type** | Make sure that you have built an Advanced flow [Android Drop-in integration](/online-payments/build-your-integration/advanced-flow?platform=Android\&integration=Drop-in). The minimum required version is 5.0.0. |
| **Setup steps**      | Before you begin, [add Touch''n Go in your Customer Area](/payment-methods/add-payment-methods).                                                                                                                  |

## API reference

### Tab: Sessions flow

When you [make the `/sessions` request](/online-payments/build-your-integration/sessions-flow?platform=Android\&integration=Drop-in#create-a-payment-session), Touch''n Go does not require any additional fields.

### Tab: Advanced flow

When you [make the `/payments` request](/online-payments/build-your-integration/advanced-flow?platform=Android\&integration=Drop-in#make-a-payment), Touch''n Go does not require any additional fields.

## Drop-in Configuration

### Tab: Sessions flow

When you [configure](/online-payments/build-your-integration/sessions-flow?platform=Android\&integration=Drop-in#configure) Drop-in, Touch''n Go does not require any additional configuration.

### Tab: Advanced flow

When you [configure](/online-payments/build-your-integration/advanced-flow?platform=Android\&integration=Drop-in#configure) Drop-in, Touch''n Go does not require any additional configuration.

### Tab: Sessions flow

After adding configuration to Drop-in, [create the checkout session](/online-payments/build-your-integration/sessions-flow?platform=Android\&integration=Drop-in#create-the-checkout-session).

### Tab: Advanced flow

After adding configuration, [launch and show Drop-in](/online-payments/build-your-integration/advanced-flow?platform=Android\&integration=Drop-in#launch-and-show).

## Test and go live

Check the status of Touch'n Go test payments in your [Customer Area](https://ca-test.adyen.com/) > **Payments** > **Payment list**.

To accept live Touch'n Go payments, you must contact our [Support Team](https://ca-test.adyen.com/ca/ca/contactUs/support.shtml?form=other) to add Touch''n Go in your live Customer Area.
