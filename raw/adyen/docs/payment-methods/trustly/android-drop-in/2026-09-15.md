# Trustly Drop-in integration

Add Trustly to an existing Drop-in integration.

This page explains how to add Trustly to your existing Android Drop-in integration.

This page is for **v5.0.0**, released in October 2023. If you are using an earlier version, use [the guide for earlier versions](/payment-methods/trustly/android-drop-in/earlier-versions) instead.

## Requirements

Select the [server-side flow](/online-payments/build-your-integration) that your integration uses:

### Tab: Sessions flow

| Requirement          | Description                                                                                                                                                                                                      |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Integration type** | Make sure that you have built a Sessions flow [Android Drop-in integration](/online-payments/build-your-integration/sessions-flow?platform=Android\&integration=Drop-in). The minimum required version is 5.0.0. |
| **Setup steps**      | Before you begin, [add Trustly in your Customer Area](/payment-methods/add-payment-methods).                                                                                                                     |

### Tab: Advanced flow

| Requirement          | Description                                                                                                                                                                                                       |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Integration type** | Make sure that you have built an Advanced flow [Android Drop-in integration](/online-payments/build-your-integration/advanced-flow?platform=Android\&integration=Drop-in). The minimum required version is 5.0.0. |
| **Setup steps**      | Before you begin, [add Trustly in your Customer Area](/payment-methods/add-payment-methods).                                                                                                                      |

## API reference

### Tab: Sessions flow

When you [make the `/sessions` request](/online-payments/build-your-integration/sessions-flow?platform=Android\&integration=Drop-in#create-a-payment-session), Trustly does not require any additional fields.

### Tab: Advanced flow

When you [make the `/payments` request](/online-payments/build-your-integration/advanced-flow?platform=Android\&integration=Drop-in#make-a-payment), Trustly does not require any additional fields.

## Drop-in Configuration

### Tab: Sessions flow

When you [configure](/online-payments/build-your-integration/sessions-flow?platform=Android\&integration=Drop-in#configure) Drop-in, Trustly does not require any additional configuration.

### Tab: Advanced flow

When you [configure](/online-payments/build-your-integration/advanced-flow?platform=Android\&integration=Drop-in#configure) Drop-in, Trustly does not require any additional configuration.

### Tab: Sessions flow

After adding configuration to Drop-in, [create the checkout session](/online-payments/build-your-integration/sessions-flow?platform=Android\&integration=Drop-in#create-the-checkout-session).

### Tab: Advanced flow

After adding configuration, [launch and show Drop-in](/online-payments/build-your-integration/advanced-flow?platform=Android\&integration=Drop-in#launch-and-show).

## Test and go live

Trustly provides a [test environment](https://docs.trustly.com/get-started/adyen). For **Login ID/Personal number** values, you can enter any digits, following the format `YYMMDD-XXXX` (for example: **111111-1111**).

You can check the status of Trustly test payments in your [Customer Area](https://ca-test.adyen.com/) > **Payments** > **Payment list**.

Before you can accept live Trustly payments, you need to submit a request for Trustly in your [live Customer Area](https://ca-live.adyen.com/).
