# Manage split configuration profiles

Learn how you can view, change, and delete the conditions and instructions in split configuration profiles.

After a split configuration profile is applied to your user's store, we automatically split all payments according to the instructions from the rule that has the [highest priority](/platforms/automatic-split-configuration#rule-hierarchy).

If you need to add or remove a rule, or change the conditions and split instructions of an existing rule, you can do so at any time in your [Customer Area](https://ca-test.adyen.com/) or using the [Management API](https://docs.adyen.com/api-explorer/Management/latest/overview). However, you can only [change the description of a profile](/platforms/automatic-split-configuration/manage-split-configurations/api#update-description) or [set a card region condition](/platforms/automatic-split-configuration/manage-split-configurations/api#update-condition) by using the [Management API](https://docs.adyen.com/api-explorer/Management/latest/overview).

Adyen always checks the split configuration profile when we capture the payment. If you update the profile after a payment is authorized but before it is captured, we apply the updated profile to the capture. Transaction-specific split instructions in a capture request override the profile.
