# Split refunds

Split a refund between the balance accounts in your platform.

If your user need to return funds to a customer, for example, if they returned an item, you need to send a refund request to Adyen. You can refund the full captured amount, a partial amount, or multiple partial amounts. The sum of the partial refunds cannot exceed the captured amount. However, some payment methods do not support partial refunds. You can check that in the [overview of payment methods](/payment-methods).

## Refund methods

When refunding a split payment, you can either deduct the same amount from the same balance accounts as used in the original payment request, or provide new split instructions in the refund request.

We recommend that you always provide split instructions for refunds. That way, you are always in control and can support different refund scenarios, such as partial and multiple partial refunds.

If you do not include the split instructions in the refund request, the refund is split the same way as the original payment request. Only omit the split instructions from a refund request if you want to deduct the same amounts from the same balance accounts as you defined in the payment request.

To return funds to your user's customer, with or without split instructions, you need to issue a referenced refund using a Terminal API [ReversalRequest](https://docs.adyen.com/api-explorer/terminal-api/latest/post/reversal).
