# Other 3D Secure flows

Learn how you can implement alternative 3D Secure flows.

**Adyen is no longer developing the Classic API integration**

This page is for the Classic API (`/authorise`) integration, which we no longer accept new integrations with.

We strongly recommend migrating to the newer [other 3D Secure flows on Checkout API](/online-payments/3d-secure/other-3ds-flows) integration. To use this newer integration, you must also [migrate to the Checkout API](/online-payments/upgrade-your-integration/migrate-to-checkout-api).

In a full 3D Secure integration with Adyen, we will perform the authentication and proceed with the payment authorisation. However, depending on your implementation, you can choose to perform other 3D Secure flows:

* [Authorise with 3D Secure MPI data](/online-payments/classic-integrations/classic-api-integration/3d-secure-authentication/other-3ds-flows/authorize-mpidata): Use a third-party 3D Secure provider and perform the payment authorisation request with Adyen.
* [Submit a 3D Secure 2 data-only request](/online-payments/classic-integrations/classic-api-integration/3d-secure-authentication/other-3ds-flows/data-only): Submit a 3D Secure 2 request without requesting for an authentication. Data-only flow is currently only available in Brazil for Mastercard.
