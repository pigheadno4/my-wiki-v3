# Custom 3D Secure implementation

**Adyen is no longer developing the Classic API integration**

This page is for the Classic API (`/authorise`) integration, which we no longer accept new integrations with.

We strongly recommend migrating to the newer [authorisation-only flow on Checkout API](/online-payments/3d-secure/other-3ds-flows/authorize-mpidata) integration. To use this newer integration, you must also [migrate to the Checkout API](/online-payments/upgrade-your-integration/migrate-to-checkout-api).

Outlines authorising payments using either an external 3D secure MPI (Merchant Plug In) or an acquirer with hosted or non-standard 3D secure MPI.

***

This documentation is provided for testing purposes and is subject to change in the future.

Depending on your integration, processing 3D secure payments through the Adyen API may not be possible. You can process 3D Secure payments over the SOAP API with:

* [An external 3D Secure MPI](/online-payments/classic-integrations/classic-api-integration/3d-secure-authentication/3d-secure-1/custom-3d-secure-implementation/custom-3d-secure-using-an-external-mpi) (your own or through another processing system)
* [An acquirer that uses a hosted or non-standard 3D Secure MPI](/online-payments/classic-integrations/classic-api-integration/3d-secure-authentication/3d-secure-1/custom-3d-secure-implementation/custom-3d-secure-using-a-hosted-mpi).
