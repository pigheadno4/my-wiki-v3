# Online payouts

Send funds to your suppliers, partners, or customers.

We are no longer accepting new integrations with the [Payout API](https://docs.adyen.com/api-explorer/Payout/latest/overview); use the [Transfers API](https://docs.adyen.com/api-explorer/transfers/latest/overview) instead. With the Transfers API, you can:

* Handle multiple payout use cases with a single API.
* Use new payout functionalities, such as instant payouts.
* Receive webhooks with more details and defined transfer states.

If you are:

* Building a new integration, refer to [Payouts](/payouts/payout-service/) to integrate with the Transfers API.
* Already integrated with the Payout API, reach out to your Adyen contact for information on how to migrate to the Transfers API.

Adyen Payout API allows you to make payments such as insurance claims, rebates, affiliate and contractor payouts, expense reimbursements, or gaming winnings.

We support two types of online payouts: **instant card payouts** and **payouts in stages**. You can complete an [instant card payout](#instant-card-payouts) by sending a single API request. [Payouts in stages](#payouts-to-bank-accounts-and-wallets) require sending two separate API requests. Payouts in stages is intended for merchants that require a review of the payout before disbursing the funds. Within the company, multiple reviewers with different roles are involved in the payout. This is known as a four-eye policy check.

Using the Payout API requires additional approval and configuration on our end. To enable payouts, contact our [Support Team](https://ca-test.adyen.com/ca/ca/contactUs/support.shtml?form=other). 

## Instant card payouts

Adyen supports paying out to cards instantly, and immediately returns the result of the payout attempt.\
Payouts to debit and credit cards are currently supported only for Visa and Mastercard. 

When you have enabled these payouts, you will have one API credential. This user can check card eligibility, submit instant payouts, and store payout details.

We support instant payouts for:

* **Cards** – Funds disbursements to the cardholder's bank account, or money transfers between two\
  individuals, virtual wallets or accounts.  \
  For more information and examples, refer to [Instant card payouts](/online-payments/online-payouts/instant-payouts).

## Payouts in stages

These payouts require a four-eye policy check: each payout has to be confirmed and checked by a user different from the one that submitted the payout. When you have enabled these payouts, you will have two API credentials:

* **storePayout\@Company.****\[Company Account Code]** – This user can store payout details, and submit payouts.

* **reviewPayout\@Company.****\[Company Account Code]** – This user can confirm or decline payouts.

We support payouts in stages for:

* **Bank accounts** – Payouts processed as a bank transfer. \
  For more information, refer to [Payouts in stages](/online-payments/online-payouts/payouts-to-bank-accounts-and-wallets).\
  For examples, refer to: 
  * [Payouts to a bank account](/online-payments/online-payouts/payouts-to-a-bank-account)

* **Wallets** – Payouts to digital wallets, supported for Paypal.
