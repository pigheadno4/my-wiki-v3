# Standalone solution

Process payments through Adyen using a terminal that is not linked to a POS system.

If you do not need a fully-featured POS system, you can use our Standalone solution instead.

This is our quickest way to start accepting in-person payments. It does not require any development or integration work. Instead of using a POS app, you initiate transactions directly from a standalone terminal.

## Fallback

Standalone terminals can also be used as a fallback when your POS app cannot communicate with integrated terminals. For example, if there is a network problem and you cannot start a transaction on your integrated terminal from the POS app, you can continue making transactions using a standalone terminal. All you have to do is enable [cellular connectivity](/point-of-sale/design-your-integration/network-and-connectivity/cellular-failover#using-3g-4g-terminals) or [offline payments](/point-of-sale/offline-payment) on the standalone terminal.

## Compliance and supported terminals

A compliance requirement from the card schemes is that you are able to provide the customer with a printed receipt. For this reason, only terminals that have a built-in printer can be used as standalone terminals. When [selecting a new terminal](/point-of-sale/what-we-support/select-your-terminals), choose one of the following models:

* S1F2 and S1F2L
* V210
* V240m Plus (for Brazil)
* V400c Plus
* V400m

## Supported features

The Standalone solution supports the basic payment-related features:

* [Make a payment](/point-of-sale/standalone/standalone-use#make-a-payment). This includes:

  * Credit and debit card payments
  * NFC wallet payments such as Apple Pay and Google Pay
  * [QR code wallet payments](/point-of-sale/standalone/standalone-use#qr-code) such as Alipay and WeChat Pay
  * [Manual Keyed Entry (MKE) payments](/point-of-sale/standalone/standalone-use#mke)
  * [Mail Order/Telephone Order (MOTO) payments](/point-of-sale/standalone/standalone-use#moto)

* [Tipping](/point-of-sale/standalone/standalone-use#tipping-standalone)

* [Cancel an in-progress payment](/point-of-sale/standalone/standalone-use#cancel)

* [Refund a payment](/point-of-sale/standalone/standalone-use#refund)

* [Offline payments](/point-of-sale/offline-payment)

* [Accessibiliy mode](/point-of-sale/android-terminals/accessibility-mode). You can activate an accessible payment on standalone terminals:

  * [Activate accessibility mode through the terminal audio jack socket](/point-of-sale/android-terminals/accessibility-mode/accessibility-from-terminal#activate-accessibility-mode-through-the-terminal-audio-jack-socket)
  * [Activate accessibility mode with the accessibility button](/point-of-sale/android-terminals/accessibility-mode/accessibility-from-terminal#activate-accessibility-mode-with-the-accessibility-button)
  * [Activate accessibility mode on the terminal PIN pad:](/point-of-sale/android-terminals/accessibility-mode/accessibility-from-terminal#activate-accessibility-mode-with-the-pin-pad)

* [Surcharge based on store configuration](/point-of-sale/surcharge/configuration)

In addition, you can view and [print day or shift totals](/point-of-sale/standalone/standalone-use#totals) and [reprint receipts](/point-of-sale/standalone/standalone-use#reprint-transaction-receipt).

With the Standalone solution, you will not be able to use features like [shopper recognition](/point-of-sale/shopper-recognition) or [tax free shopping](/point-of-sale/shopper-recognition/tax-free-shopping). You will also need to manually reconcile your point-of-sale transactions against your sales and returns.
