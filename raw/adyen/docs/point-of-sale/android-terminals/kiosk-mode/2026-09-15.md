# Kiosk mode

Enable kiosk mode from your Customer Area.

Kiosk mode is intended for payment terminals in unattended environments, such as next to a vending machine, token dispenser, or parking payment systems. Kiosk mode hides the navigation bar and the settings and transaction buttons at the bottom of the screen. In this way, you can prevent customers from using the terminal screen to change or minimize the default app, or to power off the terminal.

## Requirements

Before you begin, take into account the following requirements.

| Requirement                                    | Description                                                                                                                                                                                                                                                                                     |
| ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Integration type**                           | A [Terminal API integration](/point-of-sale/get-started) with payment terminals or a [Standalone solution](/point-of-sale/standalone).                                                                                                                                                          |
| **[Customer Area roles](/account/user-roles)** | To enable kiosk mode from the Customer Area, you need the following [roles](/account/user-roles/#pos):- **Merchant POS Terminal Management Admin** for configurations at any level.
- **Merchant POS Terminal Management** for configurations at the level of the merchant account (and lower). |
| **Hardware**                                   | You can enable kiosk mode on Android payment terminal models AMS1, S1E2L, S1E, S1E4Pro, S1F2, S1F4Pro, or S1U2. On the P630 terminal model, kiosk mode is enabled by default.                                                                                                                   |

## Enable kiosk mode

You can set a default [Android app that you uploaded](/point-of-sale/android-terminals/deploy-apps/upload/) for customer interaction.

To enable kiosk mode:

1. In your [Customer Area](https://ca-test.adyen.com/), go to **Devices** > **Device settings** > **Device**.

2. Under **Kiosk mode**:

   1. Turn on the **Hide navigation bar** toggle.
   2. At **Default start app**, select the default app for your customers to interact with.
   3. Optionally, at **Apps allowed in kiosk mode**, select other apps that can be used in kiosk mode.

3. Under **Home screen**:

   1. Turn off the **Settings menu** toggle.
   2. Turn off the **Transactions menu** toggle.

4. Select **Save**.
