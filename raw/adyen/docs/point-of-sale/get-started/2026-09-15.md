# Integration overview

Use checklists to get started with in-person payments at your point of sale.

To help you build an in-person payments integration with the Adyen Terminal API and Adyen-provided payment terminals, we provide two checklists:

* An [integration checklist](/point-of-sale/get-started/tapi-checklist) to build a test integration.
* A [go-live checklist](/point-of-sale/get-started/go-live-tapi).

The checklists link to resources with detailed information about the building blocks of your point-of-sale integration:

* Structure and configuration of your Adyen account.
* Terminal models for your use cases.
* Integration architecture: communicating with the terminals through the cloud or through your local network.
* Network and connectivity configuration.
* Terminal API.
* Notifications and webhooks.

## Other checklists

To help you build other in-person payment solutions with Adyen, we have dedicated checklists.

* For a standalone solution, see the [standalone integration checklist](/point-of-sale/standalone/standalone-build/standalone-checklist) and the [standalone go-live checklist](/point-of-sale/standalone/standalone-build/go-live-standalone).

* For a Mobile solution, see the [Android Mobile checklists](/point-of-sale/mobile-android/checklists) or the [iOS Mobile checklists](/point-of-sale/mobile-ios/checklists).
