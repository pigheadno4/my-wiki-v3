# End of 2G/3G network coverage

Take steps to manage the impact of 2G and 3G network deprecation.

Mobile operators around the world are ending coverage for 2G and 3G cellular networks to free up the bandwidth for 4G and other newer technologies. Some payment terminal models only support up to 3G. On those terminals, you will not be able to accept payments when relying on 2G or 3G cellular connectivity at the time of transaction.

Here we describe:

* The [terminals models](#affected-models) that only support up to 3G.
* The [countries/regions](#affected-countries) where the coverage up to 3G is ending.
* The [solutions](#possible-solutions) to consider.

## Terminals affected

The following terminal models only support cellular connections up to 3G:

* [e285 and e285p](/point-of-sale/user-manuals/e285-user-manual)
* [V240m Plus](/point-of-sale/user-manuals/v240m-user-manual)
* [VX690](/point-of-sale/user-manuals/terminal-deprecation/vx690-user-manual)

The V240m Plus is used only in Brazil. Because mobile operators in Brazil do not intend to end 3G coverage in the near future, currently there is no negative impact of continuing to use this model.

## Possible solutions

If you use VX690, e285, e285p, or V240m Plus terminal models with 2G/3G, there are several solutions:

* The affected terminals automatically fall back from 3G to the 2G network if available. In this case, note that:

  * 2G is not available everywhere, and the coverage will also end in the following years.
  * Configuration and software updates of terminals on 2G can take a long time and can get interrupted.

* Connect the affected terminals to a [router with 4G cellular connection](/point-of-sale/design-your-integration/network-and-connectivity/cellular-failover). The terminals connect to the router using Wi-Fi.

* Order new terminals of [similar capabilities](/point-of-sale/what-we-support/select-your-terminals#use-cases) that [support 4G](/point-of-sale/what-we-support/select-your-terminals#terminal-connectivity).
