# Android Mobile solutions

Accept in-person payments on an Android mobile device like a phone, or using a mobile device and a card reader.

This part of the documentation focuses on the Mobile in-person payments solutions for the Android platform:

* Tap to Pay on Android solution
* Card reader on Android solution
* Android Payments app solution

You can look up the system requirements, security considerations, and checklists for getting started and going live.

There is background information which can help to choose between solutions.

And you can learn how to build your solution, how to make your solution available and keep it up to date, and how to handle errors that can be shown on the mobile devices.
