# Assign terminals

Prepare your payment terminals for boarding.

To make a terminal ready to accept payments, you need to assign it to a store or a merchant account representing a store, and then board the physical terminal.

There are three ways to assign terminals:

* [On the payment terminal itself](/point-of-sale/managing-terminals/board-terminal#manually-board-your-terminal), by selecting a store during boarding. This method is not practical in case of a large number of stores to choose from or a large number of terminals, or if the terminal does not have a display.

* [Through Management API requests](/point-of-sale/automating-terminal-management/assign-terminals-api). This enables you to automate assigning terminals.

* From your Customer Area. You can pre-assign terminals to a store from the terminals list. You can also upload a CSV with the details if you want to assign a large number of terminals to many stores in one go.

This page describes how to use the Customer Area to initially assign terminals, and to reassign terminals that have already been boarded.

## Requirements

Before you begin, take into account the following requirements, limitations, and preparations.

| Requirement                                    | Description                                                                                                                                                    |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Integration type**                           | A [Terminal API integration](/point-of-sale/basic-tapi-integration/) with payment terminals, or a [standalone solution](/point-of-sale/standalone).            |
| **[Customer Area roles](/account/user-roles)** | To assign terminals using the Customer Area, you must have one of the following roles:- **Merchant POS Terminal Management Admin role**
- **Manage terminals** |

## Assign a terminal from your Customer Area

When we ship the terminals you ordered, we add them to the **Inventory** of your company account. From there, you assign the terminals to the stores where they will be boarded and used.

To assign one or more terminals to the same store:

1. Log in to your Customer Area:

   * For a test terminal, go to your [test Customer Area](https://ca-test.adyen.com/).
   * For a live terminal, go to your [live Customer Area](https://ca-live.adyen.com/).

2. Go to **Devices** > **Device list**, and select the **Terminals** tab.

3. Search for the terminal by serial number.

4. Select the terminal. You can either select its checkbox or click on the row of the terminal. Use the checkboxes if you are assigning multiple terminals to the same store.

5. Select **Reassign**.

6. If a **Terminal reassignment** message appears, select **Got it**.\
   The message gives information about [reassigning terminals that are already boarded](#reassign-boarded-terminals).

7. Select the **Store** that you want to assign the terminal to.

   Select an **Inventory** if you want to reassign a terminal from a store back to an inventory.

8. **Confirm** the assignment and **Close** the dialog.

## Assign terminals in bulk

If you have a lot of terminals to assign, or various stores that you need to assign terminals to, you can do that in one go by uploading a CSV file with the details.

To assign terminals in bulk using the Customer Area:

1. View the instructions for the file structure:

   1. In your [Customer Area](https://ca-test.adyen.com/), go to **Devices** > **Device list**, and select the **Terminals** tab.

   2. Select **More options** > **Bulk reassignment**.

   3. Select the links to view a description and download an example file.

2. Prepare your CSV file according to the instructions.

3. In your [test Customer Area](https://ca-test.adyen.com/) or [live Customer Area](https://ca-live.adyen.com/), go to **Devices** > **Device list**, and select the **Terminals** tab.

4. Select **More options** > **Bulk reassignment**.

5. In the box under **Upload your CSV file**, select the file you prepared.

   If errors are found, fix the errors and try again.

6. Select **submit**.

## Reassign boarded terminals

If you have a terminal that was already assigned and boarded to a store and now you want to use it for a different store, you must reassign the terminal.

When you reassign a terminal that is boarded already, the terminal still uses the configuration of the old store until it synchronizes with the Adyen platform. The terminal then removes its configuration and shows **Board the terminal** again so that it can collect the new configuration.

To successfully assign and board the terminals, note the following:

* The terminals need to be turned on and have a stable internet connection.

* It can take up to three hours before the reassignment takes effect. That is because the synchronization of the terminal with the Adyen platform happens every three hours.

  If you want the reassignment to take effect instantly, you can:

  * Enable [WebSockets](/point-of-sale/diagnostics/check-cloud-connection/#use-the-customer-area) before the reassignment.
  * For non-Android terminals, update the configuration manually. See [Configuration changes](/point-of-sale/managing-terminals/maintain-performance#configuration-changes) for more information.

To reassign terminals that are already boarded:

1. Follow the steps in [Assign a terminal from your Customer Area](#step-1-pre-assign-the-terminal-to-a-store).

2. [Board the terminal](/point-of-sale/managing-terminals/board-terminal) again when the message **Board the terminal** appears.
