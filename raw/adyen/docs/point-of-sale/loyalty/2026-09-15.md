# Shopper loyalty

Use shopper recognition for loyalty purposes.

With Adyen, you can set up a loyalty program where shoppers do not need to have a physical loyalty card. Instead, you identify shoppers based on data that you receive in card acquisition and payment responses.

If you recognize a shopper from identifiers in API responses, you can offer tailored benefits like discounts on the spot, or make product recommendations based on their purchase history. If you do not recognize a shopper, you can enroll them on the spot using the payment terminal.

To use this method, you need to create customer profiles in your back-end system. A customer profile should contain the response data that you use to identify the shopper, together with any other details that your use case requires, such as purchase history data.
