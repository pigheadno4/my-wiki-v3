# Get started manuals

Learn how to set up the terminal, connect it to your network, and use the menus.

Use this overview to see available payment terminals based on use case, location, and desired features.

If you do not need a physical terminal, look at our [mobile solutions](/point-of-sale/ipp-mobile). These enable you to accept Tap to Pay transactions on a mobile device like a smartphone, or using a combination of a mobile device and a card reader.

PCI PTS 5 payment terminals will no longer be available for order starting **April 30, 2026**.

## Available filters

Use case, Countries/Regions, Suitable for, Feature, Connectivity, PCI compliance
