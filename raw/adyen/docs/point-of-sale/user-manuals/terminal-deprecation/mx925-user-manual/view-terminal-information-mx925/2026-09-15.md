# View device info - MX925

Quickly look up information about the terminal such as network information and terminal ID.

## Steps

* Press **5** and then press **\*\*![](/user/pages/reuse/image-library/buttons/14.confirmmx925/ConfirmMX915.png)**.\*\*

The terminal display shows the following details for your terminal:

* IP address.
* Terminal ID.
* Software version.
* QR code with an encoded IP address, MAC address, network name, store name, merchant account name, and terminal ID.
