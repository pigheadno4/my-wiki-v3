# Use the Admin menu - MX925

## Steps

1. Press **9** and then press **![](/user/pages/reuse/image-library/buttons/14.confirmmx925/ConfirmMX915.png)** to open the Admin menu.
2. Enter the PIN code for the Admin menu. If you do not know this code, see our [POS Troubleshooting section](/point-of-sale/pos-troubleshooting/terminal-turns-on/admin-pin/).\
   The terminal shows the Admin menu.
