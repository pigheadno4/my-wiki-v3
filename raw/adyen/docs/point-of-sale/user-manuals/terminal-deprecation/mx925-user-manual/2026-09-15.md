# MX925 user manual

Get started with the MX925 payment terminal.

It is not possible to order new terminals of this type. See [Deprecation of eVo terminals](/point-of-sale/user-manuals/terminal-deprecation).

![](/user/pages/reuse/terminal-manuals/photos/noText_vx925.png)

## Quickstart

The following topics will help you get your new terminal up and running quickly:

* Connect the power supply to your PED.

* Connect your Ethernet cable to the ETH port on the power cable.

  Using the wrong type of cable in the wrong port (for example, an Ethernet cable in the RS232 port) might severely damage the device.

* Perform a [device security inspection](/point-of-sale/user-manuals/terminal-deprecation/mx925-user-manual/inspect-device-security-mx925).

* [Board the terminal](/point-of-sale/user-manuals/terminal-deprecation/mx925-user-manual/board-the-terminal-mx925)

Once you have completed these steps, you are ready to process payments!

## Provided components

* MX 925 payment terminal (PED)
* Power supply
* Ethernet dongle
