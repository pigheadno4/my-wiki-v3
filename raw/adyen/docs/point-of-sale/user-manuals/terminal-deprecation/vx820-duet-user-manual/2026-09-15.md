# VX820 Duet user manual

Get started with the VX820 Duet payment terminal.

It is not possible to order new terminals of this type. See [Deprecation of eVo terminals](/point-of-sale/user-manuals/terminal-deprecation).

![](/user/pages/reuse/terminal-manuals/photos/noText_vx820duet.jpg)

## Quickstart

The following topics will help you get your new terminal up and running quickly:

* Plug the power supply cable in.
* Connect the base to the power supply cable.
* Connect the Duet base to the Internet via the ETH port.
* [Place the receipt paper roll in the Duet base](/point-of-sale/user-manuals/terminal-deprecation/vx820-duet-user-manual/install-or-replace-paper-rolls-vx820-duet).
* Perform a [device security inspection](/point-of-sale/user-manuals/terminal-deprecation/vx820-duet-user-manual/inspect-device-security-vx820-duet).
* [Board the terminal](/point-of-sale/user-manuals/terminal-deprecation/vx820-duet-user-manual/board-the-terminal-vx820-duet)

Using the wrong type of cable in the wrong port (for example, an Ethernet cable in the RS232 port) might severely damage the device.

Although it is technically possible to use a serial connection between the POS and the PED, Adyen strongly recommends using Ethernet connectivity, due to its superior speed and performance with a number of Operating Systems.

If the terminal shows an exclamation at the top bar, this means that the terminal holds data that it failed to synchronize with the Adyen payments platform due to lack of an outgoing internet connection.

## Provided components

* VX820 payment terminal (PED)
* Duet (base station with built-in printer)
* Power supply
* Privacy shield
* Ethernet dongle
* 1 paper roll
