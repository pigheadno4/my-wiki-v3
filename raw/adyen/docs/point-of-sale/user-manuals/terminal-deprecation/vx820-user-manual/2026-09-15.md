# VX820 user manual

Get started with the VX820 payment terminal.

It is not possible to order new terminals of this type. See [Deprecation of eVo terminals](/point-of-sale/user-manuals/terminal-deprecation).

![](/user/pages/reuse/terminal-manuals/photos/noText_vx820.jpg)

## Quickstart

The following topics will help you get your new terminal up and running quickly:

* Connect the power supply with the dongle that is already connected with your PED.
* Connect your Ethernet cable to the ETH port on the power cable.
* Perform a [device security inspection](/point-of-sale/user-manuals/terminal-deprecation/vx820-user-manual/inspect-device-security-vx820).
* [Board the terminal](/point-of-sale/user-manuals/terminal-deprecation/vx820-user-manual/board-the-terminal-vx820)

Using the wrong type of cable in the wrong port (for example, an Ethernet cable in the RS232 port) might severely damage the device.

## Provided components

* VX820 payment terminal
* Power supply
* Privacy shield
* Ethernet dongle
