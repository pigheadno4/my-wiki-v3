# Remove configuration and reboard

If a terminal is already boarded, and the app and terminal have the same settings, this step can be skipped. 

## Steps

Remove the current merchant configuration from the terminal as follows:

1. Press **![](/user/pages/reuse/image-library/buttons/01.confirme355/2_e355.png)** + **9** to open the Admin menu.\
   **Note:** Use the **\*** and **#** key to scroll up and down through the menu.
2. Press **3. Configuration**.
3. Press **6. Erase**.
4. Press **![](/user/pages/reuse/image-library/buttons/01.confirme355/2_e355.png)** to confirm.
5. The terminal will reboot.

## Next Steps

From here, re-board the terminal using the process outlined in [Boarding the terminal E355](/point-of-sale/user-manuals/terminal-deprecation/e355-user-manual/board-the-terminal-e355).
