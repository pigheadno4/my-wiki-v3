# Troubleshoot the Bluetooth connection

### App keeps showing "initializing" status

Most likely app and terminal do not support the same protocol version. Make sure this is the case.

### There is no Bluetooth icon visible

1. Make sure that the app and terminal are within each others range. In theory the maximum range is 60 meters in open space, but when troubleshooting make sure you are at least within 10 meters distance. In the office the range is around 30 meters.
2. If the icon does not appear within 20 seconds and both devices are paired, try restarting the app first.
3. If this does not work restart the terminal.

### Other issues

It is always a good idea to start with a clean Bluetooth configuration. Make sure that you remove other paired devices unless they are necessary. To do this follow the [unpair devices for a clean configuration](/point-of-sale/user-manuals/terminal-deprecation/e355-user-manual/make-a-payment-on-the-e355-over-bluetooth/step-1-clean-the-bluetooth-configuration) procedure.
