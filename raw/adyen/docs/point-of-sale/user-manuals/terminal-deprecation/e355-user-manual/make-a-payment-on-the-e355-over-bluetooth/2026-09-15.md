# Make a payment on the e355 over Bluetooth

Make a payment on the e355 Pin Entry Device (PED) through the Bluetooth connection.

## Prerequisites

It is always a good idea to start with a clean Bluetooth configuration. Make sure that you remove other paired devices unless they are necessary. To do this follow the [unpair devices for a clean configuration](/point-of-sale/user-manuals/terminal-deprecation/e355-user-manual/make-a-payment-on-the-e355-over-bluetooth/step-1-clean-the-bluetooth-configuration) procedure.

## Key steps

The procedure can be separated into 3 steps:

1. [Step 2 - Pair the e355 with a mobile device](/point-of-sale/user-manuals/terminal-deprecation/e355-user-manual/make-a-payment-on-the-e355-over-bluetooth/step-2-pair-the-e355-with-a-mobile-device)
2. [Remove configuration and reboard](/point-of-sale/user-manuals/terminal-deprecation/e355-user-manual/make-a-payment-on-the-e355-over-bluetooth/remove-configuration-and-reboard)
3. [Step 3 - Start a transaction](/point-of-sale/user-manuals/terminal-deprecation/e355-user-manual/make-a-payment-on-the-e355-over-bluetooth/step-3-start-a-transaction)

The POS app and the e355 should both use the same serial communication protocol version. At the moment this is version 2. If the protocol version differs between the POS and the e355, communication will fail. Pairing will succeed but boarding and starting a transaction will not and the app will be stuck in the initialization phase.
