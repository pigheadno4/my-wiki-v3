# Board the terminal - e355

Board a terminal to register and use it with the Adyen payments platform.

## Requirements

* Board the terminal only after successfully connecting the device to the internet, and performing a device security inspection. For more information, see the [quick start guide](/point-of-sale/user-manuals/terminal-deprecation/vx675-user-manual).
* Choose the boarding method for your terminal.

You can board using:

* The Adyen POS App: Board the terminal with the Adyen payments platform using the Adyen POS App
* The Adyen POS App with the E355 frame: Board the terminal with the Adyen payments platform using the Adyen POS App and the E355 frame
* The Adyen customer area: Board with the Adyen Customer Area
* Standalone mode: Board the terminal with the Adyen payments platform in standalone mode
* Custom integrations:  Board the terminal with custom integrations

## Steps

1. Hold **![](/user/pages/reuse/image-library/buttons/01.confirme355/2_e355.png)** + **9** to enter the settings menu.

2. Enter the PIN code for the Admin menu. If you do not know this code, see our [POS Troubleshooting section](/point-of-sale/pos-troubleshooting/terminal-turns-on/admin-pin/).\
   The terminal shows the Admin menu.

3. Press **1. Network**.

4. Press **2. Wi-Fi.**

5. Press **3**. **TCP/IP settings** to view and make a note of the terminal's IP address.

6. Download and install the Adyen POS App from the [Apple App Store](https://www.apple.com/app-store/) or the Google Play Store.

## Board the terminal with the Adyen payments platform using the Adyen POS App and the E355 frame

1. [Attach a tablet to the Frame](/point-of-sale/user-manuals/terminal-deprecation/e355-user-manual/attach-and-use-the-e355-frame/attach-a-tablet-to-the-frame).
2. Download and Install the Adyen POS App from iTunes.
3. If the E355 is turned on, [turn it off](/point-of-sale/user-manuals/terminal-deprecation/e355-user-manual/turn-on-and-off-the-e355).
4. Insert the e355 into the frame.
5. Turn on the e355.\
   The e355 shows the message: "Board the terminal".
6. Open the Adyen POS App on the mobile device.

#### Board with an Android device

1. Open the Adyen POS App.
2. Enter the details of your API credentials. To learn how to retrieve these, see [Basic authentication](/development-resources/api-credentials#basic-authentication).
3. Tap **☰**.
4. Tap **Payment device**.\
   The app will prompt to select between Bluetooth and Wi-Fi connection.
5. Enter the IP address of your terminal and tap **Add Device**.\
   The Adyen POS App identifies the terminal, synchronizes with the Adyen payments platform, and verifies the terminal configuration.
6. The terminal begins boarding and restarts.\
   After rebooting, the terminal will begin to update to the latest merchant configuration. Once the latest configuration has been applied, you can begin processing payments.

#### Board with an iOS device

1. Open the Adyen POS App on the mobile device.
2. Tap the **![](/user/pages/reuse/image-library/buttons/13.bluetoothmenu/ic-pos-bluetooth-3x.png)**  icon.
3. Tap the '**+**' at the top of the **Payment device** popup menu.
4. Enter the device hostname or IP.\
   The device will now be listed in the **Payment device** menu with the status "Not Boarded".
5. Tap the name of the device.\
   The device shows a message saying the device is not configured, with options to **Cancel** or **Board device**.
6. Tap **Board Device**.
7. The terminal begins boarding and restarts.\
   After rebooting, the terminal will begin to update to the latest merchant configuration. Once the latest configuration has been applied, you can begin processing payments.
