# Understand the LED colors - e355

LED lights are used to communicate the status of your terminal.

***

| **LED behavior**                                                                      | **Status**                                                   |
| ------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| Green, blinks every 4 seconds                                                         | Sleep                                                        |
| Red, 1HZ rate, 50% duty cycle (Battery low condition: battery voltage 3.7V)           | Battery Low                                                  |
| Red, 4Hz rate, 50% duty cycle (Battery extremely low condition: battery voltage 3.6V) | Battery Extremely Low                                        |
| Orange, 1Hz rate, 50% duty cycle                                                      | Battery Charging                                             |
| Orange, continuously on                                                               | Charging Timer Fault                                         |
| Green, continuously on                                                                | Normal Operation                                             |
| Off                                                                                   | LEDs are turned OFF when charging the e355 on a gang charger |
