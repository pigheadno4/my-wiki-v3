# e355 user manual

Get started with the e355 payment terminal.

It is not possible to order new terminals of this type. See [Deprecation of eVo terminals](/point-of-sale/user-manuals/terminal-deprecation).

![](/user/pages/reuse/terminal-manuals/photos/noText_E355.jpg)

## Quickstart

The following topics will help you get your new terminal up and running quickly:

* Charge the device.
* Perform a [device security inspection](/point-of-sale/user-manuals/terminal-deprecation/e355-user-manual/inspect-device-security-e355).
* [Connect the e355 to your wireless network](/point-of-sale/user-manuals/terminal-deprecation/e355-user-manual/connect-the-e355-to-your-wireless-network)
* [Board the terminal](/point-of-sale/user-manuals/terminal-deprecation/e355-user-manual/board-the-terminal-e355)

Once you have completed these steps, you are ready to process payments!

## Provided components

* e355 payment terminal
* USB to Micro-USB cable

Integrate the Verifone using the Adyen POS App, or your own POS app.
