# Print a summary of transaction totals - VX680

Print a summary with an overview of the total amounts processed since the last reset.

The terminal can print a summary with an overview of the total amounts processed since the last reset. 

### Steps

If you want to print a summary report periodically, reset the counters after printing the report.

To print the day totals, do the following:

1. Press ****![](/user/pages/reuse/image-library/buttons/05.confirmvx680/9_vx680.png)**** + 9.
2. Enter the PIN code for the Admin menu. If you do not know this code, see our [POS Troubleshooting section](/point-of-sale/pos-troubleshooting/terminal-turns-on/admin-pin/).
3. Press **4. Totals**.
4. Press **2. Print totals&#xA0;**&#x74;o print the day totals\*\*.
5. After printing the day totals, press **Yes** to reset the counter.

If you do not have your admin PIN code, contact our [Support Team](https://ca-test.adyen.com/ca/ca/contactUs/support.shtml?form=other).
