# VX680 user manual

Get started with the VX680 payment terminal.

It is not possible to order new terminals of this type. See [Deprecation of eVo terminals](/point-of-sale/user-manuals/terminal-deprecation).

![](/user/pages/reuse/terminal-manuals/photos/noText_VX680.jpg)

If the terminal shows an exclamation at the top bar, this means that the terminal holds data that it failed to synchronize with the Adyen payments platform due to lack of an outgoing internet connection.

## Quickstart

The following topics will help you get your new terminal up and running quickly:

* Charge the device.
* [Install a paper roll.](/point-of-sale/user-manuals/terminal-deprecation/vx680-user-manual/install-or-replace-paper-rolls-vx680)
* Perform a [device security inspection](/point-of-sale/user-manuals/terminal-deprecation/vx680-user-manual/inspect-device-security-vx680).
* [Connect the terminal to your network](/point-of-sale/user-manuals/terminal-deprecation/vx680-user-manual/connect-the-vx680-to-your-wi-fi-network).
* [Board the terminal](/point-of-sale/user-manuals/terminal-deprecation/vx680-user-manual/board-the-terminal-vx680)

## Provided components

* VX680 PED
* Charging cradle
* Power supply
* Battery
* 1 paper roll
