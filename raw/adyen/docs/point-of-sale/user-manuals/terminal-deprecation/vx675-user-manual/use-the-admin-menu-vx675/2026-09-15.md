# Use the Admin menu - VX675

Use the Admin menu to change network settings, use the installer, use the merchant menu to edit or remove configurations and make maintenance calls, use the totals menu to print and reset totals.

## Steps

1. To enter the terminal Admin menu, press **9** and **![](/user/pages/reuse/image-library/buttons/03.confirmvx675/6_vx675.png)** at the same time.
2. Enter the PIN code for the Admin menu. If you do not know this code, see our [POS Troubleshooting section](/point-of-sale/pos-troubleshooting/terminal-turns-on/admin-pin/).\
   The terminal displays the Admin menu.
