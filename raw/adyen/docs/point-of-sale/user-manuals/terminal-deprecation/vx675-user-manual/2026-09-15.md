# VX675 user manual

Get started with the VX675 payment terminal.

It is not possible to order new terminals of this type. See [Deprecation of eVo terminals](/point-of-sale/user-manuals/terminal-deprecation).

![](/user/pages/reuse/terminal-manuals/photos/noText_VX675.jpg)

## Quickstart

The following topics will help you get your new terminal up and running quickly:

* Charge the device.
* Perform a [device security inspection](/point-of-sale/user-manuals/terminal-deprecation/vx675-user-manual/inspect-device-security-vx675).
* [Install the paper roll](/point-of-sale/user-manuals/terminal-deprecation/vx675-user-manual/install-or-replace-paper-rolls-vx675).
* [Connect the VX675 to your wireless network](/point-of-sale/user-manuals/terminal-deprecation/vx675-user-manual/connect-the-vx675-to-your-wireless-network)
* [Board the terminal](/point-of-sale/user-manuals/terminal-deprecation/vx675-user-manual/board-the-terminal-vx675)

## Provided components

* VX675 payment terminal

* Power Cord/Plug (EU)

* 2x ADYEN Receipt roll
