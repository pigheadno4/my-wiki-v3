# e315 user manual

Get started with the e315 payment terminal.

It is not possible to order new terminals of this type. See [Deprecation of eVo terminals](/point-of-sale/user-manuals/terminal-deprecation).

![](/user/pages/reuse/terminal-manuals/photos/noText_e315.png)

## Quickstart

* Charge the device.
* Perform a [device security inspection](/point-of-sale/user-manuals/terminal-deprecation/e315-user-manual/inspect-device-security-e315).
* Connect the terminal to your network (using the iOS device's connection).
* [Board the terminal](/point-of-sale/user-manuals/terminal-deprecation/e315-user-manual/board-the-terminal-e315)

Once you have completed these steps, you are ready to process payments!

## Provided components

* e315 payment terminal
* USB to Micro-USB cable

Integrate the Verifone using the Adyen POS App, or your own POS app.
