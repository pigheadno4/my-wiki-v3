# Use the Admin menu - e315

Perform basic functions on your terminal, like making a chip or magnetic stripe transaction, printing totals and performing refunds.

***

For devices up to and including version 1.11:

1. Press **![](/user/pages/reuse/image-library/buttons/12.cancele315/1_e315.png)**  + **![](/user/pages/reuse/image-library/buttons/11.confirme315/confirm_e315.png)**  + **![](/user/pages/reuse/image-library/buttons/12.cancele315/1_e315.png)** + **![](/user/pages/reuse/image-library/buttons/11.confirme315/confirm_e315.png)**. 
2. Enter the PIN code for the Admin menu. If you do not know this code, see our [POS Troubleshooting section](/point-of-sale/pos-troubleshooting/terminal-turns-on/admin-pin/).

For devices with version 1.14 and later:

1. Press **![](/user/pages/docs/03.point-of-sale/48.user-manuals/26.terminal-deprecation/01.e315-user-manual/06.use-the-admin-menu-e315/e315Clear.png)** followed by **1,** then **5,** and then **9** 
2. Enter the PIN code for the Admin menu. If you do not know this code, see our [POS Troubleshooting section](/point-of-sale/pos-troubleshooting/terminal-turns-on/admin-pin/).
