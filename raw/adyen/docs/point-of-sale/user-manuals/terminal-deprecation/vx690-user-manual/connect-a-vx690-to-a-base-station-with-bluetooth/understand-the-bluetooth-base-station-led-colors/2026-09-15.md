# Understand the Bluetooth base station LED colors

LED lights are used to communicate the status of your terminal.

***

| LED behavior                                                                                                                  | Status                |
| ----------------------------------------------------------------------------------------------------------------------------- | --------------------- |
| All three LEDs (Green, Orange, Blue) light up.The green LED keeps blinking for roughly 10 seconds and then remains turned on. | Powering on           |
| Blue LED blinks slowly.                                                                                                       | Discover mode enabled |
| The blue LED blinks quickly.                                                                                                  | Pairing               |
| The blue LED remains turned on.                                                                                               | Connected             |
