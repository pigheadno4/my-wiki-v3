# Board the terminal - VX690

Board a terminal to register and use it with the Adyen payments platform.

## Requirements

* Board the terminal only after successfully connecting the device to the internet, and performing a device security inspection. For more information, see the [quick start guide](/point-of-sale/user-manuals/terminal-deprecation/vx690-user-manual).

## Steps

### Board the terminal with the Adyen POS App (Integrated)

#### Prepare to board

1. Press **![](/user/pages/reuse/image-library/buttons/07.confirmvx690/13_vx690.png)** **+ 9** to open the Admin menu. 
2. Enter the PIN code for the Admin menu. If you do not know this code, see our [POS Troubleshooting section](/point-of-sale/pos-troubleshooting/terminal-turns-on/admin-pin/).\
   The terminal displays the Admin menu.
3. Press **1. Network**.
4. Press **2. Wi-Fi**.
5. Press **3. TCP/IP settings** to view and make a note of the terminal's IP address.
6. Download and install the Adyen POS App from the [Apple App Store](https://www.apple.com/app-store/) or the Google Play Store.

#### Board with an Android device

1. Open the Adyen POS App.
2. Enter the details of your API credential. To learn how to retrieve these, see [Basic authentication](/development-resources/api-credentials#basic-authentication).
3. Tap **☰**.
4. Tap **Payment device**.\
   The app will prompt to select between Bluetooth and Wi-Fi connection.
5. Enter the IP address of your terminal and tap **Add Device**.\
   The Adyen POS App identifies the terminal, synchronizes with the Adyen payments platform, and verifies the terminal configuration.
6. The terminal begins boarding and restarts.\
   After rebooting, the terminal will begin to update to the latest merchant configuration. Once the latest configuration has been applied, you can begin processing payments.

#### Board with an iOS device

1. Open the Adyen POS App on the mobile device.
2. Tap the **![](/user/pages/reuse/image-library/buttons/13.bluetoothmenu/ic-pos-bluetooth-3x.png)**  icon.
3. Tap the '**+**' at the top of the **Payment device** popup menu.
4. Enter the device hostname or IP.\
   The device will now be listed in the **Payment device** menu with the status "Not Boarded".
5. Tap the name of the device.\
   The device shows a message saying the device is not configured, with options to **Cancel** or **Board device**.
6. Tap **Board Device**.
7. The terminal begins boarding and restarts.\
   After rebooting, the terminal will begin to update to the latest merchant configuration. Once the latest configuration has been applied, you can begin processing payments.

### Boarding with the Adyen Customer Area (Standalone)

1. Log in to the Adyen Customer Area with your credentials.
2. Go to your Merchant account page.
3. Click **Customize this page**.\
   A widget dock appears.
4. Drag the **Point of Sale** widget from the widget dock to columns on the page.
5. Click **Back to Dashboard**.
6. On the **Point of Sale** widget, click **Board terminal**.
7. Under **Register Terminal**, specify whether your terminal is integrated with a POS system.
8. Under **Receipt**, review the printer status and custom receipt lines.
9. Under **Terminal(s)**, type your serial number and select an API credential.
10. Click **Add more** to board more terminals.
11. Click **Register**.
12. Make sure that the terminal is powered on.
13. Click "**Show one time password**".
14. Enter your one-time password on the terminal.\
    The terminal may reboot more than once.
15. After rebooting, the terminal will begin to update to the latest merchant configuration.
16. Once the latest configuration has been applied, you can begin processing payments..

### Board the terminal with the Adyen Application (Standalone)

Board the terminal using the Adyen POS App once to register it to the Adyen payments platform and configure it for standalone mode. From there you can continue to use the terminal in standalone mode, without the use of the Adyen POS App or our integrations.

If you have any issues boarding your terminal, see our [POS Troubleshooting](/docs/point-of-sale/pos-troubleshooting) section
