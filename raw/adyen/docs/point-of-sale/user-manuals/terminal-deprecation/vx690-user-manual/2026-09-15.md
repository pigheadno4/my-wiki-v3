# VX690 user manual

Get started with the VX690 payment terminal.

* It is not possible to order new terminals of this type, because they are being [deprecated](/point-of-sale/user-manuals/terminal-deprecation).
* This terminal does not support 4G and later technologies. Mobile operators are [ending coverage for 2G/3G](/point-of-sale/design-your-integration/network-and-connectivity/end-of-3g). If you rely on cellular connectivity, choose a terminal that supports 4G.

![](/user/pages/reuse/terminal-manuals/photos/noText_vx690.jpg)

## Quickstart

The following topics will help you get your new terminal up and running quickly:

* Charge the device.

* [Install the paper roll](/point-of-sale/user-manuals/terminal-deprecation/vx690-user-manual/install-or-replace-paper-rolls-vx690).

* Perform a [device security inspection](/point-of-sale/user-manuals/terminal-deprecation/vx690-user-manual/inspect-device-security-vx690).

* [Connect the VX690 to your wireless network](/point-of-sale/user-manuals/terminal-deprecation/vx690-user-manual/connect-the-vx690-to-your-wireless-network)

  If you are using the Bluetooth base station to connect to a network, see [Connect a VX690 to a base station with Bluetooth](/point-of-sale/user-manuals/terminal-deprecation/vx690-user-manual/connect-a-vx690-to-a-base-station-with-bluetooth).

* [Board the terminal](/point-of-sale/user-manuals/terminal-deprecation/vx690-user-manual/board-the-terminal-vx690)

## Provided components

* VX690 payment terminal

* Power Cord/Plug (EU)

* Receipt roll

* Privacy shield
