# Terms of Service components

Use Adyen's prebuilt UI components to collect information from your users as part of your onboarding flow.

##### Learn more

![Megaphone icon](/user/pages/reuse/pfs-components/platform-experience/megaphone.svg?decoding=auto\&fetchpriority=auto)  [Explore the latest updates](/release-notes/platforms-and-financial-products)

The Onboarding components are only compatible with legal entities created with v3 or v4 of the [Legal Entity Management API](https://docs.adyen.com/api-explorer/legalentity/latest/overview).

The Terms of Service components enable users to manage legal documents within your portal's user interface (UI) with minimal engineering effort. These components integrate all the features required to display legal documents and capture acceptance without making multiple API requests.

We recommend using the Terms of Service components in your [API-only onboarding flow](/marketplaces/onboard-users/onboarding-steps) to reduce engineering efforts and speed up implementation. It is important to note that the Terms of Service components only cover functionality related to Terms of Service documents, and you still need to implement API calls for other parts of your API-only onboarding flow.

This page provides guidance on:

* The available Terms of Service components, which include the **Accept Terms of Service** component and the **Manage Terms of Service** component.
* A standard user flow that these components cover.
* Functionalities such as accepting the latest Terms of Service documents, viewing their current status, and downloading signed copies for user records.

The guidance and features available may differ based on the library version in use. We recommend using the latest library version to take advantage of the newest features and improvements.

Ensure you select a version in the next section before starting your integration.
