# Transition to the new Customer Area menu

Learn what changes to expect and how to navigate the updated Customer Area menu.

Starting in July 2026, we are updating the Customer Area menu to make it easier to find what you need. Menu items will be moved and renamed to better align with your workflows. This page explains what is changing and when these changes will take place.

## What has changed

### Renamed and moved pages

Some pages have been renamed or moved to different sections in the menu, for example:

* **Transactions** is now **Payments**.
* **Finance** pages are now in **Balances**, **Reconciliation**, or **Reports**.
* **Insights** is now **Analytics**.

For a full list of changes, see [Where did a page move to](#where-did-a-page-move-to).

### Search for a page

You can search for pages using both their new and old names. To search for a page:

1. Select the search icon at the top of the menu.
2. Start typing to see matching pages.
3. Select a page from the results to open it.

### Expand or collapse menu sections

You can view or hide multiple sections at the same time:

1. Select a section to expand it.
2. Repeat this for any other sections you want to view. Sections stay open as you navigate.
3. Select the **Hide all pages** icon to collapse all sections.

## Timeline

We are rolling out the new Customer Area menu in phases:

| Phase                                  | Availability      | What to expect                                                                                                                                                                                                                                                                                                                |
| -------------------------------------- | ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Early access** (starts mid-May)      | Selected accounts | The new menu is the default for selected accounts to gather initial feedback. If you have access during this phase, you can:- Switch back to the old menu using the **Switch to old menu** button.
- Share feedback about the new menu using the **Give feedback** button.                                                    |
| **Public preview** (starts 6 July)     | All users         | The new menu is available for all users to try. The old menu remains the default. During this phase, all users can:- Switch to the new menu using the **Try new menu** button.
- Switch back to the old menu using the **Switch to old menu** button.
- Share feedback about the new menu using the **Give feedback** button. |
| **Official launch** (starts 15 July)   | All users         | The new menu becomes the default menu for all users of the Customer Area. During this phase, you can:- Continue using the new menu by default.
- Switch back to the old menu if needed.                                                                                                                                       |
| **Full transition** (starts 15 August) | All users         | The new menu is fully rolled out.- The old menu is no longer available.
- All users use the new menu.                                                                                                                                                                                                                         |
