# Country and feature support

There are 4 levels of payout features:

| Type of payout              | Features                                       |
| --------------------------- | ---------------------------------------------- |
| Send, receive, and withdraw | A merchant can send payouts from this country. |

A PayPal account holder can receive and withdraw money from this country. |
| Send, receive, and withdraw in local currency | A merchant can send payouts from this country.

A PayPal account holder can receive and withdraw money in local currency from this country. |
| Fully localized | A merchant can send payouts from this country.

A PayPal account holder can receive and withdraw money in local currency from this country.

The PayPal app is available in the local language. |
| Receive and withdraw | A merchant can't send payouts from this county.

A PayPal account holder can receive and withdraw money from this country. |

### Payouts restrictions

The following table lists the countries with currency restrictions that affect payouts.

| Country | Currency code | Restrictions                                                             |
| ------- | ------------- | ------------------------------------------------------------------------ |
| Brazil  | BRL           | Brazilian users: This currency is supported as a payment and balance for |

                in-country PayPal accounts only. If the recipient is not from Brazil,
                then PayPal converts funds into the primary currency of the recipient's
                account. The currency conversion rate includes PayPal's spread or fee. |

| Malaysia | MYR | Malaysian users can:

- Send payments in MYR to other Malaysian users.
- Send payments in currencies other than MYR to all
  users.

Malaysian users can't:

- Send payments that require exchange to or from MYR .
- Send MYR balances to non-Malaysian users. |
