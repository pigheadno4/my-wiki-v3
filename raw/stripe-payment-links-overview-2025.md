# Accept payments online without writing code

Create a payment link and share it on social media, in emails, or on your website.

## Payment Links

Accept payments with shareable links. Allow your customers to use a link to pay in their local language and currency with their preferred payment method.

## Features and availability

| Feature | Value |
| --- | --- |
| UI | Stripe-hosted page |
| UI customization | Limited — 20 preset fonts, 3 preset border radius options, custom logo/background/button colors |
| Integration effort | No code |
| Language | Preferred language rendering (browser language) |
| Currency | Local currency with Adaptive Pricing |
| Payment methods | 40+ |
| Automatic receipts | Yes |
| No-code refunds | Yes |

## Get started

- **Create a payment link** — Create a custom payment page without code
- **Share a payment link** — Share across social media, emails, or your website
- **Track a payment link** — Use URL parameters and UTM codes
- **Create an embeddable buy button** — Embed on your website
- **Customize your checkout session** — Collect additional information, taxes, or update branding

## Additional no-code capabilities

- **Collect addresses** — Collect addresses and phone numbers without code
- **Charge for shipping** — Create different shipping rates
- **Promotion codes, optional items, and upsells** — Add promotion codes, upsells, optional items
- **After receiving a payment** — Track payments, manage fulfillment automatically, view metrics
- **Use the API to create and manage payment links** — Create and manage with the API

## Compare Invoicing and Payment Links

| | Invoicing | Payment Links |
| --- | --- | --- |
| Description | Collect one-time or recurring payments from a specific customer | Sell a product, subscription, or accept a donation |
| Customer | Specific individuals or businesses | Anyone with the link |
| Reusability | Can't reuse; can duplicate and edit | Reuse multiple times, or limit number of purchases |
| Integration effort | No code | No code |
| Sharing options | Email from Dashboard; copy invoice link; send PDF; auto-charge on file; QR code | Copy link; share over email/SMS/social; add buy button to website |
| UI customization | Editable template (icons, brand colors, payment terms, page sizes, memo/footer) | Limited (20 fonts, 3 border radius, logo/background/button color) |
| Payment methods | 40+ managed in Dashboard | 40+ dynamic, managed in Dashboard |
| Preferred language | 30+ languages; set per customer in Dashboard | 30+ languages; matches browser setting |
| Recurring payments | Subscription/recurring invoices via Stripe Billing | Create payment link for subscription |
| Collection tools | Smart Retries, reminder emails | Smart Retries + reminder emails for subscription links only |
| Reconciliation | Auto-reconciliation of bank payments | Simple reconciliation via URL parameters |
