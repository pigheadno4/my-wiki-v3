# Eligibility

This page covers the countries, currencies, card brands, and payment methods that Expanded Checkout supports.

If you have an Express Checkout or PayPal Checkout integration, PayPal recommends upgrading to Expanded Checkout using the JavaScript SDK. Visit Upgrade your Checkout integration for more information.

## 3D Secure authentication 
3D Secure is available for Expanded Checkout payment integrations.

If you are based in Europe, you may be subject to the Second Payment Services Directive (PSD2):
- Include 3D Secure as part of your integration.
- Pass the cardholder's billing address as part of the transaction processing.
