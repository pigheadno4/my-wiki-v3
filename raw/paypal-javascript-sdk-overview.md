# JavaScript SDK
The JavaScript SDK displays PayPal-supported payment methods on your page to give your buyers a personalized and streamlined checkout experience.

You can use the JavaScript SDK to render [buttons](https://developer.paypal.com/sdk/js/reference/#buttons) , payment method icons ( [marks](https://developer.paypal.com/sdk/js/reference/#marks) ), and credit and debit card form fields ( [card-fields](https://developer.paypal.com/sdk/js/reference/#link-cardfields) ). You can also use the JavaScript SDK to check the [funding-eligibility](https://developer.paypal.com/sdk/js/reference/#funding-eligibility) of a given payment method.

## Configuration
[Configure and customize your integration](/docs/business/javascript-sdk/javascript-sdk-configuration/) by passing query and script parameters in the JavaScript SDK script. These parameters personalize your setup and help PayPal decide the optimal funding sources and buttons to show to your buyers.
