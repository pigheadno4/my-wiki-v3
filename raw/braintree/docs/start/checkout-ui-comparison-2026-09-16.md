# Checkout UIs

To accept payments, you will need a payment form. You can integrate using the Drop-in UI – our
ready-made payment form – or choose to build your own checkout UI for more customization and
control.|  | Drop-in UI | Custom UI |
| --- | --- | --- |
| Supported platforms | ![Browser,icon](https://www.paypalobjects.com/btdevdoc/braintree/img/temporary/browser_icon.svg) Desktop and mobile web

![Mobile,icon](https://www.paypalobjects.com/btdevdoc/braintree/img/temporary/mobile_icon.svg) iOS and Android apps | ![Browser,icon](https://www.paypalobjects.com/btdevdoc/braintree/img/temporary/browser_icon.svg)  Desktop and mobile web using Hosted Fields

![Mobile,icon](https://www.paypalobjects.com/btdevdoc/braintree/img/temporary/mobile_icon.svg) iOS and Android apps |
| Customizability | Pre-made checkout form with customization options | Create your own payment form with custom colors and layout |
| Security and PCI compliance | Typically qualifies you for SAQ A | Typically qualifies you for SAQ A when using[Hosted Fields](/braintree/docs/guides/hosted-fields/overview)and mobile SDKs |
| Translations | Available in up to 23 languages | Add your own translations |
| Supported payment methods | Cards, PayPal, Apple Pay, Google Pay*, Masterpass, UnionPay*, and Venmo*


- Mobile only | Cards, PayPal, Apple Pay, Google Pay, Masterpass, UnionPay, Venmo, and Visa Checkout |
| Fraud protection | Supports both Basic and Premium Fraud Management Tools | Supports both Basic and Premium Fraud Management Tools |
