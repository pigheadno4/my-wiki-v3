# Countries

You can specify the country using name, alpha-2 code, alpha-3 code, or numeric code.


## Alpha-2 code


### Callback
```javascript

gateway.transaction.sale({
  amount: "10.00",
  paymentMethodNonce: nonceFromTheClient,
  billing: {
    countryCodeAlpha2: "US"
  }
}, (err, result) => { });

```

### Promise
```javascript

gateway.transaction.sale({
  amount: "10.00",
  paymentMethodNonce: nonceFromTheClient,
  billing: {
    countryCodeAlpha2: "US"
  }
}).then(result => { });

```
