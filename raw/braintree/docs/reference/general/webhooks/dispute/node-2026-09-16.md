# Dispute


### Notification kinds

The notification kind, returned by calling`kind`on the[notification object](/braintree/docs/guides/webhooks/parse), reveals what triggered the webhook. The`webhook_notification.kind`for Dispute webhooks will be one of the following:The following table describes the conditions that trigger each kind of webhook.

| **Notification Type** | **Description** |
| --- | --- |
| ```syntax-inline
dispute_accepted
``` | A dispute is accepted. |
| ```syntax-inline
dispute_auto_accepted
``` | A dispute is automatically accepted. |
| ```syntax-inline
dispute_disputed
``` | A dispute is disputed. |
| ```syntax-inline
dispute_expired
``` | A dispute is expired. |
| ```syntax-inline
dispute_lost
``` | A dispute is lost. |
| ```syntax-inline
dispute_opened
``` | A dispute is opened. |
| ```syntax-inline
dispute_under_review
``` | A dispute is under internal review with PayPal. |
| ```syntax-inline
dispute_won
``` | A dispute is won. |
