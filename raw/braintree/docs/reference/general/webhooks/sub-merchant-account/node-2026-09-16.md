# Sub-merchant Account


### Notification kinds

The notification kind, returned by calling`kind`on the[notification object](/braintree/docs/guides/webhooks/parse), reveals what triggered the webhook. The`webhook_notification.kind`for Sub-merchant Account webhooks will be one of the following:

The following table describes the conditions that trigger each kind of webhook.

| Notification Type | Description |
| --- | --- |
| sub_merchant_account_approved | A sub-merchant has been approved. |
| sub_merchant_account_declined | A sub-merchant has been declined. |


### Attributes

The kind of webhook notification.The UTC date/time at which the webhook was triggered.A[MerchantAccount](/braintree/docs/reference/response/merchant-account)object.

See the [sub-merchant onboarding guide](/braintree/docs/guides/braintree-marketplace/confirmation/node#sub-merchant-declined) for additional attributes available on a sub_merchant_account_declined webhook.
