# Transaction


**AVAILABILITY**
 Transaction webhooks are available for ACH and SEPA Direct Debitandrequests. 


### Notification kinds

The notification kind, returned by calling`kind`on the[notification object](/braintree/docs/guides/webhooks/parse), reveals what triggered the webhook. The`webhook_notification.kind`for Transaction webhooks will be one of the following:

The following table describes the conditions that trigger each kind of webhook.

| **Notification Type** | **Description** |
| --- | --- |
| ```syntax-inline
transaction_settlement_declined
``` | Settlement for the transaction was declined.

 May be triggered after the ```syntax-inline
transaction_settled
```
 webhook if the customer's bank returns the refund after it has appeared to settle. |
| ```syntax-inline
transaction_settled
``` | Transaction successfully settled. |


### Attributes

The kind of webhook notification.The UTC date/time at which the webhook was triggered.A[Transaction](/braintree/docs/reference/response/transaction)object. The associated transaction.
