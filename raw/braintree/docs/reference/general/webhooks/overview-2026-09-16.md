# Overview

For information on how to create or parse webhooks, go to [the webhooks guide](/braintree/docs/guides/webhooks/overview).


## Notification kinds

The notification kind, returned by calling `kind` on the notification object, reveals what triggered the webhook.

These can be events related to a variety of things - for example, subscription activity or the underwriting of Braintree Marketplace merchant accounts. The specific trigger conditions depend on the notification kind.

Each type falls into one of the following broader categories:


- [Account Updater](/braintree/docs/reference/general/webhooks/account-updater)
- [Braintree Auth](/braintree/docs/reference/general/webhooks/braintree-auth)
- [Disbursement](/braintree/docs/reference/general/webhooks/disbursement)
- [Dispute](/braintree/docs/reference/general/webhooks/dispute)
- [Fraud Protection](/braintree/docs/reference/general/webhooks/fraud-protection)
- [Grant API](/braintree/docs/reference/general/webhooks/grant-api)
- [Local Payment Methods](/braintree/docs/reference/general/webhooks/local-payment-methods)
- [OAuth](/braintree/docs/reference/general/webhooks/oauth)
- [Payment Method](/braintree/docs/reference/general/webhooks/payment-method)
- [Sub-merchant Account](/braintree/docs/reference/general/webhooks/sub-merchant-account)
- [Subscription](/braintree/docs/reference/general/webhooks/subscription)
- [Test](/braintree/docs/reference/general/webhooks/test)
- [Transaction](/braintree/docs/reference/general/webhooks/transaction)
- [Transaction Issues](/braintree/articles/control-panel/transactions/transaction-issues)


## Attributes

All webhook notifications have a `kind`, a `timestamp`, and an additional attribute that is specific to the notification [type](#notification-kinds).


## Triggers

The specific trigger conditions depend on the notification [kinds](#notification-kinds).


## Exceptions

An [invalid signature exception](/braintree/docs/reference/general/exceptions/ruby#invalid-signatur) is raised if the webhook notification you attempt to parse has an invalid signature.
