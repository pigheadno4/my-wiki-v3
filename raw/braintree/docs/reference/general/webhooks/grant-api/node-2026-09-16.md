# Grant API


### Notification kinds

The notification kind, returned by calling`kind`on the[notification object](/braintree/docs/guides/webhooks/parse), reveals what triggered the webhook. The`webhook_notification.kind`for Grant API webhooks will be one of the following:

The following table describes the conditions that trigger each kind of webhook.

| **Notification Type** | **Description** |
| --- | --- |
| ```syntax-inline
granted_payment_instrument_update
``` | A payment instrument that was previously granted to another Braintree merchant has been updated. The ```syntax-inline
kind
```
 will either be ```syntax-inline
GrantorUpdatedGrantedPaymentMethod
```
 or ```syntax-inline
RecipientUpdatedGrantedPaymentMethod
```
 depending on which side of the relationship the webhook is being sent to. |
| ```syntax-inline
granted_payment_instrument_revoked
``` | A payment instrument that was previously granted has been revoked by the grantor. |


### Attributes

The kind of webhook notification.The UTC time at which the webhook was triggered.An alphanumeric value that references a specific payment method stored in your Vault.A value representing an existing customer's payment method stored in your Vault. Use[Customer: Find](/braintree/docs/reference/request/customer/find)call to look up a single customer.The[PaymentMethod](/braintree/docs/reference/response/payment-method)object associated with the revoked granted payment method.The[merchant ID](/braintree/articles/control-panel/important-gateway-credentials#merchant-id)of the Braintree merchant that owns the payment instrument.The[merchant ID](/braintree/articles/control-panel/important-gateway-credentials#merchant-id)of the Braintree merchant that was granted the payment instrument.An object containing the payment method nonce, which represents the updated payment instrument.A payment method nonce representing the updated payment instrument.A value that indicates if the payment method nonce has been used.An array of strings denoting all of the fields of the payment instrument that were updated.

See the [Grant API webhooks guide](/braintree/docs/reference/xml-api/grant-api/webhooks) for additional attributes specific to each webhook kind.
