# Disbursement


### Notification kinds

The notification kind, returned by calling `kind` on the [notification object](/braintree/docs/guides/webhooks/parse), reveals what triggered the webhook. The `webhook_notification.kind` for Disbursement webhooks will be one of the following:

The following table describes the conditions that trigger each kind of webhook.

| **Notification Type** | **Description** |
| --- | --- |
| ```syntax-inline
disbursement
``` | **Braintree-funded merchant accounts only**    We have sent a disbursement to your account (meaning it will leave our bank account today). The difference between this and a ```syntax-inline
transaction_disbursed
```
 webhook is that this is sent per merchant account per day, rather than per transaction. |
| ```syntax-inline
transaction_disbursed
``` | **Braintree-funded merchant accounts only**   **Deprecated**   A transaction has been marked for disbursement (meaning it will leave our bank account today). |
