# Upgrade to Braintree SDKs


## Integration features

If you've done a previous integration with Braintree, you may want to upgrade to our SDKs to support new features. Here is a table showing feature support across different integrations:

|  | **Server-to-Server** | **Transparent Redirect** | **Braintree.js** | ****[Braintree SDKs](/braintree/docs/start/overview) |
| --- | --- | --- | --- | --- |
| Accept credit cards and debit cards | × | × | × | × |
| Accept PayPal, Apple Pay, Google Pay, and Venmo |  |  |  | × |
| PCI compliant | × | × | × | × |
| Native SDKs for iOS, Android, and web |  |  |  | × |
| Supports AJAX |  |  | × | × |


## How to upgrade

Below are upgrade instructions for each legacy Braintree integration option. 
**NOTE**
Note, if you're using the Vault, you can safely upgrade. All your previously Vaulted customer information and payment information will still be accessible.


### Server-to-Server

The Braintree [client SDKs](/braintree/docs/start/hello-client) produce a payment method nonce used in place of credit card details to create a transaction on your server. To upgrade:


- Add the[client SDKs](/braintree/docs/start/hello-client)to your app or site.
- Update your server integration to[accept a payment method nonce](/braintree/docs/start/hello-server/)in place of credit card details.


### Transparent Redirect

Braintree's Drop-in integration replaces Transparent Redirect. To upgrade:


- Add the[Drop-in payment form](/braintree/docs/start/hello-client)to your site.
- Update your server integration to[accept a payment method nonce](/braintree/docs/start/hello-server/)in place of confirming the redirect.


### Braintree.js

The [client SDKs](/braintree/docs/start/hello-client) replace the old Braintree.js integration. To upgrade:


- Add the[client SDKs](/braintree/docs/start/hello-client)to your app or site.
- Update your server integration to[accept a payment method nonce](/braintree/docs/start/hello-server/)in place of encrypted card fields.
