# Network Tokenization Fields

Braintree supports credit card processing with network tokens. A transaction will be qualified to be
processed with a network token if the vaulted credit card has been tokenized. This capability is
currently supported for Visa and Mastercard vaulted credit cards.
**IMPORTANT**
To ensure that your merchant account is eligible for network tokenization, contact our [Customer Success team](/braintree/help?issue=feeHelp) .


## Server-Side Response Objects

Below response fields will betrueif aCreditCardhas been tokenized and
aTransactionhas been processed with a network token.

| Field | Type | Explanation |
| --- | --- | --- |
| `is_network_tokenized?` | ```syntax-inline
boolean
``` | Indicates whether this card has been network tokenized. A network tokenized card is an alternative payment credential type with a token account number (TPAN) that is used in place of the underlying source card. |

| Field | Type | Explanation |
| --- | --- | --- |
| `processed_with_network_token?` | ```syntax-inline
boolean
``` | Indicates whether this transaction has been processed with a network token. |
| `network_token` | ```syntax-inline
map
``` | Ifis`network_token`, the details of the token used for the transaction are in key value pair. |
