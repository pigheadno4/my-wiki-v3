# Enterprise Third-Party Plugins

We make it easy for enterprise merchants to connect Braintree to many of the major ecommerce and ERP
platforms.
## SAP Commerce Cloud (Hybris)

| [https://www.sap.com/products/commerce-cloud.html](https://www.sap.com/products/commerce-cloud.html) |
| ##### Type

Ecommerce


##### Supported versions


- Hybris Commerce v6.0-6.7
- B2B
- B2C


##### Details


- Provides ecommerce customer interface (checkout page)
- Supports transaction and customer management
- Supports PayPal Smart Payment Button
- Supports manual order creation for phone transactions
- Supports Backoffice and Braintree Customer Service Cockpit | ##### Capabilities

**Payment method types**
- PayPal
- Credit cards
- Apple Pay

**Processing/Settlement**
- Multi-currency
- Partial refunds
- Multiple partial settlements

**Additional functionality**
- Premium Fraud Management Tools
- 3D Secure
- Vault
- Hosted Fields |
**Visit the**[SAP App Center](https://store.sap.com/dcp/en/)and[email our Plugins team](mailto:braintreepaypalplugins@paypal.com)for additional information or support.

## Netsuite ERP

| [https://www.suiteapp.com/PayPal-Braintree-for-NetSuite-SuitePayments](https://www.suiteapp.com/PayPal-Braintree-for-NetSuite-SuitePayments) |
| ##### Type

Enterprise Resource Planning (ERP)


##### Details


- Supports NetSuite One World, Multiple currencies
- Basic Fraud and L2/L3
- Built for NetSuite Certified | ##### Capabilities

**Payment method types**
- Credit/Debit Cards
- ACH (US Only)
- PayPal

**Processing**
- MOTO Payments - NetSuite BackOffice
- E-commerce - SuiteCommerce & Third-party platforms
- Online Customer Payments - Payment Link and My Account

**Additional functionality**
- Payment Token Retrival for External E-commerce Orders
- Vaulting - Credit Card Tokenization |
****[Email our plugins team](mailto:braintreepaypalplugins@paypal.com)for additional information or support.
