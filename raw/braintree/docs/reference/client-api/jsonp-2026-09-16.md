# Accessing the Client API via JSONP

Most methods in the Client API can be accessed via JSONP. Instead of issuing aPOSTrequest, methods are invoked as:
### curl
```curl
curl -X GET http://client-api.endpoint?_method=POST&callback=myCallbackName
```
Responses will invokemyCallbackNamewith the JSON returned by the API. In addition to
their normal content, response objects will contain astatuskey
corresponding to the HTTP status code the request would have returned if the request had not been a
JSONP request. An error response will be returned for unsuccessful requests.
