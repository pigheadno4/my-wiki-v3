# Client API

The Client API is an HTTP API for handling different types of payment methods in a unified way. It
accepts details for different payment method types and returns transactable[payment method nonces](/braintree/docs/guides/payment-method-nonces). The Braintree[iOS](https://github.com/braintree/braintree_ios),[Android](https://github.com/braintree/braintree_android), and[JavaScript](/braintree/docs/guides/client-sdk/setup/javascript/v3)SDKs use the Client
API to tokenize, vault, and retrieve supported payment methods.
## Requests

All requests are authenticated with an[authorization fingerprint](/braintree/docs/reference/client-api/authorization)that
grants limited authorization safe for use on an untrusted client. Requests may be either GET or POST
depending on endpoint, and should have anAccept: application/jsonheader. GET params
should be URL-encoded. POST requests must send JSON with aContent-Type: application/jsonheader.
### bash
```bash
curl -X POST https://api.braintreegateway.com/merchants/MERCHANT_ID/client_api/v1/payment_methods/credit_cards \
    -H 'Content-Type: application/json' \
    -H 'Accept: application/json' \
    -d '{
        "authorizationFingerprint": AUTHORIZATION_FINGERPRINT,
        "creditCard": {
            "number": "4111111111111111",
            "expirationDate": "01/19"
        }
    }'
```

## Responses

The client API returns JSON (or a JavaScript function invocation, in the case of[JSONP](/braintree/docs/reference/client-api/jsonp)).
### JSON
```json

{
  "creditCards": [
    {
      "type": "CreditCard",
      "nonce": "A_PAYMENT_METHOD_NONCE",
      "description": "ending in 11",
      "details": {
        "cardType": "Visa",
        "lastTwo": "11"
      }
    }
  ]
}

```
```json## Errors Errors are indicated via HTTP status codes and error object responses. Validation and authorization errors are returned with developer-facing information about what went wrong. The basic format is:
### JSON
```json

{
  "error": {
    "message": "a descriptive error message"
  },
  "fieldErrors": []
}

```
`fieldErrors` is a nested structure that may contain field-level errors:
### JSON
```json

    {
    "fieldErrors": [
        {
        "field": "credit_card",
        "fieldErrors": [
            {
            "field": "number",
            "code": "001",
            "message": "is invalid"
            },
            {
            "field": "number",
            "message": "has a problem"
            }
        ]
        }
    ]
    }

```
