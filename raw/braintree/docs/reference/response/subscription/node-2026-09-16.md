# Subscription


**NOTE**
Results are limited according to the [PayPal Data Protection Addendum For Card Processing Products policy](https://www.paypal.com/us/legalhub/braintree/data-protection-addendum) .


## Subscription history

Each subscription history object returned on a subscription includes the following details:| Field Name | Description |
| --- | --- |
| `balance` | The balance of the subscription. |
| `price` | The price of the subscription. |
| `status` | The subscription status. Possible values: 
- Active
- Canceled
- Expired
- PastDue
- Pending |
| `subscription_source` | Where the subscription event was created. Possible values: 
- api
- control_panel
- recurring |

Here's an example of how to get a subscription's history using themethod:
### Callbacks
```node
gateway.subscription.find("a_subscription_id", function(err, subscription) {
  subscription.statusHistory[0].balance;
  // "12.34"
});

```

### Promises
```node
gateway.subscription.find("a_subscription_id").then(subscription => {
  subscription.statusHistory[0].balance;
  // "12.34"
});

```
