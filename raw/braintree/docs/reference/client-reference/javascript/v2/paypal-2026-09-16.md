# PayPal


## Options

The PayPal functionality of Braintree.js accepts a few different options. The below options can be
used for all PayPal integration types (Vault, Checkout with PayPal).
**IMPORTANT**
If you are using a custom or dropin setup, you must specify paypal as its own object and nest the following configuration under it. For an example, see our [Drop-in guide](/braintree/docs/guides/drop-in/setup-and-integration/javascript/v2#paypal) .
