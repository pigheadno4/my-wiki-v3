# Config


**AVAILABILITY**
 **Use of the production** [Forward API](/braintree/docs/reference/forward-api/overview/) is subject to eligibility. 

 Contact your Account Manager for more information or [submit an inquiry to our Business Development team](https://www.braintreepayments.com/products/braintree-extend#contact) .

The config of the[**Forward API**](/braintree/docs/reference/forward-api/overview/)describes the third-party destination: request encoding, HTTP method, and how to inject the payment data.


- In production, you will send us a JSON file for each config, which we will review, approve, and load.
- In sandbox, you may[include a config object in-line](/braintree/docs/reference/forward-api/forward#config)with forwarding requests or send us a JSON file.

Identifying the config by [name](/braintree/docs/reference/forward-api/forward#name) is supported in both sandbox and production after the config has been loaded.
