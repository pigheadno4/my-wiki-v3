# Forward


**AVAILABILITY**
 **Use of the production** [Forward API](/braintree/docs/reference/forward-api/overview/) is subject to eligibility. Contact your Account Manager for more information or [submit an inquiry to our Business Development team](https://www.braintreepayments.com/products/braintree-extend#contact) .

The available keys on an incoming[Forward API](/braintree/docs/reference/forward-api/overview/)request.```syntax-inline
POST
```
[https://forwarding.sandbox.braintreegateway.com/](https://forwarding.sandbox.braintreegateway.com/)


#### Trace-ID

You can add a tracer to a Forward API request by including the header -H “Trace-Id: 123456790357”. The tracer value you pass in Trace-Id will show up in all of the logs for this request.


#### Parameters

[client_cert](#client_cert)StringA [PEM-encoded](https://en.wikipedia.org/wiki/Privacy-enhanced_Electronic_Mail)  [X.509](https://en.wikipedia.org/wiki/X.509) certificate for [TLS mutual authentication](/braintree/docs/guides/extend/forward-api/cryptography#tls-mutual-authentication). (sandbox only)

[client_key](#client_key)StringThe [PEM-encoded](https://en.wikipedia.org/wiki/Privacy-enhanced_Electronic_Mail) private key used to create the [CSR](https://en.wikipedia.org/wiki/Certificate_signing_request) that generated the [client_cert](#client_cert). (sandbox only)

[config](#config)objectWhen config is present it will be used in lieu of the [config](/braintree/docs/reference/forward-api/config) specified by name. Just like production configs, the types key must be present and must contain the type of the forwarded payment instrument. (sandbox only)

[configs](#configs)arrayWhen configs is present it will be used in lieu of the [config](/braintree/docs/reference/forward-api/config) specified by name. It is a list of configs; the first one with a types key which contains the type of the forwarded payment instrument will be used. (sandbox only)

[cse_data](#cse_data)object

**Only for payment data captured via our deprecated client-side encryption integration**

A map containing client-side encrypted values. The decrypted value will be bound to the global variable specified by the key and made available to transformations.



[data](#data)objectA list of values which are made available to transformations as global variables. (Seevariable lookupin the [functions](/braintree/docs/reference/forward-api/functions) section.)

[debug_transformations](#debug_transformations)booleanWhen debug_transformations is present no request is sent to the destination. A representation of the request which would have been executed in the absence of debug_transformations is instead returned. The query string which would have been used is returned in theX-Query-Stringheader. (sandbox only)

[merchant_id](#merchant_id)String

RequiredThe unique identifier of the merchant whose Vault will be accessed.



[method](#method)String

RequiredThe HTTP method to use when making the request.



[name](#name)StringThe name of the endpoint receiving the card information (used to lookup which [config](/braintree/docs/reference/forward-api/config) to use for this request). Required in production.

[override](#override)objectA map structured like the one in [template](/braintree/docs/reference/forward-api/config#template). Used to override the transformations, any transformation which would have written to a part of the template specified here will no-op.

[body](#body)objectA representation of the body of the request.

[header](#header)objectA map which will become the headers of the request.

[urlparam](#urlparam)objectThe map which will become the query string of the request.

[payment_method_nonce](#payment_method_nonce)StringThepayment_method_nonceof the payment instrument being forwarded.

[payment_method_token](#payment_method_token)StringThepayment_method_tokenof the payment instrument being forwarded.

[payment_method_tokens](#payment_method_tokens)arrayThe array ofpayment_method_tokens to forward. Variable bindings are 1-indexed (e.g.$number_1corresponds to the card number of the first token).

[sensitive_data](#sensitive_data)objectA list of values that are made available to transformations as global variables. They will not be logged by the Forward API.

[url](#url)StringThe URL to which the request will be made.

[urls](#urls)arrayIt's possible that different types of payment instrument will need to be forwarded to different endpoints.urlsspecifies a list of candidate endpoints to use. Once a config has been chosen the first url matching that config's url regex will be used.

[variable_aliases](#variable_aliases)objectA map of alias -&gt; backing variable name, provided as a convenience for complex integrations [forwarding multiple payment methods](/braintree/docs/guides/extend/forward-api/examples#forwarding-multiple-payment-methods-with-aliases).
