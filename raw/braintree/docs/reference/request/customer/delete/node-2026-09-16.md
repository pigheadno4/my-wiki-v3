# Customer: Delete

You can delete a customer using its ID. When a customer is deleted, all associated payment methods
are also deleted, and all associated recurring billing subscriptions are canceled.
### Node
```javascript
gateway.customer.delete("theCustomerId", (err) => {
    err; // null
});
```
