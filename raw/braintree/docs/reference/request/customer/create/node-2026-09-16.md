# Customer: Create

See also the [Customer](/braintree/docs/reference/response/customer) response object.

You can create a customer by itself, with a payment method, or with a [credit card with a billing address](#customer-with-a-payment-method-and-billing-address).


**NOTE**
 If you intend to create a transaction at the same time as a customer, you may want to usewith either theoroptions. 


### Node
```javascript
gateway.customer.create({
  firstName: "Jen",
  lastName: "Smith",
  company: "Braintree",
  email: "jen@example.com",
  phone: "312.555.1234",
  fax: "614.555.5678",
  website: "www.example.com"
}, (err, result) => {
  result.success;
  // true

  result.customer.id;
  // e.g. 494019
});
```

## Examples


### Specify your own customer ID

You can optionally choose what you would like the ID to be. Customer IDs are case insensitive.

### Callback
```javascript

gateway.customer.create({
  id: "customer_123",
  firstName: "Katrina"
}, (err, result) => {
});

```

### Promise
```javascript

gateway.customer.create({
  id: "customer_123",
  firstName: "Katrina"
}).then(result => { });

```

### Customer with a payment method

You can also create a payment method along with a customer. If all [customer validations](/braintree/docs/reference/general/validation-errors/all#customer) and [credit card validations](/braintree/docs/reference/general/validation-errors/all#payment-method) or [PayPal account validations](/braintree/docs/reference/general/validation-errors/all#paypal) pass, and the credit card is verified (if supplied and verification [is requested](/braintree/docs/reference/general/validation-errors/all#payment-method) ), success will return true.

If you do not specify a token for the payment method, as in the example above, the gateway will generate one. If you are using a custom integration, you can also choose what you want the token to be.

### Callback
```javascript

gateway.customer.create({
  creditCard: {
    token: "creditCard123",
  },
  paymentMethodNonce: nonceFromTheClient
}, (err, result) => {
});

```

### Promise
```javascript

gateway.customer.create({
  creditCard: {
    token: "creditCard123",
  },
  paymentMethodNonce: nonceFromTheClient
}).then(result => { });

```


#### Customer with a payment method and billing address

You can also pass in a billing address when creating a customer and payment method.


### Callback

gateway.customer.create({

      lastName: "Smith",

      locality: "City",

});

#### Card verification

By default we will run[credit card validations](/braintree/docs/reference/general/validation-errors/all#credit-card)but not perform[verification](/braintree/docs/guides/credit-cards/server-side/node#card-verification). Braintree strongly recommends verifying all cards before they are stored in your Vault by[enabling card verification for your entire account](/braintree/articles/control-panel/vault/card-verification)in the Control Panel. If you choose to manually verify cards, set`verify_card`to`true`.
### Callback
```javascript

gateway.customer.create({
  paymentMethodNonce: nonceFromTheClient,
  firstName: "Fred",
  lastName: "Jones",
  creditCard: {
    options: {
      verifyCard: true
    }
  }
}, (err, result) => {
});

```

### Promise
```javascript

gateway.customer.create({
  paymentMethodNonce: nonceFromTheClient,
  firstName: "Fred",
  lastName: "Jones",
  creditCard: {
    options: {
      verifyCard: true
    }
  }
}).then(result => { });

```

**IMPORTANT**
 If you are using our Premium Fraud Management Tools, we strongly recommend passing [`device_data`](/braintree/docs/guides/premium-fraud-management-tools/server-side/node#using-device-data) each time you verify a card.

 


### Use custom fields

Use custom fields to store additional data about your customers in Braintree. You'll need to [configure your custom fields in the Control Panel](/braintree/articles/control-panel/custom-fields) to use them via the API.

Here is an example of setting custom fields with API names of custom_field_one and custom_field_two :


### Callback
```javascript

gateway.customer.create({
  firstName: "Bob",
  lastName: "Smith",
  customFields: {
    customFieldOne: "value one",
    customFieldTwo: "value two"
  }
}, (err, result) => {
  result.customer.customFields["customFieldOne"]
  // value one

  result.customer.customFields["customFieldTwo"]
  // value two
});

```

### Promise
```javascript

gateway.customer.create({
  firstName: "Bob",
  lastName: "Smith",
  customFields: {
    customFieldOne: "value one",
    customFieldTwo: "value two"
  }
}).then(result => {
  result.customer.customFields["customFieldOne"]
  // value one

  result.customer.customFields["customFieldTwo"]
  // value two
});

```
