# Credit Card: Find


**IMPORTANT**
 **Typically requires** [PCI SAQ D compliance](https://www.pcisecuritystandards.org/pci_security/completing_self_assessment) We recommend using [`payment_method`](/braintree/docs/guides/payment-methods/node#find) functions to avoid any PCI concerns with raw credit card data being present on your server.


### Node
```javascript
gateway.creditCard.find(creditCardToken, (err, creditCard) => {
});
```
