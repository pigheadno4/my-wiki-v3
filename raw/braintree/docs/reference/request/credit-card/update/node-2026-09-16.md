# Credit Card: Update


**IMPORTANT**
 **Typically requires** [PCI SAQ D compliance](https://www.pcisecuritystandards.org/pci_security/completing_self_assessment) We recommend using [`payment_method`](/braintree/docs/guides/payment-methods/node#update) functions to avoid any PCI concerns with raw credit card data being present on your server.


**NOTE**
If you have [card verification](/braintree/articles/control-panel/vault/card-verification) enabled, any updates made to credit cards are subject to those rules.


### Node
```javascript
gateway.creditCard.update(creditCardToken, {
    cardholderName: 'New Holder',
    number: '4111111111111111',
    expirationDate: '06/2022',
    cvv: '456',
    billingAddress: {
        region: 'IL'
    },
    options: {
        verifyCard: true
    }
}, (err, result) => {
    
});
```

## Payment method nonces vs. raw card data

While it is possible to pass both raw card data and a payment method nonce in the same call, we
recommend passing only a payment method nonce. Passing both will result in a payment method that has
a mix of their attributes, with precedence given to the fields individually, then to the attributes
of the payment method nonce. For example, if you pass both a card number and a payment method nonce,
the payment method will have the number you passed explicitly, but the rest of the attributes will
be obtained through the nonce.
