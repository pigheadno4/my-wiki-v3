# Payment Method: Delete

You can delete a payment method using its token. All associated subscriptions will also be[canceled](/braintree/docs/reference/request/subscription/cancel)immediately and the
customer will forfeit any remaining days they've already paid for.
### Node
```javascript
gateway.paymentMethod.delete("theToken", (err) => {});
```
