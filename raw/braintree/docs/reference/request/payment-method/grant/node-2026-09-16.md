# Payment Method: Grant

See also the[Payment Method](/braintree/docs/reference/response/payment-method)response
object.
**AVAILABILITY**
 **The Grant API is currently in a limited release.**  [Contact us](https://www.braintreepayments.com/products/braintree-extend#contact) to determine whether it's right for your needs and to request access to the API.

The[Grant API](/braintree/docs/reference/xml-api/grant-api/overview)allows you to give
another Braintree merchant controlled access to one of your customer's payment methods.
### Node
```javascript
const gateway = new braintree.BraintreeGateway({
    accessToken: accessTokenForRecipient
});
gateway.paymentMethod.grant(
    "the_payment_method_token",
    {
        allow_vaulting: false,
        include_billing_postal_code: true
    },
    (err, grantResult) => {
        const nonceToSendToRecipient = grantResult.paymentMethodNonce.nonce;
        // ...
    }
);
```
