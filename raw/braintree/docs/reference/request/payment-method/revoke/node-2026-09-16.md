# Payment Method: Revoke

See also the[Payment Method](/braintree/docs/reference/response/payment-method)response object.


**AVAILABILITY**
 **The Grant API is currently in a limited release.**  [Contact us](https://www.braintreepayments.com/products/braintree-extend#contact) to determine whether it's right for your needs and to request access to the API.

The[Grant API](/braintree/docs/reference/xml-api/grant-api/overview)allows you to give another Braintree merchant controlled access to one of your customer's payment methods.

When you[revoke](/braintree/docs/reference/xml-api/grant-api/revocation/node)a grant, we delete the version of the payment method from the receiving merchant's Vault.
### Node
```javascript
gateway.paymentMethod.revoke(
    "theToken",
    (err, result) => {}
);
```
