# Merchant Account: Update

See also the [Merchant Account](/braintree/docs/reference/response/merchant-account) response object.


### Node
```javascript

const merchantAccountParams = {
  individual: {
    firstName: "Jane"
  }
};

gateway.merchantAccount.update("blue_ladder_store", merchantAccountParams, (err, result) => {
  result.success;
  // true
});

```
If the merchant account can't be found, it will return a [notFoundError](/braintree/docs/reference/general/exceptions/node#not-found-error).
