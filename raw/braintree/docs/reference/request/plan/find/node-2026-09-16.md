# Plan: Find

See also the[Plan](/braintree/docs/reference/response/plan)response object. If you want
to look up a single plan using its ID, use themethod.
### Callback
```javascript
gateway.plan.find("aPlanId", (err, result) => { });
```

### Promise
```javascript
gateway.plan.find("aPlanId").then(result => { });
```
If the plan can't be found, it will return a[notFoundError](/braintree/docs/reference/general/exceptions#not-found-error).
