# Credit Card Verification: Create

You can perform a standalone credit card verification without storing the card in the Vault.
However, to do so you must pass raw credit card data, which**should only be done in a PCI compliant environment**. If in doubt, use ato perform a standard[card verification](/braintree/docs/guides/credit-cards/server-side/node#card-verification)and vault the card.
