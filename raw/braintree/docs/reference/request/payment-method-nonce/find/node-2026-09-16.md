# Payment Method Nonce: Find

See also the[Payment Method Nonce](/braintree/docs/reference/response/payment-method-nonce)response object.

You can get more information about a payment method nonce by passing the nonce string as an argument to the find method.

Unlike other calls, a find call does not consume the payment method nonce - instead, it returns the nonce string back to your server along with 3D Secure information such as`liability_shifted`and`liability_shift_possible`. This can be used for server-side risk checking before creating transactions.
### Callback
```javascript
gateway.paymentMethodNonce.find("nonce_string", (err, paymentMethodNonce) => {
  const info = paymentMethodNonce.threeDSecureInfo;
  if (info) {
    info.enrolled;
    info.status;
    info.liabilityShifted;
    info.liabilityShiftPossible;
  } else {
    // This means 3D Secure info was not captured with this payment method nonce
  }
});
```

### Promise
```javascript
gateway.paymentMethodNonce.find("nonce_string").then(paymentMethodNonce => {
  const info = paymentMethodNonce.threeDSecureInfo;
  if (info) {
    info.enrolled;
    info.status;
    info.liabilityShifted;
    info.liabilityShiftPossible;
  } else {
    // This means 3D Secure info was not captured with this payment method nonce
  }
});
```
If the payment method nonce can't be found, it will return a[notFoundError](/braintree/docs/reference/general/exceptions/node#not-found-error).
