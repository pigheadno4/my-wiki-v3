# Payment Method Nonce: Create

See also the[Payment Method Nonce](/braintree/docs/reference/response/payment-method-nonce)response
object.
**NOTE**
You should only create payment method nonces server-side when using [3D Secure](/braintree/docs/guides/3d-secure/overview) or [Checkout with PayPal](/braintree/docs/guides/paypal/checkout-with-paypal) .

To create a payment method nonce, only the payment method token is required.
### Callback
```javascript
gateway.paymentMethodNonce.create("A_PAYMENT_METHOD_TOKEN", function(err, response) {
    const nonce = response.paymentMethodNonce.nonce;
});
```

### Promise
```javascript
gateway.paymentMethodNonce.create("A_PAYMENT_METHOD_TOKEN").then(response => {
    const nonce = response.paymentMethodNonce.nonce;
});
```
If the payment method can't be found, it will return a[notFoundError](/braintree/docs/reference/general/exceptions/node#not-found-error).
