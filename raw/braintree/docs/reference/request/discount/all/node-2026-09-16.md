# Discount: All

Returns a collection of [Discount](/braintree/docs/reference/response/discount) objects.


### Node
```javascript

gateway.discount.all((err, result) => { const discounts = result.discounts; });

```
If the discount can't be found, it will return a [notFoundError](/braintree/docs/reference/general/exceptions/node#not-found-error).
