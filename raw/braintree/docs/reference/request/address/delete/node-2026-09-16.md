# Address: Delete

Addresses are uniquely identified by a customer id and an address id, so you need both of these
fields to delete an address.
### Node
```javascript
gateway.address.delete("theCustomerId", "theAddressId", (err) => {
});
```

**NOTE**
When an address is deleted from a customer, it is also removed from any Vault payment methods that reference the address for billing or shipping.

If the address or customer can't be found, it will return a[notFoundError](/braintree/docs/reference/general/exceptions/node#not-found-error).
