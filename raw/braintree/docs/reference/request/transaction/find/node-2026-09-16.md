# Transaction: Find


**NOTE**
Results are limited according to the [PayPal Data Protection Addendum For Card Processing Products policy](https://www.paypal.com/us/legalhub/braintree/data-protection-addendum) .

See also the[Transaction](/braintree/docs/reference/response/transaction)response object.
### Callback
```javascript
gateway.transaction.find("theTransactionId", (err, transaction) => { });
```

### Promise
```javascript
gateway.transaction.find("theTransactionId").then(transaction => { });
```
If the transaction can't be found, it will return a[notFoundError](/braintree/docs/reference/general/exceptions/node#not-found-error).
### Escrow status on Braintree Marketplace transactions

Use the transaction's`id`to find the[`escrow_status`](/braintree/docs/reference/general/statuses#escrow)on[Braintree Marketplace](/braintree/docs/guides/braintree-marketplace/overview)transactions:
### Callback
```javascript
gateway.transaction.find("transactionId", (err, transaction) => { 
    transaction.escrowStatus // "held"
});
```

### Promise
```javascript
gateway.transaction.find("transactionId").then(result => { 
    result.escrowStatus // "held"
});
```
