# Transaction: Cancel Release

See also the[Transaction](/braintree/docs/reference/response/transaction)response object.

This functionality is specific to[Braintree Marketplace](/braintree/docs/guides/braintree-marketplace/overview)merchants.
### Callback
```javascript
gateway.transaction.cancelRelease("transaction_id", function (err, result) {
    // Handle result
});
```

### Promise
```javascript
gateway.transaction.cancelRelease("transaction_id")
    .then(result => {
        // Handle result
    });
```
If the transaction can't be found, it will return a[notFoundError](/braintree/docs/reference/general/exceptions/node#not-found-error).

If you previously released an escrowed[Braintree Marketplace transaction](/braintree/docs/guides/braintree-marketplace/create), you can cancel the release while the[`escrow_status`](/braintree/docs/reference/general/statuses#escrow)is`release_pending`.
