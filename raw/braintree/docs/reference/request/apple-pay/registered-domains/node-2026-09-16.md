# Apple Pay: Registered Domains


**AVAILABILITY**
Currently only our [PHP](/braintree/docs/reference/response/apple-pay-options/php) and [Ruby](/braintree/docs/reference/response/apple-pay-options/ruby) SDKs support managing domains for Apple Pay on the web via our API.
