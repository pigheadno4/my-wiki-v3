# Add On: All

Returns a collection of[Add-On](/braintree/docs/reference/response/add-on/ruby)objects.
### Callback
```javascript
gateway.addOn.all((err, result) => {
    const addOns = result.addOns;
});
```

### Promise
```javascript
gateway.addOn.all().then(result => {
    const addOns = result.addOns;
});
```
If the add-on can't be found, it will return a[notFoundError](/braintree/docs/reference/general/exceptions/node#not-found-error).
