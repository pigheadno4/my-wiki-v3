# Transaction Line Item: Find All


**NOTE**
Results are limited according to the [PayPal Data Protection Addendum For Card Processing Products policy](https://www.paypal.com/us/legalhub/braintree/data-protection-addendum) .

Returns a collection of[Transaction Line Item](/braintree/docs/reference/response/transaction-line-item)objects.

To retrieve a list of transaction line items that were provided when a transaction was created with, use.
### Callback
```javascript

gateway.transactionLineItem.findAll(
  "theTransactionId",
  (err, transactionLineItems) => {
  });

```

### Promise
```javascript

gateway.transactionLineItem.findAll("theTransactionId")
.then(transactionLineItems => { });

```
