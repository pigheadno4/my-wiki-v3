# Subscription: Cancel

If you want to stop billing a credit card, you can cancel the subscription.
### Callback
```javascript
gateway.subscription.cancel("theSubscriptionId", (err, result) => {
});
```

### Promise
```javascript
gateway.subscription.cancel("theSubscriptionId").then(result => {
});
```
If the subscription can't be found, the API will return a[notFoundError](/braintree/docs/reference/general/exceptions/node#not-found-error).
**NOTE**
If you cancel a subscription, you won't be able to edit or reactivate it. You will need to [create a new subscription](/braintree/docs/guides/recurring-billing/create) instead.
