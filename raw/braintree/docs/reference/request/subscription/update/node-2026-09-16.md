# Subscription: Update

See also the[Subscription](/braintree/docs/reference/response/subscription)response object.
### Callback
```javascript
gateway.subscription.update("aSubscriptionId", {
    id: "newId",
    paymentMethodToken: "newPaymentMethodToken",
    price: "14.00",
    planId: "newPlan",
    merchantAccountId: "newMerchantAccount"
}, (err, result) => {
});
```

### Promise
```javascript
gateway.subscription.update("aSubscriptionId", {
    id: "newId",
    paymentMethodToken: "newPaymentMethodToken",
    price: "14.00",
    planId: "newPlan",
    merchantAccountId: "newMerchantAccount"
}).then(result => {
});
```
If the subscription can't be found, it will return a[notFoundError](/braintree/docs/reference/general/exceptions/node#not-found-error).
## Examples


### Add-ons and discounts


**NOTE**
You can only add an add-on or discount to a subscription once. If you'd like to apply an add-on or discount to a subscription several times, you can pass `quantity` when creating or updating the add-on/discount.

When updating a subscription, you can modify the add-ons and discounts in 3 ways:
- New add-ons/discounts can be added
- Existing add-ons/discounts associated with the subscription can be updated
- Existing add-ons/discounts associated with the subscription can be removed


### Callback
```javascript
gateway.subscription.update("theSubscriptionId", {
    addOns: {
        add: [
            {
                inheritedFromId: "addOnId1",
                amount: "25.00"
            }
        ],
        update: [
            {
                existingId: "addOnId2",
                amount: "50.00"
            }
        ],
        remove: ["addOnId3"]
    },
    discounts: {
        add: [
            {
                inheritedFromId: "discountId1",
                amount: "7.00"
            }
        ],
        update: [
            {
                existingId: "discountId2",
                amount: "15.00"
            }
        ],
        remove: ["discountId3"]
    }
}, (err, result) => {
});
```

### Promise

### Update with 3D Secure enriched payment method nonce

If you use 3D Secure and need to apply 3DS to the next transaction of an existing subscription, you must update the subscription using a[3DS-enriched nonce](/braintree/docs/guides/3d-secure/client-side). See the[3D Secure](/braintree/docs/guides/3d-secure/overview)guide for details on how to properly obtain a 3DS-enriched nonce, and see the[3D Secure for Recurring Transactions](/braintree/docs/guides/3d-secure/recurring-transactions)page for more information on utilizing 3DS for subscription transactions. Once you've obtained a 3DS-enriched nonce, provide it on the subscription update call:
### Callback
```javascript
gateway.subscription.update({
    paymentMethodNonce: "nonce_from_the_client",
    id: "subscriptionId"
}, (err, result) => {
});
```

### Promise
```javascript
gateway.subscription.update({
    paymentMethodNonce: "nonce_from_the_client",
    id: "subscriptionId"
}).then(result => {
});
```

### Multiple updates

You can also add, update and remove multiple add-ons/discounts at the same time.
### Callback
```javascript
gateway.subscription.update("theSubscriptionId", {
    paymentMethodToken: "thePaymentMethodToken",
    planId: "thePlanId",
    addOns: {
        add: [
            {
                inheritedFromId: "addOnId1",
                amount: "20.00"
            },
            {
                inheritedFromId: "addOnId2",
                amount: "30.00"
            }
        ],
        update: [
            {
                existingId: "addOnId3",
                quantity: 2
            },
            {
                existingId: "addOnId4",
                quantity: 3
            }
        ],
        remove: ["addOnId5", "addOnId_6"]
    }
}, (err, result) => {
});
```

### Promise
```javascript
gateway.subscription.update("theSubscriptionId", {

            }

            {

```

### Override details

When adding add-ons/discounts, all details will be inherited from the add-on/discount specified by the`inherited_from_id`. You can override any of the following:
- `amount`
- `number_of_billing_cycles`or`never_expires`
- `quantity`


### Callback
```javascript
gateway.subscription.update("theSubscriptionId", {
    addOns: {
        add: [
            {
                inheritedFromId: "addOnId1",
                amount: "20.00",
                numberOfBillingCycles: 2,
                quantity: 4
            }
        ],
        update: [
            {
                existingId: "addOnId2",
                amount: "15.00",
                neverExpires: true,
                quantity: 3
            }
        ]
    }
}, (err, result) => {
});
```

### Promise
```javascript
gateway.subscription.update("theSubscriptionId", {
    addOns: {
        add: [
            {
                inheritedFromId: "addOnId1",
                amount: "20.00",
                numberOfBillingCycles: 2,
                quantity: 4
            }
        ],
        update: [
            {
                existingId: "addOnId2",
                amount: "15.00",
                neverExpires: true,
                quantity: 3
            }
        ]
    }
}).then(result => {
});
```

### Remove add-ons and discounts

If you prefer to update a subscription and remove all existing add-ons and discounts, you can pass the`replace_all_add_ons_and_discounts`option.
### Callback
```javascript
gateway.subscription.update("theSubscriptionId", {
    options: {
        replaceAllAddOnsAndDiscounts: true
    }
}, (err, result) => {
});
```

### Promise
```javascript
gateway.subscription.update("theSubscriptionId", {
    options: {
        replaceAllAddOnsAndDiscounts: true
    }
}).then(result => {
});
```
