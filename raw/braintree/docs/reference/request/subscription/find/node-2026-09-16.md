# Subscription: Find


**NOTE**
Results are limited according to the [PayPal Data Protection Addendum For Card Processing Products policy](https://www.paypal.com/us/legalhub/braintree/data-protection-addendum) .

See also the[Subscription](/braintree/docs/reference/response/subscription)response object.

If you want to look up a single subscription using its ID, use themethod.
### Callback
```javascript
gateway.subscription.find("aSubscriptionId", (err, result) => {
});
```

### Promise
```javascript
gateway.subscription.find("aSubscriptionId").then(result => {
});
```
Otherwise, use.

If the subscription can't be found, it will return a[notFoundError](/braintree/docs/reference/general/exceptions/node#not-found-error).
