# Settlement Batch Summary: Generate

See also the[Settlement Batch Summary](/braintree/docs/reference/response/settlement-batch-summary)response object.

The settlement batch summary displays the total sales and credits for each batch for a particular date. The transactions can be grouped by a single[custom field's](/braintree/articles/control-panel/custom-fields)values.
### Callback
```javascript
gateway.settlementBatchSummary.generate({
    settlementDate: "2012-01-01",
    groupByCustomField: "custom_field_1"
}, (err, result) => {
    console.log(result.settlementBatchSummary.records);
});
```

### Promise
```javascript
gateway.settlementBatchSummary.generate({
    settlementDate: "2012-01-01",
    groupByCustomField: "custom_field_1"
}).then(result => {
    console.log(result.settlementBatchSummary.records);
});
```

#### Validation Errors

If you call this method with incorrect arguments, you may receive[validation errors](/braintree/docs/reference/general/validation-errors/all#search).
