# Dispute: Search


**NOTE**
Results are limited according to the [PayPal Data Protection Addendum For Card Processing Products policy](https://www.paypal.com/us/legalhub/braintree/data-protection-addendum) .

Returns a collection of[Dispute](/braintree/docs/reference/response/dispute)response objects.
**AVAILABILITY**
Managing disputes via the API is only available to merchants who can access disputes in the Braintree Control Panel.

For operators available on[search fields](/braintree/docs/reference/general/searching/search-fields), see the search fields page.
### Node
```javascript
gateway.dispute.search((search) => {
    search.id().is("dispute_id");
}, (err, response) => {
    response.forEach((dispute) => {
        console.log(dispute.id);
    });
});
```

## Examples


### Multiple kinds

This example shows searches on the`kind`parameter:
### Node
```javascript
gateway.dispute.search((search) => {
    search.kind().in([
        braintree.Dispute.Kind.Chargeback,
        braintree.Dispute.Kind.Retrieval
    ]);
}, (err, response) => {
});
```

### Amount disputed range

This example shows searches on the`amount_disputed`parameter:
### Node
```javascript
gateway.dispute.search((search) => {
    search.amountDisputed().between("100.00", "200.00");
}, (err, response) => {
});
```
