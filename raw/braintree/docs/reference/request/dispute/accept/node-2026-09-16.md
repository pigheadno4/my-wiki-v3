# Dispute: Accept

See also the[Dispute](/braintree/docs/reference/response/dispute)response object.
**AVAILABILITY**
Managing disputes via the API is only available to merchants who can access disputes in the Braintree Control Panel.

You can only accept disputes that have a[`status`](/braintree/docs/reference/response/dispute/node#status)of. If you have already issued a refund for the disputed
transaction,**do not accept the dispute**- instead, submit[file](/braintree/docs/reference/request/dispute/add-file-evidence)or[text](/braintree/docs/reference/request/dispute/add-text-evidence)evidence of the
refund.
### Promise
```javascript
const result = gateway.dispute.accept("a_dispute_id");
```
If the dispute is successfully accepted, the result will be successful. Otherwise, check for
validation errors.
### Promise
```javascript
result.then((response) => {
    if (response.success) {
        // dispute successfully accepted
    } else {
        console.log(response.errors);
    }
});
```
