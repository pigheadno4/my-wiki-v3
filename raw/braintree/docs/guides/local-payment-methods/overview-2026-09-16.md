# Overview

Local Payment Methods allow customers to pay with banks, wallets, or other means that operate only in specific regions of the world. For example, a customer in the Netherlands might want to pay using iDEAL, which is used by more than 60% of consumers in the Netherlands for online purchases, whereas a customer in Belgium on the same website might want to pay using Bancontact, a popular payment method there.


## Supported payment methods

The following table shows currently supported Local Payment Methods by customer country and any applicable transaction limits:

| Local Payment Method | Customer country | Customer transaction limits |
| --- | --- | --- |
| BLIK | Poland | Min: 1.00 PLN, Max: 10,000 PLN |
| Bancontact | Belgium | Min: 1.00 EUR |
| BANCOMAT Pay | Italy | Min: 0.01 EUR |
| Boleto Bancário (non-instant) | Brazil | Max: 35,000 BRL |
| EPS | Austria | Min: 1.00 EUR |
| Giropay | Germany | Min: 1.00 EUR |
| iDEAL | The Netherlands | N/A |
| Klarna Pay Now / SOFORT | Austria, Belgium, Germany, the Netherlands, Spain, and the United Kingdom | Min: 1.00 EUR, Max: 5000 EUR (outside the United Kingdom) Min: 1.00 GBP, Max: 5000 GBP (the United Kingdom only) |
| MB WAY | Portugal | Min: 1.00 EUR |
| Multibanco (non-instant) | Portugal | Max: 99.999,99 EUR |
| MyBank | Italy | N/A |
| OXXO (non-instant) | Mexico | Max: 10,000 MXN |
| Pay Upon Invoice | Germany | Min: 5.00 EUR, Max: 2.500,00 EUR |
| P24 | Poland | Min: 1.00 PLN, Max: 55,000 PLN |
| [Swish](/braintree/docs/guides/swish/overview/) | Sweden | Min: 0.01 SEK, Max: 999999999999.99 SEK |

**IMPORTANT**
Giropay will be sunset on June 30, 2024. PayPal will not support Giropay payments starting July 1, 2024. Offer your users PayPal wallet and other alternative payment methods.

  
**IMPORTANT**
Sofort will be sunset this year. PayPal will not support Sofort payments starting April 18, 2024. Offer your users PayPal wallet and other alternative payment methods. [Learn more](https://www.paypal.com/cshelp/article/help1145).

  
**AVAILABILITY**
MyBank is currently with limited access. If you want to process with MyBank, please [contact us](/braintree/help?issue=acceptPaymentTypes).

  
**AVAILABILITY**
Swish is currently supported only for Braintree Web SDK integrations.


## Recurring transactions and Vault support

Vaulting payment methods and creating recurring transactions are currently not supported with Local Payment Methods.
