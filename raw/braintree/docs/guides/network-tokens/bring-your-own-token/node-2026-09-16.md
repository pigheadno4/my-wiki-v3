# Bring Your Own Token

Through Bring Your Own Token (BYOT), merchants who tokenize cards with another Payment Service Provider (PSP) or who vault Network Tokens themselves can use their existing Network Tokens with Braintree.


## Creating transactions

A BYOT transaction can be created using [``](/braintree/docs/reference/request/transaction/sale/node) with the required network token parameters. The required parameters differ based on the type of BYOT transaction being created.


### Required parameters

The following parameters are always required:


- [`amount`](/braintree/docs/reference/request/transaction/sale/node#amount)
- [`credit_card.number`](/braintree/docs/reference/request/transaction/sale#credit_card-number)(token)
- [`credit_card.expiration_date`](/braintree/docs/reference/request/transaction/sale#credit_card-expiration_date)(token)
- [`credit_card.network_tokenization_attributes.cryptogram`](/braintree/docs/reference/request/transaction/sale/node#credit_card-network_tokenization_attributes-cryptogram)

For more information on what should be passed in the cryptogram field, see the "Customer Initiated Transactions" and "Merchant Initiated Transactions" fields below.


### Optional parameters

The following parameters are always optional:


- [`credit_card.network_tokenization_attributes.ecommerce_indicator`](/braintree/docs/reference/request/transaction/sale/node#credit_card-network_tokenization_attributes-ecommerce_indicator)
- [`credit_card.network_tokenization_attributes.token_requestor_id`](/braintree/docs/reference/request/transaction/sale/node#credit_card-network_tokenization_attributes-token_requestor_id)

Refer to [``](/braintree/docs/reference/request/transaction/sale/node) for detailed examples and a complete listing of transaction options.


### Customer initiated transactions

When creating a customer initiated transaction (CIT) or the first in a recurring series, a network-issued cryptogram is required. We also recommend including the external_vault object with status: "vaulted". While this is currently optional, it may become required in future updates to support proper transaction context.


### Callback
```javascript
gateway.transaction.sale({
  amount: "10.00",
  creditCard: {
    number: "4111111111111111",
    expirationDate: "05/2027",
    networkTokenAttributes: {
      cryptogram: "/wAAAAAAAcb8AlGUF/1JQEkAAAA=",
      tokenRequestorId: "45310020105",
      ecommerceIndicator: "05"
    }
  },
  externalVault: {
    status: "vaulted",
  }
}, (err, result) => {
  if (result.success) {
    // See result.transaction for details
    // result.transaction.processedWithNetworkToken == true
  } else {
    // Handle errors
  }
});
```


### Merchant initiated transactions

When creating a merchant initiated transaction (MIT) or subsequent transaction, a network transaction identifier (NTI) and related parameters are required. The [`cryptogram`](/braintree/docs/reference/request/transaction/sale/node#credit_card-network_tokenization_attributes-cryptogram) must still be present, but a static cryptogram value of "STATIC_RECURRING" should be included in place of a network-issued cryptogram.


#### Required parameters


- [`transaction_source`](/braintree/docs/reference/request/transaction/sale/node#transaction_source)=recurring,unscheduled, orinstallment
- [`external_vault.status`](/braintree/docs/reference/request/transaction/sale/node#external_vault-status)=vaulted
- [`external_vault.previous_network_transaction_id`](/braintree/docs/reference/request/transaction/sale/node#external_vault-previous_network_transaction_id)
- [`credit_card.network_tokenization_attributes.cryptogram`](/braintree/docs/reference/request/transaction/sale/node#credit_card-network_tokenization_attributes-cryptogram)


### Callback
```javascript
gateway.transaction.sale({
  amount: "10.00",
  transactionSource: "recurring",
  creditCard: {
    number: "4111111111111111",
    expirationDate: "05/2027",
    networkTokenAttributes: {
      tokenRequestorId: "45310020105",
      ecommerceIndicator: "05",
      cryptogram: "STATIC_RECURRING"
    }
  },
  externalVault: {
    status: "vaulted",
    previousNetworkTransactionId: "123456789012345"
  }
}, (err, result) => {
  if (result.success) {
    // See result.transaction for details
    // result.transaction.processedWithNetworkToken == true
  } else {
    // Handle errors
  }
});
```
