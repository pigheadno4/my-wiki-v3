# Overview


**AVAILABILITY**
Google Pay is currently available with our latest Android and JavaScript SDKs.

Google Pay provides a purchasing experience both in app and on the web for customers with supported Android devices. It allows customers to pay with cards and PayPal accounts stored in their Google account, in addition to those stored in Google Pay.

For more details on compatibility and availability, see our[Google Pay support article](/braintree/articles/guides/payment-methods/google-pay).
## Getting started

If you don't already accept Google Pay, you'll follow these steps to add a Google Pay button to your existing Braintree integration:


- [Configure Google Pay](/braintree/docs/guides/google-pay/configuration)
- [Integrate on the client side](/braintree/docs/guides/google-pay/client-side)
- [Integrate on your servers](/braintree/docs/guides/google-pay/server-side)
- [Test and go live](/braintree/docs/guides/google-pay/testing-go-live)

If you haven't completed a Braintree integration yet, we recommend following our [Get Started guide](/braintree/docs/start/overview) to set up a basic client and server implementation for credit card payments first.




**NOTE**
Before you can process Google Pay transactions in production, you must [obtain a Google merchant ID](/braintree/docs/guides/google-pay/testing-go-live#go-live) .


## Transitioning from Android Pay

If you have an existing integration with Android Pay and would like to transition to Google Pay, update your Android app by following the [Client-Side Implementation](/braintree/docs/guides/google-pay/client-side/android/v4) page.


## Google Pay and the Payment Request API

Google Pay for the web is built on the [Payment Request API](https://developers.google.com/web/fundamentals/payments/), an open web standard candidate that relies on the customer's browser as a secure intermediary for payments.



**The JavaScript version of this guide explains how to accept Google Pay by adding a standalone button to your existing Braintree JavaScript integration.**This is the simplest option if you just want to add Google Pay to your web checkout.

However, our JavaScript SDK also includes a Payment Request component that lets you accept both credit card and Google Pay payments using the Payment Request API itself. If you are interested in this alternative, see our[Payment Request API integration guide](/braintree/docs/guides/payment-request/overview).
