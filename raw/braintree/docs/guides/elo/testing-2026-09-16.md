# Testing


**AVAILABILITY**
Elo is currently in limited release and is only available to select merchants using the latest version of our [JavaScript v3 SDK](/braintree/docs/guides/client-sdk/setup/javascript/v3) and server SDKs. [Contact us](/braintree/help) to request access to the release.


## Test card numbers

When testing Elo in the sandbox environment, you can use any of the following cards to test your
integration.| Test Value | Card Type | Description |

## Testing other error cases

You can trigger additional error cases by sending special values in certain fields when performing
verification or enrollment API calls.| Field | Test Value | Description |
| --- | --- | --- |
| `expirationYear` | `2020` | Customer entered expired card. |
| `expirationDate` | `10` | Customer entered expired card. |
