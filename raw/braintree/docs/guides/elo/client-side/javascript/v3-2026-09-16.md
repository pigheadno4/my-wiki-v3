# Client-Side Implementation


**AVAILABILITY**
Elo is currently in limited release and is only available to select merchants using the latest version of our [JavaScript v3 SDK](/braintree/docs/guides/client-sdk/setup/javascript/v3) and server SDKs. [Contact us](/braintree/help) to request access to the release.


## Checkout form


### Dual-branded cards

Some Elo cards will have both the Elo logo and the Discover logo on the customer's card. As such,
these dual-branded cards can be processed through either brand's network. If your business is based
outside of Brazil, card network rules around dual-branded Elo cards dictate that transactions must
be processed through the Discover network.
### Card capabilities

Elo cards can only be credit. This capability determines what information you will need to collect
in your checkout form, as well as your options for processing the transaction on your server:
- Credit cards
- Require CVV and expiration date
- Support both immediate and delayed settlement – you can either submit the transaction for settlement upon creation or make a separate submit for settlement call
