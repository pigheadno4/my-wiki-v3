# Setup


## Quick installation

We support using CocoaPods to implement the PayPal Commerce SDK in your project. CocoaPods is a
dependency manager for Cocoa and Cocoa Touch projects. Information for installing and setting it up
in your project is available on[CocoaPods.org](http://cocoapods.org/). To install the
PayPal Commerce SDK using CocoaPods, simply add this to your**Podfile**and runpod install:
### 
```bash
pod 'PayPalCommerce', :git => 'git@github.com:braintree/paypal-commerce-ios.git'
```
If you don't already use CocoaPods acknowledgements, you'll need to include the[PayPalCommerce-Acknowledgements.md](https://github.com/braintree/paypal-commerce-ios/blob/master/PayPalCommerce/PayPalCommerce-Acknowledgements.md)somewhere in your app, so proper licensing attribution will be covered. If you'd like to manage the
installation on your own, you can find download links and instructions in[Installation without CocoaPods](/braintree/docs/guides/paypal-commerce-ios/installation-without-cocoapods).
## Configure the client


### Create an OAuth Client

Add your app to the[PayPal Commerce Panel](https://commerce.paypal.com/channels/ios/sdk)and copy yourclient IDandsecret. You'll use these to configure the SDK.
### Add PayPal Commerce to your app delegate

In your app delegate:
### Objective-C
```objectivec
#import <paypalcommerce/paypalcommerce.h>
```
Use the client ID and secret you created above.
**IMPORTANT**
You must obfuscate the client ID and secret somehow (this protects your store and your customers).

Withinapplication:didFinishLaunchingWithOptions::
### Objective-C
```objectivec
[PayPalCommerce configureWithClientID:@"client-id"
                         clientSecret:@"client-secret"
                        launchOptions:launchOptions];
```
If you are using a tab bar controller to present the store to your users, or if you are presenting
modally and would like to be notified of transitions, please implement the[PayPalCommerceDelegate](/braintree/docs/guides/paypal-commerce-ios/paypal-commerce-delegate)protocol.
### Apple Pay

In order for your customers to use Apple Pay, you'll need to take care of a few things:
- Create your Apple Pay merchant ID and certificate in the[Apple Developer Member Center](https://developer.apple.com/account/overview.action).
- Enable Apple Pay in the[PayPal Commerce Panel](https://commerce.paypal.com/settings/gateways).
- Update your project to use Apple Pay (under your**Target**>**Capabilities**>**Apple Pay**).
- In your app delegate, configure your Apple Pay merchant ID:


### Objective-C
```objectivec
[PayPalCommerce configureApplePayMerchantID:@"merchant.com.your.apple.pay.id"];
```

### Custom URL scheme for user login

PayPal Commerce uses a login system that eschews passwords in favor of an email-based login flow.
New users will be let in immediately. However, if a returning user logs in to your store, we will
send them an email with a login link, and in the app we will display a message requesting they open
their email to tap that link, which will have the custom URL scheme that's unique to your app.
Tapping the link will open your app, PayPal Commerce will verify their email address, and they will
be able to continue shopping, view their previous orders, update their profile, etc. Additionally,
PayPal login requires a custom URL scheme to function properly.
**IMPORTANT**
In order for this flow to work properly, please add the custom URL scheme for PayPal Commerce.

You can get your URL scheme from the[**Commerce Panel**>**Channels**>**iOS SDK**](https://commerce.paypal.com/channels/ios/sdk). Then, add your URL scheme to your project:
- In**Xcode**, select your Target.
- Select**Info**.
- Under**URL Types**, add a new type (**+**button).
- In the**URL Scheme**field, enter the scheme provided by PayPal Commerce (e.g.pypl-acme-shovels).
- Under**URL Types**, add a new type (**+**button).
- In the**URL Scheme**field, enter your bundle identifier (e.g.com.acme.store)orsimply the variable$(PRODUCT_BUNDLE_IDENTIFIER).

If you are building multiple apps that include the same PayPal Commerce store, please be sure to[create multiple OAuth clients](#multiple-ios-apps-per-store).
### URL handling

In order for PayPal Commerce to be able to see these URLs, you'll need to add or modify theapplication:openURL:…method in your app delegate:
### Objective-C
```objectivec
- (BOOL)application:(UIApplication *)application openURL:(NSURL *)url sourceApplication:(NSString *)sourceApplication annotation:(id)annotation {
    [PayPalCommerce openURL:url sourceApplication:sourceApplication annotation:annotation];
    return YES;
}
```
To deep-link to products and categories, please follow our[URL specs docs](/braintree/docs/guides/paypal-commerce-ios/url-specs).
### Push notification support

For PayPal Commerce to be able to support push notifications for your store, you will need to add or
modify these methods in your app delegate:
### Objective-C
```objectivec
- (void)application:(UIApplication *)application didRegisterForRemoteNotificationsWithDeviceToken:(NSData *)deviceToken {
    [PayPalCommerce didRegisterForRemoteNotificationsWithDeviceToken:deviceToken];
}

- (void)application:(UIApplication *)application didFailToRegisterForRemoteNotificationsWithError:(NSError *)error {
    [PayPalCommerce didFailToRegisterForRemoteNotificationsWithError:error];
}

- (void)application:(UIApplication *)application didRegisterUserNotificationSettings:(UIUserNotificationSettings *)notificationSettings {
    [PayPalCommerce didRegisterUserNotificationSettings:notificationSettings];
}

- (void)application:(UIApplication *)application didReceiveRemoteNotification:(NSDictionary *)userInfo {
    [PayPalCommerce didReceiveRemoteNotification:userInfo];
}
```

### iOS 9 Spotlight search indexing

In order for products in your users' spotlight search to open the app in the correct place, please
add this to your app delegate:
### Objective-C
```objectivec
- (BOOL)application:(UIApplication *)application continueUserActivity:(NSUserActivity *)userActivity restorationHandler:(void(^)(NSArray *restorableObjects))restorationHandler {
    [PayPalCommerce continueUserActivity:userActivity restorationHandler:restorationHandler];
    return YES;
}
```

### 3D Touch


**AVAILABILITY**
This feature is only on iPhones 6s and up. This includes the 6s, 6s Plus, 7, and 7 Plus.

In order for your users to be able to open the app from the home screen app icon's 3D Touch menu,
you'll need to add this to your app delegate:
### Objective-C
```objectivec
- (void)application:(UIApplication *)application performActionForShortcutItem:(nonnull UIApplicationShortcutItem *)shortcutItem completionHandler:(nonnull void (^)(BOOL))completionHandler {
    BOOL didPerformAction = [PayPalCommerce performActionForShortcutItem:shortcutItem];
    if (!didPerformAction) {
        // if you added any custom 3D Touch shortcuts, you can handle them here
    }
    completionHandler(didPerformAction);
}
```

## Present the store

There are three types of apps you might be creating.
### Modal presentation

The most popular approach is to present the store modally. Use this method wherever you want the
store presented, typically from a button or some other user action.
### Objective-C
```objectivec
[PayPalCommerce presentModalStore];
```
[![Modal,store](https://www.paypalobjects.com/btdevdoc/braintree/img/developers/commerce/thumbs/modal_shop.gif)](https://www.paypalobjects.com/btdevdoc/braintree/img/developers/commerce/thumbs/modal_shop.gif)
### Tight UI integration

If you want to integrate the store UI more tightly with your own app, you can use the embedded view
controller via:
### Objective-C
```objectivec
UIViewController *paypalCommerceViewController = [PayPalCommerce paypalCommerceRootViewController];
```
One popular approach is to use this in a tab bar:
### Objective-C
```objectivec
tabViewController.viewControllers = @[infoVC, paypalCommerceViewController, aboutVC];
```
[![Tab,store](https://www.paypalobjects.com/btdevdoc/braintree/img/developers/commerce/thumbs/tab_shop.png)](https://www.paypalobjects.com/btdevdoc/braintree/img/developers/commerce/thumbs/tab_shop.png)
### Standalone store

Finally, if you wantjustthe store as an app, without anything else, you can implement
this method in yourapplication:didFinishLaunchingWithOptions:after you[configure the client](#configure-the-client).
### Objective-C
```objectivec
[PayPalCommerce presentStoreApp];
```

## Multiple iOS apps per store

If you are building multiple iOS apps that will interact with a single PayPal Commerce store, then
you will need to set up multiple OAuth clients. This is necessary to keep our email verification
system functional. In the PayPal Commerce Panel, there's a section called**Channels**,
and under that is**iOS SDK**([commerce.paypal.com/ios/sdk](https://commerce.paypal.com/channels/ios/sdk)). There you will see your primary OAuth client, as well as a space to add more. Each will provide
you with your PayPal Commerce URL scheme, as well as its own client ID and secret. Read[Configuring the Client](#configure-the-client)for more on where to put those items.
