# URL Specs

You will need to use the PayPal Commerce URL scheme on all URLs. For example, if your app is "Acme",
your URL scheme might bepypl-acme://. You can get your url scheme on the[PayPal Commerce Panel](https://commerce.paypal.com/channels/ios/sdk).| Description | Formatting |
| --- | --- |
| ProductLink directly to a product detail view | **/product/&lt;str:product_linking_id&gt;**Example:Link to product ID**abcdef12345**:pypl-acme://product/abcdef12345 |
| Product VariantLink directly to a product detail view, with a specific variant selected | **/product/variant/&lt;str:product_variant_sku&gt;**Example:Link to product variant with SKU**tshirt-108**:pypl-acme://product/variant/tshirt-108 |
| CategoryLink directly to a category view | **/category/&lt;str:fully_qualified_category_slug&gt;**Example:Link to category with slug**tshirts**:pypl-acme://category/tshirts |
| SearchLink directly to any search result. You can search across specifically against search types **upc** or **name**, or use the catchall **q** type | **/search?&lt;str:search_type&gt;=&lt;str:search_term&gt;**Example:Link to a search on the query**tshirt**:pypl-acme://search?q=tshirt Example:Link to a search on the upc**123456**:pypl-acme://search?upc=123456 |
