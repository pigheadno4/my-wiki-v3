# Examples

We created these examples to show a few of the many possibilities of styling Hosted Fields. We recommend using your own CSS and JS to style your integration and blend the fields into your UI.


### Example: Bootstrap styled

[Bootstrap](http://getbootstrap.com/) is a popular framework for HTML, CSS and JS. This sample shows Hosted Fields integrated into a Bootstrap styled form.

See the Pen[Check out the code](https://codepen.io/braintree/pen/mPgdPN)


### Example: Material Design styled

[Google's Material Design](https://www.google.com/design/spec/material-design/introduction.html) has become very popular as a visual framework for building UI components. This example shows Hosted Fields as Material Design inputs.

See the Pen[Check out the code](https://codepen.io/braintree/pen/zeamxM)


### Example: animating events

You can use Hosted Fields events to detect card types and alter the UI as a customer is entering information.

See the Pen&lt; [Check out the code](https://codepen.io/braintree/pen/ZWPpPG)


### Example: minimal

Hosted Fields inputs can't support custom webfonts (this is due to specific SAQ A regulations regarding server assets). However, you can still specify potential system fonts that your customer might have, and provide fallbacks.

See the Pen[Check out the code](https://codepen.io/braintree/pen/EKJVXp)


### Example: 3D transform

Accepting credit cards doesn't have to be boring! Leverage CSS transforms with Hosted Fields to make a unique form experience.

See the Pen[Check out the code](https://codepen.io/braintree/pen/d9027135c62f52adc371cabbf2380f12).
