# Client-side Implementation


**AVAILABILITY**
ACH Direct Debit is available to [eligible merchants](/braintree/articles/guides/payment-methods/ach#availability) using our [JavaScript v3 SDK](/braintree/docs/guides/client-sdk/setup/javascript/v3) .


**IMPORTANT**
The SSL certificates for Braintree Mobile (iOS and Android) SDKs are set to expire on March 30, 2026. This will impact existing versions of the SDK in published versions of your app. To reduce the impact, upgrade the iOS SDK to version 6.17.0+ &gt;Android SDK to version 4.45.0+ or version 5.0.0+ for the new SSL certifications.   If you do not decommission your app versions that include the older SDK versions or force upgrade your app with the updated certificates by the expiration date, 100% of your customer traffic will fail.
