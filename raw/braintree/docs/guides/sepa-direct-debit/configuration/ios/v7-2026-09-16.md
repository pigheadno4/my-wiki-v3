# Configuration

Before you can accept SEPA Direct Debit, you will need to ensure you have completed the following
steps:
- [Create, verify, and link](/braintree/articles/guides/payment-methods/paypal/setup-guide)your PayPal business account in the Braintree Control Panel. In order to process SEPA Direct Debit, you need to have a valid PayPal business account.
- [Generate a client token](/braintree/docs/start/hello-server#generate-a-client-token)on your server
- You will use the client token when you initialize your components


- [Integrate SEPA Direct Debit](/braintree/docs/guides/sepa-direct-debit/client-side)on your client
- The SEPA Direct Debit integration was introduced in v3 of the JavaScript SDK, v5 of the iOS SDK, and v4 of the Android SDK.


- [Create a SEPA Direct Debit transaction](/braintree/docs/guides/sepa-direct-debit/server-side/)on your server
- [Configure Braintree webhooks](/braintree/docs/guides/webhooks/overview)
- Process a SEPA Direct debit transaction in[sandbox](/braintree/docs/guides/sepa-direct-debit/testing-go-live#sepa-direct-debit-testing-with-linked-paypal-account)or[production](/braintree/docs/guides/sepa-direct-debit/testing-go-live#go-live)successfully
