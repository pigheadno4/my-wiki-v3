# Vaulting

A payment method represents transactable payment information such as a customer's authorization to charge a SEPA Direct Debit account. Payment methodsbelong toa[customer](/braintree/docs/guides/customers), are securely stored in the Braintree Vault, and have a[`payment_method_token`](/braintree/docs/reference/request/transaction/sale/node#payment_method_token)attribute that you can store on your servers (with reduced PCI compliance burden) and later use to[create transactions](/braintree/docs/reference/request/transaction/sale).
## Create

Use[```syntax-inline
Payment Method: Create
```
](/braintree/docs/reference/request/payment-method/create)to create a payment method for an existing customer using[a payment method nonce received from the client](/braintree/docs/guides/sepa-direct-debit/client-side):
### Callback
```javascript
gateway.paymentMethod.create({
    customerId: "12345",
    paymentMethodNonce: nonceFromTheClient
}, (err, result) => {
    // handle response
});
```

### Promise
```javascript
gateway.paymentMethod.create({
    customerId: "12345",
    paymentMethodNonce: nonceFromTheClient
}).then(result => {
    // handle response
});
```
Alternatively, you can[create a new customer with a payment method](/braintree/docs/guides/customers/node#create-with-payment-method)using[```syntax-inline
Customer: Create
```
](/braintree/docs/reference/request/customer/create)with the[`payment_method_nonce`](/braintree/docs/reference/request/transaction/sale/node#payment_method_nonce)parameter.

Once successfully created, you can use[```syntax-inline
Transaction: Sale
```
](/braintree/docs/reference/request/transaction/sale)with the[`payment_method_token`](/braintree/docs/reference/request/transaction/sale/node#payment_method_token)parameter to create a transaction.
## Find

Use[```syntax-inline
Payment Method: Find
```
](/braintree/docs/reference/request/payment-method/find)to find a payment method:
### Callback
```javascript
gateway.paymentMethod.find("token", (err, paymentMethod) => {
    // handle response
});
```

### Promise
```javascript
gateway.paymentMethod.find("token").then(paymentMethod => {
    // handle response
});
```
If the payment method can't be found, it will return a[notFoundError](/braintree/docs/reference/general/exceptions/node#not-found-error).

The return value of the[```syntax-inline
Payment Method: Find
```
](/braintree/docs/reference/request/payment-method/find)call will be a[```syntax-inline
PaymentMethod
```
](/braintree/docs/reference/response/payment-method)response object.


**NOTE**
The find action will also return a link to the mandate associated with the customer's payment method.


## Delete

Use[```syntax-inline
Payment Method: Delete
```
](/braintree/docs/reference/request/payment-method/delete)to delete a payment method:
### Callback
```javascript
gateway.paymentMethod.delete("theToken", (err) => {
    // handle response
});
```

### Promise
```javascript
gateway.paymentMethod.delete("theToken").catch(err => {
    // handle error
});
```
If the payment method can't be found, it will return a[notFoundError](/braintree/docs/reference/general/exceptions/node#not-found-error).
### Callback
```javascript
gateway.paymentMethod.delete("theToken", (err) => { });
```

### Promise
```javascript
gateway.paymentMethod.delete("theToken").catch(err => { });
```
If the payment method can't be found, it will return a[notFoundError](/braintree/docs/reference/general/exceptions/node#not-found-error).


**NOTE**
The delete action will also revoke the mandate associated with the customer's payment method.
