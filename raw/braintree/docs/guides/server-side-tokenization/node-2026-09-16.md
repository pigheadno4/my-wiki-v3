# Server-Side Tokenization


## Using Braintree Server SDK to create single-use payment methods (nonces) without vaulting

In this document, we'll demonstrate how to create a single-use payment method, also referred to as a
nonce, from raw credit card details. In order to provide the fastest access to this feature, it is
available now via the GraphQL client that comes built into each Braintree Server SDK. In short, the
main steps are:
- Create a new[Braintree gateway instance](/braintree/docs/start/hello-server/node#install-and-configure)
- Execute a GraphQL query with a provided query definition and set of inputs
- Retrieve the single-use payment method from the query results


## Execute a GraphQL query

To create the single-use payment method, we'll execute a GraphQL query using aTokenizeCreditCardmutation. The fields in the query indicate which fields you'd like
returned in the query results. You can customize this list to your convenience; a full list of
available fields is available within the[Braintree GraphQL API Explorer](/braintree/graphql/explorer), using[introspection queries](/braintree/graphql/guides/#schema-and-types), or examining[the GraphQL schema itself](https://github.com/braintree/graphql-api). For the best
performance, use only the fields you need. Here's an example query:
### Node
```javascript
undefined
```
We'll also separately supply an input to our mutation (TokenizeCreditCardInput) with
the input values. Create nested data structures to build your input variables. Experiment with the
"Query Variables" section in the[Braintree GraphQL API Explorer](/braintree/graphql/explorer)to determine the final data
structure to build for your needs. Here's an example input for the query above, representingTokenizeCreditCardInput, including a card number, expiration year and month. You can
find more input variables to add with the[Braintree GraphQL API Explorer](/braintree/graphql/explorer), using[introspection queries](/braintree/graphql/guides/#schema-and-types), or examining[the GraphQL schema itself](https://github.com/braintree/graphql-api).
### Node
```javascript
const variables = {
    input: {
        creditCard: {
            number: '4111111111111111',
            expirationYear: '2024',
            expirationMonth: '05',
            cardholderName: 'Joe Bloggs'
        }
    }
};
```
The data structure above would correspond to a JSON input variable data structure of:
### JSON
```json
{
    "input": {
        "creditCard": {
            "number": "4111111111111111",
            "expirationYear": "2024",
            "expirationMonth": "05",
            "cardholderName": "Joe Bloggs"
        }
    }
}
```
To issue the query against the Braintree Gateway, use the GraphQL client included on your configured
Braintree Gateway instance:
### Callback
```javascript
gateway.graphQLClient.query(query, variables, (err, result) => {
    // use result
});
```

### Promise
```javascript
gateway.graphQLClient.query(query, variables)
    .then(result => {
        // use result
    });
```

## Retrieve the single-use payment method (nonce)

With the result from the previous step, assign the result to a Dictionary and begin accessing the
relevant parts of the response; the fields will correspond to those requested in the GraphQL query.
Access the value from theidfield as you would a typical nonce.
### Callback
```javascript
gateway.graphQLClient.query(query, variables, (err, result) => {
    const token = result.data.tokenizeCreditCard.paymentMethod.id;
    // token === 'tokencc_bf_437869_9rtyjh_w9y74p_cn2vv2_tw5'
});
```

### Promise
```javascript
gateway.graphQLClient.query(query, variables)
    .then(result => {
        const token = result.data.tokenizeCreditCard.paymentMethod.id;
        // token === 'tokencc_bf_437869_9rtyjh_w9y74p_cn2vv2_tw5'
    });
```
Using the[Braintree GraphQL API Explorer](/braintree/graphql/explorer)will also show
you a full representation (in JSON) of the response shape. The JSON result for our query above would
look something like this:

## Going further

In order to iterate interactively on your GraphQL query, try pasting the above GraphQL query, along
with the input variables below, into the[Braintree GraphQL API Explorer](/braintree/graphql/explorer):
### JSON
```json
{
    "input": {
        "creditCard": {
            "number": "4111111111111111",
            "expirationYear": "2024",
            "expirationMonth": "05",
            "cardholderName": "Joe Bloggs",
            "billingAddress": {
                "postalCode": "94611",
                "countryCodeAlpha3": "USA"
            }
        }
    }
}
```
You can explore with your Braintree Sandbox and interactively add new fields and objects to your
inputs and query results. The API Explorer will offer to autocomplete appropriate additional fields
within the query and variables sections; for example, you can put your cursor into the
"billingAddress" object and type"to have a list of available input keys appear. You
can also navigate through the field listing on the right side of the API Explorer (the "Docs" tab or
"Documentation Explorer").
