# Webhooks


**AVAILABILITY**
This feature is only available if Braintree manages the funding for your merchant account. [Contact us](/braintree/help) to find out if your account is eligible.

After you're set up to [receive webhooks](/braintree/docs/guides/webhooks/overview), you can collect information from them to create reports based on different [triggers](/braintree/docs/reference/general/webhooks/overview#triggers). For example, you could collect the information on notifications for:


- **Subscription Canceled**to create a report for customer subscription cancelations
- **Dispute Opened**and compare that to your transactions sales to create a report on your chargeback ratio
- **Disbursement**to create a funding report


## General workflow


- Set up at least one[destination URL](/braintree/docs/guides/webhooks/create)to receive webhooks from the gateway
- [Parse the contents](/braintree/docs/guides/webhooks/parse)of the webhook notifications
- Create logic to store the details of theWebhookNotificationobjects for a specific kind of[trigger](/braintree/docs/reference/general/webhooks/overview#triggers)


## Disbursements

Disbursement webhooks differ from other webhooks. Each disbursement or disbursement exception webhook includes a disbursement object. Unlike transactions or subscriptions objects, there are no alternative ways for retrieving the disbursement object from the gateway.


**NOTE**
For triggering disbursement exceptions in sandbox, see [Sandbox Disbursement Exceptions](/braintree/docs/guides/braintree-marketplace/testing-go-live/node#disbursement-exceptions) .


## Transactions associated with a disbursement


**NOTE**
The `bt_signature` and `bt_payload` variables in the following code snippets represent parameters received from the webhook POST request. For more information, read the documentation on [parsing webhooks](/braintree/docs/guides/webhooks/parse) .

To find all transactions associated with a given disbursement, you can [parse the disbursement webhook notification](/braintree/docs/guides/webhooks/parse) and use the data in the payload to perform a [transaction search](/braintree/docs/reference/request/transaction/search/node#ids).


### Callback
```javascript
gateway.webhookNotification.parse(
  btSignature,
  btPayload,
  (err, webhookNotification) => {
    const transactions = webhookNotification.disbursement.transactionIds;
    const stream = gateway.transaction.search((search) => {
      search.ids().in(transactions);
    });
  }
);
```

### Promise
```javascript
gateway.webhookNotification.parse(
  btSignature,
  btPayload
).then(webhookNotification => {
    const transactions = webhookNotification.disbursement.transactionIds;
    const stream = gateway.transaction.search((search) => {
      search.ids().in(transactions);
    });
  }
);
```
See[Search Results](/braintree/docs/reference/general/searching/search-results)for more information.
