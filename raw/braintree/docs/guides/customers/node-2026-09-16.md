# Customers



 **GraphQL**     [Click here](/braintree/graphql/guides/customers/) to view this implementation using GraphQL.

The customer object is an important component of the Braintree gateway. Use customers to store and organize [payment methods](/braintree/docs/guides/payment-methods). A single customer can have multiple payment methods.

This guide will walk you through the basics. See [Customer Request](/braintree/docs/reference/request/customer/create) and [Customer Response](/braintree/docs/reference/response/customer) references for complete details. Make sure to include the customer's email and phone information if planning to use Risk Products.


## Create

Use [Customer: Create](/braintree/docs/reference/request/customer/create) to add new customers.

You can create just a customer without an associated payment method, and the operation will be successful if all [customer validations](/braintree/docs/reference/general/validation-errors/all#customer) pass:


### Callbacks
```javascript
gateway.customer.create({
    firstName: "Jen",
    lastName: "Smith",
    company: "Braintree",
    email: "jen@example.com",
    phone: "312.555.1234",
    fax: "614.555.5678",
    website: "www.example.com"
}, (err, result) => {
    result.success; // true
    result.customer.id; // e.g. 494019
});
```

### Promises
```javascript
gateway.customer.create({
    firstName: "Jen",
    lastName: "Smith",
    company: "Braintree",
    email: "jen@example.com",
    phone: "312.555.1234",
    fax: "614.555.5678",
    website: "www.example.com"
}).then(result => {
    result.success; // true
    result.customer.id; // e.g. 494019
});
```

### Create with payment method

You can also create a customer with an associated payment method:


### Callbacks
```javascript
gateway.customer.create({
    firstName: "Charity",
    lastName: "Smith",
    paymentMethodNonce: nonceFromTheClient
}, (err, result) => {
    result.success; // true
    result.customer.id; // e.g 160923
    result.customer.paymentMethods[0].token; // e.g f28wm
});
```

### Promises
```javascript
gateway.customer.create({
    firstName: "Charity",
    lastName: "Smith",
    paymentMethodNonce: nonceFromTheClient
}).then(result => {
    result.success; // true
    result.customer.id; // e.g 160923
    result.customer.paymentMethods[0].token; // e.g f28wm
});
```
Success depends on both [customer validations](/braintree/docs/reference/general/validation-errors/all#customer) and [payment method validations](/braintree/docs/reference/general/validation-errors/all#payment-method), and whether the payment method is verified (if [card verification](/braintree/articles/control-panel/vault/card-verification) is enabled).


**NOTE**
Braintree strongly recommends verifying all cards before they are stored in your Vault by [enabling card verification for your entire account](/braintree/articles/control-panel/vault/card-verification) in the Control Panel. If you choose to manually verify cards, set `verify_card` to `true` .

See [the reference](/braintree/docs/reference/request/customer/create) and [more examples of creating a customer](/braintree/docs/reference/request/customer/create/node#examples).


## Update

Use [Customer: Update](/braintree/docs/reference/request/customer/update) to update an existing customer:


### Callbacks
```javascript
gateway.customer.update(
    "theCustomerId",
    {
        firstName: "New First Name",
        lastName: "New Last Name"
    }, (err, result) => {
});
```

### Promises
```javascript
gateway.customer.update(
    "theCustomerId",
    {
        firstName: "New First Name",
        lastName: "New Last Name"
    }).then(result => {
});
```
If the customer can't be found, it will return a [notFoundError](/braintree/docs/reference/general/exceptions/node#not-found-error).

See [the reference](/braintree/docs/reference/request/customer/update) and [more examples of updating a customer](/braintree/docs/reference/request/customer/update/node#examples).


## Find

Use [Customer: Find](/braintree/docs/reference/request/customer/find) to find a customer by ID:


### Callbacks
```javascript
gateway.customer.find(
    "theCustomerId",
    function(err, customer) {
    }
);
```

### Promises
```javascript
gateway.customer.find("theCustomerId").then(customer => { });
```
If the customer can't be found, it will return a [notFoundError](/braintree/docs/reference/general/exceptions/node#not-found-error).

The return value of this call will be a [Customer](/braintree/docs/reference/response/customer) response object.


## Delete

Use [Customer: Delete](/braintree/docs/reference/request/customer/delete) to delete a customer and its payment methods using the customer's ID:


### Callbacks
```javascript
gateway.customer.delete("theCustomerId", (err) => {
    err; // null
});
```

### Promises
```javascript
gateway.customer.delete("theCustomerId").catch(err => {
    err; // null
});
```
If the customer can't be found, it will return a [notFoundError](/braintree/docs/reference/general/exceptions/node#not-found-error).
