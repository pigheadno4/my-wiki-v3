# Payment Methods

A payment method represents transactable payment information such as credit card details or a customer's authorization to charge a PayPal or Venmo account. Payment methods belong to a [customer](/braintree/docs/guides/customers), are securely stored in the Braintree Vault, and have a [`payment_method_token`](/braintree/docs/reference/request/transaction/sale/node#payment_method_token) attribute that you can store on your servers with reduced PCI compliance burden and later use to [create transactions](/braintree/docs/reference/request/transaction/sale).


## Create

Use [Payment Method: Create](/braintree/docs/reference/request/payment-method/create) to create a payment method for an existing customer using [a payment method single-object token received from the client](/braintree/docs/start/hello-server/node#receive-a-payment-method-nonce-from-your-client) :


### Callback
```javascript
gateway.paymentMethod.create({
    customerId: "12345",
    paymentMethodNonce: nonceFromTheClient
}, (err, result) => {
});
```

### Promise
```javascript
gateway.paymentMethod.create({
    customerId: "12345",
    paymentMethodNonce: nonceFromTheClient
}).then(result => {
});
```
Alternatively, you can [create a new customer with a payment method](/braintree/docs/guides/customers/node#create-with-payment-method) using [Customer: Create](/braintree/docs/reference/request/customer/create) with the [`payment_method_nonce`](/braintree/docs/reference/request/transaction/sale/node#payment_method_nonce) parameter.

After the payment method is successfully created, you can use [Transaction: Sale](/braintree/docs/reference/request/transaction/sale) with the [`payment_method_token`](/braintree/docs/reference/request/transaction/sale/node#payment_method_token) parameter to create a transaction.


**NOTE**
 Braintree strongly recommends verifying all cards before they are stored in your Vault by [enabling card verification for your entire account](/braintree/articles/control-panel/vault/card-verification) in the Control Panel.

 


## Update

Use [Payment Method: Update](/braintree/docs/reference/request/payment-method/update) to update an existing payment method.


### Make default

Use the [`make_default`](/braintree/docs/reference/request/payment-method/update/node#options-make_default) option to set a payment method as the default for its customer:


### Callback
```javascript
gateway.paymentMethod.update("theToken", {
    options: {
        makeDefault: true
    }
}, (err, result) => {
});
```

### Promise
```javascript
gateway.paymentMethod.update("theToken", {
    options: {
        makeDefault: true
    }
}).then(result => {
});
```

### Billing address

Update the billing address:


### Callback
```javascript
gateway.paymentMethod.update("theToken", {
    billingAddress: {
        streetAddress: "100 Maple Lane",
        options: {
            updateExisting: true
        }
    }
}, (err, result) => {
});
```

### Promise
```javascript
gateway.paymentMethod.update("theToken", {
    billingAddress: {
        streetAddress: "100 Maple Lane",
        options: {
            updateExisting: true
        }
    }
}).then(result => {
});
```
You can also omit the [`update_existing`](/braintree/docs/reference/request/payment-method/update/node#billing_address-options-update_existing) option to create a new billing address for the payment method.

See [the reference](/braintree/docs/reference/request/payment-method/update) and [more examples of updating a payment method](/braintree/docs/reference/request/payment-method/update/node#examples). If you want to update both payment method and customer information together, use [Customer: Update](/braintree/docs/reference/request/customer/update).


## Find

Use [Payment Method: Find](/braintree/docs/reference/request/payment-method/find) to find a payment method:


### Callback
```javascript
gateway.paymentMethod.find("token", (err, paymentMethod) => { });
```

### Promise
```javascript
gateway.paymentMethod.find("token").then(paymentMethod => { });
```
The return value of the [Payment Method: Find](/braintree/docs/reference/request/payment-method/find) call will be a [`payment_method`](/braintree/docs/reference/response/payment-method) response object.


## Delete

Use [Payment Method: Delete](/braintree/docs/reference/request/payment-method/delete) to delete a payment method:


### Callback
```javascript
gateway.paymentMethod.delete("theToken", (err) => { });
```

### Promise
```javascript
gateway.paymentMethod.delete("theToken").catch(err => { });
```
