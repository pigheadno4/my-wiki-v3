## Overview

Optimized debit routing routes eligible debit cards through lower-cost PINless debit networks. This feature is only available for the United States merchants on interchange pricing models. Authorization rate, network availability, and latency are also taken into consideration when routing to PINless debit networks.

Routing to lower-cost debit networks can help merchants reduce their transaction fees.

**Optimized debit routing is subject to**[eligibility](/braintree/docs/guides/pinless-debit/optimized-debit-routing/eligibility).**NOTE**
Split shipment transactions are now supported on PINless debit networks
