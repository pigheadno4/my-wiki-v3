# Client-Side Implementation


**AVAILABILITY**
Apple Pay is only available for [iOS](/braintree/docs/guides/apple-pay/client-side/ios/v5) or [JavaScript SDK v3](/braintree/docs/guides/apple-pay/client-side/javascript/v3) .


**IMPORTANT**
 The SSL certificates for Braintree Mobile (iOS and Android) SDKs are set to expire on March 30, 2026. This will impact existing versions of the SDK in published versions of your app. To reduce the impact, upgrade the Android SDK to version 4.45.0+ or version 5.0.0+ for the new SSL certifications.  If you do not decommission your app versions that include the older SDK versions or force upgrade your app with the updated certificates by the expiration date, 100% of your customer traffic will fail.
