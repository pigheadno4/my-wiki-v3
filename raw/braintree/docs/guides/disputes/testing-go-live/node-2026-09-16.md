# Testing and Go Live


**AVAILABILITY**
Managing disputes via the API is only available to merchants who can access disputes in the Braintree Control Panel.

We strongly recommend that you test your dispute workflows in the sandbox before using them in production.

You can use the following test card number in the sandbox to create sale transactions of any amount* that are instantly disputed:

| Test Value | Card Type | Description |
| --- | --- | --- |
| 4023898493988028 | Visa | Creates a settled sale transaction that has a dispute with anopenstatus |

*Some transaction amounts trigger specific dispute behavior in the sandbox; see [creating test disputes that require compelling evidence](#creating-test-disputes-that-require-compelling-evidence) below.

In addition to creating a test dispute, using this test card to create sandbox transactions will allow you to:


- Receive a dispute email notification
- Receive a Dispute Opened webhook ([if set up](/braintree/docs/guides/disputes/managing#using-dispute-webhooks))
- Search for or find the dispute in the Control Panel or via the API
- Respond to the dispute in the Control Panel or[via the API](/braintree/docs/guides/disputes/managing#responding-with-evidence)with specific evidence that will update the dispute status towonorlost


##### Creating test disputes that require compelling evidence

The following transaction amounts will set the dispute [Transaction: Sale](/braintree/docs/reference/response/dispute/node#reason_code) accordingly:

| Amount | Dispute Reason Code |
| --- | --- |
| 83.00 | 83Visa Fraud |
| 10.40 | 1040Visa Fraud |
| 13.10 | 1310Visa Fraud |
| 70.30 | 7030Discover Fraud |

## Creating a disputed test transaction

Use [Transaction: Sale](/braintree/docs/reference/request/transaction/sale) to create a test transaction via the API. When specifying a credit card number for the test transaction, you can use the test card number above.


### Callback
```javascript
gateway.transaction.sale({
    amount: "10.00",
    credit_card: {
        expiration_date: "01/2022",
        number: "4023898493988028"
    }
}, (err, result) => {
    if (result.success) {
        // See result.transaction for details
    } else {
        // Handle errors
    }
});
```

### Promise
```javascript
gateway.transaction.sale({
    amount: "10.00",
    credit_card: {
        expiration_date: "01/2022",
        number: "4023898493988028"
    }
}).then(result => {
    if (result.success) {
        // See result.transaction for details
    } else {
        // Handle errors
    }
});
```



## Simulating a won dispute

Specify the string "compelling_evidence" when [adding text evidence](/braintree/docs/reference/request/dispute/add-text-evidence) in the sandbox. Once finalized, this will update the dispute status to won.


### Callback
```javascript
let disputeId;
gateway.dispute.find("a_dispute_id", (err, findResult) => {
    disputeId = findResult.dispute.id;
    gateway.dispute.addTextEvidence(disputeId, "compelling_evidence", (err) => {
        gateway.dispute.finalize(disputeId, () => {});
    });
});
```

### Promise
```javascript
let disputeId;
gateway.dispute.find("a_dispute_id").then(findResult => {
    disputeId = findResult.dispute.id;
    return gateway.dispute.addTextEvidence(disputeId, "compelling_evidence");
}).then(() => {
    return gateway.dispute.finalize(disputeId);
});
```



## Simulating a lost dispute

Specify the string "losing_evidence" when [adding text evidence](/braintree/docs/reference/request/dispute/add-text-evidence) in the sandbox. Once finalized, this will update the dispute status to lost.


### Callback
```javascript
let disputeId;
gateway.dispute.find("fkrnb2b4f743kvnj", (err, findResult) => {
    disputeId = findResult.dispute.id;
    return gateway.dispute.addTextEvidence(disputeId, "losing_evidence", (error) => {
        gateway.dispute.finalize(disputeId, () => {});
    });
});
```

### Promise
```javascript
let disputeId;
gateway.dispute.find("fkrnb2b4f743kvnj").then(findResult => {
    disputeId = findResult.dispute.id;
    return gateway.dispute.addTextEvidence(disputeId, "losing_evidence");
}).then(() => {
    return gateway.dispute.finalize(disputeId);
});
```
