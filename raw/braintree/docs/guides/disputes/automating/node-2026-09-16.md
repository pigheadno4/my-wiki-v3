# Automating Dispute Management


**AVAILABILITY**
Managing disputes via the API is only available to merchants who can access disputes in the Braintree Control Panel.

A key benefit of managing disputes via the API is the option to automate part or all of your dispute management workflow.


## Automation with webhooks

One way to trigger an automated workflow is with dispute webhooks. Your flow should follow these basic steps:


- [Inspect the incoming webhook](/braintree/docs/guides/webhooks/parse)to determine its kind
- If the webhook is for a newly-opened dispute, get the dispute ID from the webhook payload
- Use the dispute ID to[find](/braintree/docs/reference/request/dispute/find)the dispute object
- Automatically gather and submit evidence based on your desired criteria
- [Finalize](/braintree/docs/reference/request/dispute/finalize)the dispute

Below is an example of an automation workflow for an ecommerce merchant whose products are typically shipped to customers. Because this merchant has a shipping confirmation attached to each transaction, they can automatically submit these confirmations as evidence for chargebacks with the reason Product not received.


### Node
```javascript
// Parse the incoming webhook
let webhookNotification = gateway.webhookNotification.parse(
  bt_signature_param,
  bt_payload_param
);

// If the webhook kind is DisputeOpened, and the dispute.reason is
// "product_not_received", evidence submission can be automated
if (webhookNotification.kind == WebhookNotification.Kind.DisputeOpened) {
  let dispute = gateway.dispute.find(webhookNotification.dispute.id);

  if (dispute.reason == Dispute.Reason.ProductNotReceived) {
    let transactionId = dispute.transaction.id;

    let result = gateway.documentUpload.create(
      kind: DocumentUpload.Kind.EvidenceDocument,
      file: fs.createReadStream('/shipping_confirmations/${transaction_id}.pdf'),
    )

    if (result.success) {
      gateway.dispute.addFileEvidence(
        dispute.id,
        result.documentUpload.id
      );
      gateway.dispute.finalize(dispute.id);
    }
  } else {
    // Persist the webhook and follow another workflow to address the dispute
  }
}
```
