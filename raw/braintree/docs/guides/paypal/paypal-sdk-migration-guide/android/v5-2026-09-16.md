# Migrating from checkout.js to the PayPal JS SDK


**AVAILABILITY**
 This page is only relevant for JavaScript v3 PayPal custom integrations (not Drop-in UI).

  This guide won't be relevant to you if:

  
- You are using the v2 JavaScript SDK (we recommend[migrating to v3](/braintree/docs/guides/client-sdk/migration/javascript/v3)of the JavaScript SDK first)
- You are using the[Android](/braintree/docs/guides/paypal/overview/android/v4)or[iOS](/braintree/docs/guides/paypal/overview/ios/v5)SDKs
- You are using the[Drop-in UI to process PayPal](/braintree/docs/guides/drop-in/setup-and-integration/javascript/v3#paypal)
- You are starting a[new PayPal web integration](/braintree/docs/guides/paypal/overview/javascript/v3)
