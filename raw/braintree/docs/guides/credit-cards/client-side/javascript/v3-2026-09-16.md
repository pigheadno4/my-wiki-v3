# Standard Client-Side Implementation


**IMPORTANT**
 Braintree's JavaScript v3 SDK does not support Card Fields. Card Fields are available for client-side integration on [Android v5](/braintree/docs/guides/credit-cards/client-side/android/v5/) and [iOS v7](/braintree/docs/guides/credit-cards/client-side/ios/v7/) only.

  Braintree's JavaScript v3 SDK supports Hosted Fields. Read more about using [Hosted Fields](/braintree/docs/guides/hosted-fields/overview/javascript/v3/) to meet SAQ A eligibilityand keep control of your checkout design.
