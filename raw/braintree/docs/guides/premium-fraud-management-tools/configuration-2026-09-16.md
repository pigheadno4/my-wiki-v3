# Configuration

Complete these 3 steps at the same time before you can use Premium Fraud Management Tools:


- [Enable Premium Fraud Management Tools in the Control Panel](/braintree/articles/guides/fraud-tools/premium/overview#enabling-premium-fraud-management-tools)
- [Update your client-side code](/braintree/docs/guides/premium-fraud-management-tools/client-side)to include the data collector setup
- [Update your server-side code](/braintree/docs/guides/premium-fraud-management-tools/server-side)to pass the collected data with transaction and verification requests

**IMPORTANT**
You may see client-side errors or declined transactions if you enable this feature in the Control Panel before deploying your code changes, or vice versa. To avoid problems in production, we strongly recommend testing your integration thoroughly in sandbox first.
