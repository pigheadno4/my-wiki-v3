# Webhooks

**AVAILABILITY**
Fraud Protection webhooks are only available for merchants using Fraud Protection Advanced. For an overview on available Fraud Tools, see our [Support article](/braintree/articles/guides/fraud-tools/overview#fraud-tool-comparison). If you are using standard Fraud Protection instead of Fraud Protection Advanced, you can skip this step and proceed to our [Testing & Go Live Page](/braintree/docs/guides/premium-fraud-management-tools/testing-go-live) to complete your integration.

 Once you're set up to [receive webhooks](/braintree/docs/guides/webhooks/overview), you can collect information from them to create reports based on different [triggers](/braintree/docs/reference/general/webhooks/overview#triggers). For example, you could collect the information on notifications for:


- **Fraud Protection**to be notified when a transaction marked for review has been approved or rejected
- **Dispute Opened**to compare opened disputes with your transactions sales and create a report on your chargeback ratio
- **Disbursement**to create a funding report


## General workflow


- Set up at least one[destination URL](/braintree/docs/guides/webhooks/create)to receive webhooks from the gateway
- [Parse the contents](/braintree/docs/guides/webhooks/parse)of the webhook notifications
- Create logic to store the details of theWebhookNotificationobjects for a specific kind of[trigger](/braintree/docs/reference/general/webhooks/overview#triggers)


## Fraud Protection

When a transaction has been formally reviewed in the Fraud Protection Advanced dashboard, we'll send a TRANSACTION_REVIEWED webhook containing information that you can use to update your records: 
### Callbacks
```node
app.post("/webhooks", (req, res) => {
  gateway.webhookNotification.parse(
    req.body.bt_signature,
    req.body.bt_payload,
    (err, webhookNotification) => {
      console.log("[Webhook Received " + webhookNotification.timestamp + "] | Kind: " + webhookNotification.kind);

      // Example values for webhook notification properties
      console.log(webhookNotification.kind); // "transactionReviewed"
      console.log(webhookNotification.transactionReview.transactionId); // "123abc"
      console.log(webhookNotification.timestamp); // Sun Jan 1 00:00:00 UTC 2012
      res.status(200).send();
    }
  );
});
```

### Promises
```node
app.post("/webhooks", (req, res) => {
  gateway.webhookNotification.parse(
    req.body.bt_signature,
    req.body.bt_payload,
  ).then(webhookNotification => {
    console.log("[Webhook Received " + webhookNotification.timestamp + "] | Kind: " + webhookNotification.kind);

    // Example values for webhook notification properties
    console.log(webhookNotification.kind); // "transactionReviewed"
    console.log(webhookNotification.transactionReview.transactionId); // "123abc"
    console.log(webhookNotification.timestamp); // Sun Jan 1 00:00:00 UTC 2012
    res.status(200).send();
  });
});
```
 You can use the transaction ID provided in the webhook's payload to make a Transaction.find API call and retrieve additional information if needed: 
### Callbacks
```node
gateway.transaction.find("theTransactionId", (err, transaction) => { });
```

### Promises
```node
gateway.transaction.find("theTransactionId").then(transaction => { });
```
