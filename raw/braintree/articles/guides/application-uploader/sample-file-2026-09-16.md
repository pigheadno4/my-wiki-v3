# Sample File


**AVAILABILITY**
 The Application Uploader is only available for select merchants at this time.

 

The [Paypal Intake Data Dictionary](/braintree/articles/guides/application-uploader/paypal-intake-data-dictionary) guides you to provide all the application information you need to provide in order to use the Intake API or the [Application Uploader](/braintree/articles/guides/application-uploader/overview).

It can be tricky to absorb all the information in the Data Dictionary without seeing a practical example. If you're using the [Application Uploader](/braintree/articles/guides/application-uploader/overview), the example file provides a model of what an application file should look like. Below, you’ll find both a full example file and a version of the sample file for those using a branded solution.


**NOTE**
 By downloading the example file and erasing the test data, you can get a template of the headers required in order to use the Application Uploader. The first row of data in your Application Uploader file must be headers. There are two acceptable input schemas for the PayPal Intake Data Dictionary (v1 and v2).
