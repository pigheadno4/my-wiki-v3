# Grant API Report (Beta)


**AVAILABILITY**
 **The Grant API is currently in a limited release**. For more information on the Grant API, [see our developer docs](/braintree/docs/reference/xml-api/grant-api/overview).

 

The Grant API report provides the number of transactions and transaction volume for each recipient, grouped by currency. Recipients will only appear on the report if they have consented via the [OAuth flow](/braintree/docs/guides/extend/oauth/overview).


## Running a Grant API report

To run a Grant API report:


- Log into the[Control Panel](https://www.braintreegateway.com/login)
- Click on**Reports**in the navigation bar
- Next to**Grant API Report**, click the**Run Report**button
- Select your desired date range
- Click the**Run Grant API Summary**button
