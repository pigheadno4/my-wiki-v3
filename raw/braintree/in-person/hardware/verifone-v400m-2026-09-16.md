# Verifone V400m

This page gives an overview of the Verifone V400m device with the Braintree In-Person solution.


## Overview

The Verifone V400m is part of the Engage series of Verifone payment terminals. This device is a wireless mobile payment terminal that supports WiFi network connectivity. The glass display screen has touchscreen capabilities for seamless interaction with your customers. This device is perfect for merchants who need a flexible device that is well-suited for mobility for charging customers anywhere in the store (ex. curbside, mobile POS stations, pop-up stores, tradeshows, etc...) or works well at a fixed lane register.

## Available Charging Bases for the Verifone V400m


#### V400m Charging Only Base

The V400m supports multiple functional accessories, including a pass-through charging base that facilitates the transition between a charging state and mobile use. This charging base is ideal for merchants who plan to consistently use the V400m as a mobile payment terminal.

![](https://www.paypalobjects.com/devdoc/btdocs-gitbook/v400mChargingBase.png)V400m Charging Base
#### V400m Full Feature Base

There is also a pass-through charging base that supports ethernet connectivity when the V400m device is connected to the charging base. This charging base is ideal for merchants who intend to use the V400m device as a fixed payment terminal tethered to an ethernet-connected charging base.

**NOTE**
The V400m Charging + Ethernet Base does not automatically switch between ethernet and WiFi network interfaces when the V400m is connected or disconnected from the base.

![](https://www.paypalobjects.com/devdoc/btdocs-gitbook/v400m2.png)V400m Charging + Ethernet Base**NOTE**
Both charging bases are available for purchase from Braintree.

## Customize your Reader Idle Screen

You may choose to add a custom logo or image to the card reader idle screen, which can be great to add your branding to another customer touch point. The images can be configured at either the reader level, location ID level, or at the [gateway account](/braintree/in-person/get-started-1/account-structure/#braintree-account-hierarchy) level. In order to facilitate this, you will need to follow the below steps.


### V400m Custom Image File Specs


- Dimensions: 320 by 464 pixels with 72dpi


- Supported file formats:.jpg,.gif,.png


- Max file size: 2mb


- Animation is supported only using.gif file format




### Tips for creating your image files


- For logos on a flat color background, choose.png file format for a crisp render of your logo


- For a screensaver with photographic backgrounds, choose.jpg file format. Use Photoshop to save for web compression at 80%


- For animations, use.gif file format and use save for web compression with 128 colors or less




### Process to Upload Custom Images


- Create a custom image file adhering to the V400m Custom Image File Specs


- Identify the readers that you would like this to be enabled for ( we'll need serial numbers if you'd like this enabled for specific readers or location IDs for specific locations, otherwise we can enable at the gateway account level )


- Send the image file along with a list of the reader serial numbers to your PayPal Solutions Engineer or Integration Engineer to kick off the enablement


- The readers will refresh their configuration within a 12-hour interval or upon the next reboot



**NOTE**
If you would like to update the custom image files post go live please follow the above steps and email the support team at **eis-hw-support@paypal.com**
