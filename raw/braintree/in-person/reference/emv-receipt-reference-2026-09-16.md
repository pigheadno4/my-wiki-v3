# EMV Receipt Reference

This page includes an example EMV compliant receipt with an overlay explaining the various data elements


## [](#emv-compliant-receipt-overview)EMV Compliant Receipt Overview

It is important to make sure that the receipts you produce for your customers include all of the necessary information to maintain EMV compliance as well as making sure you give your customer all of the information they need.

The below receipt example includes an overlay which explains what the various data elements represent as it relates to EMV compliance. See our [Receipt Data Handling Documentation](/braintree/in-person/guides/making-a-transaction/receipt-data-handling/) for more information.
