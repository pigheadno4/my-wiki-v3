# Supported file types and sizes

When handling disputes, you can upload supporting files as evidence to strengthen your case. Evidence can include receipts, delivery confirmations, photos, or other relevant documentation.

Ensure the files meet the following criteria:

- **Supported file types**: `.jpg`, `.jpeg`, `.gif`, `.png`, and `.pdf`
- **Individual file size**: Less than 10 MB per file
- **Total file size**: Up to 50 MB per API call
