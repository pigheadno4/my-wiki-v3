# Countries and supported features

You can use the following information to review country and currency requirements before sending payouts.

<Warning>You can use Venmo as a payout method only for recipients in the United States.</Warning>

## Feature sets and what they mean

The following table summarizes the payout feature sets:

| Feature set                                   | Description                                                                                                                                                               |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Send, receive, and withdraw                   | Merchants can send payouts from this country. PayPal account holders can receive and withdraw money.                                                                      |
| Send, receive, and withdraw in local currency | Merchants can send payouts from this country. PayPal account holders can receive and withdraw money in local currency.                                                    |
| Fully localized                               | Merchants can send payouts from this country. PayPal account holders can receive and withdraw money in local currency. The PayPal app is available in the local language. |
| Receive and withdraw                          | Merchants cannot send payouts from this country. PayPal account holders can receive and withdraw money.                                                                   |

## Currency conversion

PayPal Payouts supports automatic currency conversion when the payout currency differs from the recipient’s account currency. However, some countries and currencies have exclusions or restrictions.

Before initiating a payout with currency conversion, you can:

- Check the recipient’s country and currency eligibility.
- Review the exclusion and restriction rules for countries to avoid payout failures.
- Use the supported currency list to determine if automatic conversion is available for your use case.

<Note>The conversion rate applied to payouts includes PayPal’s spread or fee. For more information, see the <a href="https://www.paypal.com/us/business/paypal-business-fees#paypal-payouts" target="_blank" rel="noopener noreferrer">PayPal Merchant Fees</a> page.</Note>
