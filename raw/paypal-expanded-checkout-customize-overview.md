# Customize your buyers' experience

Extend your advanced credit and debit card integration with the following features:

| Feature | What you get |
| --- | --- |
| 3D Secure | Provide customer authentication with 3D Secure. |
| Acquirer reference number | Track transactions using an acquirer reference number. |
| Card fields style guide | Change the layout, width, height, and outer styling of the card fields. |
| Card field properties | Capture the card field properties and customize their event callbacks or style. |
| Card field events | Subscribe to card events to make UI updates. |
| Fraud protection | Risk management toolkit to integrate advanced credit and debit card payments. |
| Chargeback protection | Tool to reduce the risk of fraudulent credit or debit card transactions by approving or declining transactions using fraud analysis. |
| Real-time account updater | Use real-time account updates to reduce declined card payments. |
| SCA payment indicators | Process payments that require Strong Customer Authentication. |
| Level 2/Level 3 processing | Send additional payment information to qualify for reduced processing costs. |
| Third-party network token processing | Process payments using third-party network tokens without handling actual card data. |
| Update order details | Adjust the order and transaction details during the checkout process. |
| Handle errors | Handle payment errors to manage the payer's checkout experience. |
| Initiate future transactions | Website Payments Pro merchants can initiate future transactions using a transaction ID. |
