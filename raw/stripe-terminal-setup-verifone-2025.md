# Set up Verifone readers

Learn how to set up Verifone readers compatible with Terminal SDKs and the Stripe API.

> #### Verifone reader support
>
> Verifone reader support is in public preview for the United States and Canada. Some verifone readers are in private preview for Ireland and the United Kingdom (V660p, UX700, P630) and for Singapore (V660p, P630). To join the preview, you must [contact the Sales team to order the applicable reader](https://stripe.com/contact/sales).

Stripe supports four Verifone readers. Each device has its strengths, and the choice between them depends on specific business needs, such as display size requirements, battery life needs, processing power, and compatibility with existing systems. Not all Verifone readers are available in every country. See [Global availability](https://docs.stripe.com/terminal/payments/setup-reader.md#availability) for details.

To learn how to set up each reader, see:

- [V660p](https://docs.stripe.com/terminal/payments/setup-reader/v660p.md)
- [UX700](https://docs.stripe.com/terminal/payments/setup-reader/ux700.md)
- [P630](https://docs.stripe.com/terminal/payments/setup-reader/p630.md)
- [M425](https://docs.stripe.com/terminal/payments/setup-reader/m425.md)
