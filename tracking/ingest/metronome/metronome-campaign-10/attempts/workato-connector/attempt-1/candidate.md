## Overview

This guide explains how to connect a Metronome environment to Workato through Metronome's custom Workato connector. Metronome positions the connector as an SDK-like way for Workato workflows to perform actions on Metronome endpoints.

## Key takeaways

- Metronome identifies third-party billing invoicing, customer provisioning, and contract provisioning as example workflows for the Workato integration.
- Setup requires installing the Workato connector, generating a Metronome API token, and pasting that token into a new Workato connection.
- Each Metronome environment requires its own Workato connection.

## Setup boundary

The source describes connecting Workato to Metronome but does not enumerate the connector's available actions, endpoint coverage, API-token permissions, workflow triggers, data mappings, error handling, retry behavior, or connection-rotation procedure. It links to Metronome's API-authorization documentation for token-generation instructions.
