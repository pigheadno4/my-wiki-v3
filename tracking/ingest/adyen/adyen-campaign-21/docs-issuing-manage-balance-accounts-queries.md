Q1. How does the guide create a balance account under an account holder, and where can linked cards and balances be viewed?
Answer: Send Configuration API POST /balanceAccounts with the account holder ID and retain the returned balance-account ID (raw lines 23–27, 227–254). Customer Area Balances > Balance accounts or GET /accountHolders/{id}/balanceAccounts and GET /balanceAccounts/{id} show accounts and balances; GET /balanceAccounts/{id}/paymentInstruments lists associated cards (raw lines 256–278). Q2. What must be true before permanently closing a balance account, and how is closure requested?
Answer: The account must have zero balance. The guide says to transfer remaining funds if needed, then update the balance-account status to Closed using the update operation (raw lines 473–480). Account-holder permanent deactivation is a separate linked action (raw line 482); the examples do not prove a live transfer or successful closure.
