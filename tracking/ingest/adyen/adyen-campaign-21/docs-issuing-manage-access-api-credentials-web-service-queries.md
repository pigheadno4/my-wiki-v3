Q1 — Which credentials does this balance-platform page describe, and what is its prerequisite? Its Requirements table specifies an Adyen for Platforms integration and Balance platform admin role despite the Issuing URL (raw lines 33-40). It distinguishes web-service users for Configuration/Transfers and some configured APIs from LEM users for legal entities and onboarding sessions (42-52). Additional credentials are managed at company-account level (65-125). Q2 — What can fail during rotation or deactivation? A new API key becomes active immediately while the old key stays active for 24 hours by default; it can be reset to 24 hours or expired now, and the new key cannot be copied again after leaving the page (raw lines 129-176). A new basic-auth password deactivates its predecessor immediately (178-184). Live uses newly created live credentials/keys (127, 155, 206). Credentials cannot be deleted but can be deactivated to prevent key use (223-232). These procedures are not evidence of current account permission or a successful live API request.
