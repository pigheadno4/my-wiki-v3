Q1. What is a custom payout execution and how can it be viewed?
A. A schedule-initiated payout attempt on a balance account is an execution. The 2026-09-15 Adyen Platforms guide shows it in Customer Area under account holder → balance account → Scheduled transfers → custom schedule → Events; API viewing uses Configuration API `GET /balanceAccounts/{balanceAccountId}/sweeps/{id}/executions` and a `sweepExecutions` array. API viewing needs `Bank Scheduled Payouts Merchant Role`; Customer Area viewing needs Balance platform base and Configure scheduled payouts roles. A custom schedule displays transfer schedule, while managed shows estimated arrival. An execution record is not proof of beneficiary bank receipt. Q2. What do success, skip, and failure mean, and what evidence follows success?
A. Customer Area uses Sent, Not sent, and Failed; Configuration webhooks use `balancePlatform.balanceAccountSweepExecution.succeeded`, `.skipped`, and `.failed`. A succeeded execution supplies a `transferId` for the resulting bank transfer, not completed bank receipt. Skips carry reasons such as no balance, thresholds, or disabled configuration; failures include routing, counterparty, capability, account, reserve-collateral and amount/address problems. A final failure can disable the schedule and `sweepConfigurationDisabled` reports that condition. The API sample instead uses `sweepDisabled` as a string, and blocked-counterparty codes differ across examples, so verify the actual payload. Follow Transfer webhooks for subsequent authorization, capture, or possible bank return; no shown state proves beneficiary credit.
