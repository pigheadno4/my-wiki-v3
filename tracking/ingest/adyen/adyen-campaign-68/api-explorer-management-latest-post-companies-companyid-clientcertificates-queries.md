# C68 original-query answers: api-explorer-management-latest-post-companies-companyid-clientcertificates

## Q1

The 2026-11-07 Management API `latest` capture describes `POST /companies/{companyId}/clientCertificates`, “Generate a client certificate,” on the shown TEST v3 server `https://management-test.adyen.com/v3`. Required path `companyId` is the company account; the body requires intended `apiCredential` in `ws_*@Company.*` form and a Base64 DER `certificateSigningRequest`. The **calling** credential needs Management API - Client certificates read and write. The CSR must be signed by its private key, with RSA at least 2048 bits or ECC at least 224 bits; only the public key is enrolled. Adyen ignores the CSR subject and constructs `subjectDN` from `companyId` and target `apiCredential` in the documented UID/CN/O form. A company account has a maximum of 10 valid client certificates at a time. A `201` response requires `caChain`, `id`, Base64 DER `leaf`, `serialNumber`, and `subjectDN`; the chain excludes the leaf. There are no optional request fields, defaults, or additional limits stated. ## Q2

`201` establishes successful generation of a signed client certificate; it does not establish usable mTLS or successful subsequent authentication. The returned DN must be assigned separately to the specified API credential through Customer Area or credential PATCH. The source does not say that generation automatically performs this association, activates access, replaces a prior certificate, or proves payment execution. `400` describes a malformed/incorrect CSR, `401` says the API credential used in the request is invalid, without specifying whether it is the caller or the body-named target credential, `403` insufficient permissions, `422` missing/invalid fields, CSR requirements or the certificate limit, `429` a rate-limit excess, and `500` an unrecoverable server error. This snapshot gives no idempotency, renewal/deletion/reversal, asynchronous approval, or version/conflict contract; a TEST example is no evidence of current Live eligibility, compliance, connectivity, or financial outcome.
