# C68 compatible nonprofits POST query answers

## Q1

`POST /companies/{companyId}/nonprofits` is a captured Management API `latest` v3 TEST-server list operation, despite its POST method. It returns supported nonprofits compatible with **all** account holders identified in the required body `accountHolderIds`, for choosing a cause when creating a Giving campaign. Required path `companyId` identifies the company account. Optional query `goal` accepts repeated `unsdg_<number>` values; `pageSize` defaults to 10 and is capped at 100, `pageNumber` selects a page, and `searchTerm` is capped at 100 characters. The raw states no operation-specific credential role. A `200` requires `itemsTotal` and `pagesTotal`; `_links` and `nonprofits` are optional. Returned nonprofit entries can include separate optional Adyen-generated nonprofit and cause IDs plus name, descriptions, goals, locales, regions, links and cause metadata. See [[source-adyen-api-explorer-management-latest-post-companies-companyid-nonprofits]] and [captured API reference](https://docs.adyen.com/api-explorer/Management/latest/post/companies/(companyId)/nonprofits), lines 5–70.

## Q2

A `200` establishes a successful compatibility-list read for the submitted account-holder IDs, with totals and any returned optional list. It does not create or verify a nonprofit, create or activate a campaign, authorize a donation, prove eligibility outside the listed context, settle funds, or establish bank receipt. The reference describes no idempotency key, mutation lifecycle, review/approval, rollback, consistency guarantee, or snapshot stability. It lists `400`, `401`, `403`, `422`, and `500` failures; `503` specifically says campaign management is temporarily unavailable for this account but donations themselves are unaffected. The displayed server is test v3, and the 2026-11-07 documentation snapshot is not proof of current live availability or financial outcome. See [[source-adyen-api-explorer-management-latest-post-companies-companyid-nonprofits]] and [captured API reference](https://docs.adyen.com/api-explorer/Management/latest/post/companies/(companyId)/nonprofits), lines 7–10, 20–70, 73–184.
