# C68 merchant terminal-theme GET query answers

## Q1

The 2026-11-07 Adyen Management API `latest` capture documents `GET /merchants/{merchantId}/terminalThemes` as a paginated metadata list for one merchant account. The listed server is Test `/v3`, and the caller's API credential needs `Management API - Terminal themes read and write`. Required path parameter `merchantId` uniquely identifies the merchant account. Optional query parameters are `search` (case-insensitive substring match on theme name), `page` (defaults to 1) and `pageSize` (defaults to 10). The query table specifies no size range; a `422` example illustrates rejection of `pageSize=200` with a message saying it must be 1–100. `200` returns required `data` and `hasNextPage`; each theme in `data` has required `id`, `name` and `mode`, with `dark` or `light` modes. `hasNextPage` reports whether later pages exist. Images and videos are excluded; a separate theme-detail GET supplies asset URLs. See [[source-adyen-api-explorer-management-latest-get-merchants-merchantid-terminalthemes]] and [the captured operation](https://docs.adyen.com/api-explorer/Management/latest/get/merchants/(merchantId)/terminalThemes), raw lines 5–43, 144–160.

## Q2

A `200` response establishes a metadata listing for the requested merchant and page. It does not create, update, assign or activate a theme; return image/video assets; prove a particular terminal has downloaded or displayed one; or show device or payment readiness. The reference lists `400` bad request, `401` unauthorized, `403` forbidden, `404` not found, `422` unprocessable entity and `500` server error. Its `403` example says the caller lacks access to the account; its `404` example says the account cannot be found or accessed, so that example alone does not prove the account is absent. This read has no documented idempotency, deletion, propagation, asynchronous approval, reversal or financial effect. The Test v3 reference is a 2026-11-07 snapshot, not proof of present Live eligibility. See [[source-adyen-api-explorer-management-latest-get-merchants-merchantid-terminalthemes]] and [the captured operation](https://docs.adyen.com/api-explorer/Management/latest/get/merchants/(merchantId)/terminalThemes), raw lines 5–14, 31–67, 69–173.
