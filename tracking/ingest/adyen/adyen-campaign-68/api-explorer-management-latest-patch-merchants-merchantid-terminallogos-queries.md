# C68 merchant terminal-logo PATCH query answers

## Q1

`PATCH /merchants/{merchantId}/terminalLogos` is the captured Management API `latest` v3 TEST-server operation for updating the logo of one terminal model under the merchant account identified by required path `merchantId`. Required query `model` selects a model from the raw allowlist. The credential needs `Management API—Terminal settings read and write`. The request-body `data` field is table-optional, but the operation prose directs callers to send a Base64-encoded image to change the logo or an empty logo value to restore the company-level logo. The merchant logo covers that model's terminals except where a store or terminal logo overrides it. `200` may return Base64 `data`; `204` returns no content. The raw states no image-size limit or request default. See [[source-adyen-api-explorer-management-latest-patch-merchants-merchantid-terminallogos]] and [captured API reference](https://docs.adyen.com/api-explorer/Management/latest/patch/merchants/(merchantId)/terminalLogos), lines 5-40 and 57-69.

## Q2

The reference calls `200` a succeeded request and `204` successful processing with no additional content; its `200` examples illustrate inherited or uploaded logo data. It does not document on-device application time or a terminal confirmation, idempotency, or review/approval/activation transitions. An empty logo value restores company inheritance; lower-level store or terminal overrides can still apply. Authentication and permission failures are separately listed as `401` and `403`; request/validation failures as `400` and `422`, and server failure as `500`. Live requests are rate-limited, while the displayed server is test v3. A documentation readback is neither account eligibility nor a payment or financial outcome. See [[source-adyen-api-explorer-management-latest-patch-merchants-merchantid-terminallogos]] and [captured API reference](https://docs.adyen.com/api-explorer/Management/latest/patch/merchants/(merchantId)/terminalLogos), lines 7-21, 57-73, 92-153, and 171-187.
