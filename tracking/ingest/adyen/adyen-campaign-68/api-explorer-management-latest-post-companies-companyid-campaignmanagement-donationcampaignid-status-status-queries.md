# C68 worker query answers: api-explorer-management-latest-post-companies-companyid-campaignmanagement-donationcampaignid-status-status

## Q1

The 2026-11-07-captured Management API `latest` `POST /companies/{companyId}/campaignManagement/{donationCampaignId}/status/{status}` lists TEST server `https://management-test.adyen.com/v3`. It starts or stops a company-account donation campaign selected by required `companyId` and `donationCampaignId`. Required path `status` is `activate` for an inactive campaign or `end` for an active one; other transitions are disallowed. The caller needs the Campaign Management read and write API-credential role. There is no listed query parameter, request body, numeric default, or limit. On `200`, the campaign response requires `id`, `name`, `nonprofitCause`, and current `status`; account-holder IDs, activation/end times, and in-person/online settings are optional. Nested amount and currency fields are required only within present optional amount items.
