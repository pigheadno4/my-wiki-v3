# C68 company Giving campaign POST query answers

## Q1

`POST /companies/{companyId}/campaignManagement` is the captured Management API `latest` v3 TEST-server creation route for a Giving campaign that may cover online, in-person, or both donation channels. Required path `companyId` identifies the company account. Required body `name` names the campaign and `nonprofitCauseId` identifies its supported cause. Optional `accountHolderIds`, `online`, and `inPerson` associate other identity scopes and channel settings; merchant-account and Adyen-generated store IDs are channel-specific. An in-person object has required nested `displayTextField` and `donationFlow`; `presentCardTimeoutMs` is required when flow is `twoStep` and defaults to 10000 ms within 5000–15000 ms. `promptTimeoutMs` has the same default/range. Each optional `defaultAmount` requires a currency code and 1–3 minor-unit amounts. The credential needs Campaign Management read-and-write. A `200` requires generated campaign `id`, `name`, `nonprofitCause`, and `status`; channel details and `activatedAt`/`endedAt` are optional. See [[source-adyen-api-explorer-management-latest-post-companies-companyid-campaignmanagement]] and [captured API reference](https://docs.adyen.com/api-explorer/Management/latest/post/companies/(companyId)/campaignManagement), lines 5–91.

## Q2

A `200` says the creation request succeeded and returns a campaign identity and status; the reference does not enumerate status values or say that creation automatically activates the campaign. Optional activation/end timestamps cannot be assumed present. The operation does not prove shopper display, a donation request, donation outcome, settlement, or nonprofit bank receipt. It specifies no idempotency key, duplicate handling, version/conflict guard, review or activation sequence, rollback, or propagation time. `400`, `401`, `403`, `422`, and `500` are listed; `503` specifically says campaign management is temporarily impossible for this account while donations themselves are unaffected. The displayed server is test v3, and this 2026-11-07 reference does not prove current account eligibility or live campaign state. See [[source-adyen-api-explorer-management-latest-post-companies-companyid-campaignmanagement]] and [captured API reference](https://docs.adyen.com/api-explorer/Management/latest/post/companies/(companyId)/campaignManagement), lines 7–14, 49–91, and 94–205.
