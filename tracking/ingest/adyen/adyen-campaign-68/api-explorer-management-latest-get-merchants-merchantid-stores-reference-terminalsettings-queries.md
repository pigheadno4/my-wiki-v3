# C68 worker query answers: api-explorer-management-latest-get-merchants-merchantid-stores-reference-terminalsettings

## Q1

The 2026-11-07 capture documents `GET /merchants/{merchantId}/stores/{reference}/terminalSettings` in Management API `latest`, with a listed v3 TEST server at `https://management-test.adyen.com/v3`. It reads store-configured terminal settings, subject to an individual terminal's different settings. Required path IDs are the unique merchant-account `merchantId` and the identifying store `reference`; no query or body inputs are listed. The API credential needs Terminal settings read or read and write, plus Advanced read and write for sensitive settings. Live requests are rate limited. The `200` response groups are optional, ranging across receipt, connectivity, gratuities, hardware, payment, refunds, surcharge, store-and-forward, Wi-Fi and terminal instructions. The schema gives conditional details and defaults inside those groups: store-and-forward limits/card types must be locally configured or inherited; restart and totals reset hours default to 6:00 AM in terminal time zone; each ranges 0–23. The response example is illustrative, not a promise that any optional group is returned. ## Q2

A `200` establishes a successful read of configured store-level settings; a `204` establishes successful processing without content. Individual terminal overrides can make a terminal's values different. The reference specifies credential-role gates, Live rate limits and 400/401/403/422/500 error responses, but no idempotency key, update, deletion, asynchronous approval, activation or reversal transition for this GET. The response table describes consequential configuration boundaries: enabling DCC carries receipt obligations; unreferenced refunds carry merchant loss liability; first changing contactless currency requires an Adyen compliance check; store-and-forward parameters must be configured or inherited. The captured TEST server and optional readback do not establish Live access, applied device configuration, compliance clearance, transaction authorization, capture, settlement or bank receipt.
