## Q2 — Central capability, prerequisites and warnings

`source-adyen-docs-payment-methods-sepa-direct-debit-ios-component` requires an existing Sessions iOS Components flow with Checkout API v68+ or an existing Advanced iOS Components flow, plus Customer Area setup. Sessions says no extra ordinary `/sessions` parameters/configuration and initializes `SEPADirectDebitComponent`; Advanced requires owner name and unencrypted IBAN, with billing address conditional on the listed non-EEA SEPA IBAN countries/territories (raw `raw/adyen/docs/payment-methods/sepa-direct-debit/ios-component/2026-09-15.md:25-72`, `:917-971`). The Advanced prerequisite URL names Drop-in despite a Components label, and the action row's `direct` type links a redirect anchor (same raw `:925-926`). If automatic capture is off, use delayed or manual capture; the page says SEPA authorizations do not expire and multiple partial captures need Support (same raw `:1007-1016`). Tokenization for shopper-absent Subscription/UnscheduledCardOnFile uses standard creation fields, `recurring.token.created` and later `/payments`; explicit permission is strongly recommended, while some Advanced token-creation examples omit prose-required bank fields (same raw `:78-84`, `:283-314`, `:963-971`, `:1020-1028`, `:1188-1225`, `:1377-1408`, `:1688-1715`). TEST IBANs and live Customer Area request are at `:903-915` and `:1995-2007`.
