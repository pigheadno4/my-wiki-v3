Q1. What are the base React Native Drop-in requirements and the extra steps for KakaoPay recurring payments?
Answer: Sessions lists existing React Native Drop-in, Checkout API v68+, redirect handling and Customer Area KakaoPay, with no extra method-specific `/sessions` or configuration parameters (raw lines 25–48). Advanced lists its existing Drop-in/redirect/Customer Area setup and no extra base `/payments` or configuration parameters (raw lines 300–322). For recurring use, a separate `/payments` request has `storePaymentMethod: true` and `shopperReference`; after shopper confirmation and payment settlement, `recurring.token.created` supplies the stored ID, then future requests use that ID, same shopper reference, `ContAuth` and fixed/non-fixed processing model (raw lines 50–89 and 324–363).
