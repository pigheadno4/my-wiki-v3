## Overview

This [[adyen]] KakaoPay for Web page is a **navigation chooser**. It points readers to the KakaoPay **Web Drop-in** and **Web Components** child guides, and to the main Web Sessions and Advanced integration guides for each UI path. It does not itself specify child-page configuration, method eligibility, SDK/API versions, transaction behavior, or payment outcome. [[adyen-online-payments]]

## Key takeaways

- **UI choices:** The page labels the Drop-in route an all-in-one UI solution and labels the Components route **Redirect** for KakaoPay. These are descriptions and links to separate child guides, not implementation steps or proof of an enabled method. See raw lines 19–27.
- **Main integration first:** Its See also section directs readers to create a main Web integration before adding KakaoPay and links the Web Drop-in and Web Components guides under **Sessions** and **Advanced** flows. The linked guides, rather than this chooser, govern their respective requirements. See raw lines 29–36.
