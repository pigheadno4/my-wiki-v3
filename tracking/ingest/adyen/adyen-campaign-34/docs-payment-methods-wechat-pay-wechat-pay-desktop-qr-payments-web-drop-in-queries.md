Q1. How does this Web Drop-in guide distinguish desktop QR and mobile-browser WeChat Pay setup?
A1. It requires an existing Sessions-flow Web Drop-in for /sessions or Advanced-flow Web Drop-in for /payments (raw lines 21–39). Both tabs say to add WeChat Pay in Customer Area for desktop QR, while mobile-browser use requires contacting Adyen Support with the web shop URL for enrollment; Web Drop-in v6 also shows a WeChat resource import (raw lines 30–47).
