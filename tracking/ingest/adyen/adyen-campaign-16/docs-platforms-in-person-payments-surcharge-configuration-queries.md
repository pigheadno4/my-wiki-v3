Q2. Which rule, device, disclosure, booking and double-surcharge constraints matter?
- Expected: The guide lists Terminal API terminal or Tap to Pay Mobile and standalone support, excluding SFO1 terminals and NYC1 Mobile readers. It requires a Management API key with terminal-settings read and read/write roles; payment-terminal software gates are v1.108 for caps, v1.112 for commercial/consumer distinction, v1.115 for tip exclusion and v1.117 for MOTO/MKE. Live terminal-settings endpoints are rate-limited. Tap to Pay surcharge use needs Support-enabled single tap; Tap to Pay has no confirmation screen and Mobile or skipped confirmation needs another disclosure form. From v1.117 configured rules also apply to MOTO/MKE, risking a double charge where custom surcharging already exists; Adyen-contact opt-out is available.
