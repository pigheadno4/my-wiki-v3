## Q1 — purpose, scope, and what must not be inferred

**Question:** What is this page for, whose campaign does it configure, and what can its setup or activation not prove?

**Answer:** This is the 2026-09-15 Adyen for Platforms Giving guide for a platform to create and manage donation campaigns for **account holders**, using Customer Area or Management API, including a possible platform-built UI for user self-service. Campaigns can cover online, in-person or both channels. It routes through [[adyen-giving]] (root [[wiki/index]] → [[adyen-index]] → [[adyen-giving]]), with [[adyen-platforms]] as platform context and [[source-adyen-docs-platforms-donations-create-manage-campaigns]] as the source. It describes configuration and status, while separate online/in-person donation guides cover shopper transactions; campaign setup or activation is not evidence that a donation succeeded, that a payment succeeded or that nonprofit funds settled. ## Q2 — central capability, prerequisites, and material warnings

**Question:** How can an eligible platform configure and manage an account-holder Giving campaign, and which limits or irreversible states matter?

**Answer:** The platform chooses an available onboarded nonprofit cause, participating account holders and channel-specific stores, then configures donation type and, for in-person, interaction flow in Customer Area or the Management API. The API route requires the Campaign Management read/write credential role; Customer Area viewer and manager roles differ. The documented scope is platform model, online API-only Checkout API v67+ and/or Terminal API/Standalone with terminal software v1.109+ (some features v1.110+), plus supported method, region, currency and terminal. Maximum 400 account holders per campaign; one store can belong to only one active campaign. The API creation result is inactive, not activated. Inactive campaigns can be activated and active ones ended, but these transitions cannot be reversed, and only never-started inactive campaigns can be deleted. Editing active or inactive campaigns is possible, with account-holder country/industry nonprofit compatibility, full replacement arrays on PATCH and delayed in-person terminal propagation; online pre-checkout presentation is implemented in the payment flow, not campaign settings. In-person one-step still entails two transactions, and donation is unavailable offline even if the payment continues. See [[adyen-giving]] → [[source-adyen-docs-platforms-donations-create-manage-campaigns]]; raw lines 23–42, 44–87, 114–161, 270–295, 335–340, 402–419, 572–586, 666–711; canonical URL https://docs.adyen.com/platforms/donations/create-manage-campaigns.
