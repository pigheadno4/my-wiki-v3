# Fixed retrieval checks — Manage automatic split profiles

## Q1. What does this page cover, and where are the management details?

The 2026-09-15 Platforms hub says a split-configuration profile applied to a user's store supplies the highest-priority matching rule's instructions for automatic payment splitting. It says rules, conditions and split instructions can be managed through Customer Area or Management API, while profile-description changes and card-region conditions require Management API. Its linked Customer Area and API guides hold method details. This hub does not specify role permissions, request payloads, deletion effects or proof of an active linked profile. ## Q2. What happens if the profile changes between authorization and capture?

Adyen says it checks the profile at capture. An update after authorization but before capture applies to the capture, and transaction-specific split instructions in the capture request override the profile. Thus an earlier authorization does not fix the later profile-based capture split. The statement is a rule for configuration selection, not evidence that a particular capture, split booking or payout happened.
