## api-explorer-balanceplatform-latest-post-paymentinstruments-paymentinstrumentid-authorisedcardusers

Q1. The 2026-11-02 Balance Platform API capture documents `POST /paymentInstruments/{paymentInstrumentId}/authorisedCardUsers` on TEST `https://balanceplatform-api-test.adyen.com/bcl/v2`. It assigns authorised users to the card identified by required string path `paymentInstrumentId`; the users must have the `authorisedPaymentInstrumentUser` capability to use the card. The only request-body table field is optional `legalEntityIds`, an array of legal-entity ID strings linked to that instrument. The page states no whole-body requiredness, empty-array meaning, cardinality limit or default; its two-ID example is illustrative. A successful operation returns 204 with no response-body schema, resource ID or assignment-status fields.
