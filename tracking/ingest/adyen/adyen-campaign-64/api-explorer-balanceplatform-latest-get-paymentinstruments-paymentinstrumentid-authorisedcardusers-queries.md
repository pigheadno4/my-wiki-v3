## api-explorer-balanceplatform-latest-get-paymentinstruments-paymentinstrumentid-authorisedcardusers

- Q1: `GET /paymentInstruments/{paymentInstrumentId}/authorisedCardUsers` returns authorized card users for a specified payment instrument. This 2026-11-02 Balance Platform API Explorer snapshot gives TEST `https://balanceplatform-api-test.adyen.com/bcl/v2` (v2 despite `latest` in the reference URL). The only required input is string path `paymentInstrumentId`; its table description is blank, and no query/body input, default, limit or pagination is listed. A 200 successful-operation body has one optional `legalEntityIds` array of strings, described as IDs of authorized card users linked to that payment instrument. Those legal-entity IDs are distinct from the parent payment-instrument ID and from balance-account or account-holder IDs. The two-ID example is illustrative, not a required count.
