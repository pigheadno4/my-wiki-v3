Only the `https://balanceplatform-api-test.adyen.com/bcl/v2` server is shown. This page specifies no caller role, query fields, pagination or request body. The 200 response table marks `transactionRules` optional; within an item, `description`, `entityKey`, `interval`, `reference`, `ruleRestrictions` and `type` are marked required, while the rule `id` and `status` are optional. `entityKey` holds resource type/reference, distinct from the balance-account path ID; the listed scope types also include platform, account holder, payment instrument and payment-instrument group. `requestType` defaults to authorization and also lists authentication, tokenization and bank transfer. Conditional rule descriptions include rolling/sliding duration (90-day maximum or equivalent), score for score-based outcomes (-100 to 100), and bypass's overridden rule ID with empty restrictions. These descriptions belong to the response schema, not GET input requirements.
