Required path `id` is the group identifier; the reference gives no query parameters, request body, caller role, defaults or limits. A 200 response requires `balancePlatform`, the owning balance-platform identifier, and `txVariant`, the group's transaction variant. Response `id`, `description`, `properties` and `reference` are optional in the schema. The example `txVariant: mc` is illustrative; the raw gives no enum of allowed values or schema for `properties`.
