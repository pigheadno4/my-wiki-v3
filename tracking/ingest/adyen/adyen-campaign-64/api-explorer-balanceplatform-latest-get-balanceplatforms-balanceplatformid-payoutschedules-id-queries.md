## Q1

The 2026-11-02-captured Balance Platform API v2 `GET /balancePlatforms/{balancePlatformId}/payoutSchedules/{id}` reads a specific managed payout schedule configured on a balance platform. The only displayed server is `https://balanceplatform-api-test.adyen.com/bcl/v2`. Both path strings are required: `balancePlatformId` is the platform ID; `id` is the platform payout-configuration ID. The page identifies no credential role, query parameter, request body or idempotency input. The 200 response requires `balancePlatformId`, `createdAt`, `payoutScheduleDescription`, `userSettlementDelay`, `userSettlementTime` and `userSettlementTimeZone`; returned `id`, `automaticApplication`, `enabled`, country/currency, payout defaults, amount thresholds and `updatedAt` are optional. `defaultFrequencyValue` is allowed only with monthly (1–31) or weekly (1–5) frequency, with described weekend/missing-day adjustments. Minimum and maximum amounts default to 0, with max 0 meaning no maximum; retained amount defaults to 0 and can prevent initiation if available funds are lower. The page does not state a unit for those integer amount fields. ## Q2

A 200 establishes a read of platform-level schedule configuration, not application to any balance account, payout execution, successful transfer, settlement or beneficiary bank receipt. `automaticApplication` describes new-account application settings; `enabled` is worded as enabled immediately after creation. Standard/Accelerated labels carry stated timing descriptions relative to settlement, not a guarantee about a particular payout. This GET does not create, activate, delete or propagate a schedule. The page documents 401 authentication-required, 404 not-found, 422 validation and 500 server errors without a specified authentication role/method or response examples; it gives no idempotency, asynchronous execution, failure/reversal or deletion-effect contract. Separate application, execution and transfer evidence is needed for those stages. Its TEST server and `latest` URL do not establish current live availability, version or eligibility.
