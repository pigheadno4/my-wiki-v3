## Q1

The 2026-11-02-captured Balance Platform API v2 `DELETE /balanceAccounts/{balanceAccountId}/payoutSchedules/{id}` removes a managed payout schedule applied to one balance account. The only shown server is `https://balanceplatform-api-test.adyen.com/bcl/v2`. Both path strings are required: `balanceAccountId` is the account ID and `id` is that account's applied schedule ID, distinct from a platform-level schedule definition. The page specifies no caller role, query parameter, request body, default, limit or idempotency input. Success is HTTP 204 with no response-body schema.
