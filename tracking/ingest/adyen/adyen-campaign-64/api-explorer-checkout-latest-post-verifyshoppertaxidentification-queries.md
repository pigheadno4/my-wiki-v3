# Fixed query answers — api-explorer-checkout-latest-post-verifyshoppertaxidentification

## Q1

The 2026-11-02 capture is Checkout API v72's TEST-server `POST /verifyShopperTaxIdentification` (`https://checkout-test.adyen.com/v72`). A merchant submits a shopper's tax identification where regulatory compliance requires collection and verification. The request table marks `merchantAccount`, the merchant's unique non-PII `shopperReference` that binds the shopper context, and `shopperTaxIdentification` as required properties; its nested `taxCountryCode`, `taxIdentificationNumber` and `taxIdentificationType` are also marked required. Initially the country is only `IN` and type only `PAN`; no default or numeric limit is stated. The optional 200 response fields are `reason`, `reasonCode`, `result` (examples `valid`/`invalid`), `taxVerificationReference`, masked verified-tax-ID data, and `verifiedShopperTaxIdentificationToken`, the successful-verification token required in `/payments`. See [[source-adyen-api-explorer-checkout-latest-post-verifyshoppertaxidentification]] and [the captured API reference](https://docs.adyen.com/api-explorer/Checkout/latest/post/verifyShopperTaxIdentification), raw lines 5–10, 12–22 and 24–40.

## Q2

A 200 says the verification request succeeded; because `result` and the token are optional response fields and the page gives `valid` or `invalid` examples, 200 alone does not establish valid tax identification. A token represents successful verification for later `/payments` submission, not payment authorization, capture or settlement. The captured page lists 401 authentication and 403 permission errors, plus 400 request-reading, 422 validation and 500 server errors; it states no idempotency, deletion, propagation, asynchronous result, reversal or downstream payment outcome contract. Its `latest` URL and TEST v72 server are snapshot evidence, not proof of current version, live availability or merchant eligibility. See [[source-adyen-api-explorer-checkout-latest-post-verifyshoppertaxidentification]] and [the captured API reference](https://docs.adyen.com/api-explorer/Checkout/latest/post/verifyShopperTaxIdentification), raw lines 5–10, 24–40 and 43–105.
