## api-explorer-checkout-latest-post-calculatetax

Q1. The 2026-11-02 capture of Checkout API `POST /calculateTax` lists the TEST v72 server `https://checkout-test.adyen.com/v72`. It calculates applicable tax from a merchant-account request, taxable amount and tax context; the initially supported case is India LRS TCS. The request-body table requires `merchantAccount`, `taxCalculationContext` and `taxableAmount`; nested required context fields are `calculationType` (initially `LRS_TCS`), `lrs.remittancePurpose`, `lrs.sublimitStatus` and `taxCountryCode` (initially `IN`). `taxableAmount.currency` is a three-character ISO code and `value` an integer in minor units. Whole-body requiredness is not separately stated, and this page specifies no default or numeric limit. The 200 schema marks `taxCalculation`, `taxCalculationReference` (unique to the calculation attempt) and `taxCalculationToken` optional; the calculation may include accepted inputs, tax components, total tax and total amount. Within `taxCalculation`, the response table marks `currency` and `value` required for the optional `taxableAmount`, `totalAmount` and `totalTaxAmount` objects, but lists no children for optional `taxCalculations[].taxAmount`. The page directs `taxCalculation.totalAmount` and the opaque token into a later `/payments` request. Q2. A 200 response establishes that the calculation request succeeded; the response describes a canonical calculation and potential attempt reference/token, not a payment authorization, capture, settlement or tax remittance. The response schema marks the top-level calculation, reference and token optional, although the prose directs using total amount and token in `/payments`; their presence in every 200 response is not guaranteed by this schema. The page documents 400 request, 401 authentication, 403 permission, 422 validation and 500 server errors. It gives no idempotency header, token lifetime, deletion/reversal, propagation timing or asynchronous payment outcome contract. The `latest` path and captured TEST v72 server establish neither current version nor LIVE availability or account eligibility.
