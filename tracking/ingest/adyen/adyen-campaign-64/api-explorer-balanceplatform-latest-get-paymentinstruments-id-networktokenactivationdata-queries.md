# C64 network-token activation-data GET: original fixed-query answers

## Q1

The 2026-11-02-captured Balance Platform API v2 TEST `GET /paymentInstruments/{id}/networkTokenActivationData` retrieves activation data for the payment instrument identified by the required path `id`, using the listed `https://balanceplatform-api-test.adyen.com/bcl/v2` server. The pinned reference lists no body or query parameters, defaults or numeric limits. A 200 means the request succeeded and lists only string `sdkInput` in its response table. The field is marked optional there, although its prose says `sdkInput` is required to initialize Adyen's network-token provisioning SDK. The raw links Apple Pay and Google Wallet SDK repositories for further implementation detail, without incorporating their contents. [[source-adyen-api-explorer-balanceplatform-latest-get-paymentinstruments-id-networktokenactivationdata]]; https://docs.adyen.com/api-explorer/balanceplatform/latest/get/paymentInstruments/(id)/networkTokenActivationData; verified raw lines 5–27.

## Q2

A 200 establishes successful retrieval, not guaranteed `sdkInput` presence, network-token activation, wallet provisioning, payment authorization, capture or settlement. The response-field optional marker and downstream SDK-use requirement have different subjects. The raw lists 400/401/403/422/500 errors but no 200 example, operation-specific idempotency, activation-state transition, expiration or retry timing, reversal, live-server contract or credential grant. Generic 422/500 examples concern balance-account reassignment and instrument creation, so they are not proof of this GET endpoint's activation failure modes. The `latest` URL and TEST capture do not establish current live availability or an individual instrument's provisioning eligibility. [[source-adyen-api-explorer-balanceplatform-latest-get-paymentinstruments-id-networktokenactivationdata]]; https://docs.adyen.com/api-explorer/balanceplatform/latest/get/paymentInstruments/(id)/networkTokenActivationData; verified raw lines 19–27, 30–195.
