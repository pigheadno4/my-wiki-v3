# C22 worker retrieval checks — docs-issuing-report-types

## Q1: Which Issuing balance-platform reports does the overview list, and in what formats?

The 2026-09-15-captured page lists the Accounting Report for financial activity, Balance Report for platform account balances, Payment Instrument Report for instruments and their current-date statuses, and Received Payments Report for attempts on a specified day (raw lines 21–26). It says all can be downloaded in CSV and the Accounting Report also in TSV (line 28). ## Q2: Does listing the Received Payments Report establish it as the preferred current report?

No. The overview lists it at raw line 26, but its [[source-adyen-docs-issuing-report-types-received-payments-report|dedicated guide]] explicitly says it has been deprecated and to use the Accounting Report instead ([[raw/adyen/docs/issuing/report-types/received-payments-report/2026-09-15|related raw line 19]]). This page is a report catalog, not evidence of generated reports, reconciled balances or payment success.
