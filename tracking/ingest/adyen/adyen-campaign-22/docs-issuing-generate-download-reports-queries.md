Q2. What signals availability, how is a report downloaded, and what action can remove the schedule? The report-created webhook carries `downloadUrl` when a generated report is available (raw lines 77–95). The file can be downloaded in Customer Area or by authenticated HTTP GET using report credentials and that URL; the guide shows API-key and basic-auth options (raw lines 98–144). Deselecting Automatic generation deletes the schedule (raw lines 44–46). CSV is standard, with optional TSV for the Accounting report (raw line 100). Availability or download alone does not establish reconciliation accuracy.
