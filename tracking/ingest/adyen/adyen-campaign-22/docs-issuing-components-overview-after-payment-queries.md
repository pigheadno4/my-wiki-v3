# C22 Issuing after-payment component retrieval checks

## Q1 — What does this page route users to after a card payment?

It routes users who have made payments with the platform's cards to the Platform Experience **Transactions** component for viewing transactional data; its child link lists filtering/export by account or date and detail views with fees, IDs and refunds (raw lines 15–25). The stated context is a card payment already made; the page gives no standalone component-session or role setup prerequisites, which belong in the linked detailed guide. ## Q2 — What should a reader avoid concluding from this navigation page?

The feature list is a link summary, not a specification of which transaction states, account permissions, refund details or export formats are available (raw lines 21–25). It provides no evidence that a particular payment, refund, report or export succeeded; follow [[source-adyen-docs-issuing-components-overview-after-payment-transactions-component]] for the child guide.
