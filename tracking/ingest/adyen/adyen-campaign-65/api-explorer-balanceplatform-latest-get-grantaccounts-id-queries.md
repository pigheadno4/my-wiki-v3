## Q1

For `GET /grantAccounts/{id}`, the 2026-11-03-captured Adyen Balance Platform API reference exposes `/bcl/v2` on the TEST server `https://balanceplatform-api-test.adyen.com/bcl/v2` and says the endpoint returns details of one grant account. Its only listed input is the required string path `id`, the unique grant-account identifier. It lists no query parameter, request body, caller role, endpoint-specific default or limit, or idempotency key. A `200` means the request succeeded. Its optional top-level fields are `balances`, `fundingBalanceAccountId` (the balance account used to fund the grant), grant-account `id`, and `limits`. Returned balance items require `currency`, `fee`, `principal`, and `total` (principal plus fee); a returned limit `amount` requires `currency` and integer `value` in minor units. Those nested requirements do not require the optional parent fields.
