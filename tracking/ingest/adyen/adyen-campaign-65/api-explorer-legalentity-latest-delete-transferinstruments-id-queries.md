## Q1

The 2026-11-03 Legal Entity Management API v4 reference documents `DELETE /transferInstruments/{id}` for deleting one transfer-instrument resource at the captured TEST base `https://kyc-test.adyen.com/lem/v4`. The required string path `id` identifies the transfer instrument, not its owning legal entity, an account holder, a balance account, a payout or a payment. No request body, query parameter, conditional input, default or idempotency key is documented. The page names no specific caller role, but lists 401 authentication and 403 insufficient-permission responses. It specifies captured rate limits of 700 requests per five seconds in live, 200 per five seconds in test, and five failed requests per ten seconds. Success is 204 with no response-body fields shown; the page says to inspect the actual response code. Source: [[source-adyen-api-explorer-legalentity-latest-delete-transferinstruments-id]]; https://docs.adyen.com/api-explorer/legalentity/latest/delete/transferInstruments/(id); pinned raw lines 5–30, 46–69.

## Q2

A 204 documents success of the transfer-instrument DELETE request without returning resource or payout state. The separate Platforms management guide says a delete request cannot be undone, a new transfer instrument must be created if the same account is needed again, and future scheduled or on-demand payouts using the deleted ID will fail. That guide consequence is distinct from the API page's terse 204 description. Neither source establishes reversal of an earlier payout, movement of funds, settlement or bank receipt. The API page lists 400 request, 401 authentication, 403 permission, 422 validation and 500 server failures; its generic error fields are all marked optional, including a `pspReference` described as a payment PSP reference rather than a deletion result. It documents no retry/idempotency rule, propagation timing, asynchronous review or approval, version conflict, recovery path, account eligibility or completed financial outcome. The live/test rate limits are snapshot documentation, not proof of current live access. Sources: [[source-adyen-api-explorer-legalentity-latest-delete-transferinstruments-id]]; https://docs.adyen.com/api-explorer/legalentity/latest/delete/transferInstruments/(id); pinned raw lines 9–18 and 27–95; [[source-adyen-docs-platforms-manage-transfer-instruments]]; https://docs.adyen.com/platforms/manage-transfer-instruments; guide raw lines 838–844 and 986.
