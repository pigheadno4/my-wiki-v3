## Q1

The 2026-11-03-captured Adyen Legal Entity Management API `/lem/v4` POST returns a Terms of Service document for a legal entity; the listed server is TEST `https://kyc-test.adyen.com/lem/v4`, while live/test rate limits are stated separately. The required `id` path parameter is the owner's individual legal-entity ID for sole proprietorships or the organization ID for organizations. The body requires `language=en|fr` and a `type` from the listed Terms types; `termsOfServiceDocumentFormat` is optional, defaults to `JSON`, and allows `JSON`, `PDF`, or `TXT`. The request table's JSON default (raw line 32) conflicts with the `200` example: it labels the format JSON (line 136), but its Base64 `document` (line 134) decodes to a `%PDF-1.4` signature. The example is internally inconsistent and does not establish the returned content format. The twelve listed types include Platforms, Issuing, Capital, account, card, and direct-debit variants; the Issuing example is not a general default. Rate limits are 700 live or 200 test requests per 5 seconds, plus 5 failures per 10 seconds. A `200` response can contain optional Base64 `document`, legal-entity `id`, `language`, format, document ID and type; French is available only for some integration types in certain countries/regions. No caller role, query parameter, or idempotency key is given. A `200` establishes successful document retrieval, with all response fields marked optional. It does not establish presentation to an authorized signer, consent or acceptance, satisfaction of a Terms requirement, onboarding approval, capability activation, grant funding, payment, or payout. The endpoint documents retrieval, not an acceptance action or status transition; it gives no lifecycle/deletion, asynchronous review, propagation, reversal, version/conflict, or idempotency rule. It lists `400`, `401`, `403`, `422`, and `500` errors; the response example is illustrative and internally inconsistent: its format label is JSON (raw line 136), but its Base64 document decodes with a `%PDF-1.4` signature (line 134). Do not infer content format or acceptance from that sample. The `latest` URL, TEST server and dated capture do not prove current live access or account eligibility, and a document ID is not settlement or bank-receipt evidence.
