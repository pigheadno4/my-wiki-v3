# Original query answers: POST /balancePlatforms/{id}/transferLimits

## Q1

The 2026-11-03 captured Balance Platform API v2 TEST reference creates a transfer-limit configuration for the balance platform identified by required path string `id`; the returned transfer-limit `id` is a different identifier. Its listed server is `https://balanceplatform-api-test.adyen.com/bcl/v2`. The API body requires `amount` (currency and integer minor-unit value), `scope` (`perTransaction` or `perDay`) and `transferType` (`instant` or `all`). `reference`, `startsAt`, `endsAt`, and parent `scaInformation` are optional in this API table; nested `exemption` is also marked optional and lists `lowerLimit`, `notRegulated`, `setByPlatform`, `initialLimit`, and `alreadyPerformed`. Optional `scaOnApproval` defaults to `false` for SCA initiation after submission; `true` permits initiation during later approval of pending limits. A future start schedules the limit, and omission of `endsAt` is described as leaving it active until override. The 200 body requires `amount`, limit `id`, `limitStatus`, `scope`, `startsAt`, and `transferType`; optional returned `scaInformation` has required `status` if present. The API table names no numeric ceiling, query parameter, caller credential role or idempotency key. [[source-adyen-api-explorer-balanceplatform-latest-post-balanceplatforms-id-transferlimits]] [API reference](https://docs.adyen.com/api-explorer/balanceplatform/latest/post/balancePlatforms/(id)/transferLimits), API raw lines 5–33 and 54–74.

The separate 2026-09-15 [[source-adyen-docs-business-accounts-use-transfer-limits-balance-platform|balance-platform transfer-limits guide]] says the caller needs an Adyen for Platforms Business Accounts integration, Configuration API **Balance platform base role**, and Transfer and Transaction webhook subscriptions. Its product scope is outgoing external transfers from platform balance accounts, excluding internal and incoming external transfers (guide raw lines 15–32). Its POST setup table marks `scaInformation.exemption` required and says to use `setByPlatform` (guide raw lines 44–60), in tension with the API table's optional parent and child and five values. This is a guide-specific setup instruction, not an unconditional API-schema requirement. [Guide URL](https://docs.adyen.com/business-accounts/use-transfer-limits/balance-platform).

## Q2

An API 200 means the creation request succeeded and returned a limit resource, but `limitStatus` can be `active`, `inactive`, `pendingSCA`, or `scheduled`. The example is `pendingSCA` with SCA `pending`, so it does not prove completed authentication or active enforcement. The guide's how-it-works steps say a newly created limit is `scheduled` (guide raw lines 34–40), which conflicts with the API's broader returned statuses and pending example (API raw lines 66–74, 125–134); read the actual response rather than assuming that guide step is universal. The API describes SCA timing and exemptions but no automatic exemption, later approval, successful authentication, or propagation guarantee. It lists 404 and 422 errors without an operation-specific conflict or idempotency rule. Its request/response examples differ by one hour for `endsAt` while both print `+01:00`, so they do not establish a conversion rule (API raw lines 49–50, 125–134). [[source-adyen-api-explorer-balanceplatform-latest-post-balanceplatforms-id-transferlimits]] [API reference](https://docs.adyen.com/api-explorer/balanceplatform/latest/post/balancePlatforms/(id)/transferLimits), API raw lines 20–33, 54–112 and 114–135.

For later lifecycle, the separate [[source-adyen-docs-business-accounts-use-transfer-limits-balance-platform|guide]] says only pending or scheduled platform limits can be deleted; an active limit must be overridden by creating a new limit (guide raw lines 246–250). This POST reference itself does not define deletion. Neither source's configuration or status description proves a particular transfer was authorized, booked, settled, reversed, or received by a bank. The API supplies only a dated TEST `/bcl/v2` server, and `latest` does not establish current live availability, account eligibility or regulatory compliance. [Guide URL](https://docs.adyen.com/business-accounts/use-transfer-limits/balance-platform).
