## Q1

The 2026-11-03 Legal Entity Management API v4 capture documents `GET /documents/{id}` on TEST `https://kyc-test.adyen.com/lem/v4`, using required document path ID `id` and optional boolean `skipContent` to avoid loading document content. It names no GET body, caller role, conditional input, query default or idempotency key. Stated limits are 700 requests per 5 seconds in Live, 200 per 5 seconds in Test, and 5 failed requests per 10 seconds. The 200 response requires root `description` and `type`; optional attachment parent or attachment-array items mark nested Base64 `content` required if present, while optional `owner` identifies either a legal entity or bank-account transfer instrument. The example's registration document is illustrative. ## Q2

A 200 is document retrieval, possibly with attachment content depending on `skipContent`; the capture does not specify the exact omission shape when content is skipped. It does not mean the document passed checks, a legal entity was verified, a capability was allowed, PCI requirements were satisfied, or a payment/transfer occurred. The page lists 400, 401, 403, 422 and 500 responses, but no credential role, idempotent-repeat rule, asynchronous review/approval result, version/conflict behavior or financial outcome. The generic error `pspReference` label is not payment evidence. The TEST snapshot and `latest` route do not establish current live eligibility.
