## Q1

The 2026-11-03 Legal Entity Management API v4 reference documents `POST /legalEntities/{id}/pciQuestionnaires/generatePciTemplates` on TEST `https://kyc-test.adyen.com/lem/v4`, generating questionnaires from the user's sales channel. Required path `id` identifies the legal entity; optional body `additionalSalesChannels` adds listed commerce/POS channels when relevant to signing, and is not required when stores and payment methods precede generation. Optional `language` uses a two-character ISO 639-1 code. The page names no specific caller role or default. Rates are 700 requests per 5 seconds Live, 200 per 5 seconds Test, and 5 failed requests per 10 seconds. The 200 body may contain optional Base64 `content`, `language`, and generated `pciTemplateReferences`; an empty reference array means the user is not required to sign questionnaires.
