Q1: The 2026-11-03-captured Legal Entity Management API Explorer `latest` page documents `GET /legalEntities/{id}/acceptedTermsOfServiceDocument/{termsofserviceacceptancereference}` to return an accepted Terms of Service document for a legal entity. Its only listed server is TEST `https://kyc-test.adyen.com/lem/v4`, identifying the visible server version as v4. Required string path `id` is the legal-entity ID: an owner's individual legal-entity ID for sole proprietorship, or the organization's ID for an organization. Required string path `termsofserviceacceptancereference` is an Adyen-generated acceptance reference, separate from the legal-entity ID. Optional query `termsOfServiceDocumentFormat` accepts JSON, PDF or TXT; no default is stated. No request body or caller role is listed. Rate limits are 700 requests per five seconds live, 200 per five seconds test, and five failed requests per ten seconds. A 200 marks request success, but its `document` (Base64-encoded bytes in the requested format), `id`, acceptance reference and format response fields are all optional. The response has no signer identity, acceptance timestamp or approval status. This GET reference specifies no idempotency key, mutation, deletion, propagation or reversal behavior, and no asynchronous approval step.
