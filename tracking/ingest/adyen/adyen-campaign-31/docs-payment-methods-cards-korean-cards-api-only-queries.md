Q1. How does the dated guide add Korean Card Payments via redirect to an API-only checkout?
A1. It assumes an existing API-only Advanced integration already handling redirects and the method added in Customer Area. For `/paymentMethods`, request `countryCode: KR` and `amount.currency: KRW`; the example response identifies `kcp_creditcard`. The `/payments` example yields `RedirectShopper` with a redirect action that the existing integration must handle. Raw lines 19–29, 46–53, 331–342, 682–696.
