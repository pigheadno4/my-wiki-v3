## Overview

This [[adyen]] **VX820 non-Duet** manual page, last modified **2019-04-19** and captured 2026-09-15, describes how the physical terminal displays its **Admin menu** after a model-specific key combination and Admin PIN (raw lines 14–22). It belongs to the historical [[adyen-payment-terminals]] route. The separate [[source-adyen-docs-point-of-sale-user-manuals-terminal-deprecation|eVo deprecation schedule]] lists VX820, distinct from VX820 Duet, with **29 March 2024** as “No more transactions” (deprecation raw line 34). This menu guide is not evidence of current processing support, account access or a completed device operation.

## Key takeaways

- The page says the Admin menu can be used for **network settings**, the **installer**, the **merchant menu** to edit or remove configurations and make maintenance calls, and the **totals menu** to print and reset totals (raw line 16). These are menu purposes only; the page does not document selection, execution, success or reversal of any such operation.
- Its two numbered steps say to press **9** simultaneously with the **pictured VX820 key**, then enter the **Admin-menu PIN**; if the PIN is unknown, it links to POS Troubleshooting. The terminal then displays the Admin menu (raw lines 18–22). The button image is the evidence for the second key; its text does not supply a stable key name. The page states no Customer Area role or PIN value.
- A displayed Admin menu does not show that a configuration was removed, maintenance call completed, totals counter reset, terminal connected or payment processed. The historical VX820 page must also not be merged with the separately documented VX820 Duet hardware route.
