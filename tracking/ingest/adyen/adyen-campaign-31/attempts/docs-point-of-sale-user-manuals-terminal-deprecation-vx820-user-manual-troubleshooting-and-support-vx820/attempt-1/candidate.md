## Overview

This 2019-modified, 2026-09-15-captured [[adyen]] historical support route is for the **VX820 non-Duet** terminal, via [[adyen-payment-terminals]]. It directs a user with a terminal issue to troubleshooting documentation first, then to the page's Support Team contact if unresolved. It is a support-navigation record, not proof that the linked channel, repair service or device transactions remain available.

## Key takeaways

- The page recommends first trying Adyen's linked POS troubleshooting documentation to diagnose and solve a terminal issue. If that does not resolve it, it points to a Support Team email link.
- For that support request, the page asks for the merchant account, the transaction PSP reference **if applicable**, and the terminal serial number. It says the serial is available in **Device info** and printed on the terminal back; its `S/N:123-456-789` text is an example, not an observed identifier.
- This page sits under the separate eVo terminal deprecation schedule, which lists **VX820 and VX820 Duet separately by model** in the same PTS PCI 3 row: approval expiry **30 April 2021**, repair end **31 March 2023**, and **no more transactions 29 March 2024**. That schedule also states a separate classic-library transaction cutoff after **31 March 2024**. These historical dates bound the old support instructions; the support link is not current service or payment-readiness proof.
