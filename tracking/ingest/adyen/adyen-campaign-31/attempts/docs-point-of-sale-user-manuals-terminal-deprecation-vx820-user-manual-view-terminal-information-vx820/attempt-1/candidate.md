## Overview

This [[adyen]] page, last modified 2019-04-19 and captured 2026-09-15, is a **VX820 non-Duet** Quick Info display guide. It describes viewing network and device identifiers; see [[adyen-payment-terminals]] and the [[source-adyen-docs-point-of-sale-user-manuals-terminal-deprecation-vx820-user-manual|VX820 manual]]. Its displayed fields are a historical device-screen description, not a current support, connection, boarding, PCI or payment-state check. See raw lines 15–30.

## Key takeaways

- The guide says to press a **pictured key** and **5** simultaneously to open Quick Info. The first key is an image-only symbol in the captured raw; do not infer its label from the Markdown text. See raw lines 19–25 and the linked raw image path on line 23.
- The described display shows the IP address, terminal ID and software version. It also shows a QR code encoding the IP address, MAC address, network name, store name, merchant account name and terminal ID. The guide does not say these values were verified, current, or sufficient to transact. See raw lines 25–30.
- This non-Duet VX820 guide sits under deprecated terminal manuals. The separate [[source-adyen-docs-point-of-sale-user-manuals-terminal-deprecation|eVo deprecation table]] lists **VX820** and **VX820 Duet** separately among models with **“No more transactions” on March 29, 2024** (deprecation raw lines 32–35). Opening Quick Info does not override that historical cutoff or establish device eligibility now.
