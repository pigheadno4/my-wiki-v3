Q1. Which Apple Pay certificate can the documented web and native mobile integrations use, and what does the Adyen-certificate web path require?
Answer: Web Drop-in/Components and API-only web may use merchant-owned or Adyen's certificate; iOS Drop-in/Components and API-only mobile require merchant-owned. The Adyen-certificate web setup calls for secure server communication, HTTPS Apple Pay pages, a valid SSL certificate, Customer Area addition with merchant account/name and shop website URLs; `http://localhost` cannot be used to test. Raw lines 19–27 and 34–55. It states channel choices and web setup conditions, but does not provide own-certificate provisioning/renewal steps or any live payment or PCI result.
