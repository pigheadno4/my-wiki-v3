# Lodging enhanced scheme data retrieval checks

Q1. Who can send lodging ESD and on which request route? This captured guide covers US domestic Visa/Mastercard lodging ESD for merchant MCCs 3501–3999 or 7011 and commercial or consumer cards (pinned raw lines 17–50), subject to parent ESD Advanced-flow/webhook requirements. For automatic/delayed automatic capture it directs Checkout `/payments`; for manual single/multiple partial capture, **existing Classic API** `/capture` (lines 32–41, 52–57). Checkout API capture lodging ESD is expressly unsupported in this snapshot (line 36).
