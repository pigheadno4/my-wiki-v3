# Android Cards Drop-in v4.x.x retrieval checks

Q1. What does this earlier-version guide cover, and what integration is required? It covers cards in existing Android Drop-in v4.x.x (pinned raw lines 15–21). The Requirements row explicitly says **Advanced flow** and Customer Area card addition (lines 23–28). Server `/paymentMethods` country/currency selects shown cards, and client component data goes to merchant server `/payments` (lines 30–35, 83–89). Sessions-flow links elsewhere on the page are a source inconsistency, not a replacement requirement.
