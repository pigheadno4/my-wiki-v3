# C31 VX820 manual retrieval checks

## Q1 — Main purpose and prerequisites

**Question:** What does the historical VX820 manual hub say to connect and check before boarding, and how does it differ from VX820 Duet?

**Answer:** It describes the **VX820** terminal with a power supply connected to the dongle already attached to the PED, an Ethernet cable to the ETH port on the power cable, a linked device security inspection, and a linked boarding guide (pinned raw lines 23–30). Its provided-component list is VX820 terminal, power supply, privacy shield and Ethernet dongle (lines 34–39); the separately ingested VX820 Duet manual covers a printer base. ## Q2 — Material boundary or failure

**Question:** What cable hazard and historical support limit does this VX820 page carry?

**Answer:** It warns that a cable in the wrong port, such as Ethernet in RS232, might severely damage the device (pinned raw line 32). It also says new terminals of this type cannot be ordered (line 19), despite generic \"new terminal\" quickstart wording (line 25). The separate eVo deprecation table lists **VX820 and VX820 Duet** with **29 March 2024** as \"No more transactions\" (deprecation raw lines 32–35). The quickstart gives no proof of current availability, boarding or payment.
