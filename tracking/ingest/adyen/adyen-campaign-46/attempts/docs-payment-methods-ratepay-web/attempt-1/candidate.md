## Overview

This 2026-09-15-captured Ratepay for Web page is a short chooser for Adyen UI integrations on a website. It links the method-specific Web Drop-in and Web Components guides and the general Web UI guides. It does not itself define Ratepay account eligibility, supported countries, request fields, payment results, invoice/capture handling or live readiness. [[adyen]] [[adyen-online-payments]]

## Key takeaways

- **Drop-in** links to `/payment-methods/ratepay/web-drop-in` and is described as an all-in-one UI solution for adding Ratepay to a website.
- **Components** links to `/payment-methods/ratepay/web-component` and is described as a prebuilt Component to render Ratepay on a website.
- The page points to general Web Drop-in and Components documentation for more information. Use the selected method-specific guide for Open Invoice versus Direct Debit scope, version, country/currency, fingerprint, result and modification requirements. The chooser alone cannot establish a working implementation or completed payment.
