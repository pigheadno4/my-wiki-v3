## Q1 — purpose, scope, and what not to infer

The Classic CSE guide describes a website form whose card fields are encrypted in the shopper's browser with Adyen's CSE library, then passed to a merchant server for a legacy Payment API `/authorise` request (`raw/adyen/docs/online-payments/classic-integrations/classic-api-integration/client-side-encryption/2026-09-15.md:26–32, 54–94, 126–138`). Adyen says CSE **Web** integrations are being phased out and no longer accepted for new CSE integrations, and that mobile integrations are unaffected (`:16–24`). This does not establish mobile SDK behavior, eligibility for a new Web CSE build, PCI compliance, protection from merchant-page compromise, or a successful authorization/capture. The sample `Authorised` response is conditional example data (`:192–205`).

## Q2 — central capability, prerequisites, and warnings

For an existing CSE Web route, the merchant needs a test account, API credentials, and a unique Customer Area library URL (`:34–44`). The library can be Adyen-hosted or merchant-hosted (`:30–32`). Card inputs use `data-encrypted-name` without ordinary `name` so plaintext card fields are not posted to the server (`:54–92`). The page states that SRI must be applied for PCI DSS v4.0.1 by 2025-03-31, using the Customer Area integrity hash (`:58–70`). A server-generated `generationtime` avoids a bad client clock; Adyen says transactions sent more than 24 hours after it are refused (`:90–99`). The server sends the encrypted payload in `additionalData.card.encrypted.json` to Classic `/authorise`, with merchant account, reference and minor-unit amount; validation and risk analysis precede a conditional authorization attempt (`:126–205`). The raw calls the default encrypted data container `adyen-encrypted-data` at `:110` but later says `adyen.encrypted.data` at `:138`; it leaves that mapping unresolved. Its SAQ A go-live link at `:221–225` is subject to separate PCI-guide eligibility and merchant control scope, including risks of a merchant-served form and optional self-hosted library (PCI raw `raw/adyen/docs/development-resources/pci-dss-compliance-guide/2026-09-15.md:179–205`).
