## Where does Adyen's standalone build page send a merchant preparing a test solution?

The 2026-09-15 hub links an **integration checklist** for a test integration, a **standalone setup** guide, and a separate **go-live checklist**. It is a route map: use the linked checklist and setup sources for their actual steps and requirements. The hub itself does not establish terminal eligibility or prove a test payment worked. Source: [[source-adyen-docs-point-of-sale-standalone-standalone-build]], pinned raw opening list and **Next steps**.

## Does setting up standalone terminals for a test integration also complete live setup?

No. The hub explicitly says the standalone terminal setup instructions need to be followed for **both** the test integration and the live integration, and it provides a separate go-live checklist. It does not say which account or device conditions are satisfied for a particular merchant or prove readiness to accept live payments.
