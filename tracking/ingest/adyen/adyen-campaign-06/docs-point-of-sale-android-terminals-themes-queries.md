# C06 fixed-query answers: docs-point-of-sale-android-terminals-themes

## 1. Purpose, scope, and what not to infer

**Answer:** The pinned 2026-09-15 Adyen guide describes creating, applying, modifying and deleting visual themes for the new payment-flow UI on Android payment terminals in Terminal API or standalone integrations. Theme creation requires the Merchant POS Terminal Management Admin Customer Area role and terminal software 1.120 or later. It is a dated configuration guide, not evidence of present merchant or model eligibility, a downloaded configuration, a rendered screen, payment success, or permission to change PIN/cardholder security screens. Start at [[adyen-android-terminals]], then [[source-adyen-docs-point-of-sale-android-terminals-themes]] and its [[raw/adyen/docs/point-of-sale/android-terminals/themes/2026-09-15|pinned raw]]. The provider catalog entry is pending coordinator promotion.

## 2. Central capability, prerequisites, limits, and retrieval route

**Answer:** A user with the stated role creates a light/dark theme at company or merchant level, previews model-specific screens, uploads eligible media, then separately applies it at company, merchant, store or terminal level. The guide specifies JPG/PNG/GIF images for all terminals, MP4/MOV video only on SFO1 and M450, a 100 MB file limit, and a video resolution limit of 1280 × 800, or 574 × 634 for shopper-engagement screens. Idle content is limited to countertop, non-battery devices; shopper-engagement content requires a larger screen. After-payment content adds transaction time and is bypassed when another payment request arrives. Without a custom theme applied, Adyen dark mode is used. A saved application takes effect when the terminal downloads configuration at a maintenance call; WebSockets can make it almost immediate, and manual update is offered. The page does not specify precedence when several configuration levels have themes or the device result of deleting an in-use theme. Use [[adyen-android-terminals]] as the main route and the source's Requirements, Create a theme, Apply a theme and Manage themes raw locators for details.
