## Overview

Adyen's 2026-09-15 webpage snapshot is an in-person payments navigation guide for ordering, inspecting, assigning, boarding, and operating payment terminals. Start at [[adyen-terminal-management]] for fleet administration; [[adyen-terminal-api]] explains the separate POS-to-terminal payment-message boundary. This overview does not establish current device availability, account eligibility, completed boarding, payment readiness, or inspection outcome.

## Key takeaways

- The guide says a terminal must be assigned to a store before boarding; boarding is the step it describes as making the terminal ready to accept payments in that store. The linked assignment and boarding guides contain the procedures.
- It calls for security inspection on receipt and every week in use, and awareness of suspicious activity near terminals. This page does not itself prove a terminal is untampered.
- It routes to ordering, replacement and returns; customization of language, logo and receipts; battery management for battery-powered terminals; automatic maintenance calls and reboots; terminal menus; and a POS Terminal fleet Scheduled report. These are linked topics, not detailed model/firmware instructions in this overview.
- It also points to API requests for ordering, assigning, and configuring terminals. This is terminal-fleet administration; the overview does not specify Management API endpoints, permissions, action effects, or role requirements.
