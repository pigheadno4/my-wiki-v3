# C06 fixed-query answers: docs-point-of-sale-android-terminals-scan-barcode

## 1. Purpose, scope, and what not to infer

**Answer:** The pinned 2026-09-15 Adyen overview names integrated barcode scanners on S1E Barcode, S1E2L, S1F2L and S1U2 Android payment terminals and routes three ways to use them: a device button feeding an installed Android input-field app, a single Terminal API request returning content in its response, or a Terminal API multi-scan session delivering event notifications. The overview is navigation plus a symbology matrix; it gives no software-version floor or full app, button, session or event configuration procedure. It is not proof of current model availability, enabled scanning, a successful scan, account eligibility, or payment execution. Start at [[adyen-android-terminals]], then [[source-adyen-docs-point-of-sale-android-terminals-scan-barcode]] and its [[raw/adyen/docs/point-of-sale/android-terminals/scan-barcode/2026-09-15|pinned raw]]. The provider catalog entry is pending coordinator promotion.

## 2. Central capability, model/types, session/event and retrieval route

**Answer:** Choose the route by where the barcode data must arrive: the on-device button pastes into an installed Android app's input field; a one-scan Terminal API request returns data in its response; and the multi-scan Terminal API path scans while the button is held and delivers data in event notifications. The linked button, single-session and batch-session guides own activation, request/session lifecycle and event setup. Model decoder support varies: this snapshot's table marks CODE 128, MaxiCode and PDF417 unavailable on S1U2, while the other three named models have checks for them. If data is scanned but the symbology is unrecognized, the response can still contain `Barcode.Data` with `Barcode.Symbology=UNKNOWN`. Start at [[adyen-android-terminals]], inspect the overview's Barcode scanning, Barcode symbologies and Next steps raw sections, then open the mode-specific guide. A scan or event is barcode input, not payment authorization or settlement proof.
