# Fixed retrieval answers: docs-point-of-sale-android-terminals-app-requirements

1. **Can an Android app with an extra permission be uploaded for Adyen payment terminals?** In the pinned 2026-09-15 app-requirements guide, only its listed permissions are allowed; an unlisted permission makes the app invalid on upload. The same guide prohibits a custom accessibility service, a CATEGORY_HOME launcher, manifest testOnly and BIND_DEVICE_ADMIN. Those are Adyen payment-terminal app rules, not merchant-phone Android SDK behavior. Route: [[adyen-android-terminals]]. Evidence: [[source-adyen-docs-point-of-sale-android-terminals-app-requirements]]; [[raw/adyen/docs/point-of-sale/android-terminals/app-requirements/2026-09-15|raw §§ Allowed permissions, Restrictions]].

2. **How should a developer check device compatibility and debug an Adyen Android-terminal app?** Use the dated model/region/Android/API-level/CPU table as a starting locator, check live Customer Area for regional device availability, set a manifest minSdkVersion the target terminal supports, and include ABI-matching native libraries. For WebView, inspect Settings > Device info and the terminal-software/Android version matrix. Adyen says USB ADB debugging cannot be enabled on the payment terminal; debug on a regular Android device, then upload and integration-test on a test terminal, followed by live-terminal final testing. The page caps APKs at 700 MB in test and 200 MB in live. These instructions do not prove present compatibility or passed tests. Route: [[adyen-android-terminals]].
