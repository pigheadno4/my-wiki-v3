# Fixed answers: S1F2 user manual

## Query 1 — How do I set up an S1F2 or S1F2L and decide whether the delivered terminal is safe to start?

**Answer:** This dated device manual identifies S1F2 as the standard model and S1F2L as the variant with a barcode-scanning camera. Inspect the unopened box and security tape; if Customer Area access is available, compare the box serial number with the order and delivery tracking, then compare the terminal serial number with the box. Look for missing screws, extra wires or labels, holes, or attached items. If a check fails, contact Adyen Support immediately. Insert a receipt-paper roll, connect the supplied USB-C cable and regional plug, switch the terminal on, charge it for at least four hours, select a language, connect to a network, and confirm or change the shown store. If the store screen does not appear, the manual says to wait until the next Adyen-platform synchronization (on average three hours) and retry.

**Prerequisites and warnings:** Wi-Fi or cellular connectivity is needed for platform communication and boarding. The S1F2 guide describes an eSIM and cellular failover, but older devices boarded before 2022 may lack an activated SIM if no subscription was set up. Do not use metal tools when replacing a physical SIM. Store and return batteries using the manual's charge, inspection, and disposal guidance; do not put a faulty battery in the return package. A completed checklist or this snapshot does not prove that a particular device passed inspection, boarded successfully, supports a current OS version, or is currently eligible to transact.

## Query 2 — Does the S1F2 manual make Apps, Network, refunds, or US PIN behavior available without admin access?

**Answer:** The manual describes local menu controls, with different passcodes. Admin & Settings protects Apps, Configuration, Network, software-version changes, and Power. The Apps menu shows installed apps and certificates; opening it carries out an already scheduled install or removal. Transactions protects history, totals, and new transactions, and a new refund also needs the Refunds passcode. The Payment button starts a normal payment without a menu passcode when the terminal is used standalone. The manual does not state a US-specific PIN rule or establish that a transaction or refund will succeed.

**Prerequisites and warnings:** Obtain the applicable passcodes through Customer Area or the company's admin user. Changing Wi-Fi later requires the Network menu passcode. Airline airplane mode requires Adyen Support to enable it, then Settings > Network access; while on it disconnects Wi-Fi, Bluetooth, and cellular. Kiosk mode is described as a separate unattended-use feature, with details in its linked guide. The S1F2 manual is a 2026-09-15 snapshot and does not establish the Android OS version, current app approval, or live account/device permissions.
