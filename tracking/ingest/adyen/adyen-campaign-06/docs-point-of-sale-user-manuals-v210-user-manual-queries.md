# Fixed answers: V210 user manual

## Query 1 — What does the V210 manual require before boarding and testing a delivered terminal?

**Answer:** Inspect the delivery first: check the tamper-evident box seal, compare the box serial number with the Customer Area order when accessible, compare the device serial number with the box, and look for signs of tampering. Contact Adyen Support immediately if any check fails. Install the 57 x 40 mm receipt roll, connect power, allow at least four hours of charging, configure a network, then select **Board the terminal**, choose the store, and confirm. Boarding can take up to 30 minutes. If the boarding prompt is missing, the guide says to wait for the next Adyen-platform synchronization, on average three hours, and try again. Check the PSP connection afterward; for a POS-system integration also run Terminal API and Endpoints diagnostics. A standalone setup skips the POS-system connection test.

**Prerequisites and warnings:** The manual describes Wi-Fi and cellular failover, with a conditional eSIM caveat for some terminals boarded before 2022 when no SIM subscription was configured. Do not use metal tools in the SIM slot. Its PSP diagnostic specifically accepts a red cross on **Receiving data** when the result is **No Error**. The setup sequence and diagnostic statuses do not prove that a particular terminal is safe, currently boarded, eligible for service, or able to complete a payment.

## Query 2 — Does the V210 menu's “Bypass PIN” entry authorize PIN bypass, and which passcodes apply?

**Answer:** The manual lists **Bypass PIN** in the special-payments menu for standalone use, but it gives no conditions authorizing a PIN bypass or guarantee of a successful payment. Its menu table applies from terminal software version 1.90; earlier non-Android software may show the old menu. In the listed structure, Device info and Diagnostics need no menu passcode; Configuration, Network, Software, and Power require Admin & Settings. The standalone Transactions menu requires its passcode for normal and special payments, with a separate Refunds passcode also needed for Refund and MOTO refund. The standalone **Payment** button can start a normal payment without a menu passcode.

**Prerequisites and warnings:** Confirm the terminal's actual software version through Device info and consult the linked menu-access and transaction guides for current permissions and transaction behavior. A menu label is neither a cardholder PIN rule nor live merchant feature eligibility. Battery handling is separate: avoid prolonged storage above 70% or below 40% charge, inspect every six months for leakage/swelling, and keep faulty batteries out of terminal return packages.
