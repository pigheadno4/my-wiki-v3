# C06 fixed-query answers: docs-point-of-sale-managing-terminals-maintain-performance

## 1. Purpose, scope, and what not to infer

**Answer:** This pinned 2026-09-15 Adyen page explains how Terminal API and standalone payment terminals learn about configuration/software changes through maintenance calls, then normally apply them at a daily restart hour. It also covers the Customer Area restart-hour setting, immediate-update exceptions, an optional Management API application-restart setting, and power/network preparation. A maintenance call, scheduled reboot, PATCH request or example response does not establish that a specific terminal installed a release, received configuration, passed a live health check, or processed a payment. ## 2. Central behavior, prerequisites, exceptions, and retrieval route

**Answer:** A maintenance call normally discovers changes; the terminal generally applies configuration and eligible automatic software updates when it reboots at its restart hour. The page gives a default three-hour call interval and default 6:00 AM local restart hour, and says the terminal postpones a call when busy. It estimates an ordinary reboot at about two minutes and software installation at up to 30 minutes. Adyen-directed urgent changes, Android app install/uninstall, and manual configuration updates are exceptions to waiting for the scheduled restart. Changing restart hour in Customer Area requires an admin user; a manual **Config > Update** retrieves configuration and restarts the terminal. For daily update receipt, keep the terminal on and network-connected for at least one three-hour interval before restart; it must also be on at restart hour and online to download software then. `terminalInstructions.adyenAppRestart` is an optional Management API setting for applying configuration with an Adyen-app restart, while the code samples are versioned test examples. Use [[adyen-terminal-management]] for the fleet route and this source's maintenance, restart, configuration and software raw locators for exact details. The page gives no device-specific installed-version proof or physical battery/tamper procedure.
