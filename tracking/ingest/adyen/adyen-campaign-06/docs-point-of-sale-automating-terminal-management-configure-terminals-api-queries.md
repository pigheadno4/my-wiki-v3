1. **How can I change a store's terminal setting without wiping sibling fields?** Read the store's current `/terminalSettings` configuration and the inherited merchant value, then PATCH `/stores/{storeId}/terminalSettings` with the full object for each group you change. An omitted top-level object is untouched, but an omitted parameter inside a supplied object is removed at that level; a lower-level removal may expose the higher-level value. The snapshot gives no general rule that `null` removes a field. Start at [[adyen-terminal-management]] and see the pinned raw's `Inheritance of settings`, `Get current settings`, `Update settings`, and `Update other settings` headings.

2. **When does a Management API terminal configuration update affect the device, and what permissions are needed?** The 2026-09-15 guide calls for a POS integration, API key, Terminal settings read/read-and-write roles, and Terminal Advanced settings read-and-write for sensitive `nexo`, passcode, or Wi-Fi settings. Existing terminals automatically download updates on a maintenance call every 180 minutes and apply them on restart, normally at the restart hour (usually 6:00 AM); a manual configuration update can switch a passcode immediately, while a newly shipped terminal takes settings when boarded. Live terminal-settings endpoints have rate limits. Start at [[adyen-terminal-management]] and see the pinned raw's `Requirements`, `Sensitive terminal settings`, and `When new settings take effect` headings. This snapshot does not prove current account entitlement, successful API execution, or immediate device application.
