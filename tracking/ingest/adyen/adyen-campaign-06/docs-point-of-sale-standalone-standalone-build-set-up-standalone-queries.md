# Fixed retrieval answers — standalone setup

## How does a merchant enable standalone terminal use, and when do settings take effect?

The 2026-09-15 Adyen setup snapshot gives two routes for a standalone-capable test terminal. In Customer Area, a user with Merchant POS Terminal Management and View roles opens **Devices > Device settings > Integrations > Standalone**, enables standalone, chooses a currency and Start-button behavior, then saves. Via Management API, an API credential with Terminal settings and Terminal Advanced settings read/write roles PATCHes `/terminalSettings` at company, merchant, store, or terminal scope with `standalone.enableStandalone: true` and a `currencyCode`. After a Customer Area save, the terminal downloads configuration at a maintenance call, described as every 180 minutes, and applies it after restart; a manual configuration update downloads and restarts immediately. Live terminals must be set up separately. This is direct terminal use under [[adyen-standalone-terminals]], rather than a POS app issuing a Terminal API payment request. Source: [[source-adyen-docs-point-of-sale-standalone-standalone-build-set-up-standalone]], raw **Requirements** and **Set up standalone**.

## What safeguards and regional conditions apply to standalone tipping and refunds?

The snapshot allows shopper-entered tips or predefined terminal options. The Management API example uses `standalone.enableGratuities` with `gratuities`; the page describes at most four predefined choices, or three plus a custom entry. For Quebec, Adyen recommends manual tip entry or fixed CAD options with a custom entry to facilitate compliance with pre-tax-tip rules, and says not to use percentage options in the fixed-amount path. Standalone refunds can be guarded by an optional six-digit Refunds passcode **in addition to** the Transactions passcode, so both are needed to initiate a refund. These settings can be managed in Customer Area or Management API. The Customer Area setup section also offers optional Support contact to enable tipping and referenced refunds; it does not make Support universally required for all tipping configurations or refund-passcode changes. This is configuration evidence, not proof of a test or live refund. Source: [[source-adyen-docs-point-of-sale-standalone-standalone-build-set-up-standalone]], raw **Configure tipping**, **Configure compliant tipping in Quebec, Canada**, and **Configure refund passcode**.
