## Overview

Adyen's 2026-09-15 iDEAL | Wero for Android page is a chooser for adding the method to an Android app. It routes to an all-in-one Drop-in child guide and to a Components child guide whose link describes `IdealComponent` redirect handling. It also points to the main Android integration guides for Sessions and Advanced flows. See [[adyen]] and [[adyen-android-sdk]].

## Key takeaways

- The page directs merchants to create their main integration before adding iDEAL | Wero. Its four main-guide links cover Android Drop-in and Components with either Sessions or Advanced flow (raw lines 29-36).
- This chooser gives no request parameters, SDK or Checkout API minimums, merchant or shopper eligibility, redirect-return procedure, testing instructions, or payment-result rules. The Components link names `IdealComponent` and redirect handling as a route description; implementation requirements belong to the child guide (raw lines 19-27).
