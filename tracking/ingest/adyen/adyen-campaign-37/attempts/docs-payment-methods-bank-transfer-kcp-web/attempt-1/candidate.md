## Overview

This 2026-09-15 Adyen page is a Web integration chooser for Bank Transfer via KCP. It points to separate Drop-in and Components child guides and to the main Web Sessions and Advanced integration guides. It is navigation, not a method-specific request, version, testing, eligibility, or payment-outcome specification. See [[adyen]] and [[adyen-online-payments]].

## Key takeaways

- The Drop-in choice is described as Adyen's all-in-one UI solution for adding Bank Transfer via KCP to a website; the Components choice says to use Redirect. Those labels route readers to the corresponding child guides, where implementation details belong.
- The page explicitly tells readers to create the main integration before adding Bank Transfer via KCP and links Web Drop-in and Components variants of both Sessions and Advanced flows. It does not itself say which Checkout API or Web SDK version is required or describe redirect handling.
