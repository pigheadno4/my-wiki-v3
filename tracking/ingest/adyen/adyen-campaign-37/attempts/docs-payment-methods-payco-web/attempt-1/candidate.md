## Overview

This 2026-09-15 Adyen page is a **PAYCO Web navigation chooser**. It links method-specific Web Drop-in and Components child guides plus four Web Sessions/Advanced base integration routes. It does not itself establish merchant eligibility, API/SDK versions, redirect/result handling or payment completion. [[adyen]] [[adyen-online-payments]]

## Key takeaways

- **UI routes:** The Drop-in child is described as an all-in-one UI solution for PAYCO on a website. The Components child is described as using `Redirect`. Those are navigation descriptions; method-specific import/configuration and payment lifecycle belong to the child guides. (raw lines 19–27)
- **Main integration first:** The page instructs readers to create the main integration before adding PAYCO and lists Web Drop-in and Web Components routes for both Sessions and Advanced flows. The route list does not by itself assert version minima, local-provider setup, merchant approval or a final transaction result. (raw lines 29–36)
