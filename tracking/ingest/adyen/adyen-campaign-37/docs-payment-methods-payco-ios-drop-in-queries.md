# Q2 — Central capability, prerequisites, warnings

Sessions requires existing iOS Drop-in Sessions, Checkout API v68+, and Customer Area PayCo addition (raw/adyen/docs/payment-methods/payco/ios-drop-in/2026-09-15.md:25–34); no extra base `/sessions` parameters or PayCo configuration are stated (raw/adyen/docs/payment-methods/payco/ios-drop-in/2026-09-15.md:36–46). Advanced requires existing iOS Drop-in Advanced, redirect handling for `action.type: redirect`, and Customer Area addition (raw/adyen/docs/payment-methods/payco/ios-drop-in/2026-09-15.md:56–66); no extra PayCo configuration or base `/payments` parameters are stated (raw/adyen/docs/payment-methods/payco/ios-drop-in/2026-09-15.md:68–78). The Sessions requirements do not themselves explicitly mention redirect handling, so that Advanced row should not be silently copied over (raw/adyen/docs/payment-methods/payco/ios-drop-in/2026-09-15.md:29–34, 65). Both testing sections say no specific PayCo test credentials and refer assistance to Adyen Support (raw/adyen/docs/payment-methods/payco/ios-drop-in/2026-09-15.md:48–54, 80–86), without result proof.
