## Q2 — What are the flow, Component and credential conditions?

Sessions requires Checkout API **v68+**, Customer Area method addition and redirect handling with `action.type: redirect`; no extra method `/sessions` parameters or configuration are specified (raw lines 25–42, 67–71). Advanced requires Customer Area addition and an additional redirect action, with no extra `/payments` parameters or method configuration; no Advanced API minimum is stated (lines 132–140, 165–175, 228–232). Both flows use `InstantPaymentComponent` and `kcp_banktransfer`; Compose imports `components-compose` in addition to `instant`, with a unique key per differing screen/session and on reset (lines 44–126, 142–226). The page says no KCP bank-transfer testing credentials are available because authorization needs a Public Identification Certificate/Digital Signature for individuals (lines 128–130, 234–236); it does not establish absence of TEST or authorize live testing ([[source-adyen-docs-payment-methods-bank-transfer-kcp-android-component]]).
