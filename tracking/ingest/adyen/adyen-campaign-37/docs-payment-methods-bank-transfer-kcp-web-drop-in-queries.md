Q1. What does the KCP bank-transfer Web Drop-in guide cover, and what cannot be inferred?
A1. It is a method-specific Web Drop-in add-on for Sessions and Advanced redirect flows (raw lines 17–54, 62–90). It does not provide a country/currency or entity rule, a full return/webhook flow, a certificate actually used, or proof of bank-transfer authorization/capture/settlement (raw lines 15–96). Q2. What are the flow prerequisites and key warnings?
A2. Sessions requires existing Web Drop-in Sessions, Checkout API v68+, redirect handling and the method in Customer Area; Advanced requires existing Web Drop-in Advanced, redirect handling and setup, with no extra method request fields stated for either (raw lines 29–42, 66–90). `Redirect` import is optional tree shaking (raw lines 44–54, 74–84). The Advanced base URL has unresolved encoded platform text (raw line 70). The page says there are no KCP bank-transfer test credentials because authorization uses a Public Identification Certificate, not that TEST itself is unavailable (raw lines 56–60, 92–96).
