# Q2 — Central capability, prerequisites, warnings

Sessions requires existing Web Components Sessions, Checkout API v68+, redirect handling for `action.type: redirect`, and PayCo addition in Customer Area (raw/adyen/docs/payment-methods/payco/web-component/2026-09-15.md:25–36); it states no extra PayCo `/sessions` parameters or configuration (raw/adyen/docs/payment-methods/payco/web-component/2026-09-15.md:40–60). Both paths import and use `Redirect` (raw/adyen/docs/payment-methods/payco/web-component/2026-09-15.md:46–72, 92–112), but their samples write `type:kcp_payco` without quotes or a shown definition (raw/adyen/docs/payment-methods/payco/web-component/2026-09-15.md:71,111), so runnable syntax is unverified. Advanced requires existing Web Components Advanced, redirect handling, and Customer Area addition, and states no extra base `/payments` parameters (raw/adyen/docs/payment-methods/payco/web-component/2026-09-15.md:80–88, 114–118); no Advanced Checkout API minimum is stated. The page says there are no specific PayCo test credentials and points to Adyen Support for testing assistance (raw/adyen/docs/payment-methods/payco/web-component/2026-09-15.md:74–78, 120–124), not a successful test outcome.
