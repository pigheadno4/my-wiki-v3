## Overview

This 2026-09-15-captured Adyen **Web integration chooser** routes readers to OXXO Drop-in and Components child guides and the corresponding main Web Sessions and Advanced flow guides. It is navigation, not a complete payment recipe or evidence that a voucher was paid. See [[adyen]], [[adyen-online-payments]], and the method overview [[source-adyen-docs-payment-methods-oxxo]] for the Mexican cash-voucher journey, delayed confirmation, expiry and capability context.

## Key takeaways

- **Drop-in** is linked as Adyen's all-in-one Web UI path for OXXO (raw lines 19–23). The chooser does not state the child guide's request fields, action handling or status sequence.
- **Components** links to the OXXO Web Component page. Its label says “Use the Oxxo to make OXXO payments on your website”; this is a route description, not proof that a particular transaction completed (raw lines 25–27).
- The **See also** section says to build the main integration first and lists Web Drop-in and Components guides for both **Sessions** and **Advanced** flows (raw lines 29–36). Those links do not establish current merchant enablement or a selected child integration's behavior.
