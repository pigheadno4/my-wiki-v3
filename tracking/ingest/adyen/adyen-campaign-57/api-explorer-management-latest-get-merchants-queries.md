The captured test server is `/v3` (lines 13–14). Optional `pageSize` defaults to 10 with maximum 100 and optional `pageNumber` selects a page (lines 18–22). Merchant fields include distinct company/merchant IDs, legal-entity name/city, settings, status, data centers and related resource links (lines 43–63). Status descriptions require both merchant and company `Active` for processing/payout enablement; `Closed` is irreversible (line 63).
