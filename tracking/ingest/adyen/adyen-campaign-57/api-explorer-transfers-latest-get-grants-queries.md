The captured server is the Transfers API test base `/btl/v4` (lines 9–10). The only listed query parameter is optional `counterpartyAccountHolderId` (lines 14–17). Optional amount, fee and repayment parents have conditionally required nested fields (lines 28–30, 40–48). The listed statuses are Pending, Active, Repaid, WrittenOff, Failed and Revoked (line 49).
