# Fixed query answers — account-verification routes

## Q1

The 2026-09-15 Open Banking Gateway v1 `POST /accountVerification/routes` operation creates a list of provider routes for verifying an external third-party individual's bank account; test and live `obgateway/v1` servers are listed. Required `country` names the location where that account is registered and helps Adyen select an available provider and configure the flow. Required `redirectUrl` is where Adyen redirects the individual after completing the flow. Optional `locale` defaults to `en-US`; optional `state` identifies a callback request and must contain URL-encodable characters, with per-session CSRF protection described as guidance. A 200 response requires `routes`; each route requires a `link` and `provider` with required `name` and `logoURL`. The example shows Tink, not guaranteed provider selection. No route lifetime, provider-count limit, deletion or verification result is specified. See raw lines 5–50 and 147–164 in [[source-adyen-api-explorer-open-banking-latest-post-accountverification-routes]] ([canonical URL](https://docs.adyen.com/api-explorer/open-banking/latest/post/accountVerification/routes)).

## Q2

HTTP 200 returns a `routes` array, but the schema states no minimum length; a returned link, if any, can start the selected provider's redirect flow. The page says only a later successful connection generates a unique code for requesting bank reports and verifying identity; the route list alone proves neither connection, consent nor completed bank verification. Documented errors are 400 malformed request, 401 invalid or insufficient API credential, 422 validation, 429 rate limit and 500 server error, with no threshold or retry schedule. The page specifies no webhook acknowledgment, delivery/order/deduplication, signature or report/identity decision. See raw lines 5–7, 38–50 and 53–164 in [[source-adyen-api-explorer-open-banking-latest-post-accountverification-routes]] ([canonical URL](https://docs.adyen.com/api-explorer/open-banking/latest/post/accountVerification/routes)).
