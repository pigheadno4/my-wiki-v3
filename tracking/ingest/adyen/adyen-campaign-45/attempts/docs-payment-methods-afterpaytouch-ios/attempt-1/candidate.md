## Overview

This 2026-09-15 [[adyen|Adyen]] page is an iOS integration chooser for Afterpay. It routes to iOS Drop-in and Components method guides and to main Sessions/Advanced integration guides. See [[adyen-online-payments]]. This chooser does not define request fields, SDK/API versions, country eligibility, redirect return, capture or completed-payment behavior.

## Key takeaways

- The iOS Drop-in route is described as an all-in-one UI solution. The Components route names `InstantPaymentComponent` for making Afterpay payments in an iOS app. Follow those method-specific pages for actual integration detail.
- The See also section says to create the main integration before adding Afterpay. It links iOS Drop-in and Components base guides for both Sessions and Advanced flows. These links provide navigation, not evidence of configured account or successful payment.
