## Overview

This [[adyen]] Alipay+ Web page is an **integration chooser**, linking a Web Drop-in child guide, a Web Components redirect child guide, and the main Web Sessions/Advanced integration guides. It supplies navigation, not method-specific setup steps, country/currency or wallet eligibility, API/SDK version requirements, or a final payment-result procedure. See [[adyen-online-payments]] and the pinned raw.

## Key takeaways

- **Alipay+ Web choices:** The page describes Drop-in as the all-in-one UI route and Components as the redirect route for a website. It links to their respective Alipay+ child guides. Those labels do not establish that every underlying Alipay+ wallet is enabled or follows identical behavior. See raw lines 19–27.
- **Base integration routes:** The See also section tells readers to create the main integration first, then links Web Drop-in and Web Components for both Sessions and Advanced flows. This page does not say which path a particular merchant uses or supply the child guides' fields, testing rules or outcomes. See raw lines 29–36.
