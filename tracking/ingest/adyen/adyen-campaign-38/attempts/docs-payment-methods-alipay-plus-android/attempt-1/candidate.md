## Overview

This 2026-09-15 Adyen Android page is a **navigation chooser** for adding Alipay+ to an Android app. It points to the Alipay+ Drop-in and Components child guides and to the general Android Sessions/Advanced integration guides. It gives no on-page API request, SDK/version prerequisite, wallet-specific eligibility or payment-outcome procedure. See [[adyen]] and [[adyen-online-payments]].

## Key takeaways

- Choose [[source-adyen-docs-payment-methods-alipay-plus-android-drop-in]] for the all-in-one Android Drop-in route, or [[source-adyen-docs-payment-methods-alipay-plus-android-component]] for the `InstantPaymentComponent` redirect route. These are routes to child guidance, not evidence that every Alipay+ wallet is enabled or that redirect completion authorizes a payment.
- The page also links the main Android Drop-in and Components guides for both Sessions and Advanced flows, and says to create the main integration before adding Alipay+. The presence of those links does not establish which server-side flows, API/SDK versions, setup steps or outcomes are supported by each child route; use the child and main guides for those claims.
- This snapshot does not establish current wallet or merchant availability, account approval, successful authorization, capture or settlement. The broader Alipay+ network overview and each method-specific child have their own qualifications.
