## Overview

This 2026-09-15 Adyen page is a **PayNow Web navigation chooser**. It links the PayNow Web Drop-in and Components child guides and the four Web Sessions/Advanced main integration routes. It provides no method-specific configuration, QR lifecycle, merchant eligibility or payment-result procedure itself. [[adyen]] [[adyen-online-payments]]

## Key takeaways

- **Child routes:** Drop-in is described as an all-in-one UI option for a website. The Components route is linked separately, but its description says “Use the PayNow to make PayNow payments” without naming a particular Component or defining its behavior. Read the child guide for actual setup and QR handling. (raw lines 19–27)
- **Base routes:** The page instructs readers to create the main integration before adding PayNow and lists Web Drop-in and Web Components guides for both Sessions and Advanced flows. These are navigation links only; the page does not state Checkout API/Web SDK minimum versions, `qrCode` action handling, QR expiry, test/live money risk or webhook outcomes. (raw lines 29–36)
