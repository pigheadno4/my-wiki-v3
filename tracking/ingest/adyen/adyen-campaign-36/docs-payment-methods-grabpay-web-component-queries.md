Q2. What are the central capability, prerequisites and warnings? For GrabPay PayLater postpaid or installment, send delivery address and line items through `/sessions` or `/payments`; for Wallet these are recommended preparation, not required by this guide (`raw/adyen/docs/payment-methods/grabpay/web-component/2026-09-15.md:39-57`, `raw/adyen/docs/payment-methods/grabpay/web-component/2026-09-15.md:510-517`). `/sessions` is labeled default for Web v5+, with `/payments` for additional use cases or earlier integrations (`raw/adyen/docs/payment-methods/grabpay/web-component/2026-09-15.md:50-52`, `raw/adyen/docs/payment-methods/grabpay/web-component/2026-09-15.md:510-512`). Select `grabpay_MY`, `grabpay_PH` or `grabpay_SG` by shopper location/currency (`raw/adyen/docs/payment-methods/grabpay/web-component/2026-09-15.md:811-819`); v6 uses a Redirect constructor and v5 uses `checkout.create` (`raw/adyen/docs/payment-methods/grabpay/web-component/2026-09-15.md:829-849`). Testing needs Support test credentials and a registered phone/OTP; live requires a separate Customer Area request (`raw/adyen/docs/payment-methods/grabpay/web-component/2026-09-15.md:851-860`). Samples are not copy-ready in every language: Sessions Node examples use undeclared `Config`/`EnvironmentEnum` (`raw/adyen/docs/payment-methods/grabpay/web-component/2026-09-15.md:266-276`, `raw/adyen/docs/payment-methods/grabpay/web-component/2026-09-15.md:457-467`). The Advanced Java `/payments` PayLater sample constructs `merchantAccount` and `deliveryAddress` but does not assign either to `paymentsRequest` (`raw/adyen/docs/payment-methods/grabpay/web-component/2026-09-15.md:559-604`); this is incomplete against the required PayLater delivery-address table (`raw/adyen/docs/payment-methods/grabpay/web-component/2026-09-15.md:514-517`) and the guidance to send address and item data (`raw/adyen/docs/payment-methods/grabpay/web-component/2026-09-15.md:39-48`).
