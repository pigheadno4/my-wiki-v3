## Query 1: Which POS refund webhook applies, and what does each reference identify?

Answer: For a Terminal API **referenced** refund, `CANCEL_OR_REFUND` has `originalReference` equal to the original payment PSP reference and `pspReference` identifying the reversal modification (raw lines 39-49). For a Terminal API **unreferenced** refund, `REFUND_WITH_DATA` has `originalReference` equal to that refund request's PSP reference; the original payment PSP reference is unknown, and `pspReference` is generated when the refund is captured (lines 82-98). This page covers POS Terminal API refunds, while its Checkout reversal-response link in the referenced table is a cross-reference, not an instruction to invoke Checkout after a terminal reversal. Route: `wiki/index.md` → `wiki/adyen-index.md` (Campaign 05 catalog pending coordinator promotion) → `wiki/concepts/adyen-terminal-api.md` or `wiki/concepts/adyen-webhooks.md` → `wiki/sources/adyen/source-adyen-docs-point-of-sale-basic-tapi-integration-refund-payment-refund-webhooks.md` → `raw/adyen/docs/point-of-sale/basic-tapi-integration/refund-payment/refund-webhooks/2026-09-15.md`.

## Query 2: Does terminal success or webhook success prove the refund is final, and what setup/failures matter?

Answer: Terminal API response `Success` usually confirms request receipt; Standard webhooks must be set up for the validation outcome (raw lines 19-24, 30-37). In either refund event, `success: true` means Adyen validation succeeded and it sent the request to the card scheme; rare later scheme rejection or reversal can still occur, with `REFUND_FAILED` or `REFUNDED_REVERSED` linked as exceptions (lines 41-49, 84-98). `success: false` provides a reason; the table includes over-balance requests, insufficient in-process funds, before-capture attempts, expiry, too-low amount and currency mismatch (lines 130-148). Scheme and card-use country/region sometimes permit a synchronous unreferenced-refund result via `acquirerResponseCode` (line 26). The guide says posting to the shopper's account occurs within a few days, without proving a particular refund's timing (line 28). Follow the same index → concept → source → raw route above.
