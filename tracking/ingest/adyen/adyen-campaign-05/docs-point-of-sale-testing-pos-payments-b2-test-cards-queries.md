2. **What central test capability and limits should a reader retrieve?** The described Europe set has six cards and North America set seven; each listed set has chip/magstripe and EMV contact/contactless test use, with the detailed brand/region/currency rows at raw lines 43–68. A B2 card can probe test-method handling on an Adyen test terminal, but a specific amount cannot trigger a selected CVM (lines 70–76). Offline tests are excluded for every North America card and for B2 cards generally except the French Mastercard in the Europe set, marked Offline Capable (lines 49–50, 56–58, 76). MKE testing requires expiration 03/30 regardless of the printed date (lines 78–80). Decline mechanics are only linked to another test-card page at line 74; read that target before specifying triggers or PIN behavior. Nothing here establishes live payment results.
