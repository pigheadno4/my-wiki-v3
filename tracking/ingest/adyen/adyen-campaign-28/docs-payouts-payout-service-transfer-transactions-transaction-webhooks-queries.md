Q1. When is a transaction webhook sent, and how does it differ from a Transfer webhook?
Answer: For a balance-account debit or credit from an external bank/card or internal transfer, the guide describes `balancePlatform.transaction.created`; unlike Transfer webhooks for every transfer status change, transaction webhooks are sent when funds are credited/debited (raw lines 19-21, 40-45, 217-223). The prerequisite table names Platforms, Issuing or Payouts integrations and lists Standard/Transaction subscriptions with Transfer optional plus an accepting server (lines 23-31). Q2. Can these TEST payloads prove a matched bank payout or pair the internal examples?
Answer: No. The external example says EUR 100 (raw line 49), its request shows value 150000 EUR (lines 59-62), and the TEST transaction shows -10000 EUR (lines 99-107, 132-134). The internal outgoing and incoming examples use different transaction IDs **and** nested transfer IDs (lines 183-193, 242-253), so their relationship cannot be inferred. An actual booked transaction notification reports balance-account movement, not final bank/card beneficiary receipt (lines 19-21, 83-91, 223-231).
