# Query proposal — docs-payouts-payout-service-reports-and-fees-statement-report

Q1. What does the Payout Service Balance Platform Statement Report provide, and which IDs/date fields distinguish stages?
Answer: It is a daily opening/transaction-change/closing balance report for available currencies, generated in Customer Area on schedule or for a day (raw lines 15-26). The field table separates pending-debit/credit **Transfer Id** from completed-debit/credit **Transaction Id** (lines 51-52), with Booking Date/Time Zone and Value Date/Time Zone (lines 59-62), plus currency/amount/start/end balances (lines 63-68). Q2. Does the report guarantee every balance-changing transaction or prove bank receipt?
Answer: No. Although the introduction describes all transactions changing a daily balance, it explicitly omits any balance account whose opening **and** ending balances are zero (raw line 19). The sample can differ from actual account-generated columns/data (lines 28-32). The table types Amount and starting/ending balances as Alpha text without a sign or minor-unit rule (lines 63-68), and it gives no report cutoff timezone or bank-receipt evidence.
