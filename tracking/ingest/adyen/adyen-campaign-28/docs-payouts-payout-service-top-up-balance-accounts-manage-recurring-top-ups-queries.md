Q1. How does the dated Payout Service guide let an enterprise-payout integration manage recurring balance-account top-ups?
Answer: With the relevant Configuration API credential/BankAPI Advanced Webservice role or the listed Customer Area human roles, it documents GET listing by balance-account ID with cursor pagination, PATCH of schedule/amount/threshold/status/reference fields, and DELETE of a particular schedule.
