# Q1 — How are balance-platform reports generated, and what access is needed?

On the correct merchant account's Customer Area Reports page, choose scheduled automatic or one-off manual generation; manual options can include bulk, period, account/holder filters, and time zone. Deselecting Automatic generation deletes its schedule (pinned raw lines 30–75). Customer Area generation/download roles and a report-service API key with BalancePlatform Report Download role for API download are listed, along with `balancePlatform.report.created` subscription (lines 21–28). # Q2 — When is a report available, and does its URL alone permit download?

The `balancePlatform.report.created` webhook signals availability and carries `downloadUrl`; the example is TEST, and manual generation can take minutes (pinned raw lines 75–96). A report can be downloaded in Customer Area or by HTTP GET with report credentials, API key or basic-auth password, using that URL; the URL alone is not described as an anonymous download grant (lines 98–144). Reports are CSV, with Accounting optionally TSV. Neither report creation nor download verifies reconciliation or beneficiary receipt.
