Q1. For Standard Web Drop-in, which configuration is optional, and when does an imported-method setting become required?

Importing individual methods for bundle size makes `paymentMethodComponents` required and newly added methods must be imported too (raw lines 21–38, 73–75). Q2. What submission, deletion, and sample-code boundaries matter?
A2. `beforeSubmit` should call `actions.resolve()` even for unsuccessful result codes; `actions.reject()` is for failed server-side Adyen API requests or network problems (raw lines 55–60). Enabling the stored-method remove button requires `onDisableStoredPaymentMethod`, which makes the DELETE request and resolves or rejects according to its response (raw lines 80–81, 89–95). The individual-import snippet omits `Ideal` while the later component-array sample includes it (raw lines 33–38, 97–107); align imports before use.
