Q1. What setup and token handoff does the dated Samsung Pay API-only guide require?
A1. It assumes an existing API-only integration and test Customer Area method addition. Preparation calls for an Adyen CSR request, Samsung Developer account, Adyen gateway setup, Samsung SDK integration and Support configuration of Visa/Mastercard/Maestro/Amex/Discover schemes for the merchant account. When the shopper selects Samsung Pay, obtain the SDK payload and send the **complete base64 token**, not just `3DS.data`, from the merchant server as `paymentMethod.samsungPayToken` with `type: samsungpay`.
