## Overview

This 2026-09-15-captured [[adyen]] page is a Web integration chooser for PayBright. It links Web Drop-in and Components child guides. The page says PayBright was acquired by Affirm and **Adyen will not accept new PayBright integrations**. The links are navigation for the described method, not evidence of current merchant eligibility, a completed integration or payment success. See [[adyen-online-payments]].

## Key takeaways

- The Drop-in child is described as the all-in-one UI route for a website; the Components child is described as a pre-built Component. Read the selected child guide for flow, version, request, return and modification details.
- The final links are general Web Drop-in and Components references. They do not supply PayBright-specific prerequisites or override the no-new-integrations notice.
