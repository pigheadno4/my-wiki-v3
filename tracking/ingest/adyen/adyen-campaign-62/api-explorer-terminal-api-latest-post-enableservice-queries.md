# Fixed query answers — api-explorer-terminal-api-latest-post-enableservice

## Q1

The captured [`POST /enableservice`](https://docs.adyen.com/api-explorer/terminal-api/latest/post/enableservice) is a Terminal API **latest** EnableService message for enabling services on a POI terminal before a Sale System service request, with a possible customer invitation; the documented action starts a swipe-ahead transaction or aborts one (including one started by CardAcquisition) before a Sale System service request completes it. The page lists cloud **test** device sync/async URLs parameterized by `merchantAccount` and `deviceId`, plus a local terminal IP address, but no numeric protocol version, message-header schema, POIID, caller authentication or session identity. `TransactionAction` is required; `ServicesEnabled` is mandatory for `StartTransaction` and absent otherwise, allowing CardAcquisition, Loyalty or Payment. Optional `DisplayOutput` has required nested fields and format-specific content; its `ResponseRequiredFlag` and `MinimumDisplayTime` must be absent for EnableService. No numeric size limit, default, deadline, reversal or later completion guarantee appears. Source: [[source-adyen-api-explorer-terminal-api-latest-post-enableservice]]; raw lines 5–46.

## Q2

The same [contract](https://docs.adyen.com/api-explorer/terminal-api/latest/post/enableservice) documents a `200 Success` **Enable Service processing** response with required `Response.Result` (`Success`, `Failure`, `Partial`). For non-success, `ErrorCondition` must be present; the listed conditions include Aborted, Busy, InProgress and UnavailableService, and optional `AdditionalResponse` is for POI logging. The page does not establish a separate command-acceptance acknowledgment, asynchronous callback or correlation ID, nor card authentication, payment authorization/capture, reconciliation, settlement or bank receipt. The async URL is a transport endpoint listing, not an outcome guarantee; no deprecation or version transition is stated. Source: [[source-adyen-api-explorer-terminal-api-latest-post-enableservice]]; raw lines 10–19 and 48–60.
