# C62 fixed-query answers: POST /diagnosis

## Q1

The 2026-09-15 capture at https://docs.adyen.com/api-explorer/terminal-api/latest/post/diagnosis describes a Sale-to-POI Terminal API `POST /diagnosis` request conveying information about the target POI. It lists two cloud **test** device transport URLs, `/v1/merchants/{merchantAccount}/devices/{deviceId}/sync` and `/async`, plus a local-terminal-IP option. Those path segments identify merchant and device routing in the listed cloud transport; the request table separately describes `POIID` as a POI system or terminal identifier referring to `MessageHeader.POIID`. The captured page does not specify the caller's identity, a session ID, or a numbered Terminal API protocol version; `latest` is the API Explorer path and `v1` appears in the cloud device URLs. The request table marks `POIID`, boolean `HostDiagnosisFlag`, and integer-array `AcquirerID` as **not required**; `AcquirerID` is present for a diagnosis limited to those hosts. For the response, `Response` and nested `Result` are required, `POIStatus` and `HostStatus` are optional, and `GlobalStatus` is required only within a supplied `POIStatus` object while `AcquirerID` is required within a supplied host-status object. The page states no default, numeric limit, lifecycle, reversal, or timing rule. [[source-adyen-api-explorer-terminal-api-latest-post-diagnosis]] (raw lines 5–28, 30–53).

## Q2

The same captured contract labels the HTTP response `200 Success`, but its required `Response.Result` may be `Success`, `Failure`, or `Partial`; `ErrorCondition` is absent or unused for Success and must be present in other cases. Optional `AdditionalResponse` is processing information for logging without real-time involvement. Optional `POIStatus` and `HostStatus` report terminal-component availability and host state/reachability; neither HTTP 200 nor those diagnostic fields proves payment authorization, capture, reconciliation, settlement, bank receipt, or any created resource. The captured page provides no authentication/security procedure, request-correlation contract, asynchronous completion rule, deprecation notice, rate limit, retry or reversal rule, or numbered Terminal API protocol version. It lists a cloud `/async` server, but does not define asynchronous outcome delivery or correlation. The separately linked diagnosis guide supplies additional operational behavior, which must retain its own attribution. https://docs.adyen.com/api-explorer/terminal-api/latest/post/diagnosis; [[source-adyen-api-explorer-terminal-api-latest-post-diagnosis]] (raw lines 10–19, 30–53).
