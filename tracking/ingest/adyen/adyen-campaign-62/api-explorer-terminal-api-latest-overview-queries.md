# C62 fixed query answers: api-explorer-terminal-api-latest-overview

## Q1

The captured page establishes **Adyen Terminal API v1**, based on nexo Sale to POI, for terminal and Adyen Mobile solution payments, refunds and shopper/device interactions. A POS caller sends a JSON `SaleToPOIRequest` with a `MessageHeader` identifying transaction type, terminal or Mobile SDK instance and unique transaction identifiers, plus an operation-specific body; the response is `SaletoPOIResponse` with an echoed header except `MessageType=Response` and an operation-specific body. Local POS-to-terminal-IP delivery is synchronous; cloud POS-to-Adyen-to-terminal delivery can return synchronously or by later event notification. Cloud paths identify a merchant and `deviceId` (test URL placeholder `merchantAccount`, regional live URL placeholder `merchantId`); the page lists `/sync` and `/async` routes and requires choosing the closest live data center. It gives no field-level requiredness, numeric limits, operation lifecycle, failure/reversal criteria or timing guarantees; its POST operation table is a directory only. ## Q2

The overview establishes a transport and envelope contract, not that a received cloud request or response proves a payment was authorized, captured, reconciled, settled or received by a bank. Synchronous cloud communication keeps the connection open for the response; asynchronous cloud communication closes it and obtains the response in an event notification, so the original request and later result must remain distinct. Each Cloud device API request requires `X-API-Key` containing a key with the Cloud Device API role, with a new live Customer Area key for go-live; the page delegates local protection to another guide. The `MessageHeader` supplies transaction and terminal/Mobile SDK correlation identifiers, but this overview does not define their field schema, uniqueness scope or error/status semantics. Old `terminal-api` endpoints remain supported with no future development, and Adyen recommends Cloud device API endpoints; this is Terminal API v1 as captured on 2026-09-15, not proof of current availability or of behavior in other API versions.
