Live access requires newly generated live API and client keys plus the geographically closest live endpoint. The server table shows TEST and five regional LIVE `/softposconfig/v3` bases; other example URLs use `v{version}` placeholders except US. This overview does not specify the endpoint caller, device or session identifiers, request/response fields, session lifetime/renewal, limits, failure/reversal, or timing. The configuration API's v3 is not an Android/iOS SDK or Terminal API payment version.
