## Q1

The captured `Hop/latest/post/getPciQuestionnaireUrl` page is a Classic HOP operation to obtain a PCI compliance questionnaire link to send to an **account holder**, and it says to use it only with a **partner platform setup**. It lists the test `https://cal-test.adyen.com/cal/services/Hop/v6` base; `Hop v6` is the captured service path, while `latest` is the documentation route label. The caller is the partner-platform integration implied by the page's restriction; the target identity is the required `accountHolderCode` supplied when the account holder was created. Optional `returnUrl` sends the holder back after questionnaire completion **or session timeout**, with a 500-character maximum. The 200 response describes a one-use `redirectUrl` that this API page says must be used within **30 seconds**. The separately retained Classic partner guide says **15 seconds** and describes a 30-minute questionnaire session after redirect; the two link windows conflict. This page does not define a device, Terminal API session, reversal, or financial lifecycle. Raw lines 5–20, 31–49; guide counterpart raw lines 98–121.
