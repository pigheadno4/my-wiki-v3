# Forward payment details retrieval checks

1. **Purpose, scope, and inference boundary.** This 2026-09-15 Adyen webpage covers server-side Checkout `/forward` requests that pass Adyen-stored card details or network tokens to a PCI-compliant third party, such as another PSP. The merchant provides the destination and placeholder-based request; Adyen substitutes details, calls the third-party API, and returns its response as a string (`raw/adyen/docs/online-payments/tokenization/forward-payment-details/2026-09-15.md:15-19,37-42`). The guide does not establish a merchant's enablement, PCI status, third-party acceptance, or payment success. The third-party status/body must be interpreted under that party's contract (`:460-462,499-506`). A separate network-tokenization guide limits Adyen-acquired *payments* to Adyen acquisition while explicitly routing network-token *forwarding* to a PCI-compliant third party (`raw/adyen/docs/online-payments/network-tokenization/2026-09-15.md:38,57-59`).

2. **Capability, requirements, warnings, and detail route.** `wiki/index.md` → `wiki/adyen-index.md` → `wiki/concepts/adyen-tokenization.md` (also `wiki/concepts/adyen-network-tokenization.md`) → proposed `wiki/sources/adyen/source-adyen-docs-online-payments-tokenization-forward-payment-details.md` → pinned raw. Source and reciprocal concept promotion are pending the coordinator. Setup calls for an online-payments integration on Checkout API v70+, Checkout webservice and Merchant Recurring roles, Recurring tokens life cycle events webhook, Adyen tokens, Support enablement, and live endpoint region matching token-vault region; network-token forwarding also calls for network tokenization implementation and a same-details Adyen token (`raw/adyen/docs/online-payments/tokenization/forward-payment-details/2026-09-15.md:21-35`). Card-detail modes and request fields are at `:48-97`. A network-token request needs a conditional body that falls back to Adyen-stored card details if the network token is unavailable; non-tokenized card details cannot accompany a network token (`:260-323`). Unencrypted card details require full PCI compliance (`:73-81`); `options.dryRun` is test-only (`:90,303`). Result fields and separate Adyen/third-party errors are at `:478-530`, and placeholders at `:532-561`. Several raw examples contain incomplete JSON punctuation (`:135-175,483-497`), so use the current API and third-party contracts for implementation. This snapshot cannot answer merchant-specific availability, current request validation, or the third party's actual outcome.
