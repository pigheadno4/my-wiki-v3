# Redirect 3DS Web Component fixed-query answers

1. **Purpose, scope, and limits.** This 2026-09-15 snapshot is an Adyen guide for adding redirect 3D Secure to an existing Web Card Component integration using Checkout API v49 or later and the `/payments` plus `/payments/details` flow (`raw/adyen/docs/online-payments/3d-secure/redirect-3ds2/web-component/2026-09-15.md:26-43`). A `/sessions`-only integration needs no extra 3DS configuration under this guide; v46 or earlier is routed elsewhere (`:28-30`). The page does not cover v47-v48, prove PSD2 compliance, guarantee authentication or payment success, or establish current merchant enablement. Its sample requests are test-environment and library-version examples (`:89-653`); do not treat their versions or values as universal requirements.
