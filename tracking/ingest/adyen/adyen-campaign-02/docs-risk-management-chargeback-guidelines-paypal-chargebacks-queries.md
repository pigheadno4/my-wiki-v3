# Fixed queries — PayPal chargeback process for marketplaces

1. **Purpose, scope, and non-inferences.** This Adyen guide covers how a marketplace handles PayPal disputes for its sellers using Adyen's Disputes API or Customer Area. Adyen says a PayPal notice does not tell it which marketplace seller owns the payment, so the marketplace must map the case and respond for that seller (`raw/adyen/docs/risk-management/chargeback-guidelines/paypal-chargebacks/2026-09-15.md:15-28`). PayPal assesses submitted defenses; Adyen records and reports webhooks/journals and a final debit if PayPal rejects the defense (`:140-152`). This 2026-09-15 snapshot does not prove current PayPal deadlines, account-specific fees or holds, Seller Protection eligibility, a live dispute's defendability, or a particular case outcome (`:11,154-159,177-187`). It is not a general PayPal merchant dispute guide outside Adyen's marketplace route.
