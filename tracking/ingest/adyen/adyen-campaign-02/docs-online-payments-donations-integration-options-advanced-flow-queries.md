# Fixed-query audit: Adyen Giving Advanced flow

1. **Purpose and scope.** The 2026-09-15 page covers donations using an Advanced-flow Web Components route and a merchant-built API-only route (raw 15–29, 429–439). In either, the donation uses the original payment method (27, 437). The Component offers its donation form after the original payment (25); API-only can offer fixed amounts or round-up before or after checkout (439, 455–493). The donation request follows authorization, and a post-checkout request also follows shopper confirmation (680–687). Do not infer a single reliable implementation sequence for Web Components: its Advanced-flow section tells the server to create a Sessions-flow payment session (46–50, 69–88), while later steps describe explicit `/donationCampaigns` and `/donations` calls (93–118, 276–323). Do not treat the synchronous `/donations` status as final shopper-facing success or the two general curl examples as copy-ready JSON; the Giving `DONATION` webhook supplies outcome and the examples lack a comma before `merchantAccount` (314–315, 718–719, 723–784).
