# Fixed queries — Manage disputes with the Disputes API

1. **Purpose, scope, and non-inferences.** This Adyen page gives the merchant's Defend Disputes API workflow: receive dispute webhooks, retrieve dispute-specific defense reasons and evidence requirements, accept a dispute or upload documents, and make a final defend request; manual Customer Area handling is a separate path (`raw/adyen/docs/risk-management/disputes-api/2026-09-15.md:15-21,38-57`). It is a 2026-09-15 capture whose own metadata says last modified 2020-05-27 (`:1-12`). It does not prove current credential access, that every dispute is defendable, a successful API call, a won dispute, or current scheme fees (`:29-36,241-265,334-363`). A `success` response after upload or submission records request success, while dispute status continues through webhooks (`:211-213,261-265`).
