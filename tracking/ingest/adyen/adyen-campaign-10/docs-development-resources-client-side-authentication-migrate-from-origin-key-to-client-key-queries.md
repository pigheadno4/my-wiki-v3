The dated guide says Web 3.10.1+, iOS/Android 3.7.0+, and client-key-only from listed 4.0.0 versions; Web replaces `originKey`, iOS uses `APIContext` with key and environment instead of `publicKey`, and Android passes `clientKey` into its builders. One key covers origins in one environment; generating it does not invalidate an older origin or public key. No required Customer Area user role is specified.
