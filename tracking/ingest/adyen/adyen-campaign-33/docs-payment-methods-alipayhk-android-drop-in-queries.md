Q1. What does Alipay HK add to Android Drop-in Sessions versus Advanced flow?
A1. Sessions requires an existing Android Drop-in Sessions flow, Checkout API v68+ and Customer Area method setup, with no extra method-specific /sessions or configuration parameters (raw lines 25–46). Advanced requires existing Advanced Drop-in, explicit redirect handling and Customer Area setup, with no extra method-specific configuration or /payments parameters (raw lines 62–82). Q2. What limits interpretation of redirect and TEST/LIVE status?
A2. The explicit redirect-handling row is in Advanced, not Sessions (raw lines 29–34, 64–70). Both sections provide test credentials/status lookup and separately require a live Customer Area request before live acceptance; there is no live approval or actual payment/webhook outcome here (raw lines 48–60, 84–94).
