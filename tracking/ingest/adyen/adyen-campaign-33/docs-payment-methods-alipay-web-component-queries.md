Q1. What must an existing Web Components integration add for Alipay in Sessions versus Advanced flow?
A1. Sessions calls for an existing Sessions integration, Checkout API v68+, redirect handling and Alipay in Customer Area; no extra /sessions parameters. Advanced calls for an existing Advanced integration, redirect handling and Alipay in Customer Area; no extra /payments parameters and no API-version minimum stated here. Both import/use Redirect with no extra method configuration (raw lines 25–77, 90–140).
