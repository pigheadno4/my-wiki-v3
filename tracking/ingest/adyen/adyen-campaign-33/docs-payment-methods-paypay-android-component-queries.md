Q1. What differs between Sessions and Advanced PayPay Android Component additions?
Answer: Sessions requires existing Android Components Sessions flow, Checkout API v68+, redirect handling and PayPay in Customer Area (raw lines 25–36), with no extra session parameters/configuration (lines 38–42, 67–71). Advanced requires existing Advanced Android Components flow, redirect additional-action handling and Customer Area addition (lines 141–149), with no extra configuration or /payments parameters (lines 174–184, 237–241). Both use InstantPaymentComponent; Sessions gets paypay from checkoutSession while Advanced selects it from /paymentMethods response (lines 75–125, 180–234).
