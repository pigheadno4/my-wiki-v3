## Overview

This 2026-09-15 Adyen iOS page is a **navigation chooser** for adding Alipay HK to an iOS app. It links to method-specific iOS Drop-in and Components guides and to the main iOS Sessions/Advanced integration guides. It does not itself specify payment setup, supported SDK/API versions, redirects, account eligibility or transaction results. [[adyen]] [[adyen-online-payments]]

## Key takeaways

- The two method-specific options are **iOS Drop-in** and **iOS Components**. The Drop-in description calls it an all-in-one UI solution. The Components description contains the unresolved phrase “Use the None”; do not infer a Component type or behavior from that placeholder. (raw lines 19–27)
- The page says to follow the main integration guides before adding Alipay HK. It links separate iOS Drop-in and Components guides for both **Sessions** and **Advanced** flows. These are navigation targets; child pages own prerequisites, version requirements and return/payment behavior. (raw lines 29–36)
- A link to a method-specific guide is not evidence that Alipay HK is enabled for a merchant or that any live authorization, capture, settlement or refund occurred. (raw lines 15–36)
