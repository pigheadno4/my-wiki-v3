## Overview

This 2026-09-15 Adyen iOS page is a **navigation chooser** for adding PayPay to an iOS app. It links method-specific iOS Drop-in and Components guides and main iOS Sessions/Advanced integration guides. It does not itself define payment setup, version requirements, redirect behavior, current eligibility or transaction results. [[adyen]] [[adyen-online-payments]]

## Key takeaways

- The method-specific choices are **iOS Drop-in** and **iOS Components**. The Drop-in description calls it an all-in-one UI solution. The Components description contains the unresolved placeholder “Use the None”; this page does not identify the Component implementation or behavior. (raw lines 19–27)
- The page says to follow the main integration guides before adding PayPay. It links separate iOS Drop-in and Components guides for both **Sessions** and **Advanced** flows. These links route to child authority; they do not establish child prerequisites or payment outcomes on this page. (raw lines 29–36)
- A listed route does not prove PayPay is enabled for a particular merchant or that a live authorization, capture, settlement or refund occurred. (raw lines 15–36)
