This 2026-09-15 Alipay for Web page is an integration chooser. It links to Alipay **Web Drop-in** and **Web Components** child guides, then to the corresponding main Web integration guides. - The Drop-in link is described as an all-in-one UI solution for a website. The Components link is described as using **Redirect** to make Alipay payments on a website. That wording is a route description here; details of redirect action, return processing and outcome belong to the child guide.
