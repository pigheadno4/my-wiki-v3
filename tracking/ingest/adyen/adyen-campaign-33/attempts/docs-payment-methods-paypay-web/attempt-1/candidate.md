## Overview

This [[adyen]] **PayPay for Web** page is an integration chooser. It links PayPay **Web Drop-in** and **Web Components** guides, then routes readers to the main Web Sessions and Advanced guides for both integration types. Its descriptions do not establish child-guide versions, request fields, live eligibility or payment outcomes. [[adyen-online-payments]]

## Key takeaways

- **Drop-in:** The page links `/payment-methods/paypay/web-drop-in` as an all-in-one UI solution for a website. See raw lines 19–23.
- **Components:** It links `/payment-methods/paypay/web-component` and describes using the Redirect to make PayPay payments on a website. The linked guide supplies the actual redirect and request details; the chooser does not document a completed payment. See raw lines 25–27.
- **Main integration first:** The See also section says to create the main integration before adding PayPay, with separate Web Drop-in and Components routes for Sessions and Advanced flows. See raw lines 29–36.
