## Overview

This [[adyen]] **Alipay for Android** page is an integration chooser. It links Android **Drop-in** and **InstantPaymentComponent** guides, then links the main Android Sessions and Advanced guides for both Drop-in and Components. These links do not establish child-guide API/SDK versions, merchant eligibility or a completed payment. [[adyen-online-payments]]

## Key takeaways

- **Drop-in:** The page describes the Android Drop-in guide as an all-in-one UI solution to add Alipay to an Android app. See raw lines 19–23.
- **Components:** It describes `InstantPaymentComponent` as handling the redirect to Alipay and links the Android Component guide. The chooser does not describe redirect return handling or final payment status. See raw lines 25–27.
- **Base integration:** The See also section says to create a main integration before adding Alipay, with links for Android Drop-in and Components under Sessions and Advanced flows. This is a routing instruction; the linked guides provide their own conditions. See raw lines 29–36.
