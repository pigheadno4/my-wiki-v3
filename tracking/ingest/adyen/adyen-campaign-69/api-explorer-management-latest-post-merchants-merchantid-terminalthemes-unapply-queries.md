# api-explorer-management-latest-post-merchants-merchantid-terminalthemes-unapply — actual query answers

## Q1

The captured Management API `POST /merchants/{merchantId}/terminalThemes/unapply` resets a merchant account's terminal-theme assignment. Android terminals under that merchant fall back to an applied company custom theme, or the default Adyen theme if there is none; store and individual-terminal custom theme assignments keep their current theme. The only captured server is TEST `https://management-test.adyen.com/v3`. The API credential needs `Management API - Terminal themes read and write`; required path `merchantId` is the merchant account's unique identifier. No request body, query input, defaults, limits or idempotency rule are specified. The response list gives `200 OK` and no success-field schema; the success example shows `{"status":"success"}`.
