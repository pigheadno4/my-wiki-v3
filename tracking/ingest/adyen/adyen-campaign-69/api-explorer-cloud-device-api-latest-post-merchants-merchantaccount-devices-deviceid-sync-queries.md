# C69 original query answers: synchronous Cloud Device request

## Q1

For `POST /merchants/{merchantAccount}/devices/{deviceId}/sync`, the 2026-11-07 capture is the Cloud device API v1 synchronous Terminal API transport reference. It sends a JSON object containing a Terminal API request to the specified payment device and returns a Terminal API response synchronously. The API credential needs the Cloud Device API role. Required path values are the merchant account's unique `merchantAccount` and payment device's unique `deviceId`; `deviceId` must match the request `MessageHeader.POIID`. A terminal integration uses a model–serial terminal ID, while a Mobile solution uses the SDK installation ID. The page gives a test v1 base URL and regional live v1 base URLs for Australia, East Asia, Europe and the United States. It specifies no body-field schema, default, limit or response-field list beyond the linked Terminal API request types and a returned Terminal API response.
