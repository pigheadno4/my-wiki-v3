## Q1

The 2026-11-07-captured Payments App API v1 reference is `GET /merchants/{merchantId}/paymentsApps` at merchant scope. It lists Payments App instances for the merchant account named by required path `merchantId`; a credential with the Adyen Payments App role is required. The reference lists live `https://management-live.adyen.com/v1` and test `https://management-test.adyen.com/v1` servers. Optional integer `offset` skips items and `limit` sets the number returned, with no default or maximum documented. Optional comma-separated `statuses` filters one or more of `BOARDING`, `BOARDED`, `REVOKED`; omission returns all statuses. The 200 body requires `paymentsApps`; each element requires `installationId` (app-instance ID), `merchantAccountCode`, and `status`, while `merchantStoreCode` is optional. The raw gives no conditional inputs.
