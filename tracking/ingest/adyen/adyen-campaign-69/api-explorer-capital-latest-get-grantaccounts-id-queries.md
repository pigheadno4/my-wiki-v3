# C69 Capital grant-account detail — original query answers

## Q1

The 2026-11-07 `GET /grantAccounts/{id}` operation belongs to Capital API v1 and returns details of the grant account that tracks existing grants for a marketplace or platform. It lists TEST and Live `/capital/v1` servers. The required path `id` is the grant-account identifier, not a grant, offer or disbursement ID; no query or body field, default, pagination or idempotency rule is given. The operation does not name a caller role, while the companion Capital v1 overview requires an API key in `X-API-Key`, the `Balance_Platform_Capital_Configuration_Role` and `Balance_Platform_Capital_Grant_Initiation_Role`, and a separate Live key. On `200`, the response schema makes `balances`, `fundingBalanceAccountId`, grant-account `id`, and `limits` optional. A present balance item requires currency, fee, principal and total, with total defined as principal plus fee; balances aggregate grants by currency. A present limit amount requires currency and integer minor-unit value. The funding balance-account ID names the source account used to fund a grant, while limits indicate maximum funds that can be disbursed. ## Q2

`200` establishes a successful grant-account lookup, not a new grant request, approved offer, completed disbursement, repayment, debt closure or bank receipt. All four top-level detail fields are optional, so the schema does not guarantee a balance, limit, funding account ID or returned grant-account ID in every success body. The operation lists `404` for entity not found and `422` for request validation, with optional error-envelope fields; it provides no JSON examples, asynchronous status, activation, deletion, reversal, propagation timing or version-conflict contract. Authentication and roles are described by the separate family overview, and listed Live routing does not establish current platform eligibility. A separate Balance Platform API v2 TEST operation uses the same relative `/grantAccounts/{id}` path but a different API family and base; do not transfer its error list or environment assumptions here.
