## Q1

`POST /merchants/{merchantId}/terminalThemes/{id}/assets` adds an image or video asset to a terminal theme owned by the merchant account named by required path `merchantId`; required `id` is the theme identifier. This is the captured Management API `latest` v3 reference with `https://management-test.adyen.com/v3` as its listed server. The API credential needs **Management API - Terminal themes read and write**. Required query `type` chooses `logo`, `homeScreen`, `idleScreen`, `afterPaymentScreen`, or `shopperEngagementScreen`; required `model` identifies the Android terminal model. `logo` requires `All`; `idleScreen` and `shopperEngagementScreen` require SFO1 or M450. Upload one required multipart/form-data `file` part with a supported specific Content-Type. SVG is limited to logo/All, MP4 and QuickTime to SFO1/M450, JPEG and PNG exclude All, and GIF excludes SFO1/M450. Asset size is at most 100 MB for SFO1/M450 or 10 MB for other models. This route is rate limited; the page states no numeric rate or default query values. `201 Created` returns required `model`, `type`, and a token-bearing CDN `url` valid for 24 hours. ## Q2

`201 Created` establishes an asset addition and returns its model, type, and 24-hour token-bearing CDN URL. The page does not state that this theme was applied, propagated, or displayed on a terminal, or that a payment can run. A duplicate type/model asset makes this add request fail and must be handled through the separate `/assets/replace` endpoint. Missing or generic file Content-Type is rejected with `422`; the captured response section also lists 400, 401, 403, 404, 422, 429, and 500, with illustrative 422 file-size and duplicate errors, a 403 logo-editing denial, and a 404 account/theme mismatch. The credential role and rate limit constrain this route. No idempotency, asynchronous approval, activation, reversal, deletion, or account-specific eligibility rule is stated here. Only the TEST v3 server is listed in the captured 2026-11-07 page, so the snapshot does not establish a live endpoint or account access.
