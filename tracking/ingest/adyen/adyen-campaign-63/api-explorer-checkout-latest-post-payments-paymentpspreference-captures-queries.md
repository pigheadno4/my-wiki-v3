The page says the outcome arrives asynchronously in a `CAPTURE` webhook (raw lines 7, 271–325). The optional `lineItems` rows mention refunded items and partial refunds despite being in this capture schema, so those rows should not be read as a new capture requirement (lines 126–152, 282–308).
