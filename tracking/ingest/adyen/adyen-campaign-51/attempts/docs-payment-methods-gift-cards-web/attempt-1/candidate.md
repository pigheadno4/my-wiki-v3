## Overview

This Adyen page, **last modified 2019-09-30** and captured 2026-09-15, is a short **Web integration chooser** for gift-card acceptance. It points to Web Drop-in and Components method guides and generic Web integration references. It does not specify API fields, partial-payment behavior, provider onboarding, payment results or merchant enablement. See [[adyen]], [[adyen-online-payments]], and the separate gift-card overview [[source-adyen-docs-payment-methods-gift-cards]].

## Key takeaways

- **Drop-in** is labeled the all-in-one UI route for website gift cards; **Components** is labeled a pre-built Component route for rendering gift cards on a website. These are navigation descriptions, not evidence that a card can be accepted by a particular merchant. See raw lines 19–27.
- The page also links generic **Web Drop-in** and **Components** references. It does **not** list Sessions versus Advanced flow choices or a checkout version. Follow the selected child method guide for request, balance, partial-payment, result and test/live behavior. See raw line 29.
- The separate gift-card overview describes provider onboarding, cross-channel stored value and partial-payment context; those details are not asserted by this 29-line chooser. See [[source-adyen-docs-payment-methods-gift-cards]] and raw lines 15–29.
