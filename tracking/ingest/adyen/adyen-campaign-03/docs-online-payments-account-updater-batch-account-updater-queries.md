# Independent retrieval checks — Adyen Batch Account Updater

1. **Purpose, scope, and inference boundary.** This 2026-09-15 Adyen guide describes a merchant-initiated Batch Account Updater route for Visa and Mastercard: submit an SFTP batch request or schedule one card through `/scheduleAccountUpdater`, then obtain the update in a later batch result file and act on it (candidate lines 14–22; raw lines 19–27, 35–70, 100–160). Support configuration is needed before integration, and an SFTP directory uses the merchant IP and SSH/PGP keys (raw lines 21, 29–33). The ACK validates the file and successful scheme processing takes at least two days after it; neither the ACK nor the API's immediate `Success` proves an updated card or payment result (raw lines 64–70, 139–155). This snapshot does not prove account enablement, a scheme-provided update, a successful card-detail update, or an authorized payment. It does not describe Real Time Account Updater's in-processing retry.
