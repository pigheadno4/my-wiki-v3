## api-explorer-recurring-latest-post-disable

Pinned raw: `raw/adyen/api-explorer/Recurring/latest/post/disable/2026-09-15.md`. Canonical source: `source-adyen-api-explorer-recurring-latest-post-disable` — https://docs.adyen.com/api-explorer/Recurring/latest/post/disable

- Q1: For `Recurring/latest/post/disable`, what purpose, API/version and object identity does this captured page establish, and what central required/conditional inputs or prerequisites govern its use?
  - A: Captured Recurring API v68 test-server `POST /disable` disables shopper-scoped stored payment details. The API body requires merchantAccount and the initial-payment shopperReference. Providing recurringDetailReference selects one stored detail; omitting it selects the shopper's whole recurring contract and all its details. Optional contract limits a use (ONECLICK, RECURRING, PAYOUT, or combination) (API raw lines 5–22). The linked Classic guide marks this endpoint inactive for new integrations and directs new builds to Checkout API, existing users to migration (guide raw 14–21). Its prose agrees with the API selector rule (guide raw 27), but its “all details” example includes recurringDetailReference (guide raw 76–85); do not use that example as an all-details recipe.
- Q2: For `Recurring/latest/post/disable`, what does the documented response or failure establish, and which lifecycle, deletion/propagation, asynchronous outcome, version/environment or missing-evidence boundaries prevent broader inference?
  - A: The 200 response's optional response field says `[detail-successfully-disabled]` or `[all-details-successfully-disabled]` according to scope (API raw 34–42). It is not proof of payment outcome, historical transaction deletion or propagation timing, none of which this API page defines. Error tables cover 400, 401, 403, 422 and 500, without examples (API raw 45–112). The latest URL is a captured v68 test-server snapshot, not current-version or live-execution proof (API raw 1–12). The linked guide's inactive notice limits new integrations (guide raw 14–21).
