## Overview

This 2026-09-15 Trustly for Web page is an **integration chooser**. It routes website integrations to Trustly Web Drop-in or a pre-built Trustly Web Component and points to general Web Drop-in/Components documentation. It supplies no Trustly request, redirect, result, funding, or live-eligibility instructions. [[adyen]] [[adyen-online-payments]]

## Key takeaways

- The **Drop-in** route is described as an all-in-one UI solution for adding Trustly to a website. The **Components** route is described as a pre-built Component for rendering Trustly. These labels select distinct child guides, not interchangeable integration instructions. See raw lines 19–31.
- The page also links the general Web Drop-in and Components guides. Its navigation alone does not establish a merchant's bank/currency eligibility or a successful payment or received funds. For method behavior and the authorization-versus-funds qualification, follow the child guides and [[source-adyen-docs-payment-methods-trustly]] respectively. See raw line 33 for the base guides.
