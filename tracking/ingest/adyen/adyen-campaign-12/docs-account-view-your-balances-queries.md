Q1: What is this page for, what scope does it cover, and what must it not establish?
A: A dated Adyen guide to viewing merchant-account balance components and company-level aggregate balances by currency through Customer Area or Balance Control API, for online/POS accounts with specified roles. It does not prove that every component is withdrawable, that a next payout reached the bank, or that a particular payment reconciled. Q2: What components, prerequisites, API routes, and warnings matter?
A: Available funds comprise pending (not settled), next payout (scheduled for next bank payout), reserve (operational cover), and conditional negative refund allowance; deposit is separately withheld against losses/liabilities. Customer Area roles are Merchant financial or Manage key financial tasks; API role is Balance control API - Balances management, and the activity log is Customer Area-only. Company API view requires companyAccountCode and currency and returns per-merchant records. The merchant endpoint printed with /companies/{merchantAccountCode}, its example merchantAccount=YOUR_COMPANY_ACCOUNT, and a USD-request company example containing non-USD entries require schema verification before implementation.
