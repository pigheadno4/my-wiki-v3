Contact Adyen to enable new features in TEST before testing (raw lines 148–150). ## Q2. Does upgrading immediately reverify existing users or settle the latest-version and transfer-instrument request shape?

No. The guide says older-version invalid capabilities do not automatically get deadlines, ToS acceptance is backfilled but new capabilities require more ToS documents, and the version update does **not immediately trigger** new verification checks; data updates or required reviews do (raw lines 83–88). It calls v4 latest stable at line 19 but v3 latest stable at line 67. It says `/transferInstruments` top-level `type` distinguishes IBAN/local (raw line 134), while the separate [[raw/adyen/docs/marketplaces/manage-transfer-instruments/2026-09-15|transfer-instrument raw lines 52–58 and 72–76]] use top-level `bankAccount` with nested identification type; check the versioned API operation before implementation. Sunset notice is approximate and a sunset version stops working after its date (raw lines 31, 61–67).
