# C24 Classic Marketpay Payout Report — retrieval checks

**Q1. What is this report for, and which payouts and setup apply?** It reconciles each Classic account holder's payout against debit and credit transactions, but is available only for automatic payouts initiated within the day (raw lines 15–25). The configured time zone affects data (lines 19–21); the report can be subscribed to in Customer Area at daily, weekly or monthly frequency (lines 29–31). **Q2. What reconciliation boundary or report-version trap matters?** Pending refunds/chargebacks can produce a non-zero rolling balance that carries to the next report (raw line 27). The report says one record line per account/currency yet also describes each line as an entry with a `Record Type` (lines 25, 39–54), so inspect row type before interpreting grain. `TransferBalance` included payment costs in prior report versions, but new platforms use it for otherwise unbooked debits/credits and put fees under `Fee`; new record types are default only for new platforms and Support-enabled for existing ones (lines 86–96). `Payout` and returned-payout rows must not be treated as independent beneficiary-bank receipt proof (lines 84–85).
