## Q1 — Purpose and access prerequisites
Q: How is a Marketplace Customer Area admin activated, and how does that admin grant team access?
A: Adyen creates the initial admin user after marketplace signup and sends an email; completing verification activates that Customer Area user. The admin can create team users and assign Customer Area roles to control permissions. See raw/adyen/docs/marketplaces/manage-access/2026-09-15.md:19, :34-38. This is a user-access overview, with exact roles in a separate guide.
