Q1. What does this release page cover, and what must an existing Classic integrator check before using a dated change?

It is the Classic Adyen for Platforms release ledger from 2018-12-27 through 2023-06-05, organized by API, notifications, HOP, Customer Area, KYC, reports and general changes (raw lines 19–31, 1629–1672). An existing integration should match the entry's release date, affected API/notification version and platform configuration before applying it: v5 made writes asynchronous and webhook outcomes necessary (lines 1629–1637), v6 renamed payout-method fields and removed notification fields (lines 1039–1085), and the 2022-08-01 entry sends existing integrations to the Classic guide while directing new integrations to upgraded-infrastructure documentation (lines 171–175). Q2. Which material lifecycle, deprecation and funds-direction boundaries prevent treating this history as a current capability checklist?

On 2021-09-27, suspended/closed holders' existing funds and new payments were still refunded by default, with a support-enabled liable-account transfer alternative; refunds/chargebacks became liable-account deductions by default, while payouts remained limited to active holders (raw lines 796–817). The API deprecated `ownerDateOfBirth` on 2022-02-21 and required `yyyy-mm-dd` formatting if still used (lines 483–487). A 2019-01-17 note removed the separate End of Month Balance Report in favor of the MarketPay Balance Report (lines 1613–1622); a 2023-01-09 note ended HRK bank-account support in Croatia (lines 73–77). The 2022-03-14 Reports entry says California `Refund terms` “Right To Refund” text was removed (release-note raw lines 412–416), while the later-modified [[source-adyen-docs-classic-platforms-reports-and-fees-marketplace-payments-accounting-report]] still describes that text in its column table (report raw line 73); do not infer the text remains populated. These are dated Classic changes, and the ledger's latest entry is 2023-06-05 (lines 37–41), so it cannot establish later or modern-Platforms status.
