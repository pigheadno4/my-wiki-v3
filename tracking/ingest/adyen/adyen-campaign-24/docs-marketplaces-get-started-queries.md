# C24 Marketplace get-started retrieval checks

## Q1 — What is the Marketplace integration path and prerequisite?

Contact Adyen to register interest and assess fit, then scope onboarding/data/document collection, payment splits, risk, payouts and reconciliation with an Adyen contact (raw lines 21–28, 42–54). Adyen sets up test Customer Area access; the platform builds and tests its integration, applies for live access, configures live, and tests there too (raw lines 56–95). ## Q2 — What does test setup or a live application fail to establish?

The test configuration is not replicated to live; the platform must configure the live account separately and test its integration in that environment (raw lines 89–95). Test dashboard access, built integration and contacting Adyen to take the account live are steps, not proof of live configuration, a verified user, an executed payment split, payout or bank receipt (raw lines 56–87).
