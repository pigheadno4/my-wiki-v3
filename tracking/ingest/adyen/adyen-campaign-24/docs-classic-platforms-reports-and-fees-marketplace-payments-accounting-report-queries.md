**Q1. What does the Classic Marketplace Payments accounting report contain and how is it obtained?**
It includes platform/marketplace payment financial status changes, events and modifications, supports an account-level transactional ledger and liable-account fee reconciliation, and has a default hourly or daily subscription (primary raw lines 15–33). Each data line is one entry; use account, reference, amount, currency and record-type columns to interpret it (primary raw lines 41–69). The platform time-zone setting affects data, and the hourly filename uses UTC (primary raw lines 19–33). **Q2. Which balances, payout stages and source discrepancies constrain reconciliation?**
The record-type matrix separates pending from available balance: captured `PendingCredit` is not yet available for payout; `Credited` follows settlement, and card `PayoutInitiated` deducts available balance at initiation rather than proving payout completion (primary raw lines 85–114). New liable-account adjustment types are default for new platforms; existing platforms must contact Support to enable them (primary raw lines 115–125). The `TransferBalance` prose calls a separate type `Fee` but the next row labels it `NewFee` (primary raw lines 116–117). The report's California `Refund terms` column describes “Right To Refund” text (primary raw line 73), while the 2022-03-14 release note says that text was removed (release-note raw lines 412–416); do not assume later rows contain it.
