# VX820 Duet boarding retrieval checks

Q1. What is this guide for, and what must happen before boarding?
A. It is the historical VX820 Duet registration/configuration guide, with integrated POS App or library routes and standalone Customer Area or one-time POS App routes (raw lines 14–16, 24–92). It says to connect to the internet successfully and inspect device security first (raw lines 18–20). Android POS App steps need an API credential and terminal IP (raw lines 31, 34–42); Customer Area standalone steps specify serial number, API credential and one-time password (raw lines 69–85). Q2. Does its post-configuration wording show current payment capability or a completed payment? What boundary matters?
A. No. The old guide says configuration application precedes “begin processing payments” (raw lines 43–44, 56–57, 86–88); it does not record an actual authorization or payment. The fully read parent deprecation table lists VX820 Duet “No more transactions” on March 29, 2024 (parent raw lines 32–35), and the parent says classic-library transactions become impossible after 31 March 2024 (parent raw lines 50–54). The old instruction and later cutoff conflict for present-use interpretation; the latter is the relevant dated boundary.
