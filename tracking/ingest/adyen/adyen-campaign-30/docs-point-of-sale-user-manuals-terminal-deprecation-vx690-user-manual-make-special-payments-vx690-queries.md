# C30 VX690 Special Payments retrieval checks

Q1. What does the VX690 Special Payments page cover, and when are options present?
Answer: It describes a custom/ad-hoc menu whose contents may vary by merchant configuration (pinned raw line 16). The pictured key + `8` opens the menu, then a PIN unlocks the device (lines 20–24). It lists normal-payment and manual-entry payment screens, with the manual-entry flow prompting for PAN and expiry after amount entry (lines 26–35). The image asset path contains `vx820` despite this being a VX690 page (lines 22, 32), so identify the key by the raw illustration, not its filename. Q2. Do the menu and normal-flow wording prove a successful payment or refund?
Answer: No. The page says a manual-entry transaction then follows the normal flow (pinned raw line 35) but gives no result; it only links to a separate refund guide (line 37). Merchant configuration governs menu availability (line 16). The separate eVo table lists VX690 “No more transactions” on 29 March 2024 (raw/adyen/docs/point-of-sale/user-manuals/terminal-deprecation/2026-09-15.md lines 32–35).
