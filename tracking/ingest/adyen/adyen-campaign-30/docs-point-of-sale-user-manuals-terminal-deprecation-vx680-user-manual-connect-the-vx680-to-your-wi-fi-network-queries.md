# VX680 Wi-Fi retrieval checks

Q1. What does the historical VX680 Wi-Fi page cover, and what precedes network selection?

It describes connecting the VX680 to Wi-Fi for Adyen and merchant back-end communication. The guide first calls for a fully charged device, then an image-only key plus 9 to enter Admin; it requires an Admin PIN unless the terminal is not yet boarded. The Network → Wi-Fi → Networks menu then offers scan or manual add. Raw lines 16, 20–39. Q2. Do these Wi-Fi steps prove present security compliance, boarding, or the ability to transact, and what is the key later boundary?

No. The 2019-modified guide presents expected scan/manual-add behavior, default-network selection, WPA/WPA-2 and TKIP/CCMP menu choices, and a next step to begin boarding; it does not report a live diagnostic or completed boarding. Raw lines 39–60. The separately ingested Adyen eVo deprecation page lists VX680 “No more transactions” on 29 March 2024 (its raw lines 32–35).
