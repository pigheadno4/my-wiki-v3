# C30 VX675 Admin-menu retrieval checks

Q1. What is the VX675 Admin menu for, and how does this guide say to reach it?
Answer: It names network settings, installer, merchant configuration editing/removal and maintenance calls, and totals print/reset purposes (pinned raw line 16). The guide says press `9` and the pictured key at the same time (line 20), then enter the Admin PIN; unknown PINs route to separate POS Troubleshooting (line 21). It says the menu then displays (line 22). Q2. Does opening this menu remove configurations, reset totals or prove current VX675 payment ability?
Answer: No. Removal and reset are named menu purposes (pinned raw line 16), while the procedure ends when the Admin menu appears (lines 20–22). The separate eVo table lists VX675 “No more transactions” on 29 March 2024 (raw/adyen/docs/point-of-sale/user-manuals/terminal-deprecation/2026-09-15.md lines 32–35).
