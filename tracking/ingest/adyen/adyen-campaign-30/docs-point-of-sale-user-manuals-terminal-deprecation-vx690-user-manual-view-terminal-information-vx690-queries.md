# C30 VX690 Quick Info retrieval checks

## Q1 — Main purpose and prerequisites

**Question:** What does the historical VX690 Quick Info page show, and how does it say to open it?

**Answer:** It says to press the illustrated key and **5** at the same time; the key is image-only and the raw shortcut line contains HTML entities (pinned raw lines 19–23). The terminal is said to display IP address, terminal ID, software version and a QR code encoding IP address, MAC address, network name, store name, merchant account name and terminal ID (lines 25–30). No PIN prerequisite appears on this page. ## Q2 — Material boundary or failure

**Question:** Does the displayed IP or merchant-account name prove the VX690 is connected, boarded or able to process payments now?

**Answer:** No. The page only describes a Quick Info display and QR-encoded fields (pinned raw lines 19–30); it records no connectivity test, account validation, boarding event or payment result. It was last modified in 2019 and captured in the deprecation tree (lines 1–11). The separate eVo deprecation table lists VX690 with a historical **29 March 2024** “No more transactions” date (deprecation raw lines 32–35).
