# C30 VX690 Bluetooth-base LED retrieval checks

Q1. What do the base-station LEDs mean in this guide?
Answer: The table labels all three LEDs lighting, then green blinking roughly 10 seconds and staying on, as **Powering on** (pinned raw line 22). Slow blue blinking is **Discover mode enabled** (line 23), quick blue blinking is **Pairing** (line 24), and steady blue is **Connected** (line 25). Q2. Does steady blue establish payment, security or current device readiness?
Answer: No. The page labels a base-station LED state “Connected” (pinned raw line 25) but gives no Adyen-platform diagnostic, boarding result, security finding or transaction result. The separate eVo table lists VX690 “No more transactions” on 29 March 2024 (raw/adyen/docs/point-of-sale/user-manuals/terminal-deprecation/2026-09-15.md lines 32–35).
