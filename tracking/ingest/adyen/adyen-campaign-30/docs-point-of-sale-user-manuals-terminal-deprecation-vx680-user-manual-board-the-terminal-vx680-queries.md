# VX680 boarding retrieval checks

Q1. What is this VX680 guide for, and what must precede boarding? It is a 2019-modified historical procedure to register the VX680 with Adyen. The manual requires an internet connection and device security inspection before boarding (pinned raw lines 14–20). Integrated routes include POS App Android/iOS or custom-library links (lines 24–67); standalone routes include Customer Area registration or a one-time POS App setup (lines 69–92). Q2. Does this manual's “begin processing payments” statement mean VX680 can transact now or that boarding succeeded? No. The manual describes a post-reboot merchant-configuration step and says payments can then begin (pinned raw lines 43–44, 56–57, 83–88); it records no observed outcome. The related eVo deprecation table lists VX680 “No more transactions” on March 29, 2024 (deprecation raw lines 32–35), so the older statement cannot establish present support. The Android path also has an incomplete app-download/install line and a Bluetooth/Wi-Fi prompt followed by IP-only instructions (pinned raw lines 32, 40–41); do not infer a working Bluetooth procedure.
