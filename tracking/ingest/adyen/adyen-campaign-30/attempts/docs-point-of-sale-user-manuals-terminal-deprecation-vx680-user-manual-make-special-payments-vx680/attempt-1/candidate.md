## Overview

This [[adyen]] **VX680** page was last modified 2019-05-20 and captured 2026-09-15 under the terminal-deprecation manual tree. It explains access to a **Special Payments** functions menu for custom or ad hoc payment options. **Available options vary by merchant configuration**; the page does not establish that a particular device has an option enabled or that any payment completes. The separate [[source-adyen-docs-point-of-sale-user-manuals-terminal-deprecation]] lists VX680 with a historical **29 March 2024** "No more transactions" date. See [[adyen-payment-terminals]].

## Key takeaways

- The historical entry sequence uses an **image-only key plus 8**, then asks for a PIN code to unlock the VX680. The raw does not give a text name for the pictured key; inspect the illustration at raw line 22. Entering the menu is not authorization to use every listed function. See raw lines 18–26.
- Depending on merchant configuration, the menu can present **Normal payment**, which opens an amount-entry screen, and **Manual entry payment**, which opens a payment screen. The manual-entry example then says to enter an amount, press the illustrated key, and input the card **PAN and expiry date** when prompted. It says the transaction follows the normal flow, but gives no result, authorization, capture, settlement or PCI-compliance evidence. See raw lines 26–35.
- The page also says the menu includes a **refund** option and points to a separate VX680 refund guide. This is a route, not the refund procedure or proof that refunds are enabled on a device. See raw line 37.
