## Overview

This [[adyen]] VX675 manual page, last modified in 2019 and captured 2026-09-15, describes opening the terminal's **Special Payments** menu and the payment options it might show. Menu contents depend on the merchant configuration; the page does not establish that a particular device has normal payment, manual entry or refund enabled. See [[adyen-payment-terminals]].

The separate [[source-adyen-docs-point-of-sale-user-manuals-terminal-deprecation]] table lists VX675 with **29 March 2024** under “No more transactions” (that page's raw lines 32–34). The old menu instructions and example flow do not establish current VX675 support, card-data handling approval, authorization, refund completion or settlement.

## Key takeaways

- **Menu access:** The guide says to press the illustrated VX675 key with **8** and enter the device-unlock PIN. The image in pinned raw line 22 identifies the key; its filename should not be used as a guessed button label. See pinned raw lines 18–26.
- **Conditional options:** Depending on merchant configuration, the menu can include Normal payment, which opens an amount-entry screen, and Manual entry payment, which opens a payment screen. After an amount is entered for the latter, the page shows an illustrated keypress and a prompt for PAN followed by card expiry. It then says the transaction follows the normal flow; this is not a result or guarantee of approval. See pinned raw lines 26–35.
- **Refund navigation:** The guide says the menu also includes a refund option and links a separate VX675 refund guide. This page contains no refund procedure or refund outcome. See pinned raw line 37.
