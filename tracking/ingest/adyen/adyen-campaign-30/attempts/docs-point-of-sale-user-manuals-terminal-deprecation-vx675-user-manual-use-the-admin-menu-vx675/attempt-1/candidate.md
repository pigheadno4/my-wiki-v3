## Overview

This 2019-modified, 2026-09-15-captured [[adyen]] VX675 manual page describes entering the terminal's PIN-protected Admin menu. It lists network settings, the installer, merchant-menu configuration editing/removal and maintenance calls, plus totals printing/reset. It is a historical access guide, not evidence that any listed action occurred or that the VX675 is currently supported. The separately captured [[source-adyen-docs-point-of-sale-user-manuals-terminal-deprecation|eVo deprecation table]] lists VX675 under **29 March 2024 "No more transactions"**. See [[adyen-payment-terminals]].

## Key takeaways

- **Access:** The guide says to press `9` and an illustrated terminal key **at the same time**, then enter the Admin-menu PIN. If the PIN is unknown, it points to separate POS Troubleshooting documentation. The pictured key is not named in text; use the raw illustration for physical identification rather than the image filename. See pinned raw lines 20–22.
- **Consequential menu purposes:** The merchant menu is named for editing or removing configurations and making maintenance calls; the totals menu is named for printing and resetting totals. This page gives no procedure or outcome for removal or reset. Opening the Admin menu is separate from executing either action. See pinned raw lines 16 and 20–22.
- **Historical boundary:** This is a VX675-specific archived menu route. Neither menu appearance nor a PIN entry proves current device eligibility, boarding, payment acceptance or settlement; the separate eVo table supplies the dated transaction cutoff.
