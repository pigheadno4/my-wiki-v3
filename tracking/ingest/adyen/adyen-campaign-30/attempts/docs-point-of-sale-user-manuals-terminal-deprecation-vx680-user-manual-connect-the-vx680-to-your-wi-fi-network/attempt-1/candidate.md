## Overview

This [[adyen]] VX680 manual page, last modified 2019-05-27 and captured 2026-09-15 under terminal deprecation, describes connecting that physical terminal to Wi-Fi for communication with Adyen's platform and merchant back-end systems. It is a historical setup procedure, not evidence of an observed connection, successful boarding, current network-security suitability, or payment readiness. Adyen's related [[source-adyen-docs-point-of-sale-user-manuals-terminal-deprecation]] table lists VX680 **"No more transactions" on 29 March 2024; the older setup wording does not override that dated cutoff. See [[adyen-payment-terminals]].

## Key takeaways

- The guide first calls for a fully charged VX680, describing a powered USB cable and an LED that remains lit. To open the Admin menu it shows an **illustrated key plus 9**; the key symbol is image-only in the raw and is not named here. Enter the Admin PIN, except that the page says no PIN is required if the terminal is not yet boarded. An unknown PIN is routed to POS Troubleshooting. See raw lines 20–29.
- In the Admin menu, select **1. Network → 2. Wi-Fi → 2. Networks**, then scan or manually add a network. The scan branch says to select the network and enter its wireless password; the terminal is expected to connect, set it as default, and then leave the menu to begin boarding. This is the manual's expected sequence, not evidence that boarding completed. See raw lines 31–49.
- The manual-add branch asks for SSID, authentication choice **WPA/WPA-2**, wireless-security choice **TKIP/CCMP**, and password; the guide says the network becomes default. These are choices displayed in this dated VX680 guide, not a recommendation that those options satisfy current network policy. The raw's final image/button markup is malformed, so consult the raw for that control rather than inferring a label. See raw lines 51–60.
