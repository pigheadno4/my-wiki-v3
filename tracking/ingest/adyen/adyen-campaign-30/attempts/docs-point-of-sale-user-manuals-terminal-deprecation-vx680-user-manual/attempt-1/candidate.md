## Overview

This [[adyen]] **VX680** payment-terminal manual overview was last modified **2021-03-25** and captured 2026-09-15. It says new VX680 terminals cannot be ordered and gives a short quickstart with linked procedures for paper, device security inspection, Wi-Fi and boarding. The separate [[source-adyen-docs-point-of-sale-user-manuals-terminal-deprecation|eVo deprecation schedule]] lists VX680 **“No more transactions” on 29 March 2024** (that source's raw line 34). This is a historical model guide in [[adyen-payment-terminals]], not current VX680 transaction or PCI-eligibility guidance.

## Key takeaways

- The overview explicitly says **new terminals of this type cannot be ordered** (raw line 19). Its following “new terminal” quickstart wording (raw line 27) is legacy setup framing, not a reversal of that restriction or the later transaction cutoff.
- An **exclamation at the top bar** means the terminal holds data it failed to synchronize with the Adyen payments platform because it lacks an outgoing internet connection (raw line 23). The page does not say that data was later synchronized or that a payment, refund or settlement succeeded.
- The quickstart lists charging, paper-roll installation, device security inspection, Wi-Fi connection and boarding (raw lines 25–33). These are separate steps or linked child guides; the overview reports no completed inspection, network connection or boarding.
- The provided-component list names a VX680 PED, charging cradle, power supply, battery and one paper roll (raw lines 35–41). It is a page list, not confirmation of any particular shipment's contents or condition.
