## Overview

This 2021-modified, 2026-09-15-captured [[adyen]] VX675 user-manual hub routes readers to charging, security inspection, paper-roll installation, wireless networking and boarding guides. It explicitly says new terminals of this type cannot be ordered. Although its quickstart calls the device a "new terminal," that wording is historical: the separately captured [[source-adyen-docs-point-of-sale-user-manuals-terminal-deprecation|eVo deprecation table]] gives VX675 a **29 March 2024 "No more transactions"** date. This page is navigation for [[adyen-payment-terminals]], not proof of current device support, boarding or payment execution.

## Key takeaways

- **Quickstart route:** The linked topics are charging, device security inspection, paper-roll installation, wireless-network connection and terminal boarding. This page lists those topics but does not itself provide their procedures or prove they succeeded. See pinned raw lines 23–31.
- **Model and lifecycle boundary:** The page says no new VX675 terminal orders and links to the eVo deprecation page (raw line 19). The quickstart's "new terminal" phrasing (raw line 25) does not override the no-order notice or the deprecation table's VX675 "No more transactions" date. The dated table is a separate page; it does not show an individual terminal's state.
- **Supplied components:** The list names the VX675 terminal, EU power cord/plug and two Adyen receipt rolls; configuration, network state and operational readiness are not asserted. See pinned raw lines 33–39.
