## Overview

This 2019-modified, 2026-09-15-captured [[adyen]] **VX820 Duet** manual page describes the terminal's Quick Info display for viewing network and device identifiers. It belongs to the deprecated-terminal manual subtree and does not establish current connectivity, boarding or payment readiness. The separately captured [[source-adyen-docs-point-of-sale-user-manuals-terminal-deprecation|eVo deprecation table]] lists VX820 Duet under **29 March 2024 "No more transactions"**. See [[adyen-payment-terminals]].

## Key takeaways

- **Menu access:** The page says to press a pictured terminal key and `5` at the same time. The key is shown as an image; identify it from the raw illustration, not an inferred label from its filename. This page states no PIN or user-role step, so it establishes neither a required credential nor unrestricted access. See pinned raw lines 19–23.
- **Displayed fields:** The guide lists IP address, terminal ID and software version. It also says the displayed QR code encodes IP address, MAC address, network name, store name, merchant account name and terminal ID. These are listed field types, not observed values for a particular VX820 Duet. See pinned raw lines 25–30.
- **Outcome boundary:** An information display is not a connection test or boarding result. It gives no transaction, reconciliation or settlement evidence, and the separate model cutoff limits any present-day payment inference.
