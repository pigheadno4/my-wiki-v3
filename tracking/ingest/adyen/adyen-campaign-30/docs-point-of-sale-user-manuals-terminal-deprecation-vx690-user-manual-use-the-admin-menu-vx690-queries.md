# C30 VX690 Admin-menu retrieval checks

## Q1 — Main purpose and prerequisites

**Question:** How does the historical VX690 page say to open the Admin menu, and what does it list the menu for?

**Answer:** It says to press **9 and the illustrated key simultaneously**, then enter the Admin-menu PIN; if that code is unknown, follow its POS troubleshooting link (pinned raw lines 20–21). The image has no text key label in the raw. The menu is listed for network settings, installer use, merchant-menu configuration edits/removal and maintenance calls, and totals printing/reset (line 16). **Answer:** No. Removal and reset are listed purposes (pinned raw line 16); the only shown endpoint is that the terminal displays the Admin menu after the shortcut and PIN (lines 20–22). No selected action or outcome is recorded. This 2019-modified page sits in the deprecation tree (raw lines 1–10), and the separate eVo table lists VX690 with a historical **29 March 2024** “No more transactions” date (deprecation raw lines 32–35).
