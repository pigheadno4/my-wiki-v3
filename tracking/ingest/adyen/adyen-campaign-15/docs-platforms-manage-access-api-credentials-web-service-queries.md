Q2. What are the central credential capabilities, prerequisites and warnings?
A. Adyen for Platforms integration plus a Customer Area Manage API credentials or Merchant admin role precede setup. Default or additional web service/LEM credentials are configured at company-account scope, with separate API families and role permissions; web service credentials require at least one enabled role. Live credentials/keys are created in live Customer Area. Keys must be stored securely and are not recopied after leaving the page; a new API key is immediately active with a 24-hour prior-key overlap, adjustable to a fresh 24 hours or immediate expiry. A new basic-auth password invalidates its predecessor immediately. Credentials cannot be deleted; deactivation prevents key use. None of these steps proves a granted resource permission, verified account holder or financial result.
