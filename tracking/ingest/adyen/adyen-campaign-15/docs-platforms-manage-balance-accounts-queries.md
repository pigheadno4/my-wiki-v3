## Q1. What is this page for, what scope does it cover, and what should a reader not infer?

**Expected answer:** It documents Adyen for Platforms Configuration API and Customer Area operations on a platform user's balance account: create, view, description update and permanent close. The account is linked to an account holder and is part of wider onboarding/verification. It is not the account holder or legal entity, not automatically a platform liable/reserve account, and not the bank-account transfer instrument. ## Q2. What central capabilities, prerequisites, and warnings does it give?

**Expected answer:** POST `/balanceAccounts` uses `accountHolderId` and returns a balance-account ID for later operations. Customer Area views one balance platform at a time; API GET can list an account holder's balance accounts (paginated), retrieve balances, or list associated payment-instrument **cards**. PATCH `/balanceAccounts/{id}` illustrates a description update. To permanently close, first ensure zero balance, separately pay out or internally transfer remaining funds, then set status `Closed`; account-holder deactivation is a separate path.
