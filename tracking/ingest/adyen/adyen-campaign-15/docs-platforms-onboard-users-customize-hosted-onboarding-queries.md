## Q2. What is the central capability, prerequisites, and material warnings?

Customer Area theme creation/editing requires Manage hosted onboarding themes and either Balance platform admin or base role; API-initiated hosted onboarding requires Legal Entity Management API credentials. A theme controls logo/header/background/tab/external-link and optional invitation-email appearance. Save yields a theme ID for onboardingLinks; Onboarding on Invite also requires Apply for invites and the hosted page. The onboardingLinks request controls locale and selected actions through settings: country selection is conditioned on editPrefilledCountry; other settings govern bank format, cross-border account choice, entity type/country editing, age gate, instant-bank-verification UI, PCI-signing flags, transfer-instrument limit and debug UI. Browser language defaults with en-US fallback. Test credentials are for test only. Debug UI defaults enabled, is intended for support/engineering, and its report has sensitive legal-entity/task data to share minimally. The dated PCI-setting descriptions have mixed required/allow wording; no compliance or verification outcome follows.
