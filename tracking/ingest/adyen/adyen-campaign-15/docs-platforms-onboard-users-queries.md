## Q2. What is the central capability, prerequisites, and material warnings?

Hosted onboarding directs users to Adyen's UI. Invite uses a Customer Area request for an account holder and Adyen-created resources, followed by a Customer Area/SMS link or the View Verification Status component; API-initiated hosted onboarding requires Legal Entity Management and Configuration API integration, resource/link creation and redirect. LEM-generated links require relevant PCI-questionnaire settings and a server to receive verification updates. API-only onboarding collects user data in the platform UI and submits it through those APIs; the optional component can create a resource. Legal-entity type/country determine required data; verification starts after receipt, and invite payment methods/stores await allowed receivePayments after verification. Trusts are hosted only in Australia/New Zealand in this snapshot; instant bank verification is location/entity-specific; ID autofill and decision-maker features require onboarding v3/v4, and autofill supports Latin-character IDs. An invitation is not completed verification; dated country/method lists and onboarding work do not establish current approval or compliance.
