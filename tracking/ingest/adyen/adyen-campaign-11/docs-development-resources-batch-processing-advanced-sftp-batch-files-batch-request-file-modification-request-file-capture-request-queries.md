## Q2. What central capability or process does it describe, with prerequisites and warnings?

A capture request must include the `Capture` `SL` record. The table marks all seven positions required: `SL`, line number, `Capture`, **original payment PSP reference**, numeric requested amount, numeric currency exponent, and three-character ISO currency code (`raw/adyen/docs/development-resources/batch-processing/advanced-sftp-batch-files/batch-request-file/modification-request-file/capture-request/2026-09-15.md:20-34`). The page gives an optional airline-data child route but no airline field schema here (`raw/adyen/docs/development-resources/batch-processing/advanced-sftp-batch-files/batch-request-file/modification-request-file/capture-request/2026-09-15.md:16`). Its example uses a `TEST` `Modification` file with `SL,1,Capture,9145754231690158,100,2,EUR` (`raw/adyen/docs/development-resources/batch-processing/advanced-sftp-batch-files/batch-request-file/modification-request-file/capture-request/2026-09-15.md:36-43`); those values illustrate a request, not a guaranteed or completed capture. A later modification PSP reference and eventual financial outcome require separate evidence.
