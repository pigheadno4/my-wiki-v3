# Retrieval checks — SFTP Cancel request

## Q1. What is this page for, what is its scope, and what must a reader not infer?

This historical Adyen page gives the `Cancel` sub-line format for an SFTP batch payment-cancellation **request** (`raw/adyen/docs/development-resources/batch-processing/advanced-sftp-batch-files/batch-request-file/modification-request-file/cancel-request/2026-09-15.md:14-30`). It was last modified 2019-04-30 and captured 2026-09-15. The `TEST` file is a positional example, not a submitted or accepted transaction (`raw/adyen/docs/development-resources/batch-processing/advanced-sftp-batch-files/batch-request-file/modification-request-file/cancel-request/2026-09-15.md:32-39`). The page does not establish whether a particular payment is eligible to cancel, whether a batch passed validation, whether the cancel modification succeeded, or whether any funds outcome changed.

## Q2. What central capability or process does it describe, with prerequisites and warnings?

A cancellation request must include the `Cancel` `SL`. Its four marked-required fields are `SL`, the sequential sub-line number, fixed `Cancel` type, and **original payment PSP reference** (`raw/adyen/docs/development-resources/batch-processing/advanced-sftp-batch-files/batch-request-file/modification-request-file/cancel-request/2026-09-15.md:18-30`). The page expressly forbids **partial cancellation modifications** and provides no amount or currency field (`raw/adyen/docs/development-resources/batch-processing/advanced-sftp-batch-files/batch-request-file/modification-request-file/cancel-request/2026-09-15.md:22-30`). The sample `TEST` `Modification` file pairs a parent `L` merchant reference with a separate `SL` original-payment PSP reference (`raw/adyen/docs/development-resources/batch-processing/advanced-sftp-batch-files/batch-request-file/modification-request-file/cancel-request/2026-09-15.md:32-39`). Sending such a request, receiving an ACK, seeing a result row, and observing financial finality are distinct stages; this page specifies only the request fields.
