Q2. What sub-lines and fields are described, and what warnings prevent treating examples as a live template? Route to the same source and pinned raw `### PaymentDetails`, `### Card`, `### IBAN`, and `### Address`; route separately to `[[source-adyen-docs-development-resources-batch-processing-advanced-sftp-batch-files]]` for SFTP/PGP transport. `PaymentDetails` plus Card or IBAN is mandatory; the PaymentDetails table distinguishes required field positions from required values. Card lists PAN/expiry/CVC/name; IBAN lists required owner name/country/IBAN and optional BIC; Address is optional. The amount is numeric with a separate exponent field, with no explicit unit conversion rule here. The shortened PaymentDetails examples misalign with table positions, and the Card sample omits a separate required CVC position; card data requires the related transport protection.
