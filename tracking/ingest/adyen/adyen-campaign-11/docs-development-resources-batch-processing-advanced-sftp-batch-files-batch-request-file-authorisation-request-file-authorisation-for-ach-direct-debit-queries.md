# Retrieval checks — ACH Direct Debit batch authorisation request

## Q1. What is this page for, what is its scope, and what must a reader not infer?

This dated Adyen SFTP batch reference describes sub-line fields for a **bank-transfer or ACH Direct Debit authorisation request**, not an executed debit. It names `PaymentDetails`, `BankAccount`, and `Address` as mandatory (`raw/adyen/docs/development-resources/batch-processing/advanced-sftp-batch-files/batch-request-file/authorisation-request-file/authorisation-for-ach-direct-debit/2026-09-15.md:14-18`) and then provides field tables and a sample (`raw/adyen/docs/development-resources/batch-processing/advanced-sftp-batch-files/batch-request-file/authorisation-request-file/authorisation-for-ach-direct-debit/2026-09-15.md:20-83`). It was last modified 2019-04-30 and captured 2026-09-15. The request schema supplies no evidence of a shopper's ACH consent or mandate, batch acceptance, issuer/bank approval, debit completion, settlement, or a real payment outcome.

## Q2. What central capability or process does it describe, with prerequisites and warnings?

For `PaymentDetails`, the table marks amount, currency exponent and three-character ISO currency code required; a shopper reference is table-optional but required for recurring payments/contracts, and blank optional positions still need commas (`raw/adyen/docs/development-resources/batch-processing/advanced-sftp-batch-files/batch-request-file/authorisation-request-file/authorisation-for-ach-direct-debit/2026-09-15.md:20-38`). The required `BankAccount` sub-line is position 2, with owner name, two-letter country code, account number and ABA routing/branch number; the page warns invalid country codes cause request/transaction rejection (`raw/adyen/docs/development-resources/batch-processing/advanced-sftp-batch-files/batch-request-file/authorisation-request-file/authorisation-for-ach-direct-debit/2026-09-15.md:40-53`). The `Address` text says to use separate billing and delivery sub-lines, yet the sample shows only Billing (`raw/adyen/docs/development-resources/batch-processing/advanced-sftp-batch-files/batch-request-file/authorisation-request-file/authorisation-for-ach-direct-debit/2026-09-15.md:55-83`). The bank-owner table says `AA`/two-letter format while the sample has `Adyen Inc` (`raw/adyen/docs/development-resources/batch-processing/advanced-sftp-batch-files/batch-request-file/authorisation-request-file/authorisation-for-ach-direct-debit/2026-09-15.md:50,77-82`). Preserve those table/example conflicts and verify actual accepted input independently; the sample cannot settle requiredness.
