Q1: What is this page for, what scope does it cover, and what must it not prove?
A: It is a dated Adyen SFTP Modification request-file sub-line schema for a `Refund` operation. It defines required fields and a TEST example, not ACK acceptance, refund success/failure, final shopper credit, partial-refund eligibility, or retry safety. Q2: Which reference and monetary fields are required, and what partial-refund warning applies?
A: The mandatory `Refund` `SL` has fixed `SL` and `Refund` positions with sequential counter, then original payment PSP reference at field 4, numeric amount at field 5, currency exponent at field 6, and three-character ISO currency at field 7. The example `123,2,EUR` is only sample field placement. This page does not state partial-eligibility limits, capture prerequisites, or a standalone minor-unit conversion rule; consult general refund guidance and result evidence for those.
