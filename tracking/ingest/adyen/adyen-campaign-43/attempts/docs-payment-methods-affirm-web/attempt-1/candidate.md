## Overview

A short **Web integration chooser** for Affirm. It offers [Affirm Web Drop-in](https://docs.adyen.com/payment-methods/affirm/web-drop-in) as an all-in-one UI route and [Affirm Web Components](https://docs.adyen.com/payment-methods/affirm/web-component) as a pre-built Component route. It also links the general Web Drop-in and Components guides. [[adyen]] [[adyen-online-payments]]

## Key takeaways

- This page describes integration choices for a **website**; it does not state financing terms, shopper or merchant eligibility, regional/currency availability, request fields, SDK versions, redirect outcome, capture/refund rules or live-testing requirements. Follow the selected child and base integration guides for those details. The route labels are navigation, not proof of a configured or successful payment. See raw lines 15–29.
