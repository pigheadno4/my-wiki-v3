## Overview

This 2026-09-15 Bancontact Card for iOS page is an integration chooser. It links card-specific iOS Drop-in and Components child guides and base iOS Sessions Drop-in/Components guides. It is a navigation page, not a Bancontact Mobile app-switch guide or proof of request fields, SDK requirements, 3DS handling or payment success. See [[adyen]], [[adyen-online-payments]] and [[source-adyen-docs-payment-methods-bancontact|the broader Bancontact overview]].

## Key takeaways

- Choose the Bancontact Card iOS Drop-in child for an all-in-one UI or the Bancontact Card iOS Components child for a prebuilt Component. These child links carry the method-specific implementation details; the parent page supplies no code or request examples.
- The only base integration links shown here are iOS Sessions-flow Drop-in and Components. This does not state that an Advanced flow is unsupported; the page simply does not describe or link one. It also does not conflate the card path with Bancontact Mobile.
