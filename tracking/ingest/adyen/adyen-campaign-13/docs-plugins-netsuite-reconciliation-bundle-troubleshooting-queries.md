# Fixed queries — docs-plugins-netsuite-reconciliation-bundle-troubleshooting

## Q1 — purpose, scope, and what not to infer

**Question:** What does the NetSuite reconciliation troubleshooting page diagnose, and does a resolved SDR or Bank Deposit prove funds reached the bank?

**Expected answer:** It diagnoses SDR-to-NetSuite matching exceptions and later NetSuite Bank Deposit creation errors in the reconciliation bundle. An unmatched SDR line has Exceptions Need Resolving / Match Not Found; deposit creation is a separate subsequent stage. The troubleshooting steps operate on NetSuite matching and accounting records. Neither a resolved exception nor a Bank Deposit record is proof of receiving-bank credit or completed financial reconciliation. ## Q2 — central capability, prerequisites, and warnings

**Question:** Which checks apply to match exceptions versus deposit errors, and when is manual reprocessing described?

**Expected answer:** First confirm bundle setup. For Match Not Found, inspect the Adyen - Find SDR Detail Matches execution log and search filters; if the log shows a needed event type/status is missing, update the saved search in the Settlement Type Map and use Rematch Transactions for the SDR. The linked initial bundle setup says to leave saved searches at their defaults during mapping; this is a condition-specific troubleshooting edit, not a change to the normal setup instruction. For Error Creating Deposit, inspect whether the transaction was already deposited, absent from Undeposited Funds, or duplicated in the Bank Deposit record (including multi-method cash-sale examples). Manual scripts are described only if the Adyen SDR already exists, via the Bank Deposit Rec Control Panel. Neither this page nor the linked setup guide documents safe replay or deduplication for repeat Rematch Transactions, manual scripts, or deposit creation; inspect the specific SDR and Bank Deposit state before rerunning, without assuming a retry will duplicate records. Check customizations and release notes, then provide merchant account, environment, reproduction, logs and settings to Support if unresolved. This page does not give initial SDR profile/currency setup or permission roles; consult the linked bundle setup guide.
