## Q2 — Which permissions, capture setting and webhook conditions does the page specify?

After the get-started prerequisite, create and securely store an API credential Basic authentication password, ask Support to enable **API PCI Payments**, ensure **Checkout webservice** and **Merchant PAL Webservice**, and associate the correct merchant accounts with that web service user (raw lines 19–40). For NetSuite Cash Sales the guide says keep the immediate-capture default; for Sales Orders choose `manual` capture delay at merchant-account level (lines 42–51). Webhooks are NetSuite notifications for payment-status/chargeback events, with company-account configuration recommended, merchant-account inclusion/exclusion options, a NetSuite payment-profile postback URL, JSON and TLS 1.2 (lines 53–84). The API Basic password is not a documented webhook credential; this page gives no HMAC setup or proof of delivery/processing. Subsequent NetSuite Customer Center and payment-flow guides own further steps (lines 86–94). Use the proposed concept→source→raw route.
