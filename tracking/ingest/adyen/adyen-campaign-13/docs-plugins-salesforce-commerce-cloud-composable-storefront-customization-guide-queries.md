## Q2. What is the central capability, prerequisites, and material warnings?

The guide's central capability is overriding package defaults without editing the npm package itself: document modular customizations; pass front-end changes through `AdyenCheckoutProvider` for styling, `paymentMethodsConfiguration`, localization and optional `beforeSubmit`/`onSubmit` callbacks (raw lines 19–46). Server customization uses controller arrays; the raw's first path `ovverrides/app/ssr.js` at line 52 conflicts with `overrides/app/ssr.js` at line 70, so verify the actual package path. After webhook setup, `AUTHORISATION` is the default handler; other event/order flows require extending the webhook controller (lines 61–70). The example preserves `authenticate`, `validateHmac` and `parseNotification` before a custom handler (lines 73–88), then points to the B2C Orders API for order/payment/export status updates (line 90). Salesforce OMS has no pre-built package integration and needs custom ready-for-export synchronization (line 92). These extensions and statuses do not prove successful payment, export or settlement.
