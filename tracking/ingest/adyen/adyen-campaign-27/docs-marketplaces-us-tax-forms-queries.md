# Query proposal — docs-marketplaces-us-tax-forms

Q1. For whom does this Marketplace page describe 1099-K filing, and how can forms be retrieved?
Answer: It scopes Adyen's stated filing to **US-based users Adyen pays out directly** (raw line 21). It says prior-year forms become available in January and can be retrieved through Customer Area or API for PDF distribution (lines 30-34). Customer Area requires the Download tax form role plus Balance platform admin/base (lines 36-50); API retrieval for tax year 2022 onward needs a Balance Platform API key and Download Tax Form via Tax Api role, then `GET /accountHolders/{id}/taxForms` with required formType/year (lines 52-82). Q2. Is the 2025 threshold or the title's 1099-NEC coverage an unambiguous current filing rule?
Answer: No. For tax year **2025**, line 24 says USD 20,000 gross volume **and** 200 transactions, but line 34 says volume **or** transaction threshold; state thresholds may vary (line 24). Gross is before fees/refunds/chargebacks and TopUp splits are excluded (lines 26-28). The title/description mention 1099-NEC (lines 6-7, 15-17), but body procedures specify `US1099k` only (lines 65-71). This dated page does not resolve the conflict or establish current law, filing or delivery.
