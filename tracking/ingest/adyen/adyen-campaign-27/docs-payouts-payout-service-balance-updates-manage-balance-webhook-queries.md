Q1. How are Payout Service Balance webhook settings managed?
A1. This pilot guide uses Configuration API GET list/detail by balance-platform and webhook IDs plus setting ID, PATCH to update type/target/currency/status/conditions, and DELETE to permanently remove a setting (raw lines 19–28, 81–147, 247–263). Q2. Which edit widens notification coverage, and what sample caveat matters?
A2. PATCH must resend conditions to keep; removing the sole condition causes alerts for all target-account balance changes, while inactive suppresses and DELETE permanently removes the setting (raw lines 155–195, 224–249). GET sample setting BWHS...01 targets balancePlatform, whereas PATCH-add sample reuses ID with balanceAccount target (raw lines 102–118, 161–185), so do not assume the sample preserves scope. Bare -d in GET/DELETE curls is not copy-ready (33–38, 92–97, 258–263). These settings do not prove fund movement.
