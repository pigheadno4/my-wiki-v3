# Fixed retrieval checks: terminal hardware tests

1. **Q:** Which physical components does this Adyen guide test, and how should an operator interpret a red or green circle? **A:** It covers chip reader, magnetic-swipe reader, NFC antenna and a keypad only on models with a physical keypad, for non-legacy Adyen terminals in Terminal API or standalone setups. Open Hardware diagnostics, run the chosen test, then read the result; a circle shown before running it can be the previous result. Green means the tested component passed the guide's check; red means that test failed, and a confidently performed failed test should be reported to Support. A component result does not certify the whole terminal, tamper state, network or payment processing. 2. **Q:** What does **Report issue** do during a frozen hardware test, and what does sending a diagnostic report do? **A:** During an unresponsive test, **Report issue** logs the issue, stops that test and returns to the menu; it is not a payment-cancel action. Separately, **Diagnostic report > Send report** creates a terminal log file and sends it to Adyen; the terminal blocks another report for five minutes. Test results also enter the terminal log and are sent during the automatic maintenance call. None of these actions proves Adyen repaired the unit or that payments succeed. This page does not document battery, printer or scanner tests.
