# C07 gift-card balance inquiry — fixed query answers

1. **Does a successful balance inquiry pay for the purchase?** No. The guide uses a Terminal API `Service` / `BalanceInquiry` request to check an activated gift card before a transaction. Its `BalanceInquiryResponse` example reports `Result: Success`, `CurrentBalance: 98.75` and `Currency: GBP`, describing a balance-query result. Payment is a separate Terminal API operation; the example gives no authorization, capture, settlement or replay guarantee. Evidence: `raw/adyen/docs/point-of-sale/alternative-payment-methods/gift-cards-terminal-api/query-the-balance/2026-09-15.md`, opening line 19, request lines 40–63, response lines 150–183 and `## See also` line 190; proposed source `[[source-adyen-docs-point-of-sale-alternative-payment-methods-gift-cards-terminal-api-query-the-balance]]`.

2. **How do scan and swipe/manual entry differ for a gift-card balance query?** Scan first, then send a request with `EntryMode: Scanned`, card number in `StoredValueID`, and `ExpiryDate`. For swipe or manual keyed entry, send the request before card presentation so the terminal prompts the shopper; include `EntryMode: MagStripe` or `Keyed` and include `StoredValueID` without providing a value. The gift-card method must be enabled on the Adyen account and the provider onboarding completed. The guide lists an optional SVS secondary security code; it does not establish a universal PIN requirement.
