# C07 S1U2 user manual — fixed retrieval checks

1. **Q: What must happen before an S1U2 unattended terminal can board, and what should the installer do if the delivery inspection fails?**
   **A:** Assign the unattended terminal to its store before boarding. The installer checks intact packaging/tamper tape, reconciles the box, Customer Area and terminal serial numbers, and inspects for tampering. If any check fails, the manual says to contact Adyen Support immediately. The boarding screen then shows the assigned store for confirmation. This dated procedure is not proof that a device has boarded or processed a payment.

2. **Q: Does the manual guarantee cellular service, and which menu actions require protected access or affect installed apps or transaction totals?**
   **A:** It describes a pre-installed eSIM and 3G/4G failover, but warns that a terminal boarded before 2022 may have an inactive eSIM if no SIM subscription was set up then; contact Support if uncertain. Software update requires the Admin & Settings passcode and reboots the terminal. The menu table puts Apps, Configuration, Network, software-version update and Power behind that passcode; Transactions and Refunds have their own passcodes. Opening Apps performs a scheduled install/removal, and Totals can reset transaction totals. The guide does not call that a factory reset or prove SIM activation or payment availability.
