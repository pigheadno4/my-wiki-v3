# C07 SFO1 terminal manual — fixed retrieval checks

1. **Q: What must an operator do before using a new SFO1, and how is it boarded to a store?**
   **A:** The dated manual calls for checking that the box is unopened, matching the terminal serial number to the box, and inspecting for tampering regardless of Customer Area access; if that access is available, the box serial number and carrier delivery are also checked against the order; a failed check requires immediate Adyen Support contact. After powering and networking, the operator either enters the Customer Area one-time password or chooses **Board the terminal**, selects a store, and confirms. Boarding can take up to 30 minutes; an absent boarding option may require waiting for the next platform sync (stated average three hours). 2. **Q: Do successful SFO1 connection diagnostics or the eSIM description prove a payment or continuous network availability? Which menu effects need care?**
   **A:** No. PSP connection, Terminal API and Endpoints are point-in-time checks; the manual describes eSIM cellular failover but does not guarantee ongoing coverage. Its protected **Transactions → Totals** menu can reset totals, while the separate Configuration, Network, Software and Power menus require an Admin & Settings passcode. The menu table also places Device info without a passcode and describes a software-version update there, so the manual does not establish one passcode rule for every update path. The original power adapter matters for NFC operation.
