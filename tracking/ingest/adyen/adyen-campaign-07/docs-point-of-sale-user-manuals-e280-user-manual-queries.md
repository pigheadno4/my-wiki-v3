# C07 e280 manual — fixed query answers

1. **Can a merchant newly order an e280, and what power hardware does its manual specify?** In the 2026-09-15 capture, Adyen marks e280 discontinued and unavailable for new orders, recommending AMS1 instead. The e280 package includes a USB cable but no charger; the manual specifies a 5V DC, 1A charger and says the battery cannot be replaced. This dated manual does not establish present inventory or certification. Evidence: `raw/adyen/docs/point-of-sale/user-manuals/e280-user-manual/2026-09-15.md`, opening and `### Supplied components`, lines 15–44; proposed source `[[source-adyen-docs-point-of-sale-user-manuals-e280-user-manual]]`.

2. **What should staff do if the e280 Board option is missing or a tamper check fails?** The manual says to wait for the next platform synchronization, averaging three hours, and retry when Board is absent. A failed shipping, serial-number or physical tamper check calls for immediate Adyen Support contact. The setup then calls for distinct PSP platform, Terminal API and four-URL Endpoints diagnostics; a successful connection test at that moment does not establish that any payment was authorized. Evidence: `raw/adyen/docs/point-of-sale/user-manuals/e280-user-manual/2026-09-15.md`, `## Get started` lines 46–64, `## Inspect the terminal` lines 66–81, and diagnostic sections lines 112–130; proposed source `[[source-adyen-docs-point-of-sale-user-manuals-e280-user-manual]]`.
