# Fixed retrieval checks: classic-library deprecation

1. **Q:** For a merchant with a classic library embedded in cash-register software, what migration path and library deadline does this Adyen notice state? **A:** The 2026-09-15 raw snapshot says Adyen is deprecating embedded classic POS libraries and presents Terminal API as the general replacement. Its timeline says no new library integrations from January 1, 2022, POS partners ready for migration and no new merchants onboarded to a library in 2022, then end of support and maintenance on March 29, 2024. It directs anyone needing classic-library transaction processing after that date to their Adyen Account Manager. An Xstore POS integration using the JNI library is an explicit exception: the notice offers OPI, using XML request/response messaging, instead of Terminal API. These dated statements do not prove today's account-specific processing state. [Raw lines 19–25, 49, 71–77](/Users/tengtao/Development/wiki-v2/raw/adyen/docs/point-of-sale/classic-library-deprecation/2026-09-15.md).

2. **Q:** Does migrating the POS library alone address the eVo terminal deadline, and what does the notice say for PCI 3 and PCI 4 eVo devices? **A:** No. The notice separately calls for replacement of Verifone Verix/eVo fleets, points to Verifone Engage/VOS alternatives, and names expiring PCI approval plus ended Verifone support/repair as reasons. PCI 4 eVo e355 and VX690 have a listed April 2023 PCI expiry; PCI 3 eVo e315, MX925, VX675, VX680, VX820, and VX820 Duet have a listed April 30, 2021 expiry. Both groups have a March 31, 2023 repair-service end and a March 29, 2024 end of support when transactions are stated to be no longer allowed. These are historical notice claims; verify current hardware and account conditions before acting. [Raw lines 51–69, 79–91](/Users/tengtao/Development/wiki-v2/raw/adyen/docs/point-of-sale/classic-library-deprecation/2026-09-15.md).
