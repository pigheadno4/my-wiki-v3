# C07 M450 user manual — fixed retrieval checks

1. **Q: What M450 placement, inspection and first-store setup conditions are documented?**
   **A:** It is an Adyen payment terminal. Before use, check tamper-evident packing tape, match order/box/device serial numbers where Customer Area access exists, inspect for physical tampering, and contact Support immediately if any check fails. Keep it at least 30.5 cm (12 inches) from an electronic security tag deactivator because interference can freeze the terminal; the manual also routes an NFC-reader failure to that placement check. First setup includes power and a four-hour charge, language/network selection and confirmation or correction of the shown store. If the store screen is absent, wait for the next synchronization (on average three hours) and retry. 2. **Q: How does the M450 manual separate network diagnostics, protected controls and support access?**
   **A:** Ethernet uses one of the documented dongles (PoE splitter power comes through Ethernet), or the terminal can use Wi-Fi; changing Wi-Fi later requires the Network-menu passcode. PSP connection tests platform connectivity; Terminal API and Endpoints are separate POS-route checks. Their Successful statuses establish the result of those tests at that time, not a completed payment. Admin & Settings protects Apps, Configuration, Network, software-version and Power; Transactions protects History, Totals and New transaction; Refunds additionally protects a new refund. The standalone Payment button needs no passcode. Remote support requires the operator to select Start session and enter a passcode, enabling screen view and interaction.
