# Fixed retrieval checks: Brazil meal vouchers

1. **Q:** Can a Brazilian PAT meal voucher be used with a standalone Adyen terminal and with a merchant's own POS UI, and what must be enabled? **A:** The guide says standalone terminals support only the Adyen UI flow; POS-integrated terminals can use Adyen UI or a merchant UI. Support must enable meal-voucher functionality for the merchant account, and separately enable Adyen UI at the chosen company, merchant, store, or terminal scope. The guide specifies PCI PTS 5 LTS 1.120.11 or PCI PTS 6 LTS 1.126.5 / version 1.129 or later. A merchant UI sends a Terminal API `PaymentRequest` with Base64-encoded JSON `selectedAccountType=MEAL_VOUCHER` in `SaleData.SaleToPOIData`. This source does not prove a particular account or terminal is enabled. 2. **Q:** What makes Brazilian PAT voucher acceptance conditional, and can the guide's test cards prove the live terminal flow? **A:** The merchant needs a compatible CNAE main activity, applicable sanitary/nutritional compliance, and an MCC from the guide's Food, Culture, or Meal table; it says an incompatible main activity leads to issuer decline. Insufficient voucher balance also refuses the transaction. Its MKE test cards test integration and reconciliation handling but explicitly do not simulate the terminal voucher flow. These details and the dated source do not establish current merchant eligibility or a successful live payment.
