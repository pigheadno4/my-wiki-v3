# C07 iOS Mobile requirements — fixed query answers

1. **Can an iPad run Tap to Pay on iPhone, and what happens if staff remove the iOS device passcode?** This 2026-09-15 requirements page limits Tap to Pay on iPhone to an iPhone; the card-reader path can use an iPhone or iPad. It requires a screen-lock passcode and says that, from iOS Mobile SDK 3.18.0, `PaymentService` functions require one. Removing it prevents transactions on that device and makes prior store-and-forward offline payments made while the passcode was set unrecoverable. Evidence: `raw/adyen/docs/point-of-sale/mobile-ios/requirements/2026-09-15.md`, `### Mobile devices` lines 27–55; proposed source `[[source-adyen-docs-point-of-sale-mobile-ios-requirements]]`.

2. **What reader and software gates does the dated iOS requirements page specify?** It distinguishes PIN-capable NYC1 (Mobile SDK 3.8.0+) from NYC1-SCR (transactions without PIN), and requires an Adyen NYC1 dock/power adapter, SDK 3.9.0+, and reader firmware 3.X.00.76+ for the dock setup. The page lists iOS 18.4 as minimum for Mobile SDK functionality, Xcode 16+ for development, and Terminal API integration in the POS app. Its US reader ordering dates and Tap to Pay OS deprecation table are historical; current region, payment-method, entitlement and account gates need separate evidence. Evidence: `raw/adyen/docs/point-of-sale/mobile-ios/requirements/2026-09-15.md`, `### Card readers` through `### Dock` lines 57–79 and `## Software requirements` lines 81–115; proposed source `[[source-adyen-docs-point-of-sale-mobile-ios-requirements]]`.
