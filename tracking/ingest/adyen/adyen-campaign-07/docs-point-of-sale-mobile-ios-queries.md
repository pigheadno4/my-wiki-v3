# C07 mobile iOS overview — fixed query answers

1. **Where does the customer present a card for each iOS Mobile solution?** In the 2026-09-15 overview, Tap to Pay on iPhone uses the merchant iPhone as the payment interface, while the paired card-reader solution uses the reader for tap, insert, swipe or digital-wallet presentation. Both transactions start in the merchant iOS POS app. Evidence: `raw/adyen/docs/point-of-sale/mobile-ios/2026-09-15.md`, `# iOS Mobile solutions`, lines 19–25; proposed retrieval source `[[source-adyen-docs-point-of-sale-mobile-ios]]`.

2. **Can one iOS POS app offer both paths, and what integration does the overview require?** The paths can coexist if the POS app permits payment-interface selection. The app must integrate with Terminal API before adding Adyen's iOS Mobile SDK; the two paths share that SDK, and the reader path includes device-pairing functionality. This overview alone does not prove current device, OS, region, merchant entitlement, SDK-version or live-payment eligibility. Evidence: `raw/adyen/docs/point-of-sale/mobile-ios/2026-09-15.md`, `# iOS Mobile solutions` line 25 and `## Mobile SDK` lines 27–31; proposed retrieval source `[[source-adyen-docs-point-of-sale-mobile-ios]]`.
