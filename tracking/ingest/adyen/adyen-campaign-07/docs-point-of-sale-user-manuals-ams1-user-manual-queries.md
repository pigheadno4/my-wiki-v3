# C07 AMS1 user manual — fixed retrieval checks

1. **Q: What are the AMS1's initial inspection, store-assignment and connectivity conditions?**
   **A:** The manual treats AMS1 as an Adyen payment terminal. Inspect box tamper tape, reconcile order/box/device serial numbers where Customer Area access is available, and inspect the device; contact Support immediately if a check fails. Power and charge it for at least four hours, select language and network, then confirm or edit the displayed store. If the store screen is absent, wait for the next Adyen-platform sync (on average three hours) and retry. The guide describes Wi-Fi plus 3G/4G cellular failover with eSIM, with a possible activation exception for pre-2022 boarded terminals lacking a subscription at boarding. 2. **Q: Which AMS1 operating actions need passcodes, and what safety or data-reset limits apply?**
   **A:** Settings actions such as Apps, Configuration and Network require Admin & Settings; Transactions History, Totals and New transaction require a Transactions passcode, while a new Refund requires Refunds. Totals reset starts a new reporting period; the manual does not claim it deletes underlying transactions. Use the supplied USB-C cable and region-specific plug; for a faulty battery, dispose of it under local rules and exclude it from the returned terminal package. Support-enabled airplane mode uses the protected Network menu and disables Wi-Fi, Bluetooth and cellular while on. A remote support session requires the operator to select Start session and enter a passcode, allowing screen view/control.
