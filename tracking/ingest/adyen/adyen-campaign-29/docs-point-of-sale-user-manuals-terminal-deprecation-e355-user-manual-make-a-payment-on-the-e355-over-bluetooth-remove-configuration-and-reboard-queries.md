Q1. When may the e355 configuration-removal step be skipped, and what does the alternative action do?
A1. It may be skipped only when the terminal is already boarded and app/terminal settings match (raw line 16). Otherwise this guide says to remove current merchant configuration via Admin menu, Configuration → Erase, confirm and reboot (raw lines 18–27). That is a destructive configuration action, not a mere Bluetooth reconnection.
