# Retrieval checks

Q1. What physical steps does the historical e315 manual give for installing an iPod or iPhone?

Answer: Follow [[index]] → [[adyen-index]] → [[adyen-payment-terminals]] → [[source-adyen-docs-point-of-sale-user-manuals-terminal-deprecation-e315-user-manual-install-an-ipod-or-iphone-into-the-e315]] → [[raw/adyen/docs/point-of-sale/user-manuals/terminal-deprecation/e315-user-manual/install-an-ipod-or-iphone-into-the-e315/2026-09-15]]. Remove the screw and casing (raw lines 20–26), orient the device PIN pad down, align the iOS port to the Lightning connector, use the spacer before an iPod, then replace and screw down the casing (raw lines 28–36).
