## Overview

This [[adyen]] e355 guide, last modified in **2019** and captured 2026-09-15 under terminal-deprecation manuals, describes mechanically attaching a tablet to the e355 frame. It is a physical fitting sequence within [[adyen-payment-terminals]], not evidence of electrical connection, Bluetooth pairing, boarding or payment readiness. The separately captured [[source-adyen-docs-point-of-sale-user-manuals-terminal-deprecation|eVo/Verix deprecation schedule]] lists **29 March 2024** as the e355 “No more transactions” date.

## Key takeaways

- First detach the Removable Module by turning its locking screws counter-clockwise and sliding the Eject button right (raw line 21).
- Align the frame's Tablet Connector with the tablet's connection port when inserting the tablet (raw line 23). The page does not specify tablet models, adapter compatibility or a force/torque limit.
- Guide the Removable Module's pins back into the frame slots, then turn the locking screws clockwise to secure the tablet (raw lines 25–27).
- The page says the fit allows easy connection to the terminal (raw line 17), but provides no test of that connection or payment operation. The later e355 deprecation notice prevents using these historical physical instructions as current transaction-support evidence.
