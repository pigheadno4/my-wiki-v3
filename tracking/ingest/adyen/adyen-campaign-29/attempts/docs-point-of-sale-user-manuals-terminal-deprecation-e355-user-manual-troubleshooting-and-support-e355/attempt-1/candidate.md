## Overview

This **2019-modified, 2026-09-15-captured** [[adyen]] e355 manual page gives an escalation route for a terminal issue: consult the separate POS troubleshooting documentation first, then contact Adyen Support if unresolved. It sits under the historical **terminal-deprecation/e355** path. See [[adyen-payment-terminals]] for the physical-device route; this page is not a diagnosis, repair record, current device-support promise or payment outcome. [Raw: lines 5–22]

## Key takeaways

- When an e355 terminal has an issue, the page tells the merchant to first use the linked POS troubleshooting documentation to diagnose and try to resolve it. This page itself supplies no fault tree or corrective procedure; the linked guide owns that detail. [Raw: lines 16–18]
- If that documentation does **not** resolve the issue, the page directs an **email to Adyen Support** with the **merchant account** and **terminal serial number**. Include the **transaction PSP reference only if applicable**. The serial number is available in **Device info** and printed on the back of the terminal; the shown S/N format is an example, not a verified serial number for any device. [Raw: lines 20–28]
- Sending details to Support is an escalation step, not evidence of a response, fix, terminal integrity, current support eligibility or successful transaction. The historical page does not replace the separate stop-use instructions for suspected tampering. [Raw: lines 5–28]
