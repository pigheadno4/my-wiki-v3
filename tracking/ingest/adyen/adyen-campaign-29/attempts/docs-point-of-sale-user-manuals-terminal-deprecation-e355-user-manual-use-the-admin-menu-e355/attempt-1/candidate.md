## Overview

This 2019-modified, 2026-09-15-captured [[adyen]] e355 user-manual page describes access to the terminal's PIN-protected Admin menu. It lists network settings, the installer, a merchant menu for editing or removing configurations and making maintenance calls, and a totals menu for printing and resetting totals. The page is in a terminal-deprecation subtree; it does not establish current e355 support or document that any listed action was performed. See [[adyen-payment-terminals]].

## Key takeaways

- **Access:** The guide says to press an illustrated terminal key followed by `9`, then enter the Admin-menu PIN. The key appears as an image in the raw; identify it from the illustration rather than inferring its label from the image file name. If the PIN is unknown, the page points to a separate POS Troubleshooting Admin PIN guide. See pinned raw lines 20–22.
- **Consequential menu actions:** Removing configurations and resetting totals are named as available menu purposes, but this page provides no procedure or outcome for either action. Opening the Admin menu is separate from performing them. See pinned raw line 16 and lines 20–22.
