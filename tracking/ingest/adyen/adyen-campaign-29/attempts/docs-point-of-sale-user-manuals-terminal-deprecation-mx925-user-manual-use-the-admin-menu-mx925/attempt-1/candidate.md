## Overview

This [[adyen]] MX925 manual page, last modified in 2019 and captured 2026-09-15, gives a short procedure for opening the terminal's PIN-protected Admin menu. It belongs to a terminal-deprecation subtree; the separate [[source-adyen-docs-point-of-sale-user-manuals-terminal-deprecation]] page lists MX925 among retired eVo devices. This menu instruction is historical documentation, not evidence of current device support or payment capability. See [[adyen-payment-terminals]].

## Key takeaways

- Press **9**, then the illustrated confirm key, to open the Admin-menu PIN prompt; enter the Admin-menu PIN. The pinned raw's image is the authority for identifying that key. See raw lines 16–20.
- If the PIN is unknown, the page directs the reader to a separate POS Troubleshooting Admin PIN guide. This page does not supply the PIN or establish that a user has access. See raw line 19.
- The stated result after PIN entry is that the terminal shows the Admin menu. Opening the menu alone does not demonstrate a later admin action, device readiness, or a payment outcome. See raw lines 18–20.
