## Overview

This [[adyen]] e355 user-manual page describes mechanically attaching the e355 terminal to its frame so it can connect easily to a tablet. It is a historical page last modified 2019-04-23 and captured 2026-09-15 under terminal deprecation; the fitting steps do not establish current device support, a completed tablet connection, boarding, or payment readiness. See [[adyen-payment-terminals]] for the physical-device context.

## Key takeaways

- Unlock the frame by turning the locking screws counter-clockwise; slide the e355 downward until it locks; then secure it by turning the screws clockwise. See raw lines 19–25, `## Steps`.
- This page addresses frame attachment only. It does not document power, network, boarding or transaction steps.
