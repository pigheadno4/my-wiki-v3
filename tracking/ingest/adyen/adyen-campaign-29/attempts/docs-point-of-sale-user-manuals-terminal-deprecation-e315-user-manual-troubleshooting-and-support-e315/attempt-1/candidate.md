## Overview

This [[adyen]] e315 manual page, last modified in 2019 and captured 2026-09-15 under terminal deprecation, is a **support-escalation route** within [[adyen-payment-terminals]]. It first points terminal issues to separate POS troubleshooting documentation, then says to contact Support if those instructions do not resolve the issue (raw lines 14–22). It contains no e315 diagnostic, reset or repair procedure of its own.

## Key takeaways

- Try the linked troubleshooting documentation first for a terminal issue; the page says this is often the quickest route (raw lines 16–18).
- If unresolved, email the linked Support Team contact and provide the merchant account and terminal serial number. Include a transaction PSP reference **if applicable** (raw lines 20–28).
- The serial number is said to appear in **Device info** and on the terminal back; the printed number is an example, not a required format or an actual device identity (raw line 28).

Its place under terminal deprecation does not establish current e315 support, live activation or a payment outcome; use the linked troubleshooting guide only as a separate source for any actual procedure.
