## Overview

This **2019-modified, 2026-09-15-captured** [[adyen]] MX925 manual page gives a two-stage route for a payment-terminal issue: use the linked POS troubleshooting documentation first, then email Adyen Support if unresolved. It sits under the historical **terminal-deprecation/MX925** manual path. See [[adyen-payment-terminals]] for the physical-device route. The page is neither a diagnosis nor evidence of a repair, present model availability or successful payment. [Raw: lines 5–22]

## Key takeaways

- First try to diagnose and solve the issue using the separate POS troubleshooting documentation. This MX925 page itself does not provide a fault tree or a repair procedure; the linked documentation owns that detail. [Raw: lines 16–18]
- If the issue remains unresolved, the page directs an **email to Adyen Support**. Supply the **merchant account** and **terminal serial number**; include the transaction **PSP reference only if applicable**. The serial number is in **Device info** and printed on the terminal's back. The example S/N format is illustrative, not a recorded serial number for any actual device. [Raw: lines 20–28]
- Following this escalation route does not establish that Support responded, the terminal was repaired, a payment completed, or this deprecated-model path is available for present operations. [Raw: lines 5–28]
