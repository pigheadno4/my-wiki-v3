# Retrieval checks: e355 frame attachment

Q1. What does this guide do, and what must happen before the e355 is secured to its frame? It gives the mechanical e355-to-frame attachment order for easier tablet connection: first unlock the frame by turning locking screws counter-clockwise (raw line 21), then slide the e355 downward until it locks (line 23), then turn screws clockwise to secure it (line 25).
