Ordinary MobilePay payment testing is described as live-only, while the separate payout-token test procedure uses a Vipps MobilePay test app (raw lines 74–107, 367–400). The curl sample uses conflicting `enablePayOut` spelling and blank currency/type/return URL, and the initialization snippet leaves `mobilepay` unquoted (raw lines 66–71, 149–169, 333–345).
