Its `/sessions` table describes `shopperStatement` fallback to `reference` and a 100 minor-unit (1.00 NOK) minimum (lines 40-47); no Vipps-specific Component configuration is needed (lines 82-92). TEST testing calls for the Vipps test app, a test-account payment request and shopper app authorization (lines 104-120; repeated 224-240). Live acceptance requires a separate live Customer Area request, followed by low-amount checks using the server `AUTHORISATION` webhook and payment list for status (lines 122-130; repeated 242-250).
