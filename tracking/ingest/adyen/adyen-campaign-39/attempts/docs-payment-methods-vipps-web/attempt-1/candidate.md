## Overview

Adyen's 2026-09-15 Vipps for Web page is a chooser for adding Vipps to a Web integration. It links to separate Web Drop-in and Web Components child guides and to the main guides for Sessions and Advanced flows. See [[adyen]] and [[adyen-online-payments]].

## Key takeaways

- The Drop-in route is described as an all-in-one UI for a website. The Components route links the Vipps Web Component child guide; its wording is "Use the Vipps to make Vipps payments" without further Component setup detail on this chooser.
- The page tells merchants to create the main integration before adding Vipps, and links each of Drop-in and Components in both Sessions and Advanced flow.
- This chooser does not itself establish request fields, API/Web SDK minimums, redirect or test behavior, eligibility, live setup, or a completed payment. Child and main-guide evidence is needed for those claims.
