## Overview

Adyen's 2026-09-15 MobilePay for Android page is a chooser for adding MobilePay to an Android app. It routes to an Android Drop-in child guide for an all-in-one UI or an Android Components child guide whose link text names `InstantPaymentComponent` for handling a MobilePay redirect. It also links the main Android integration guides for both Sessions and Advanced flows. See [[adyen]] and [[adyen-android-sdk]].

## Key takeaways

- The page directs merchants to create the main integration before adding MobilePay. Its four main-guide routes cover Android Drop-in and Components with Sessions or Advanced flow.
- The chooser itself does not specify request fields, API/SDK minimums, eligibility, redirect return mechanics, testing, or payment outcomes. The Components link's mention of redirect handling is a route description; implementation details require the child guide.
