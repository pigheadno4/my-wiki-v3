## Overview

This 2019-modified, 2026-09-15-captured **Classic Adyen for Platforms** API reference is a directory to API Explorer sections. It says Classic platforms connect to endpoints using API credentials for actions such as managing account holders, processing payments and making payouts. It directs new implementations to a separate new-integration guide. This directory does not itself specify operation contracts or demonstrate a successful payment or payout.

## Key takeaways

- The API Explorer routes named here are **Account API**, **Fund API**, **Notification Configuration API**, **Notifications**, and **Hosted onboarding API**. See [[raw/adyen/docs/classic-platforms/api/2026-09-15|raw lines 23–29]] for their exact outbound URLs; the page does not enumerate versions or endpoint-specific behavior.
- API credentials are identified as the connection mechanism, but this page gives no credential roles, request schemas, notification delivery semantics or operation outcomes. Use the relevant API Explorer reference and operation guide for those details. See [[raw/adyen/docs/classic-platforms/api/2026-09-15|raw lines 19–29]].
