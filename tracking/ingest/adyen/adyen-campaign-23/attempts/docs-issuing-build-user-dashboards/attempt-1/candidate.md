## Overview

This 2026-09-15 Issuing page is a short navigation hub for using Adyen **Platform Experience** components in a user dashboard. It identifies a Transaction component that lets users view and filter transaction data for their balance accounts, then points to its integration guide and the component-library overview. See [[adyen-issuing]] and [[adyen]].

## Key takeaways

- The stated purpose is to simplify a platform portal's UI and give users a view of transactional data and balance-account fund movements (raw lines 15–19). This describes a dashboard capability, not independent proof that a transaction has been booked, captured, settled or paid out.
- The only component explicitly listed here is **Transaction components**, described as a dashboard for viewing and filtering transactions for any of a user's balance accounts (raw lines 21–23).
- The next-step link points to the Issuing Transaction component guide with a `version=1.13.x` URL selector; a separate link points to component libraries (raw lines 25–33). This hub gives no integration prerequisites, session-role details, event semantics or outcome guarantees; those belong to the linked child guides.
