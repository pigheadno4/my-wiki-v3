Q1. What prerequisites and steps does the Issuing iOS card-details reveal guide give?
Answer: It requires Configuration API credentials with the Bank Issuing PaymentInstrument Reveal Webservice role, iOS 13.0+, and the Card Reveal iOS SDK (raw lines 40–47). The server gets a `panReveal` public key in `jwk` format (lines 49–58); the iOS SDK generates an encrypted session key (lines 234–254), the server requests encrypted details for `paymentInstrumentId` with `POST /paymentInstruments/reveal` (lines 256–266), then the SDK decrypts and the app displays the details (lines 478–492).
