## Q1

The captured Management API TEST v3 `GET /merchants/{merchantId}/apiCredentials/{apiCredentialId}/allowedOrigins` lists allowed origins for the API credential identified by required string `apiCredentialId` under the merchant account identified by required string `merchantId`. The caller needs **Management API—API credentials read and write**. The documented server is `https://management-test.adyen.com/v3`; no query parameters, body, defaults, pagination or limits are specified. A 200 response optionally carries a `data` array; each origin has required `domain`, optional origin `id`, and optional `_links` containing required `self` if that parent appears. A 204 has no additional content. The origin ID is distinct from the path's API credential and merchant IDs.
