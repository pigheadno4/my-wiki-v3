# Original query answers — api-explorer-management-latest-get-merchants-merchantid-users-userid

## Q1

For `GET /merchants/{merchantId}/users/{userId}`, the captured 2026-11-03 Management API v3 reference returns details for the merchant and user IDs in the path. Its listed server is TEST `https://management-test.adyen.com/v3`. The caller's API credential must have `Management API—Users read and write`. Both string path inputs are required: `merchantId` is the merchant identifier and `userId` is the user identifier. No query parameter, request body, conditional input, default or numeric limit is specified. A 200 response requires `email`, user `id`, the **user's** `roles`, `timeZoneCode` and `username`; optional fields are `accountGroups`, `active`, `apps`, `name` and `_links`. The optional parent `name` has required first/last names if present, and optional parent `_links` has required `self` if present. A separate 204 has no additional content. Source: [[source-adyen-api-explorer-management-latest-get-merchants-merchantid-users-userid]]; https://docs.adyen.com/api-explorer/Management/latest/get/merchants/(merchantId)/users/(userId); verified pinned raw lines 5–49.

## Q2

A 200 establishes successful user-record readback for the specified merchant/user path; 204 establishes successful processing without content. The API credential's required Users read-and-write role is a caller permission, distinct from the returned user's role list. Optional `active`, `apps` and account-group fields do not by themselves prove successful login, effective access to an app or another merchant account, or current credential entitlement. This GET does not create, activate, deactivate or modify the user. The page lists 400, 401 authentication-required, 403 insufficient-permission, 422 and 500 errors, but no idempotency, deletion/propagation, asynchronous review/approval/activation, reversal or version-conflict semantics for this read. The `latest` URL and TEST server are a dated snapshot, not proof of present Live access, merchant eligibility or payment outcome.
