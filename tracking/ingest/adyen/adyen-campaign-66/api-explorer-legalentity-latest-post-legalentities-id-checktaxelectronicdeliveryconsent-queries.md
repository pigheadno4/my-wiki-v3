## Q1

`POST /legalEntities/{id}/checkTaxElectronicDeliveryConsent` is the 2026-11-03 captured Adyen Legal Entity Management status lookup for electronic delivery of tax forms. Its listed server is TEST `https://kyc-test.adyen.com/lem/v4`; the endpoint page also states separate live and test rate limits, but does not list a live URL. The caller's organization or credential role is not specified in this operation reference. The sole required input shown is the path `id`: the owner's individual legal-entity ID for a sole proprietorship or the organization's legal-entity ID for an organization. No query or request-body parameters, input defaults, or idempotency contract are listed. The captured limit is 200 requests per five seconds in test, 700 per five seconds in live, and five failed requests per ten seconds. A successful `200` response lists optional boolean `US1099k`, representing consent to electronically deliver US1099-K. The optional field's absence has no default defined on this endpoint page. ## Q2

A `200` establishes that the consent-status lookup request succeeded and can return the optional `US1099k` boolean; it does not itself set or revoke consent, generate/file/deliver a form, establish legal compliance or prove a payment or payout. The page documents `400` request, `401` authentication, `403` permission, `422` validation, and `500` server-error responses, with generic optional error fields. It does not specify a request-body or idempotency contract, lifecycle/deletion/propagation timing, asynchronous review/approval/activation, reversal behavior, or a version-conflict rule. Those absences should not be converted into guarantees. Its only listed server is TEST v4, and the 2026-11-03 raw snapshot and `latest` URL do not prove current live availability or a particular account's eligibility.
