For `POST /companies/{companyId}/apiCredentials/{apiCredentialId}/generateClientKey`, the captured 2026-11-03 Management API v3 reference generates a new **client key** for the target API credential. Its listed server is TEST `https://management-test.adyen.com/v3`. The calling API credential needs `Management API—API credentials read and write`; the required string `companyId` identifies the company account and required string `apiCredentialId` identifies the target API credential. The page specifies no query parameters, request body, conditional input, default or numeric limit. A 200 says the request succeeded and requires a response `clientKey` string. The new client key can be used a few minutes after generation; the old client key stops working 24 hours after the new one is generated. This is the company/target-credential route, separate from the `/me` client-key endpoint and from API-key generation.
