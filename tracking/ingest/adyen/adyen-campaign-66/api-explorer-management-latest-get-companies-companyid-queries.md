## Q1

The 2026-11-03 snapshot of Management API `GET /companies/{companyId}` returns the company account identified by the required string path parameter `companyId`, provided the calling API credential has access to that company and the `Management API—Account read` role. Its declared TEST server is `https://management-test.adyen.com/v3`; no request body, query inputs, defaults, or request limits are listed. The 200 schema marks the top-level `_links` object optional and its nested `self` object required only if `_links` is present. Top-level `dataCenters`, `description` (maximum 300 characters), `id`, `name`, `reference`, and `status` are optional. Optional connected-resource links can point to API credentials, users, and webhooks. `dataCenters.livePrefix` is empty for TEST requests, and the page recommends the live URL prefix of a data center near shoppers for live requests. See [[source-adyen-api-explorer-management-latest-get-companies-companyid]] and the [captured reference](https://docs.adyen.com/api-explorer/Management/latest/get/companies/(companyId)), raw lines 5–47.

## Q2

A 200 establishes that the scoped read succeeded and returned a company-account representation, not that processing, payout, live eligibility, compliance, or any payment succeeded. The status descriptions say `Active` allows user login but processing and payouts depend on merchant-account status; `Inactive` still allows login while disabling payment processing and payouts; `Closed` is irreversible and disallows login, processing, and payouts. This GET does not perform a lifecycle transition or state when updates propagate. The captured errors are 400 request, 401 authentication, 403 permissions, 422 validation, and 500 server processing; no idempotency, asynchronous review/approval/activation, or reversal semantics are specified for this read. The declared TEST server uses `/v3`, whereas example response hrefs use `/v1`, so the example must not settle the endpoint version. The November 2026 snapshot is not evidence of current access or live results.
