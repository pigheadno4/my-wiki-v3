## Q1

The 2026-11-03-captured `GET /companies/{companyId}/apiCredentials/{apiCredentialId}/allowedOrigins` lists allowed origins for the path-identified API credential under a path-identified company account. It is an Adyen Management API reference with only TEST `https://management-test.adyen.com/v3` listed. Both IDs are required, and the calling API credential needs `Management API—API credentials read and write`; the target credential and returned origin IDs are separate identities. No query or body inputs, defaults, numeric limits, or pagination are specified. A successful `200` has an optional top-level `data` array of origins; each origin requires `domain`, can have optional `id` and `_links`, and marks `_links.self` required within that optional links object. The two-origin sample is illustrative.
