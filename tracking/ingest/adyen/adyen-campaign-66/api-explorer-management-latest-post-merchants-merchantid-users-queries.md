## Q1

`POST /merchants/{merchantId}/users` is the 2026-11-03-captured Adyen Management API v3 operation for creating a user under the merchant account named by the required string path `merchantId`, with `https://management-test.adyen.com/v3` as the shown server. The API credential needs `Management API—Users read and write`. The request-body table requires `email`, `username` and `name`; `name` requires `firstName` and `lastName` and allows 1–80 characters. `username` must match `email` per the table. Optional `accountGroups`, `roles`, `timeZoneCode` and `loginMethod` are documented; login method is `Email` or `SSO`, and SSO must already be configured with Adyen before an SSO user is created. No default login method, user role or time zone is stated. A `200` response requires the new user `id`, `email`, `roles`, `timeZoneCode` and `username`; `active`, `apps`, `accountGroups`, `name` and `_links` are optional, with `self` required inside `_links` when present. The user ID is distinct from the merchant path ID.
