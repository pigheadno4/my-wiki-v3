## Q1

`GET /legalEntities/{id}/pciQuestionnaires` is the 2026-11-03-captured Legal Entity Management API v4 lookup for a list of signed PCI questionnaires for the legal entity named by the required path string `id`. Its shown server is `https://kyc-test.adyen.com/lem/v4`; the raw separately gives live and test limits, without a live server URL. No query parameter or request body is documented, and the page identifies no specific platform or merchant caller. A `200` response has an optional `data` array whose signed-questionnaire objects list optional `createdAt`, signed-questionnaire `id`, and `validUntil`; the timestamps are ISO 8601 extended format. The signed-questionnaire ID differs from the legal-entity path ID. Limits are 700 requests per five seconds live, 200 per five seconds test, and five failed requests per ten seconds. See [[source-adyen-api-explorer-legalentity-latest-get-legalentities-id-pciquestionnaires]] and https://docs.adyen.com/api-explorer/legalentity/latest/get/legalEntities/(id)/pciQuestionnaires (verified raw lines 5–38).
