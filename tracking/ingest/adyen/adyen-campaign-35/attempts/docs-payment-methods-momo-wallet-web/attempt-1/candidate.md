## Overview

This 2026-09-15 Adyen page is a **Web integration chooser** for MoMo. It links Drop-in and Components child guides and four main Web integration guides. It says to create the main integration before adding MoMo, but supplies no independent method configuration or payment outcome. [[adyen]] [[adyen-online-payments]]

## Key takeaways

- The **Drop-in** child route is described as an all-in-one UI solution for adding MoMo to a website. The **Components** child route is described with the label “Use the Redirect” for MoMo payments. That label identifies a linked option; this page gives no constructor, mount, redirect-processing or callback procedure. (raw lines 19–27)
- The See also section directs readers to create the main integration first and links Web Drop-in and Web Components base guides for **Sessions** and **Advanced** flows. These are navigation routes and do not establish each MoMo child guide's flow support, Checkout/Web SDK minimum or method-specific request fields. (raw lines 29–36)
- This chooser states no Vietnam/VND merchant-eligibility rule, desktop QR or mobile-web journey, token/recurring steps, TEST/LIVE requirement, webhook condition or observed authorization/capture/settlement. Those details require the MoMo overview and child guides. (raw lines 15–36)
