## Overview

This Adyen Docs overview directs a POS integration using the Adyen Terminal API and Adyen-provided payment terminals to two checklists: one for building a test integration and one for preparing to go live. It is a navigation page, not a detailed Terminal API specification or proof that a particular merchant, terminal, or environment is ready to accept payments.

## Key takeaways

- The integration checklist is for building a test integration; the separate go-live checklist is for preparing to accept payments with a POS app. The overview does not itself define the steps or completion criteria for either checklist.
- The linked resources cover Adyen account structure and configuration, terminal models, cloud or local-network communication architecture, network and connectivity configuration, Terminal API, and notifications/webhooks. These are topics to investigate, not requirements specified on this page.
- Standalone and Android/iOS Mobile solutions have separate checklist routes. Do not apply the Terminal API and Adyen-provided terminal checklist as a substitute for those paths.
