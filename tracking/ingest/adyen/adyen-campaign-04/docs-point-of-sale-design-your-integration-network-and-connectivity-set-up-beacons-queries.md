2. **What central capability, setup and routing warnings should a reader retrieve?** Enable beacons at the relevant Customer Area merchant/store/terminal scope, set UUID/Major/Minor and save (raw lines 31–62). Cloud placeholders encode serial number in Major/Minor; the POS decodes it, looks up the full `POIID` via `/connectedTerminals`, and uses that `POIID` in its request (lines 64–75, 86–122). Local placeholders encode an interface IP address; the POS decodes it, maintains an IP-to-`POIID` mapping (optionally populated using a diagnosis request), and sends to the selected IP with the correct `POIID` (lines 77–84, 124–177). Advertised identifiers alone do not establish terminal authentication, local network connectivity, authorization, or payment success.
