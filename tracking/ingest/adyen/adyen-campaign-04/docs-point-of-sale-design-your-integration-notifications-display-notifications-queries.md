2. **Central setup, prerequisites, and warning?** Provide a JSON-capable HTTP callback endpoint and set a display URL via Customer Area or Management API `/terminalSettings` (raw lines 25–66, 80–104); the API path requires `Management API - Terminal settings Advanced read and write` (68–70), and removal must account for inherited settings (82). Test permits listed HTTP or TLSv1.2 HTTPS ports, while live lists only TLSv1.2 HTTPS ports (29–35, 74–78). Store a received notification, acknowledge with a successful HTTP response such as 202, and only then run business logic, because failures before acknowledgement can interfere with important event notifications (229–238).
