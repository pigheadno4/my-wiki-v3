1. **What can the diagnostics overview check, and does it prove a payment outcome?** In a Terminal API integration, remote diagnosis checks terminal components and returns conditional battery level plus the count of payments the terminal could not send to Adyen's host. Cloud Terminal API offers a separate check of a specific terminal's live WebSocket connection. On-terminal tests check the Adyen-platform connection and hardware. These are terminal and connection diagnostics, not authorization/capture or a specific transaction-status result. Locators: raw lines 17–31. The linked pages supply procedures and request details; this overview only identifies the routes. It states no test/live guarantee. For a missing or ambiguous payment result, use the separate Terminal API transaction-status guidance rather than treating a connectivity check as proof of finality.
