Q2. How are scheduled/unscheduled repayments, booking timing, identifiers and principal/fee amounts reconciled?
- Expected: A scheduled repayment is one outgoing `repayment` transfer; an unscheduled one pairs incoming `capitalFundsCollection` with outgoing `repayment`, with distinct references. Reserve is based on a fixed share of active-grant net captured volume; repayment is booked about an hour after sales-day close as funds settle, and near-close payouts can precede it. Chargebacks/refunds, excess-reserve release and mid-day settlement-delay changes can alter/split entries. Transfer webhook `category=grants`, `type=repayment`, outgoing direction and grant-ID reference identify the leg; Transaction webhook `transfer.id` confirms balance-account booking. Accounting Report `Booking Date`/`Value Date`, Transfer Id, Transaction Id and Reference support joins; optional Capital Principal/Fee columns split the amount. Payout Report uses `grants/repayment` transfer rows with payout-date grouping. Webhooks use minor units; report outgoing repayments are negative in payment currency. For remaining or fully repaid debt, inspect grant balances and status; the stated fully repaid condition is total 0 with status Repaid.
