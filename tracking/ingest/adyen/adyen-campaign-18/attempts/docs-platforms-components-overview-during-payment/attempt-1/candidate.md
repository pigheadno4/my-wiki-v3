## Overview

This short 2026-09-15 Adyen for Platforms navigation page points to Checkout components as the during-payment UI route. It says Checkout adds a checkout page to a platform UI and links to a dedicated guide about accepting ecommerce payments, collecting details and showing transaction results. It does not define implementation fields, eligibility, session roles, payment finality or a live checkout result. See [[adyen]], [[adyen-platforms]] and [[adyen-platform-components]].

## Key takeaways

- The page links the Checkout component guide for the during-payment flow and separately links component libraries (raw lines 19–29). Its payment-method wording is a broad link to a filtered payment-method catalog, not a claim that every method is enabled for a particular platform, country or user.
- Consult the linked [[source-adyen-docs-platforms-online-payments-checkout-components]] and component-library authority for setup or behavior; this page alone supplies only navigation and a one-sentence capability description.
