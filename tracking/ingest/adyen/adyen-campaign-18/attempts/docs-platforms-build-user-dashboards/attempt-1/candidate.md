## Overview

This 2026-09-15 Adyen Platform Experience hub describes UI components for building user dashboards that show transactional data and balance-account fund movement. It is an inventory and navigation page: the component descriptions point to child guides for behavior, access, versions and limits. A dashboard view or link to a child guide does not prove a live payment, account balance, report generation, dispute outcome or payout. See [[adyen]], [[adyen-platform-components]] and [[adyen-platforms]].

## Key takeaways

- **Component inventory:** The page links Transactions for account/date filtering, exports and transaction details; Payouts for reports on automatic payouts, captured funds, adjustments, net amounts and remaining balances; Reports for filtering and downloading automatically generated daily reconciliation reports; Disputes for account-filtered viewing and defense/acceptance with documents; and Pay by Link for store-branded link creation, expiration, history and sharing. These are page-level descriptions of UI areas, not a guarantee that every action is enabled for every platform user.
- **Integration and evidence boundary:** The hub links to Adyen's component repository, demo, release notes and component-library overview. Use the linked child guides for authentication, roles, product eligibility, report scope and operational prerequisites. A displayed amount or component affordance is not independent evidence that funds settled, a bank received a payout, a dispute was resolved or a payment link was paid.
