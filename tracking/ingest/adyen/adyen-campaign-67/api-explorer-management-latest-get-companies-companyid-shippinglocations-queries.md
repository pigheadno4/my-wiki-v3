# Original query answers: api-explorer-management-latest-get-companies-companyid-shippinglocations

- Q1: This 2026-11-05 Management API v3 reference lists shipping locations for the path `companyId` and all its merchant accounts, using the listed TEST server. The API credential needs Terminal ordering read or read and write. `companyId` is required; optional `limit`, `offset`, and `name` query parameters control result count, skipped entries and location-name filtering, with no default or numeric bound stated here. A 200 response's optional `data` array holds physical locations; each object's `id`, unique `name`, address and contact are marked optional in the schema. The location `id` is used as `shippingLocationId` when creating a terminal-product order. The page also says live requests are rate-limited but gives no rate figure. [[source-adyen-api-explorer-management-latest-get-companies-companyid-shippinglocations]]; https://docs.adyen.com/api-explorer/Management/latest/get/companies/(companyId)/shippingLocations; verified raw lines 5–60.
- Q2: A successful GET returns location readback for the company scope; it does not create or approve an order, prove shipping or delivery, assign or board a terminal, or establish payment/compliance readiness. The page requires an API credential with an allowed role and lists 401 authentication and 403 permission failures, plus 400, 422 and 500 errors. No idempotency key, lifecycle mutation, deletion, propagation, asynchronous review/activation, reversal or financial result is documented for this read endpoint. The TEST server listing and live rate-limit caveat do not prove current live account eligibility; sample response addresses and IDs are illustrative 2026-11-05 snapshot data.
