# C67 job 22 — original query answers

## Q1

For `POST /merchants/{merchantId}/paymentMethodSettings/{paymentMethodId}/addApplePayDomains`, the captured Management API v3 test reference adds domains to the Apple Pay domain list registered to the named merchant account and payment method. Its only shown server is `https://management-test.adyen.com/v3`. The caller needs an API credential with Management API—Payment methods read and write. Required path identities are merchant-account `merchantId` and payment-method `paymentMethodId`. The body requires `domains`, an array of merchant-domain strings, with a maximum of 99 per request. The example contains `https://example.com`; the page gives no other body fields or defaults. The only documented success is 204, with an instruction to inspect the actual response code and no response resource fields.
