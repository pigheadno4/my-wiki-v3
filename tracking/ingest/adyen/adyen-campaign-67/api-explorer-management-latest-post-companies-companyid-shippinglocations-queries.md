It does not create an order, allocate a device, prove shipment, or establish delivery or a payment outcome. The credential role is a prerequisite, with `401` authentication and `403` permission errors; `400`, `422` and `500` are also listed. The capture gives no idempotency, deletion/reversal, later propagation or asynchronous approval contract. It flags Live rate limits but lists only a TEST `/v3` server; the dated snapshot does not prove present Live eligibility. The phone-number table says 10–14 digits with optional plus, while request and response examples contain spaces, so the sample cannot settle validation.
