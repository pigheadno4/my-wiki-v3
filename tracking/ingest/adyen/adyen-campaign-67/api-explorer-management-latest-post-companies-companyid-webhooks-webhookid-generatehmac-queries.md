# Original query answers — api-explorer-management-latest-post-companies-companyid-webhooks-webhookid-generatehmac

Q1. The 2026-11-05 capture documents Management API v3 on the TEST server `https://management-test.adyen.com/v3`. `POST /companies/{companyId}/webhooks/{webhookId}/generateHmac` generates and returns an HMAC key for the named webhook configuration under the named company account, for checking notification integrity and origin. Both `companyId` and `webhookId` are required string path parameters; the caller's API credential needs `Management API—Webhooks read and write`. The page specifies no request body, defaults, or limits. The 200 response requires string `hmacKey`.
