## Q1

The 2026-11-05 captured Management API `latest` page describes updating the configuration of one company-account webhook with `PATCH /companies/{companyId}/webhooks/{webhookId}`. It lists only the Test server `https://management-test.adyen.com/v3` and requires an API credential with the “Management API—Webhooks read and write” role. The two required path parameters are the unique company-account `companyId` and webhook-configuration `webhookId` ([[source-adyen-api-explorer-management-latest-patch-companies-companyid-webhooks-webhookid]]; https://docs.adyen.com/api-explorer/Management/latest/patch/companies/(companyId)/webhooks/(webhookId); raw lines 5-22).

All request-body rows are marked optional. They cover `active`, public `url`, description, `communicationFormat` (soap/http/json), endpoint username/password, certificate acceptance flags defaulting false, `encryptionProtocol` (TLSv1.3/TLSv1.2 or Test-only HTTP, omitted uses TLSv1.2), SOAP-action header only for SOAP, Terminal API notification `networkType` defaulting public, and Standard-webhook `additionalSettings`. For company merchant filtering, `filterMerchantAccountType` selects include/exclude/all; `filterMerchantAccounts` becomes required for include/exclude and is unnecessary for all. The reference gives no general body-required flag or numerical rate/size limit ([[source-adyen-api-explorer-management-latest-patch-companies-companyid-webhooks-webhookid]]; https://docs.adyen.com/api-explorer/Management/latest/patch/companies/(companyId)/webhooks/(webhookId); raw lines 25-44). A 200 returns a full configuration with required response `active`, `communicationFormat`, `type`, `url`, and `_links.generateHmac`, `_links.self`, and `_links.testWebhook` entries as marked in the response table; other fields such as `id`, `hasError`, `hmacKeyCheckValue`, filtering and settings are optional rows. Nested `href` values are marked optional. The returned `type` can be one of the listed webhook types and is not a request-body field here ([[source-adyen-api-explorer-management-latest-patch-companies-companyid-webhooks-webhookid]]; https://docs.adyen.com/api-explorer/Management/latest/patch/companies/(companyId)/webhooks/(webhookId); raw lines 54-96).
