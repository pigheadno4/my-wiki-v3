# C67 job 5 — original query answers

## Q1

For `GET /companies/{companyId}/webhooks`, the captured Management API reference lists webhook configurations for the specified company account. Its server list gives `https://management-test.adyen.com/v3` (test); no live server appears in this pinned page. The caller's API credential needs Management API—Webhooks read or read and write. The required path `companyId` identifies the company account; there is no request body. Optional `pageSize` defaults to 10 and has maximum 100, and optional `pageNumber` selects a page. A 200 response has required `itemsTotal` and `pagesTotal`, optional pagination `_links` and optional `data` list. Each listed webhook has schema-required `active`, `communicationFormat`, `type`, and `url`; optional `id`, account references, error/security settings and resource links add detail. Company versus merchant links are scope-qualified. `filterMerchantAccounts` is conditionally required in the **configuration field description** for `includeAccounts`/`excludeAccounts`, not an input to this GET.
