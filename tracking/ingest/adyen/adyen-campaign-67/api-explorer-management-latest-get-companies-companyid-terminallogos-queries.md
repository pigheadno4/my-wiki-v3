# Original campaign query answers — api-explorer-management-latest-get-companies-companyid-terminallogos

## Q1

`GET /companies/{companyId}/terminalLogos` reads the logo configured for one terminal model at the company account named by required path `companyId`. The captured Management API page lists Test `https://management-test.adyen.com/v3`; it notes Live rate limits without a numeric limit or Live server URL. The caller's API credential needs **Management API—Terminal settings read** or **Management API—Terminal settings read and write**. Required query `model` selects a terminal model; the listed values are E355, VX675WIFIBT, VX680, VX690, VX700, VX820, M400, MX925, P400Plus, UX300, UX410, V200cPlus, V240mPlus, V400cPlus, V400m, e280, e285, e285p, S1E, S1EL, S1F2, S1L, S1U, and S7T. No request body or default model is stated. `200` means the request succeeded; its optional `data` response string contains the logo image as Base64 text when present, which must be decoded to get the image file. The company-level logo applies to all terminals of that model under the company unless a merchant-account, store, or individual-terminal logo overrides it. See [[source-adyen-api-explorer-management-latest-get-companies-companyid-terminallogos]] and [pinned API reference](https://docs.adyen.com/api-explorer/Management/latest/get/companies/(companyId)/terminalLogos), raw lines 5–44 and 146–154.

## Q2

A `200` establishes a successful read of the company/model logo configuration; optional `data` can provide the encoded image. It does not establish what any particular terminal displays, because merchant, store, or terminal-level overrides may apply. Nor does the GET update a logo, prove propagation or application on a device, board a terminal, authorize a payment, capture or settle funds, or show bank receipt. The named terminal-settings roles and 401/403 responses bound authentication and permission; the page also lists 400, 422, and 500. It notes Live rate limits but no threshold. The captured GET specifies no idempotency mechanism, lifecycle/deletion or reversal action, asynchronous review/approval/activation, conflict rule, or Live server URL. The Test `/v3` server and 2026-11-05 example do not prove current merchant eligibility, Live availability, or payment outcome. See [[source-adyen-api-explorer-management-latest-get-companies-companyid-terminallogos]] and [pinned API reference](https://docs.adyen.com/api-explorer/Management/latest/get/companies/(companyId)/terminalLogos), raw lines 5–44 and 47–154.
