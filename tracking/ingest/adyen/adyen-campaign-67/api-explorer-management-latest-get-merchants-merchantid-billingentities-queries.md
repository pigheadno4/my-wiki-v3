# Original campaign query answers — api-explorer-management-latest-get-merchants-merchantid-billingentities

## Q1

`GET /merchants/{merchantId}/billingEntities` lists billing entities for the merchant account named by the required `merchantId` path parameter. A billing entity is the legal entity Adyen charges for orders, and a separate terminal-product order must carry its ID. This captured Management API reference lists Test `https://management-test.adyen.com/v3`; Live calls are said to have rate limits, with no numeric threshold or Live URL given here. The caller's API credential needs **Management API—Terminal ordering read** or **Management API—Terminal ordering read and write**. Optional query `name` is the billing-entity name; there is no request body or other default stated. `200` says the request succeeded and defines optional `data`, an array of billing entities with optional `id`, `name`, `taxId`, `email`, and `address` plus optional address children. The item `id` is the reference for a later order's `billingEntityId`. The one-item response example is illustrative. `204` also denotes successful processing but no additional content. See [[source-adyen-api-explorer-management-latest-get-merchants-merchantid-billingentities]] and [pinned API reference](https://docs.adyen.com/api-explorer/Management/latest/get/merchants/(merchantId)/billingEntities), raw lines 5–58 and 160–181.

## Q2

A `200` confirms a successful merchant billing-entity lookup and may contain optional `data`; a `204` confirms successful processing without readback. Neither status creates or bills a terminal order, verifies the listed legal entity or tax number, approves an account, establishes current Live ordering eligibility, confirms shipment/boarding, or proves payment, settlement, or bank receipt. The caller role requirement and 401/403 error responses bound authentication and permissions; the page also lists 400, 422, and 500. Live rate limiting is noted but no figure appears in this pin. The read-only GET documents no idempotency mechanism, lifecycle or deletion/reversal effect, propagation delay, asynchronous review/approval/activation, conflict/version procedure, or Live URL. The Test `/v3` server and 2026-11-05 sample are snapshot evidence only, and the single sample entity does not establish a required result count or ID grammar.
