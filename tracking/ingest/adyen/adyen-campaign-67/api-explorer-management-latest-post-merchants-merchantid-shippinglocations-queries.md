# Checked answers: api-explorer-management-latest-post-merchants-merchantid-shippinglocations

## Q1

The 2026-11-05 Management API “latest” snapshot describes `POST /merchants/{merchantId}/shippingLocations` to create a shipping-location address for the merchant account identified by the required path `merchantId`. The listed server is TEST `https://management-test.adyen.com/v3`; the caller's API credential needs **Management API—Terminal ordering read and write**. The request table marks `address`, `contact`, `id` and unique `name` optional, with their nested fields also optional; it states no separate whole-body requirement or default. `country` uses ISO 3166-1 alpha-2; `stateOrProvince` uses ISO 3166-2 for listed countries; `contact.phoneNumber` is described as 10–14 digits with an optional plus prefix. The location ID is for later use as `shippingLocationId` in an order. A `200` body may contain ID, name, address and contact, each marked optional; `204` has no additional content. The page says Live requests face rate limits without specifying a number and states no idempotency behavior. ## Q2

A `200` reports success of the shipping-location request and may return a location record; `204` reports successful processing without content. Neither places an order, reserves a terminal, proves shipment or delivery, or establishes a payment result. The caller role is required, and the reference lists `401` authentication and `403` permissions failures alongside `400`, `422` and `500`. It gives no idempotency, propagation timing, deletion/reversal or asynchronous order-approval contract. The phone-number table says digits plus an optional prefix, while the request example contains spaces and the response example removes them; the examples do not establish validation or normalization. The page lists a TEST `/v3` server while merely warning of Live rate limits, so this dated capture does not prove present Live access or eligibility. The generic error `requestId`/`pspReference` wording does not imply a financial transaction.
