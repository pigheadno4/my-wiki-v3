The 2026-11-05 captured **Management API v3** reference uses `GET /companies/{companyId}/terminalActions/{actionId}` to return details of a terminal action. The listed server is TEST, `https://management-test.adyen.com/v3`; the page also states that live requests are rate limited but does not give a numeric limit. The API credential needs **Management API—Terminal actions read** or **Management API—Terminal actions read and write**. ## Q2

A successful `GET` returns the reported details of an existing terminal action; it does not itself schedule or execute one. `status` and `result` are action-state fields, and the single `successful` certificate-install example is not a general guarantee. `scheduledAt` and `confirmedAt` distinguish scheduling from the described carried-out time; a pending, failed, cancelled or tryLater state cannot be treated as completed. The page lists `400` request problem, `401` authentication required, `403` insufficient permissions, `422` validation error and `500` server error. It gives no idempotency, deletion, propagation timing, asynchronous approval/activation, reversal, or version-conflict contract. Its TEST server snapshot and live rate-limit notice do not establish present eligibility, actual device configuration, payment readiness, authorization, settlement or bank receipt.
