# C67 worker query answers: api-explorer-management-latest-get-companies-companyid-terminalorders-orderid

## Q1

The 2026-11-05 captured Management API `latest` page documents `GET /companies/{companyId}/terminalOrders/{orderId}` for reading details of the terminal-products order named in the path. It lists Test server `https://management-test.adyen.com/v3` and mentions Live rate limits without a numeric allowance. The API credential needs either “Management API—Terminal ordering read” or “Management API—Terminal ordering read and write.” The two required path IDs are the unique company-account `companyId` and order `orderId`; no query or request-body fields or defaults are listed ([[source-adyen-api-explorer-management-latest-get-companies-companyid-terminalorders-orderid]]; https://docs.adyen.com/api-explorer/Management/latest/get/companies/(companyId)/terminalOrders/(orderId); raw lines 5-26). A 200 returns an order representation whose listed top-level fields are all optional: `billingEntity`, `customerOrderReference`, `id`, `items`, `orderDate`, `shippingLocation`, `status`, and `trackingUrl`. Nested billing and shipping IDs are documented for use when creating an order, while item rows can have product ID/name, quantity and installments. The raw table gives nested address/contact details and the carrier-provided tracking URL ([[source-adyen-api-explorer-management-latest-get-companies-companyid-terminalorders-orderid]]; https://docs.adyen.com/api-explorer/Management/latest/get/companies/(companyId)/terminalOrders/(orderId); raw lines 28-75).

## Q2

A 200 establishes successful retrieval of the described order details, not a new order or completed fulfillment. The `status` field is described only as processing status, without an enum; the sample `Placed` value is illustrative. `trackingUrl` is optional, and neither its presence nor the example's order data proves delivery, terminal boarding, activation, inventory, or payment capability ([[source-adyen-api-explorer-management-latest-get-companies-companyid-terminalorders-orderid]]; https://docs.adyen.com/api-explorer/Management/latest/get/companies/(companyId)/terminalOrders/(orderId); raw lines 30-75, 177-229). Credential roles and 401 authentication/403 permission responses bound access; 400, 422 and 500 errors are also documented. This GET page specifies no idempotency, deletion/reversal, order propagation, review/approval timing or payment state. The sole listed server is Test v3, while the Live rate-limit mention has no number; the dated `latest` snapshot does not establish current Live availability or account eligibility. Order readback cannot be used as payment authorization, capture, booking, settlement, bank receipt or compliance evidence ([[source-adyen-api-explorer-management-latest-get-companies-companyid-terminalorders-orderid]]; https://docs.adyen.com/api-explorer/Management/latest/get/companies/(companyId)/terminalOrders/(orderId); raw lines 9-18, 78-175).
