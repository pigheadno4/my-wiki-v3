# Original query answers: api-explorer-management-latest-post-companies-companyid-webhooks-webhookid-test

- Q1: This captured Management API reference describes `POST /companies/{companyId}/webhooks/{webhookId}/test` for sending sample notifications to check a company webhook, on the listed v3 TEST server. The API credential needs Management API—Webhooks read and write. Required path IDs identify the company account and webhook configuration. Top-level `merchantIds`, `types`, and `notification` are optional, but `notification` is required if `types` includes `CUSTOM`; supplied `notification.amount` has required currency and minor-unit value. `merchantIds` has a maximum of 20, and the default is all configured merchant accounts subject to the stated 20-account sending maximum. Selected event codes generate four tests each with hard-coded EUR and GBP success/failure cases; CUSTOM sends only its specified notification. The 200 response's optional `data` array gives per-test results with required `status` and optional merchant ID, sent body, output, response code and response time. [[source-adyen-api-explorer-management-latest-post-companies-companyid-webhooks-webhookid-test]]; https://docs.adyen.com/api-explorer/Management/latest/post/companies/(companyId)/webhooks/(webhookId)/test; verified raw lines 5–45 and 84–98.
- Q2: HTTP 200 describes a succeeded test request; each returned `data.status` reflects whether the receiving server answered that sample with HTTP 2xx, and `output` plus `responseCode` can diagnose failure. It does not establish live webhook configuration, future delivery, a real payment event, authorization, capture, settlement or compliance. The reference requires an API credential with the stated role and lists 401 authentication and 403 permission errors, plus 400/422 request and 500 server errors. It documents no idempotency key, deletion, propagation, review, approval, activation or reversal effect for this test operation. Its only listed server is TEST; the 2026-11-05 snapshot and example payloads are not current availability or live outcome proof.
