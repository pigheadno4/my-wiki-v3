# C08 Shopper Insights overview — fixed query answers

1. **Does Shopper Insights automatically build a verified cross-channel customer profile?** The 2021-modified overview describes Adyen's unified payment-data proposition and suggests collecting webhook payment data into the merchant's own database for analysis across channels and regions. It does not specify an automatic merchant warehouse, a reliable person-identity match, or the fields that link individual records. The linked Collect data guide is the route for identifier mechanics. Evidence: `raw/adyen/docs/unified-commerce/shopper-insights/2026-09-15.md`, `# Shopper insights` lines 15–35 and `## Next steps` lines 46–50; proposed source `[[source-adyen-docs-unified-commerce-shopper-insights]]`.

2. **What privacy steps does this page give before storing shopper payment data, and what can the Data Protection API remove?** It says to consider local privacy regulations, consult legal or an accredited third party, ask for explicit customer permission, and explain the intended use. It points to Adyen's Data Protection API for customer-related data stored with Adyen when a customer requests removal. The page does not describe deletion of merchant-held database or webhook copies; those need their own handling. Evidence: `raw/adyen/docs/unified-commerce/shopper-insights/2026-09-15.md`, `## Data privacy` lines 37–44; proposed source `[[source-adyen-docs-unified-commerce-shopper-insights]]`.
