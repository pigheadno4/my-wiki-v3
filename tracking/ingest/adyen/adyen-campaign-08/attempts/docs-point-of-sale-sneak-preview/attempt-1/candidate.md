## Overview

This Adyen **Sneak peek** page was last modified 2026-09-14 and captured 2026-09-15. It is a short pointer to expected POS terminal software changes, release notes and update guidance. At that snapshot it called **v1.135** the “next release” and explicitly said its expected contents would be mentioned later. It therefore documents a historical preview label, not a released feature list, schedule or present terminal software version. See [[adyen-payment-terminals]] and [[adyen-terminal-management]].

## Key takeaways

- The page directs readers to separate **Release notes** for the latest software updates. It contains no feature descriptions for v1.135 or any other future release. See raw lines 17–19 and 23–27.
- For merchants on a manual update strategy, it says terminals should be updated to one of the latest Long Term Support versions and links the separate update and LTS guidance. It does not state which LTS version a terminal has, which device is eligible, or that any update was scheduled or installed. See raw line 21.
- “Next release” is time-relative to the page's 2026-09-14 modification and 2026-09-15 capture. Check the linked release notes and current account/device state before making a current-version or deployment claim. This snapshot contains no payment-execution evidence.
