# C08 Unified Commerce shopper engagement — fixed retrieval checks

1. **Q: Which shopper-engagement paths does this overview name, and does a terminal prompt or payment detail automatically prove shopper identity or consent?**
   **A:** It names POS-app Terminal API Input/Display for collecting or showing information, tokenization-based loyalty recognition from payment-response details, digital receipts by email/SMS, Giving donations and localization. These are overview examples and child-guide routes. A terminal consent question, collected email/phone number or payment detail alone is not evidence that the shopper was identified, agreed to storage, received a receipt or completed a donation. Evidence: `raw/adyen/docs/unified-commerce/shopper-engagement/2026-09-15.md:15-34,45-57`; canonical URL: https://docs.adyen.com/unified-commerce/shopper-engagement. Exact identifiers and workflows belong to the linked guides.

2. **Q: What privacy guidance and deletion scope does this page state before a merchant stores customer data?**
   **A:** It tells merchants to consider data privacy for customer and payment data, consult legal or accredited third-party advice for their operating jurisdictions, ask for explicit customer permission, and explain the intended use. It says Adyen's Data Protection API can remove customer-related data stored with Adyen when the customer asks for removal. The page does not describe deletion from a merchant CRM or prove that any consent or erasure request has been completed.
