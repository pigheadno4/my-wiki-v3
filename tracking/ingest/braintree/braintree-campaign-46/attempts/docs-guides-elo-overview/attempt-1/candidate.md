## Overview

This captured unversioned [[braintree|Braintree]] website overview identifies Elo as a commonly accepted payment method in Brazil and says Braintree SDKs enable merchants to accept Elo cards like other credit cards. Its availability notice limits Elo to select merchants in a limited release, conditions access on what the page calls the latest JavaScript v3 and server SDKs, and directs readers to contact Braintree to request access. [[braintree-payment-methods]]

## Key takeaways

- The page is a short identity and access overview: it describes Elo's Brazil context and Braintree SDK acceptance at a high level, but provides no client-side or server-side procedure.
- Access is materially qualified as a limited release for select merchants using the page-relative latest JavaScript v3 and server SDKs, with a separate contact route for requesting access.

> [!warning] Snapshot and implementation boundary
> The word "latest" is relative to this 2026-09-16 website snapshot and does not identify an exact client or server package version. The page does not establish current availability, merchant or environment enablement, card or transaction eligibility, versioned GitHub SDK implementation or history, or successful authorization, settlement or funding.
