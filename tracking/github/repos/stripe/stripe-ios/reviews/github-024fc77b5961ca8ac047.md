## Findings for ingest

1. Standalone Link adds optional billing-details collection configuration.
   A nil override preserves the controller's base configuration. Both the
   internal collect flow and preview present flow apply the override; the
   internal collectName option can then force name collection. The standalone
   LinkConfiguration is distinct from PaymentSheet.LinkConfiguration.
2. LinkAppearance becomes visible to LinkControllerPreview consumers, retaining
   configurable colors, primary-button dimensions, style, and reduced branding.
   This is private-preview access, not evidence of general availability.
3. BillingDetailsCollectionConfiguration gains a public initializer accepting
   field collection modes, address mode, attaching defaults, and allowed countries.
   This is an additive Swift API despite the packet's empty public_api_changes
   array; that automated field is not an exhaustive Swift API analysis.
4. Embedded form cancellation can rebuild the last accepted valid form instead
   of discarding the selection. Continue captures the accepted option. The
   retained helper distinguishes form-backed linked banks, new/external methods,
   Link signup, and Apple Pay.
5. Checkout-backed saved-method selection now waits for billing-address sync
   before publishing the selection and invoking immediate-action completion.
   The retained caller disables interaction, reselects the method on success,
   and restores prior selection plus displays an error on failure. The actual
   Checkout sync implementation is outside this capsule.
6. SwiftUI Embedded presentation resolves the presenter from the embedded view's
   own window and triggers a refresh on window attachment, rather than initially
   selecting an application-global window.
7. FlowController captures selection before presentation and invokes snapshot
   restoration on cancellation before publishing the payment option. Its Link
   wallet shortcut also requires a prior Continue action. Detailed snapshot
   restoration semantics require the excluded helpers listed below.
8. Checkout confirmation now suppresses save_payment_method using
   noPaymentRequired and dispatches by the returned SetupIntent first, then
   PaymentIntent, failing if neither exists. Do not infer complete subscription,
   free-order, or public Checkout SDK support from this internal handler alone.
9. Release notes announce Tempo wallet-address registration for alpha Crypto
   Onramp. Treat this as release-note evidence only: the changed network enum and
   API implementation were excluded by the checkout-focused policy.
10. Podspecs advance to 26.5.0 without a platform-floor change in the retained
    diff. No Apple Pay integration change is established by its version bump.
