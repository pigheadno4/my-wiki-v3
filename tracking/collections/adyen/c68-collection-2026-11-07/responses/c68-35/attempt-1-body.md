# GET /companies/{companyId}/campaignManagement/accountHolders/{accountHolderId} - Get the donation campaigns for an account holder

Returns a paginated list of donation campaigns associated with the account holder specified in the path. You can filter the list by campaign status.

To make this request, your API credential must have one of the following [roles](https://docs.adyen.com/development-resources/api-credentials#api-permissions):

- Management API—Campaign Management read

- Management API—Campaign Management read and write

## Servers
- https://management-test.adyen.com/v3

## Parameters

### Path parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| accountHolderId | string | Yes | The unique identifier of the account holder. |
| companyId | string | Yes | The unique identifier of the company account. |


### Query parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| pageSize | integer | No | The number of items to have on a page, maximum 100. The default is 10 items on a page. |
| pageNumber | integer | No | The number of the page to fetch. |
| status | string | No | The campaign status to return campaigns that match. Allowed values: **inactive**, **active**, or **ended**. |
