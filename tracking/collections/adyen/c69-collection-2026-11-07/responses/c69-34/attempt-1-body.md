# GET /disputes/{id} - Get dispute by ID

Get a raised dispute by ID.

## Servers

**Test Environment**
- https://balanceplatform-api-test.adyen.com/btl/api/v4

**Live Environment**
- https://balanceplatform-api-live.adyen.com/btl/api/v4

## Parameters

### Path parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| id | string | Yes | The unique identifier of the raised dispute. |
