# DELETE /balancePlatforms/{balancePlatformId}/webhooks/{webhookId}/settings/{settingId} - Delete a balance webhook setting by id

Deletes a balance webhook setting that contains the conditions for triggering [balance webhooks](https://docs.adyen.com/api-explorer/balance-webhooks/latest/post/balanceAccount.balance.updated).

## Servers
- https://balanceplatform-api-test.adyen.com/bcl/v2

## Parameters

### Path parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| settingId | string | Yes | The unique identifier of the balance webhook setting. |
| webhookId | string | Yes | The unique identifier of the balance webhook. |
| balancePlatformId | string | Yes | The unique identifier of the balance platform. |
