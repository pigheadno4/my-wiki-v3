# DELETE /balanceAccounts/{balanceAccountId}/sweeps/{sweepId} - Delete a sweep

Deletes a sweep for a balance account.

## Servers
- https://balanceplatform-api-test.adyen.com/bcl/v2

## Parameters

### Path parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| sweepId | string | Yes | The unique identifier of the sweep. |
| balanceAccountId | string | Yes | The unique identifier of the balance account. |
