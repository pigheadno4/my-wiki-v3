# PATCH /scaDevices/{deviceId} - Finish registration process for a SCA device

Finishes the registration process for a new Strong Customer Authentication (SCA) device.

## Servers
- https://balanceplatform-api-test.adyen.com/bcl/v2

## Parameters

### Path parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| deviceId | string | Yes | The unique identifier of the SCA device that you are associating with a resource. |


### Request body
| Name | Type | Required | Description |
|------|------|----------|-------------|
| sdkOutput | string | Yes | A base64-encoded block with the data required to register the SCA device. You obtain this information by using Adyen's authentication SDK. |

## Request examples

### Finish SCA Device Registration Request
```json
{
  "sdkOutput": "eyJjaGFsbGVuZ2UiOiJVWEZaTURONGNXWjZUVFExUlhWV2JuaEJPVzVzTm05cVVEUktUbFZtZGtrPSJ9"
}
```

Device registration was completed successfully.

**Response body**
| Name | Type | Required | Description |
|------|------|----------|-------------|
| scaDevice | object | No | A resource that contains information about a device, including its unique ID, name, and type. |
|   - id | string | Yes | The unique identifier of the SCA device you are registering. |
|   - name | string | Yes | The name of the SCA device that you are registering. You can use it to help your users identify the device. |
|   - type | string | Yes | Type of device registered.  Possible values: **ios**, **android**, **browser**. |
