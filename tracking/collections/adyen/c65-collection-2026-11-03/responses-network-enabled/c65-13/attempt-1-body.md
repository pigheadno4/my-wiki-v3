# DELETE /scaDevices/{deviceId} - Delete an SCA device

Deletes a Strong Customer Authentication (SCA) device.

## Servers
- https://balanceplatform-api-test.adyen.com/bcl/v2

## Parameters

### Path parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| deviceId | string | Yes | The unique identifier of the SCA device to delete. |

## Responses
