# DELETE /balanceAccounts/{id}/transferLimits/{transferLimitId} - Delete a scheduled or pending transfer limit

Delete a scheduled or pending transfer limit using its unique `transferLimitId`. You cannot delete an active limit.

## Servers
- https://balanceplatform-api-test.adyen.com/bcl/v2

## Parameters

### Path parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| transferLimitId | string | Yes | The unique identifier of the transfer limit. |
| id | string | Yes | The unique identifier of the balance account. |
