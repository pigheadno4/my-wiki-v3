## Stripe Terminal: Stripe Reader S700/S710 Accessories

Official accessory lineup for the Stripe Reader S700/S710.

## Key Takeaways

### Accessory lineup

| Accessory | Purpose | Key specs |
| --- | --- | --- |
| **Case** | Drop protection at countertop height | Exposes all ports (headphone, USB, volume); compatible with Dock |
| **Hub** | I/O expansion | 10/100M Ethernet + 2× USB-A (1A shared); 6ft USB-C cable built-in; 27W via S700/S710 adapter |
| **Dock** | Countertop display + power | Magnetic attachment + locking nut; 3 countertop mount points; power + USB pass-through; front/rear cable exit |
| **Power Adapter** | Charging | 20W; region-specific (US/UK/EU/AU); replaceable via Dashboard |
| **Stand** | Countertop mounting | No first-party stand — Stripe recommends third-party vendors |

### Critical Hub distinction

> The Hub connects peripheral devices (barcode scanner, printer, cash drawer) to **your POS device** (tablet, cash register) — NOT to the Stripe Reader S700/S710.

Hub USB-A power limit: 1A shared across both ports. High-power peripherals (printers) must have their own power source.

### Critical Dock rule

> The Dock does **not** support payment connectivity through USB. The reader must use its internet connection for payments even when docked.

The Dock provides: countertop mounting (magnetic + locking nut + 3 screw points), continuous power, USB pass-through to POS device. Dock cable exits: front or rear options. Dock does not include a USB-C power cable — use the cable included with the reader.

### Dock + Hub combination

Together, Hub + Dock create a complete countertop I/O solution:
- Dock: power + countertop mount
- Hub: Ethernet + USB peripherals connected to POS
