## Summary

Reference overview table for the 4 recurring subscription pricing models available in Stripe. Thin content — facts covered in [[stripe-subscriptions]] concept and [[source-stripe-subscriptions-design-integration]].

## 4 Pricing Models

| Model | Description |
| --- | --- |
| **Flat rate** | Service tier with flat price (Basic/Starter/Enterprise) |
| **Per-seat** | Price per user/license |
| **Tiered** | Unit cost changes with quantity (volume-based) or usage (graduated) |
| **Usage-based** | Fixed fee + overage; pay-as-you-go; credit burndown |
