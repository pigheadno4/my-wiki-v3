## Summary

Stripe provides a 1-year limited warranty on Terminal readers (excludes cables and accessories). Warranty claims for readers are submitted via the Dashboard; dock claims go to Stripe Support.

## Key Details

**Claim flow** (Dashboard): Readers page → overflow menu (⋯) → Start warranty claims → enter serial number(s) → Stripe validates warranty status → edit each claim (reason, images, description) → Submit → provide shipping address → Submit claim.

**Supported image formats**: PNG, JPG, GIF, TIFF, PDF, ZIP (ZIP for videos).

**Review**: within 48 business hours. Replacements ship to one address per claim — submit separate claims for multiple locations.

**Replacement warranty**: carries over remaining period from original reader; minimum **3 months** if less than 3 months remain.

**Check status**: Readers page → overflow menu → Manage warranty claims.
