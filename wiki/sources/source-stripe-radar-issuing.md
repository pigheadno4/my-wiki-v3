## Summary

Real-time Radar fraud risk scoring for Stripe Issuing card authorizations via the IssuingAuthorizationEvaluation API. Issuer-side decisioning before approving or declining each authorization.

## Key Details

- **API**: IssuingAuthorizationEvaluation API
- **Timing**: real-time at authorization (pre-approval/decline decision)
- **Supports**: physical and tokenized cards; optional fields to improve precision
- **Use case**: build automated approval workflows for Issuing programs
