## Summary

Overview page comparing two checkout integration modes for MCP app developers (ChatGPT, Claude, other MCP hosts). Redirect (publicly available) vs Instant Checkout (OpenAI private beta).

## Two Modes

| | Redirect | Instant Checkout |
| --- | --- | --- |
| Flow | New browser tab | Stays in chat |
| Availability | Public | OpenAI private beta |
| Payment methods | 40+ dynamic | Cards, Apple Pay, Google Pay, Link |
| Subscriptions | ✓ | ✗ |
| 3DS | ✓ | ✗ |
| Save payment methods | ✓ | ✗ |
| Promo codes, tax, upsells | Integrated | Requires API integration |
| Best for | Common use cases, minimal code | Complex flows, custom business logic |
