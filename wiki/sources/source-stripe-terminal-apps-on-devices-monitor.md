## Summary

Monitor Apps on Devices deployment progress per release version via the Stripe Dashboard.

**Path**: Terminal → Software → app details → App info → select release version.

**Deployment statuses**:

| Status | Meaning |
| --- | --- |
| Pending | Device hasn't checked for updates yet |
| Served | App delivered; installs on next reboot |
| Installed | Successfully installed |
| Failed | Install error |
