## Summary

API-based deployment of Apps on Devices APKs is in **private preview** (contact Stripe Support for access). Deploy by creating device deploy groups and associating them with locations. Same deployment behavior as Dashboard deploy: app sent immediately, device reboots to install, auto-reboots every 24h.
