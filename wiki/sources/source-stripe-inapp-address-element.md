## Summary

Overview page for the mobile Address Element — an embeddable UI component for collecting complete shipping and billing addresses. Thin overview; integration details are in the "Collect addresses" guide (not yet ingested).

## Features

- **236 regional address formats** including right-to-left formats
- **Built-in autocomplete** — reduces validation errors, increases conversion
- **Prefill saved addresses** — preload known customer addresses
- **Appearance API** — customize to match page design
- **Payment Sheet + Payment Element integration** — reuse existing Elements instance, data passes automatically
- **Cross-platform**: web, iOS, Android, React Native

## Platform Notes

- iOS: integrates with both Payment Sheet and Payment Element
- Android/React Native: integrates with Payment Element and Link
- Same feature set across all platforms
