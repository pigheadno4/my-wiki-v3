## Overview

This 2026-09-15 MobilePay for Web page is an integration chooser. It routes a website integration to Web Drop-in or Web Components and links the four main Sessions/Advanced Web integration guides. It gives no method-specific version, setup field, test/live requirement, payout-token procedure or payment result itself. [[adyen]] [[adyen-online-payments]]

## Key takeaways

- **Choice of UI:** the Drop-in child is described as an all-in-one website UI; the Components child says to use “the Redirect” for MobilePay website payments. These are descriptions of linked child routes, not a complete redirect implementation on this page. (raw lines 19–27)
- **Base integration first:** the page tells readers to create the main integration before adding MobilePay, with separate Web Drop-in and Web Components links for both Sessions and Advanced flows. Child and base guides supply the prerequisites and behavior. (raw lines 29–36)
