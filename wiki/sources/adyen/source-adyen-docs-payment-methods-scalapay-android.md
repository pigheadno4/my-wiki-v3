## Overview

This Adyen Docs page, captured 2026-09-15, is an Android integration chooser for Scalapay. It points to separate method-specific Drop-in and Components guides, and to the general Android Sessions-flow Drop-in and Components guides. It does not provide method setup, payment request requirements, product eligibility, payment results or capture terms. See [[adyen]] and [[adyen-online-payments]].

## Key takeaways

- The Drop-in child is described as an all-in-one UI solution; the Components child is described as a pre-built Component to render Scalapay in an Android app. These are navigation descriptions; use the child guides for implementation detail.
- The page's general links are Android **Sessions-flow** guides for Drop-in and Components. The chooser itself does not define whether other flows are supported by the child guides.
