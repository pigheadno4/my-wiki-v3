## Overview

This 2026-09-15-captured Adyen Android page is a PayTo integration chooser. It links Android Drop-in and Components child guides plus the four Sessions/Advanced main integration guides. It does not give a request recipe, mandate lifecycle, webhook outcome, or current eligibility proof. See [[adyen]], [[adyen-online-payments]], and [[source-adyen-docs-payment-methods-payto]] for PayTo context.

## Key takeaways

- Drop-in is labeled the all-in-one Android UI route. The Components route says to use Redirect Component for the PayTo redirect. Follow the child guides for actual setup and payment/mandate behavior: [[source-adyen-docs-payment-methods-payto-android-drop-in]] and [[source-adyen-docs-payment-methods-payto-android-component]]. See raw lines 19–27.
- The page says to create the main integration first and links Android Drop-in and Components base guides, each for Sessions and Advanced flows. These links are navigation, not evidence that every PayTo use case behaves identically across the four routes. See raw lines 29–36.
