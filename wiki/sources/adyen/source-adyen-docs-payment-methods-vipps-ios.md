## Overview

This 2026-09-15 Vipps for iOS page is a route chooser for adding Vipps to an iOS app. It points to an all-in-one Drop-in child guide or an `InstantPaymentComponent` child guide and lists the main iOS Sessions and Advanced integration guides. It supplies no method-specific SDK/API version, setup fields, redirect handling, test procedure, live approval or payment outcome itself. [[adyen]] [[adyen-online-payments]]

## Key takeaways

- **Integration choice:** the Drop-in child is described as an all-in-one UI solution; the Components child is described as using `InstantPaymentComponent` for Vipps in an iOS app. These are navigation descriptions; the child guides carry method-specific prerequisites and implementation. - **Base routes:** the page tells the merchant to create the main integration first and links iOS Drop-in and Components for both Sessions and Advanced flows. It does not prefer or validate one route for a particular merchant. (raw lines 29–36)
