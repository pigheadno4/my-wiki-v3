## Overview

This 2026-09-15-captured Adyen page is a Web integration **router** for PaySafeCard. It links separate Web Drop-in and Components method guides plus Sessions and Advanced base guides for both UIs. It does not itself define payment request fields, redirect processing, recurring behavior, or current merchant eligibility. See [[adyen]], [[adyen-online-payments]], and [[source-adyen-docs-payment-methods-paysafecard]] for the method overview.
