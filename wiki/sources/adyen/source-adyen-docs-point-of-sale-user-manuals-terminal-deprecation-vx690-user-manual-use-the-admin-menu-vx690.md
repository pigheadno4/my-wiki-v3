## Overview

This [[adyen]] **VX690** Admin-menu page was last modified 2019-04-19 and captured 2026-09-15 under the terminal-deprecation manual tree. It describes an **image-only key plus 9** shortcut and an **Admin PIN** gate for displaying the menu. The menu's listed purposes include network settings, installer access, merchant-menu configuration edits or removal and maintenance calls, plus printing and resetting totals. These are possible menu actions, **not actions performed by opening it**; the raw gives no reset or configuration-change result. The separate [[source-adyen-docs-point-of-sale-user-manuals-terminal-deprecation]] lists VX690 with a historical **29 March 2024** "No more transactions" date. See [[adyen-payment-terminals]].

## Key takeaways

- The entry sequence says to press **9 and the illustrated key at the same time**, then enter the **Admin-menu PIN**. The raw names no text label for the pictured key and provides no PIN value. If the PIN is unknown, it links to a separate POS troubleshooting route. See raw lines 18–22.
- The page says the terminal then displays the Admin menu. It does not show that a user selected network changes, installed anything, removed merchant configuration, made a maintenance call, printed totals or **reset totals**. These listed functions can be consequential, especially removal or reset, so keep menu visibility separate from execution. See raw lines 16 and 20–22.
