## Overview

This [[adyen]] **WeChat Pay for Android** page is a navigation chooser for in-app integration. It links separate Android **Drop-in** and **Components** WeChat Pay guides, plus general Android Drop-in/Components **Sessions** integration guides. The page gives no child implementation details, SDK or API version, merchant enablement, app-switch handling, payment-result contract or settlement evidence.
