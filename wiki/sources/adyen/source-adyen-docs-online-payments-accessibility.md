## Overview

This unversioned [[adyen]] documentation page describes the accessibility purpose of Web Drop-in and Components, Adyen's Voluntary Product Accessibility Template (VPAT), the WCAG 2.1 standard and its POUR principles, and a version-qualified accessibility statement. It routes accessibility evidence for the [[adyen-online-payments]] web surfaces; it does not establish accessibility or legal compliance for a merchant's complete checkout.

## Key takeaways

- The page defines digital accessibility as designing and developing digital products so people with disabilities can use and interact with them effectively. Its product scope is Web Drop-in and Components, not every Adyen product or a merchant's surrounding checkout.
- A VPAT is described as a standardized document through which a vendor reports a product or service's accessibility, particularly for public-sector or accessibility-focused procurement. The page says Adyen partnered with Level Access to obtain a VPAT for Web Drop-in and Components and that those surfaces were tested against all criteria in WCAG 2.1.
- The page describes WCAG 2.1 as a W3C Web Accessibility Initiative framework covering visual, auditory, cognitive, and motor disabilities. It summarizes the four POUR principles: perceivable, operable, understandable, and robust.
- Adyen states that Web Drop-in and Components meet WCAG 2.1 Level AA and reports a "flawless Level AA rating" for version `5.49.0` or later. The page recommends upgrading to `5.49.0` or later to use the documented accessibility improvements.
- The version claim is a statement in this captured Adyen page, last modified in 2023 and fetched on 2026-09-15. The linked Checkout Web VPAT PDF was not included in or read as part of this raw snapshot. Treat the source as a locator to the reported assessment, not as an independent audit, a guarantee about every later release or configuration, or proof that a merchant's end-to-end experience satisfies current accessibility laws or standards.
