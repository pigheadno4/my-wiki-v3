## Overview

This 2026-09-15 Adyen **Alipay HK for Web** page is an integration chooser. It links to Alipay HK Web **Drop-in** and **Components** child guides and to the main Web Sessions and Advanced integration guides. It does not itself give method-specific API fields, SDK or Checkout API versions, merchant eligibility, payment execution steps, or an outcome procedure. [[adyen]] [[adyen-online-payments]]

## Key takeaways

- The Drop-in route is described as Adyen's all-in-one UI option for adding Alipay HK to a website; the Components route is described as using Redirect for Alipay HK website payments. These are navigation descriptions, not evidence that either path has been configured or completed a payment. (raw lines 19–27)
- The 'See also' section says to create the main integration first, and links Web Drop-in and Web Components base guides for both Sessions and Advanced flows. This page supplies no child-guide prerequisites or version threshold; consult each linked guide for those details. (raw lines 29–36)
