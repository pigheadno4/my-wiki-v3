## Overview

This [[adyen]] **VX820 Duet** page, last modified **2019-04-19** and captured 2026-09-15 under terminal deprecation, describes **opening the PIN-gated Admin menu** and names its maintenance areas. The menu can be used for network settings, installer access, merchant configuration editing/removal and maintenance calls, plus printing/resetting totals (raw line 16). Listing these possible actions does not say they were selected or completed; configuration removal and totals reset are consequential operations requiring their own procedures. Route this historical device guide through [[adyen-payment-terminals]]. The separate [[source-adyen-docs-point-of-sale-user-manuals-terminal-deprecation|eVo deprecation schedule]] lists VX820 Duet **“No more transactions” on 29 March 2024** (its raw line 34).

## Key takeaways

- To open the menu, press **9 and the pictured, unlabeled key at the same time**, then enter the **Admin menu PIN** (raw lines 22–25). The raw illustration has no readable key label; do not infer one from its image filename.
- If the Admin PIN is unknown, the page links a POS troubleshooting section (raw line 24). It does not say the PIN can be bypassed, recovered or reset here.
- The terminal is described as displaying the Admin menu after the PIN step (raw line 25). This is the guide's expected interface state, not observed access to a particular device and not evidence that settings, configurations or totals changed.
- The scope is **access and menu-purpose orientation**. The source does not provide a configuration-removal or counter-reset sequence; no such effect follows merely from opening the menu (raw lines 16, 22–25).
