## Overview

This 2026-11-07-captured Management API v3 Test reference creates basic terminal-theme metadata for the merchant account identified by `merchantId`, to customize screens on Android payment terminals. Creation sets a name and dark or light mode; adding model-specific image or video assets and applying the theme are separate later steps. [[adyen]] [[adyen-android-terminals]]

## Key takeaways

- The API credential needs **Management API - Terminal themes read and write**. The captured server is `https://management-test.adyen.com/v3`; this page gives no live server.
- The path requires `merchantId`, the merchant account identifier. The body requires `name` (unique within that account, maximum 255 characters) and `mode` (`dark` or `light`). Other merchant accounts may use the same name.
- `201 Success` returns a theme `id` generated by Adyen plus `name` and `mode`. It establishes metadata creation, not asset upload, theme application or on-device display.
- The reference lists `400`, `401`, `403`, `404`, `422` and `500` errors. Its `422` examples cover a blank name and a duplicate account-scoped name; the examples are illustrative, not a complete validation or retry contract.
