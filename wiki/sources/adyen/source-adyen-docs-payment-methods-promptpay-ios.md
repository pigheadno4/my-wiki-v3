## Overview

This Adyen page, last modified 2019-09-30 and captured 2026-09-15, is an **iOS integration chooser** for PromptPay. It links to Drop-in and Components child guides and to two Sessions-flow base guides. It does not itself specify QR presentation, request fields, eligibility, shopper completion or final payment outcome. The historical route page does not prove current enablement or a completed payment. See [[adyen]] and [[adyen-online-payments]].

## Key takeaways

- Drop-in is described as the all-in-one UI route for adding PromptPay to an iOS app; the child guide owns implementation and outcome details. (raw lines 19–23)
- Components is described as a pre-built Component for rendering PromptPay in the iOS app; the child guide owns its particular flow and result handling. This chooser does not identify a specific Component class. (raw lines 25–27)
- Its final line links the main iOS Drop-in and Components **Sessions-flow** guides. That navigation does not rule out or prove a separate Advanced path; check the respective child and main guides. (raw line 29)
