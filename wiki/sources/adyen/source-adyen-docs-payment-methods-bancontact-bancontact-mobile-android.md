## Overview

A short **Android integration chooser** for **Bancontact mobile**. It offers [Android Drop-in](https://docs.adyen.com/payment-methods/bancontact/bancontact-mobile/android-drop-in) as an all-in-one UI route and [Android Components](https://docs.adyen.com/payment-methods/bancontact/bancontact-mobile/android-component) as a pre-built Component route. The page also links the base Android Drop-in and Components integration guides. It was last modified 2019-09-30 in this 2026-09-15 capture; its links are navigation, not evidence of current support, merchant enablement or successful payments. [[adyen]] [[adyen-online-payments]]

## Key takeaways

- Select the Bancontact **mobile** child guide for the chosen Android UI integration. Read the selected child and main integration guides for implementation. See raw lines 15–29.
