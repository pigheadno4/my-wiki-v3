## Overview

This 2026-09-15-captured Adyen Web page is a Pix integration chooser. It links Web Drop-in and Components child guides plus the four Sessions/Advanced main integration guides. It does not specify Pix request fields, QR expiration, payment finality, current eligibility or a full Web implementation. See [[adyen]], [[adyen-online-payments]], and [[source-adyen-docs-payment-methods-pix]] for method context.

## Key takeaways

- The Drop-in child is labeled the all-in-one Web UI route. The Components child is the Web Components route, but its short description says “Use the Pix” without identifying a Component class; the child guide supplies the actual implementation details. See raw lines 19–27 and [[source-adyen-docs-payment-methods-pix-web-drop-in]] / [[source-adyen-docs-payment-methods-pix-web-component]].
- The page says to build the main integration before adding Pix and links Web Drop-in and Components base guides, each in Sessions and Advanced flows. These are navigation links, not proof that each child has identical fields or QR/result behavior. See raw lines 29–36.
