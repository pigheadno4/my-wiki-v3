## Overview

This 2026-09-15 Marketplace-path [[adyen]] Platform Experience page is a navigation hub for UI components used in user dashboards showing transactional data and balance-account fund movement. It names five component areas and links to their child guides; those guides own integration prerequisites, access roles, version limits and operation-specific behavior. See [[adyen-platform-components]].

## Key takeaways

- **Available components:** Transactions links to account/date filtering, export and details; Payouts to reports on automatic payouts, captured funds, adjustments and balances; Reports to automatically generated daily reconciliation report filtering/download; Disputes to account-filtered viewing, defense or acceptance with supporting documents; and Pay by Link to store-branded link creation, expiration, history and sharing. These are high-level descriptions of UI areas, not a guarantee that each feature is enabled for a particular platform user. See pinned raw lines 29–59.
- **Navigation and evidence boundary:** The page also links Adyen's Platform Experience repository, demo, release notes and component-library overview. It does not specify session roles, financial event grain, payout arrival, report completeness, dispute outcome or payment-link payment. A dashboard view is not independent evidence of funds settled or received. Follow the relevant child guide for those claims. See pinned raw lines 19–27 and 61–63.
