## Overview

This 2019-modified, 2026-09-15-captured [[adyen]] VX690 manual page describes opening a PIN-protected **Special Payments** menu for custom or ad-hoc options. It says available options vary by merchant configuration. The page is historical and menu-level evidence: the separately captured [[source-adyen-docs-point-of-sale-user-manuals-terminal-deprecation|eVo deprecation table]] lists VX690 under **29 March 2024 "No more transactions"**. Neither menu access nor the listed options establish current enablement or a completed payment. See [[adyen-payment-terminals]].

## Key takeaways

- **Access and option scope:** The guide shows an illustrated terminal key + `8` to enter the Special Payments menu, followed by a device-unlock PIN. It lists **Normal payment**, which opens an amount-entry screen, and **Manual entry payment**, which opens a payment screen. These are configuration-dependent possibilities, not a guarantee every VX690 presents them. See pinned raw lines 16 and 20–30.
- **Manual-entry flow:** After amount entry, the historical guide says the terminal prompts for PAN and card expiry date, then the transaction follows the normal flow. It does not provide authorization or completion evidence. Keep card-data entry scoped to this pictured terminal flow; the page does not establish permission to collect PAN elsewhere. See pinned raw lines 30–35.
- **Refund route and image caution:** The page says the menu also includes a refund option and links to a separate VX690 refund guide rather than giving refund steps here (raw line 37). The pictured button asset in this VX690 page has a `vx820` path (raw lines 22 and 32); use the actual illustration to identify the key, not the asset filename or an inferred button label.
