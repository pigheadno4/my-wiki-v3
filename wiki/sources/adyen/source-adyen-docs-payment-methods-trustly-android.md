## Overview

This Adyen Docs page is a Trustly Android integration chooser. It directs readers to the method-specific Android Drop-in guide or Android Redirect Component guide and separately to general Android Sessions-flow Drop-in and Components guides. It does not describe a payment request, redirect/result handling, webhook, funding status or current merchant eligibility (raw lines 15–33).

## Key takeaways

- Drop-in is described as an all-in-one UI solution for adding Trustly to an Android app (raw lines 21–25).
- The Components option specifically names the Redirect Component; its child route is distinct from the Drop-in child route (raw lines 27–31).
- The final further-reading links are general Android Sessions-flow guides for Drop-in and Components. They are navigation, not evidence that every Trustly child-guide version or flow is Sessions-compatible (raw line 33).
