## Overview

This 2026-09-14-captured [[adyen]] Docs **home page** is a navigation map, not an integration guide. It opens routes for online payments, in-person payments, Adyen for Platforms and Intelligent Money Movement, with developer-resource and community links. See [[adyen-payments]] for the broad payment-family route; linked child guides own their actual setup, availability, version and outcome claims. [Raw: lines 14–49, 75–191]

## Key takeaways

- Online navigation links to an integration checklist, integration-type choice, payment-method catalog, webhooks and release notes, plus API Explorer, libraries, examples, logs, test cards and API diff tooling. These labels help locate sources; the home page does not establish a merchant's eligible methods, credential roles, webhook delivery or payment result. [Raw: lines 22–73]
- In-person navigation links to a Terminal API checklist, Terminal API, terminal-model selection, Tap to Pay and firmware release notes, with developer references and testing tools. A listed terminal route is not a supported-model or live-device decision for a particular merchant. [Raw: lines 75–116]
- The Platforms navigation distinguishes **Platforms**, **Marketplaces**, **Financial products**, and **Classic platforms**. The Classic link is explicitly described here as integrations **before Aug 1, 2022**. This is a routing distinction; do not apply Classic API behavior to modern Platforms or infer product enablement from the home-page summaries. [Raw: lines 118–160]
- Intelligent Money Movement navigation points to enterprise accounts, third-party payouts and enterprise issuing, alongside Transfers API and related developer resources. The home page advertises a connection among payments, funds management and payouts, but it does not specify an account topology, transfer direction, beneficiary eligibility, booking, payout timing or bank receipt. [Raw: lines 14, 162–191]
- Community links include a tech blog, Postman collections, GitHub, Stack Overflow, Adyen developers and a newsletter. Their listings are navigation, not authority for claims in unread destinations. [Raw: lines 193–212]
