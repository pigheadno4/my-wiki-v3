## Overview

This [[adyen]] **VX680** guide, last modified **2019-04-18** and captured 2026-09-15 under terminal deprecation, explains **opening the PIN-gated Admin menu** and names its areas: network settings, installer, merchant configuration editing/removal and maintenance calls, and printing/resetting totals (raw line 16). These are listed menu purposes, not actions shown to have been executed. It belongs to [[adyen-payment-terminals]]. The separate [[source-adyen-docs-point-of-sale-user-manuals-terminal-deprecation|eVo deprecation schedule]] lists VX680 **“No more transactions” on 29 March 2024** (its raw line 34).

## Key takeaways

- To enter the menu, press **9 and a pictured, unlabeled key at the same time**, then enter the **Admin menu PIN** (raw lines 20–22). The image has no readable button label, so its filename should not be used to name the key.
- If the Admin PIN is unknown, the page links to POS troubleshooting (raw line 21). It does not provide a bypass or reset procedure.
- The guide says the terminal then displays the Admin menu (raw line 22). This describes expected interface behavior, not observed access to a specific device or a change to network settings, merchant configuration or totals.
- Configuration removal and totals reset would affect device state, but the page gives **no execution sequence** for either operation beyond opening the menu (raw lines 16, 20–22).
