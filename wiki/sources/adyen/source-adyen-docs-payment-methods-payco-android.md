## Overview

This 2026-09-15 Adyen page is an Android integration chooser for PayCo. It points to separate Drop-in and Components child guides and to the main Android Sessions and Advanced integration guides. It is navigation rather than a method-specific version, configuration, eligibility, testing, or payment-outcome specification. See [[adyen]] and [[adyen-online-payments]].

## Key takeaways

- The Drop-in choice is described as an all-in-one UI solution; the Components choice says to use `InstantPaymentComponent` to handle a redirect to PayCo. Those descriptions identify child-guide routes, not complete procedures or proof that a redirect or payment occurred.
- The page tells readers to create their main integration before adding PayCo, with Android Drop-in and Components links for both Sessions and Advanced flows. The child guides carry their own requirements and code.
