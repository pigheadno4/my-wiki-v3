## Overview

This [[adyen]] DOKU for Web page is a **navigation chooser** for Indonesian bank-transfer and convenience-store payments on a merchant website. It links the DOKU **Drop-in** and **Components** child guides and older general Web Drop-in/Components references. See [[adyen-online-payments]]. Last modified in **2019** and captured 2026-09-15, it does not establish current variant availability, merchant eligibility, SDK/API version, account/voucher expiry, final payment status or a successful transaction. See raw lines 15–29.

## Routes and boundaries

- **Drop-in** is described as an all-in-one UI solution for rendering DOKU bank-transfer and convenience-store options. **Components** is described as a pre-built Component for those options. These are route descriptions, not a claim that all specific DOKU banks/stores are enabled, or that the shopper has paid. See raw lines 19–27.
- The page also points to general Web Drop-in and Components references; it does not select a server-side Sessions or Advanced flow or give flow-specific prerequisites. Use the selected child guide for method variants, local-entity restrictions and request/outcome handling. See raw line 29.
