## Overview

This 2026-09-15 page is the iOS integration chooser for Multibanco. It points to method-specific iOS Drop-in and Components guides and to four main iOS integration guides. It does not itself describe payment request fields, voucher handling, or payment outcomes. See [[adyen]] and [[adyen-online-payments]].

## Key takeaways

- The **Drop-in** route is `/payment-methods/multibanco/ios-drop-in`, described as an all-in-one UI solution for the iOS app. See raw lines 19–23.
- The **Components** route is `/payment-methods/multibanco/ios-component`, described here as using `InstantPaymentComponent`; the captured child guide is [[source-adyen-docs-payment-methods-multibanco-ios-component]]. See raw lines 25–27.
- The page directs readers to build the main integration before adding Multibanco, linking iOS Drop-in and Components base guides for both Sessions and Advanced flows. These are navigation choices; flow prerequisites and behavior belong to the respective child and base guides. See raw lines 29–36.
