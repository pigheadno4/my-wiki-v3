## Overview

Adyen's 2026-09-15 BLIK for Android page is an integration chooser for adding BLIK to an Android app. It links an all-in-one Drop-in child guide and a child guide described as using a Redirect Component, then offers general Android Drop-in and Components **Sessions** guides. See [[adyen]] and [[adyen-android-sdk]].

## Key takeaways

- The Drop-in route is described as an all-in-one UI solution; the Components route says to use a Redirect Component on Android (raw lines 19-31). Those link labels route to implementation guides; they do not supply the redirect steps.
- The two general integration links on this chooser are both Sessions-flow routes (raw line 33). This page does not state an Advanced route, request fields, SDK minimum, BLIK-code procedure, Customer Area setup, testing, webhook outcome or current merchant eligibility. Those details require the applicable child and base guides (raw lines 15-33).
