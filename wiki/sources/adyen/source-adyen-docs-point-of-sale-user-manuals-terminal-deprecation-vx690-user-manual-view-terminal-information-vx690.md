## Overview

This [[adyen]] **VX690** device-information page was last modified 2019-04-19 and captured 2026-09-15 under the terminal-deprecation manual tree. It describes opening **Quick Info** to view terminal and network identifiers. Displaying those fields is not evidence of a live connection, valid account configuration, successful boarding, current transaction support or payment execution. The separate [[source-adyen-docs-point-of-sale-user-manuals-terminal-deprecation]] lists VX690 with a historical **29 March 2024** "No more transactions" date. See [[adyen-payment-terminals]].

## Key takeaways

- The historical shortcut says to press an **illustrated key and 5 at the same time**. The key appears only as an image in the raw and has no textual name there; the line also contains HTML character entities. Do not infer a key label or PIN requirement from this page. See raw lines 19–23.
- The display is said to show the **IP address**, **terminal ID** and **software version**. It also shows a QR code encoding the IP address, MAC address, network name, store name, merchant account name and terminal ID. The page lists displayed or encoded information, not a diagnostic test or proof that any of those values is current, reachable or authorized. See raw lines 25–30.
