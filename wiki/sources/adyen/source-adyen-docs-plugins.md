## Overview

This 2026-09-15 snapshot of Adyen's Plugins directory describes pre-built integrations that connect existing commerce systems to the Adyen payments platform. It separates plugins built and maintained by Adyen from integrations built with partners. [[adyen]] [[adyen-partners]]

## Key takeaways

- Adyen describes plugin functionality as delivered out of the box for leading commerce platforms, while directing readers to each plugin's own documentation for supported features. The directory itself does not establish the capabilities, eligibility, configuration, or live status of any particular integration.
- The page says its range includes online and in-person payment plugins. It says some plugins can be customized to extend functionality when a specific Adyen feature is unsupported; this is conditional, not a promise that every plugin can be extended.
- The Adyen-built section lists Adobe Commerce, Salesforce Commerce Cloud B2C Commerce, Salesforce Order Management System, Oracle NetSuite, Oracle Opera, Oracle Simphony, Oracle Xstore, and Cegid Retail Y2 CPOS. The partner section links other systems and external documentation. These entries are navigation, not evidence of current support or a completed payment.
