## Overview

This 2026-09-15 [[adyen]] Docs navigation page helps a merchant select the Adyen Giving online-donation guide that matches its online payment server-side flow: Sessions or Advanced. It identifies supported interface categories for each route, while the linked guides own requirements, request sequence, donation outcomes, and version details. [[adyen-giving]]

## Key takeaways

- The page tells readers to choose the server-side flow their online-payments integration uses. Its Sessions route links to donations on a website using Drop-in or Components.
- Its Advanced route links to online donations using Drop-in, Components, or API-only integration. This is a guide-selection label; the linked Advanced guide should be checked for exact route and version applicability.
- This chooser does not describe how donation funds move, name a merchant or nonprofit as seller or merchant of record, or establish that a donation succeeded. For those claims, consult the separately sourced Giving overview and selected integration guide.
