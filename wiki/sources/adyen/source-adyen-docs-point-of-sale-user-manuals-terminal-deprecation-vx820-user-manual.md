## Overview

This [[adyen]] **VX820** payment-terminal manual hub was last modified 2021-03-25 and captured 2026-09-15 under the terminal-deprecation tree. It describes a **VX820 with an already connected PED dongle**, power and Ethernet setup, then links to security inspection and boarding. This is the **VX820 manual**, separate from the [[source-adyen-docs-point-of-sale-user-manuals-terminal-deprecation-vx820-duet-user-manual|VX820 Duet printer-base manual]]. The VX820 page says new terminals of this type cannot be ordered; its generic "new terminal" quickstart wording does not override that notice. The separate [[source-adyen-docs-point-of-sale-user-manuals-terminal-deprecation]] table lists **VX820 and VX820 Duet** in the same row with **29 March 2024** as "No more transactions". These dated instructions do not establish current device support, boarding or payment processing. See [[adyen-payment-terminals]].

## Key takeaways

- The quickstart says to connect the power supply to the dongle already attached to the VX820 PED, connect an Ethernet cable to the **ETH port on the power cable**, then follow separate device-security-inspection and boarding guides. This is a list of setup topics, not proof any step succeeded. See raw lines 23–30.
- **A wrong cable in a wrong port can severely damage the device**; the page gives an Ethernet cable in the RS232 port as an example. This is a material physical warning for the historical setup, not an instruction to try other port combinations. See raw line 32.
- The provided components listed on this **VX820** page are the payment terminal, power supply, privacy shield and Ethernet dongle. Do not substitute the Duet page's base/printer or paper-roll sequence for this model-specific hub. See raw lines 34–39 and the separate Duet source.
