## Overview

This [[adyen]] KakaoPay for iOS page is a **navigation chooser**. It links iOS Drop-in and Components child guides and points to the corresponding main iOS Sessions/Advanced integration guides. See [[adyen-online-payments]]. It supplies no KakaoPay-specific request fields, Checkout/iOS SDK minimum, payment action, merchant enablement, token/recurring setup, testing procedure or outcome contract. Those claims require the selected child and main flow guides. See raw lines 15–36.

## Routes and boundaries

- **Drop-in** links to the all-in-one UI KakaoPay iOS child guide. **Components** links to a child guide described as using `InstantPaymentComponent` in an iOS app. These are route descriptions only; the page does not say the Component has been initialized or a payment made. See raw lines 19–27.
- The “See also” section says to build the **main integration before adding KakaoPay**, then lists four iOS base routes: Drop-in with Sessions, Components with Sessions, Drop-in with Advanced, and Components with Advanced. This is a prerequisite ordering and navigation list, not proof that every KakaoPay child path supports every base flow or that its requirements are satisfied. See raw lines 29–36.
- The captured 2026-09-15 page does not establish current KakaoPay availability, eligible merchant geography/currency, approval, authorization, capture, settlement or refund. See raw lines 15–36.
