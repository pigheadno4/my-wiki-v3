## Overview

This 2026-09-15-captured Adyen page is an iOS integration **router** for Boleto Bancário. It links iOS Drop-in and Components method guides and Sessions/Advanced base guides for both UI choices. It does not itself define CPF/CNPJ fields, voucher response, expiry, or payment status. See [[adyen]], [[adyen-online-payments]], and [[source-adyen-docs-payment-methods-boleto-bancario]] for the method overview.

## Key takeaways

- The Drop-in route is described as the all-in-one iOS UI. The Components route names `BoletoComponent`. Follow [[source-adyen-docs-payment-methods-boleto-bancario-ios-drop-in]] or [[source-adyen-docs-payment-methods-boleto-bancario-ios-component]] for the respective method-specific instructions. See raw lines 19–27.
- Build the main iOS integration before adding Boleto Bancário. The page links Sessions and Advanced main guides for both Drop-in and Components. These links are navigation, not evidence that voucher issuance means payment or that child-guide requirements are identical. See raw lines 29–36.
