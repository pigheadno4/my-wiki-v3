## Overview

This 2026-09-15-captured Atome for iOS page is an integration **chooser**. It routes developers to iOS Drop-in or AtomeComponent guidance and to the corresponding main Sessions or Advanced integration guides. It does not itself specify payment request fields, country/currency eligibility, redirect handling, or payment outcomes. See [[adyen]] and [[adyen-online-payments]].

## Key takeaways

- Choose the Atome iOS Drop-in child guide for the all-in-one UI route, or the iOS Components child guide for the AtomeComponent route (raw lines 19–27).
- The page says to create the main integration before adding Atome and lists iOS Drop-in and Components base guides for both Sessions and Advanced flows (raw lines 29–36). The links identify possible guide routes; they do not establish that every child guide implements every flow or that a merchant is enabled.
- Read the linked child guide and main integration guide for actual setup and behavior. This chooser alone does not prove a successful test or live Atome payment.
