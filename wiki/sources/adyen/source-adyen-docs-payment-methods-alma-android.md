## Overview

This 2026-09-15 [[adyen|Adyen]] page is an Android integration chooser for Alma. It links to Android Drop-in and Components method guides and to main Sessions/Advanced integration guides. See [[adyen-online-payments]] and [[source-adyen-docs-payment-methods-alma|the Alma overview]] for captured method scope. This chooser does not define request fields, SDK/API versions, return handling, account eligibility or payment outcomes.

## Key takeaways

- The Android Drop-in route is described as an all-in-one UI solution. The Components route names `InstantPaymentComponent` for handling the redirect to Alma. Follow the child guides for their implementation details; this page does not show a completed redirect.
- The See also section directs readers to create the main integration before adding Alma. It links Android Drop-in and Components base guides for both Sessions and Advanced flows. These links are navigation, not evidence of configured merchant account or successful payment.
