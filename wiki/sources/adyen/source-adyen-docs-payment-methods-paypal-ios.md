## Overview

This [[adyen]] **PayPal for iOS** page is an integration chooser. It routes readers to PayPal **iOS Drop-in** or the **iOS Redirect Component**, and separately to general iOS Drop-in and Components integration material. Its link descriptions do not establish child-guide versions, prerequisites, live PayPal eligibility, consent, tokenization, or payment outcomes. [[adyen-online-payments]]

## Key takeaways

- **Drop-in:** The page links `/payment-methods/paypal/ios-drop-in` and describes it as an all-in-one UI solution to add PayPal to an iOS app. See raw lines 21–25.
- **Components:** It links `/payment-methods/paypal/ios-component` and calls it a Redirect Component for an iOS app. See raw lines 27–31.
- **Background routes:** Its final sentence links general iOS Drop-in and Components Sessions-flow pages. These are navigation links, not a statement that both PayPal child routes use the same flow. See raw line 33.
