## Overview

This 2026-09-15 Adyen page is a **Rakuten Pay iOS integration chooser**. It links method-specific Drop-in and Components child guides and the corresponding iOS Sessions/Advanced main integration guides. It does not itself define version requirements, merchant approval, redirects or final payment outcomes. [[adyen]] [[adyen-online-payments]]

## Key takeaways

- **Method choices:** The Drop-in child route is described as an all-in-one UI option. The Components route names `InstantPaymentComponent` for Rakuten Pay in an iOS app. These are route descriptions; setup details and any feature or recurring-model conditions must be read from the linked child guides. (raw lines 19–27)
- **Base routes:** The page tells readers to create the main integration first and lists iOS Drop-in and Components base guides for both Sessions and Advanced flows. The presence of both flow links is navigation, not proof that a particular merchant's setup, API/SDK version or transaction result has been validated. (raw lines 29–36)
