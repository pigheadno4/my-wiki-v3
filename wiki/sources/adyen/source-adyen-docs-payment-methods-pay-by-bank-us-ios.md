## Overview

This 2026-09-15 Adyen page is an **iOS integration chooser** for Pay by Bank (US). It links to the iOS Drop-in and Redirect Component child guides and to the corresponding Sessions main integration guides. It does not define API fields, iOS SDK requirements, Plaid registration, ACH capture timing, refunds, tokenization or final outcomes; the child and method-overview pages own those details. This route page does not prove current merchant or bank eligibility or an executed payment. See [[adyen]] and [[adyen-online-payments]].

## Key takeaways

- Drop-in is described as the all-in-one UI route for adding Pay by Bank (US) to an iOS app. Its child page, rather than this chooser, defines the actual Drop-in prerequisites and lifecycle. (raw lines 19–23)
- Components is described as the Redirect Component route for iOS. Its child page owns the Component/version and outcome requirements; the chooser does not identify a specific class or version. (raw lines 25–27)
- The final line links iOS Drop-in and Components **Sessions-flow** main guides. Those links are navigation, not a claim that only Sessions exists or that either integration is enabled for a given merchant. (raw line 29)
