## Overview

This Adyen point-of-sale documentation hub introduces alternatives to traditional card payments in an in-person terminal context. Its main routes are gift card payments, one-time numeric code payments, and QR code wallet payments; it also links to Brazil meal or food vouchers. The 2026-09-15 snapshot is a navigation overview, not a current payment-method availability, merchant eligibility, integration-detail, or successful-payment claim. [[adyen]] [[adyen-pos-alternative-payment-methods]]

## Key takeaways

- Gift cards are described as prepaid cards with stored monetary value. Whether a card can be loaded, cashed out, or disabled depends on its provider; the hub does not supply provider-specific rules. See pinned raw lines 23–24.
- For the one-time numeric code route, the shopper generates a unique single-use code with a bank or payment app and enters it on the payment terminal to authorize a transaction. See pinned raw lines 26–27.
- For the QR wallet route, the shopper uses a phone wallet app for an in-person payment, with the terminal and app communicating through a QR code. The overview says the app is linked to a credit or debit card (bank account); it does not specify the individual wallet or funding rules. See pinned raw lines 29–31.
- Brazil meal or food vouchers appear as a separate linked implementation route. This hub supplies no voucher transaction or eligibility detail. See pinned raw lines 33–37.
