This page, last modified in 2019 and captured on 2026-09-15, is a Web integration chooser for GrabPay. - **Method-guide routes:** the page describes Drop-in as an all-in-one UI option and Components as a pre-built Component option for adding GrabPay to a website. These are navigation labels, not evidence that the two routes share request fields, versions, eligibility or shopper behavior. (raw lines 19–27)

This chooser has no Sessions/Advanced, country/currency, Wallet/PayLater, environment, live-enablement, return, webhook or authorization/capture/settlement procedure; those details require the relevant child and base guide.
