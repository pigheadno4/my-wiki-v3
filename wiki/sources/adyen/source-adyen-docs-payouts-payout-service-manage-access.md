## Overview

This 2026-09-15-captured [[adyen]] Payout Service access overview describes Customer Area administration of account and balance-platform resources, users, API credentials, webhooks and reports. It says signup automatically creates a human admin user assigned **Merchant Admin** and **Balance platform admin** roles. This navigation page does not establish a particular account's live role assignments, API credential permissions, authenticated request or completed payout. See [[adyen-payouts]] (raw lines 15–21).

## Key takeaways

- The Customer Area list spans company and merchant account resources, payment methods, transfer API credentials, payout-status webhooks, reconciliation and other reports, account holders, legal entities, balance accounts, transfer instruments, transaction rules and organization users (raw lines 21–31).
- Its **Merchant Admin** and **Balance platform admin** roles describe the created Customer Area admin user. The linked API-credentials guide governs separate web service credentials for API requests; this page does not say the human roles themselves authorize Transfers API calls (raw lines 19, 25, 31, 43–45).
- The next-step links route to managing organization users, Customer Area user roles, and API credential generation/configuration. Their detailed authorization and secret lifecycle belong to those linked guides, not this overview (raw lines 33–45).
