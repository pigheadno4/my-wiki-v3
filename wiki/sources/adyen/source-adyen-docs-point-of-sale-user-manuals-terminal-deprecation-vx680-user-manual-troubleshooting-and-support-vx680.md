## Overview

This [[adyen]] **VX680** troubleshooting page was last modified 2019-04-18 and captured 2026-09-15 under the terminal-deprecation manual tree. It routes a terminal issue first to linked **POS troubleshooting documentation**, then to an email to the linked **Support Team** if the issue cannot be resolved there. It gives information for that escalation, not a diagnosis, fix, repair commitment or evidence of current support. The separate [[source-adyen-docs-point-of-sale-user-manuals-terminal-deprecation]] lists VX680 with a historical **29 March 2024** "No more transactions" date. See [[adyen-payment-terminals]].

## Key takeaways

- For a payment-terminal issue, the page says to try the linked troubleshooting documentation first. It says this is often the quickest solution, not that it will resolve every problem. See raw lines 16–18.
- **If the issue cannot be resolved using that documentation**, it says to email the linked Support Team. The page supplies a support-form link but no standalone email address in the raw. It does not record a sent message, response or successful repair. See raw lines 20–22.
- The escalation should include the **merchant account** and **terminal serial number**, plus the **transaction PSP reference if applicable**. The serial is available in Device info and printed on the terminal back; the printed `S/N:123-456-789` is explicitly an example, not a real device identity. See raw lines 24–28.
