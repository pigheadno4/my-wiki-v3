## Overview

This 2026-09-15 [[adyen]] for Platforms additional-products page tells a platform to choose a **brand-specific Industry Code (IC)** that best matches the user's brand and business activity when certain brands have distinct Merchant Category Codes (MCCs). It is a classification and approval-contact reference, not evidence that a user is eligible for a business account, approved for an industry, enabled for a capability, assigned an MCC, or processing payments. [[adyen-platforms]]

## Key takeaways

- Adyen says it assigned brand-specific ICs to capture unique MCCs for certain brands. The user's brand **and** business activity guide selection. This page does not say every brand needs a distinct code or that choosing a code itself changes the user's payment permissions.
- Contact an Adyen contact or Support if approval is needed for an industry code **before onboarding users**, or if the platform wants to offer business accounts to users in **new industries** outside its previous approval process. These are conditional escalation triggers; the page does not grant approval or specify a turnaround, country eligibility, business-account activation, or an onboarding outcome.
- The snapshot states that Adyen accepts only certain brand-specific IC values, but the pinned raw ends without the promised list or table. No actual code values, brand-to-code mapping or acceptance matrix can be extracted from this page. Its **See also** link points to the general industry-codes list; a code decision requires that source or Adyen confirmation, not an invented value.
