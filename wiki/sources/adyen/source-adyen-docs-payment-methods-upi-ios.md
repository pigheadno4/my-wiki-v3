## Overview

This 2026-09-15 **UPI for iOS** page is a navigation chooser for adding UPI to an iOS app. It links the iOS Drop-in and UPIComponent child guides and four main iOS integration guides. It does not itself specify Checkout API or iOS SDK versions, payment fields, configuration, app eligibility, redirect behavior, test conditions, or a payment-result procedure. [[adyen]] [[adyen-online-payments]]

## Key takeaways

- The chooser labels **Drop-in** as Adyen's all-in-one UI option and **Components** as the `UPIComponent` option for UPI payments in an iOS app. These labels route to child pages; they are not proof either path is enabled or has executed. (raw lines 19–27)
- The See also section says to follow an applicable **main integration** guide and links iOS Drop-in and iOS Components for each of **Sessions** and **Advanced** flows. The chooser itself does not choose a flow or state child-guide prerequisites; follow the selected base and method guide for implementation details. (raw lines 29–36)
