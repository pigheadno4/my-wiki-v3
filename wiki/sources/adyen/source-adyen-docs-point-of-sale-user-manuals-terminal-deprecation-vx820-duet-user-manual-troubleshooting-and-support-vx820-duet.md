## Overview

This [[adyen]] **VX820 Duet** manual page, last modified **2019-04-19** and captured 2026-09-15 under terminal deprecation, is a **support-routing guide** for a terminal issue. It directs merchants first to the separate POS troubleshooting documentation, then to email Adyen Support if the issue remains unresolved. The page contains no diagnosis, repair step or observed recovery. It belongs to [[adyen-payment-terminals]]. The separate [[source-adyen-docs-point-of-sale-user-manuals-terminal-deprecation|eVo deprecation schedule]] lists VX820 Duet **“No more transactions” on 29 March 2024** (its raw line 34), so this old route is not proof of current support availability or transaction processing.

## Key takeaways

- For a terminal problem, try the linked **Troubleshooting documentation** first; the page frames it as often the quickest route, not a guaranteed fix (raw line 18).
- If that does not resolve the issue, the guide says to **email its linked Support Team** (raw line 22). A link to a historical contact endpoint does not confirm present channel availability or a response.
- The support message should include the **merchant account**, the transaction's **PSP reference if applicable**, and the terminal **serial number**. The serial can be found in Device info or on the back of the terminal; the S/N shown is explicitly an example (raw lines 24–28). A PSP reference is conditional, so a non-transaction device issue does not imply one exists.
- The page does not state that self-service or Support repaired the device, restored connectivity, reboarded it or processed any payment.
