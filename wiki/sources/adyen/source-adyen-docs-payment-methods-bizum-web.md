## Overview

This 2026-09-15 Adyen Web page is a chooser for adding Bizum to a website. It routes to Drop-in and a Components child described as using Redirect, then lists main Web Sessions and Advanced integration guides for both UI choices. It provides navigation, not method-specific request, eligibility, version, redirect execution, payment outcome or live setup rules; use the child and main guides for those details. See [[adyen]] and [[adyen-online-payments]].

## Key takeaways

- Choose the Web Drop-in child for Adyen's all-in-one UI or the Web Components child described as using Redirect. The page does not establish interchangeable behavior between the two routes.
- It directs readers to create the main integration first and lists four base routes: Web Drop-in Sessions, Web Components Sessions, Web Drop-in Advanced and Web Components Advanced. The chooser does not itself verify merchant enablement or a successful payment.
