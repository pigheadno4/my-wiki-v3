## Overview

This 2026-09-15 Adyen Docs snapshot is a navigation page for inactive Classic Ecommerce integrations. It says this endpoint is no longer supported for new integrations. It directs new integrations to online payments with Checkout API and existing integrations to contact Adyen and migrate to Checkout API. See [[adyen]] and [[adyen-online-payments]].

## Key takeaways

- The page lists separate Classic API integration and payment-modification guides. The latter covers capture, cancellation, refunds, and changing the payment amount; this navigation page supplies no operation instructions or outcome guarantees.
- Its Checkout API recommendation is a migration and new-build route, not a claim that Classic API behavior is equivalent to modern Checkout API behavior.
