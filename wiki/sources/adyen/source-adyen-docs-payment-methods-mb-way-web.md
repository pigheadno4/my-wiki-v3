## Overview

This 2026-09-15-captured MB WAY Web page is an **integration chooser**. It links MB WAY Drop-in and Components child guides, plus the main Web Sessions and Advanced integrations. It does not specify request fields, action handling, payment outcome, account enablement, or successful live processing. See [[adyen]], [[adyen-online-payments]], and [[source-adyen-docs-payment-methods-mb-way]] for method-level context.

## Key takeaways

- **Drop-in** links the MB WAY Web Drop-in child guide and is described as the all-in-one website UI solution (raw lines 19–23).
- **Components** links the MB WAY Web Component child guide; the chooser's wording names `MBWay` for website payments but gives no initialization or configuration procedure (raw lines 25–27).
- The “See also” section says to build the main integration before adding MB WAY. It links **Web Drop-in** and **Web Components** for both **Sessions** and **Advanced** server-side flows. These are routes to implementation guidance, not proof of a configured or completed payment (raw lines 29–36).
