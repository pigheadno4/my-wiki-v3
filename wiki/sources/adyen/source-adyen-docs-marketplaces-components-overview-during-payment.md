## Overview

This short 2026-09-15 Marketplace-path navigation page points to **Checkout components** as its during-payment UI route. It says Checkout adds a checkout page to a platform interface and links to the dedicated guide for accepting ecommerce payments, collecting details and showing transaction results. The page is orientation rather than an integration contract or evidence of a successful transaction. [[adyen]] [[adyen-platform-components]]

## Key takeaways

- The page links a filtered payment-method catalog and says Checkout supports various methods to suit a market. It does **not** establish that any specific method is configured or available for a particular platform, country, user or transaction. See raw lines 17-21.
- The `Checkout` link leads to the separate Marketplace Checkout components guide. This navigation page does not provide request fields, server/client split, session or credential prerequisites, webhook handling, result finality, split booking, settlement or payout rules; use the child guide and transaction evidence for those questions. See raw lines 19-25.
