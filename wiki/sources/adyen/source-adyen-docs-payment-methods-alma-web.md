## Overview

It gives navigation rather than Alma request or payment-lifecycle instructions. - The page links Alma **Web Drop-in** as the all-in-one UI option and **Web Components** as the separate route described with “Redirect” wording (raw lines 19–27). This chooser itself gives no Component setup, request-field list, SDK/API version or final payment result.
