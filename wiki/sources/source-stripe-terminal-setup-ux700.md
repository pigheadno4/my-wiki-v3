## Stripe Terminal: Set Up Verifone UX700

Setup guide for the Verifone UX700 — mains-powered Android sPOS with built-in Ethernet, in preview.

## Key Takeaways

### Availability

Public preview US/CA; private preview GB/IE only (not SG — UX700 is excluded from Singapore private preview). Contact Sales to order.

### Integration support

All 5 integrations (JS, iOS, Android, React Native, server-driven). Server-driven recommended.

### Power

- 4-pin cable into 6-pin port on back of reader
- No battery — always mains-powered; Verifone adapter required (third-party may invalidate warranty)
- No screen timeout section (battery conservation not applicable)

### Settings access

Swipe right from left edge → **Settings** → admin PIN `07139` (same as all other smart Terminal readers).

### Ethernet

Built-in 10/100 Ethernet port (no optional accessory needed — unlike V660p's Full Feature Base). Network priority: Ethernet → WiFi. DHCP.

### Default UI theme

Light. Configurable via Appearance settings.

### Language

Configurable in settings; may require device restart.
