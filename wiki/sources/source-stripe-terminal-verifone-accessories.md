## Stripe Terminal: Verifone Accessories

Accessory summary for all four Stripe-supported Verifone readers.

## Key Takeaways

### Accessory summary by model

| Reader | In box | Optional accessory |
| --- | --- | --- |
| V660p | Power adapter + USB-C cable | **Full Feature Base** (optional, request separately) — adds Ethernet + charging |
| UX700 | Power adapter | None — built-in Ethernet port |
| P630 | Power adapter + **D0 Orange Dongle** (2M cable) — Ethernet only | None — dongle included |
| M425 | Power adapter + **D0 Orange Dongle** (1M cable) — Ethernet only | None — dongle included |

### Critical clarifications

- **P630 and M425**: D0 Orange Dongle is **included in the box** when ordering — it is not a separate purchase
- **V660p Full Feature Base**: optional accessory, must be requested separately — not included in box
- **UX700**: no dongle or accessory needed for Ethernet — it has a built-in port
- **D0 Orange Dongle supports Ethernet only** — it cannot be used for other purposes
- P630 uses **2M** orange cable; M425 uses **1M** orange cable
