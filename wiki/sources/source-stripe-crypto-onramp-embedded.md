## Summary

Overview page for the embedded onramp integration. Covers features specific to the embedded mode including payment methods, instant delivery, Link integration, and webhook behavior.

## Key Features

- **Payment methods**: Credit, debit, Apple Pay, ACH (US only) — all eligible for **instant crypto delivery** after KYC completion
- **Webhooks**: every session status change generates a webhook
- **Link**: returning users check out faster via Stripe Link consumer account
- **Brand customization**: embeddable widget with real-time quotes, automated KYC, multi-chain support
- **No platform fraud liability**: Stripe handles all disputes
- Same currencies and geo restrictions as Stripe-hosted mode
