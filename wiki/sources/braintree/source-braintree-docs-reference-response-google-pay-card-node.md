## Overview

This collected Braintree Node.js-routed response-reference page is an availability and compatibility stub for Google Pay Card. It directs readers to the legacy-named Android Pay Card reference and states that Braintree represents Google Pay cards as Android Pay cards in its API to prevent breaking changes, except in version 3.0.1 and later of the Ruby SDK.

## Key takeaways

- The page's only substantive guidance is the redirect to `AndroidPayCard` and the compatibility-naming statement.
- The Ruby SDK 3.0.1-and-later exception is material: the broad Android Pay representation statement must not be presented as universal across all SDK versions and languages.
- Although selected through a Node.js route, this unversioned website snapshot does not identify an exact Node package or version. It is response-reference navigation, not a request contract or evidence of transaction, authorization, capture, settlement, funding, or other payment outcome.
