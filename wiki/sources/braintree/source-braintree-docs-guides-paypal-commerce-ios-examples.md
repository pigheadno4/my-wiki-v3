## Overview

This Braintree-hosted snapshot is an examples page for the historical PayPal Commerce iOS SDK. It illustrates a store purchase sequence with linked images and routes readers to three GitHub example-project directories intended to show standalone, modal, and tab-bar store-interface placements. It is distinct from the modern modular [[braintree-ios-sdk]] and from ordinary Braintree checkout or Drop-in integration.

The page was fetched on 2026-09-16 and carries source frontmatter timestamps from 2025-04-02, but identifies no SDK release or execution environment. Its links point to the `master` branch of the separate `braintree/paypal-commerce-ios` repository; because that repository was not read for this source, the snapshot does not establish current repository contents, buildability, current SDK support, runtime behavior, or successful payment execution.

## Key takeaways

- Under `Store purchase flow`, the page links five images labelled Products, Product Detail, Product Features, Purchase Confirmation, and Receipt. These linked images illustrate a sequence; they do not by themselves prove that a purchase ran or completed.
- The page says three example projects illustrate how the PayPal Commerce SDK can fit into an app. `Shop` is described as a standalone store, `ModalShop` as presenting the store interface modally, and `TabBarShop` as presenting it in a tab bar controlled by the parent app.
- These are examples and presentation descriptions, not guarantees, requirements, or evidence of current product availability, account eligibility, exact-version compatibility, repository state, or completed payments.
