## Overview

This captured [[braintree|Braintree]] website page is a short documentation-preview route for the Braintree Functions CLI. It says the CLI is intended to generate, test and deploy a Function, and it shows a global npm installation command followed by a `btfns login` example. The same snapshot explicitly says that, during the preview phase, the CLI was available only by request and was not yet on npm. The page does not identify an exact CLI package version, Node.js/runtime version, client/server SDK placement or deployment environment, and the examples do not establish current availability, account eligibility, successful installation, authentication or deployment. As website documentation, it is also distinct from GitHub implementation or release-history evidence.

## Key takeaways

- The stated central purpose of the CLI is to generate, test and deploy a Function.
- Preview access was request-only in this snapshot; the page provides `functions-requests@braintreepayments.com` as an inquiry route and says the CLI was not yet on npm.
- The page nevertheless preserves a historical global-install example, `npm install -g @braintree/functions-cli`, followed by `btfns login` to log in to a Braintree account on the user's system. Treat these as documentation examples, not proof that the package is currently published or supported, that a particular version is installed, or that login succeeded.
