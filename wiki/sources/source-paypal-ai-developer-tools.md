## Summary

Overview of PayPal's AI developer tooling — three distinct paths for building AI-powered commerce solutions: custom agent toolkit, LLM platform integration (with MCP server), and agentic commerce (Store Sync + Agent Ready).

## Key Takeaways

- **3 paths**: agent toolkit (custom), LLM integration (ChatGPT/Claude/others), agentic commerce (shopping surfaces)
- **Agent capabilities**: payment processing, subscriptions, disputes, invoicing, customer support
- **MCP server**: quickstart available for LLM integrations (Model Context Protocol)
- **All agents**: operate within PayPal's PCI-compliant environment

## Three AI Integration Paths

| Path | Product | Use case |
| --- | --- | --- |
| Custom AI assistant | Agent toolkit | Build agents for payment workflows on your own website/app |
| LLM platform integration | LLM integration + MCP server | Enable ChatGPT, Claude, others to interact with PayPal services |
| AI-powered shopping | Agentic commerce (Store Sync + Agent Ready) | Make products discoverable through AI shopping surfaces |
